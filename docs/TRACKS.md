# 三条执行路线：技术分档与代码入口

> 读者：要决定画面在哪里执行的人｜状态：技术分档说明｜依据：2026-11-06

本页把「画面在哪里执行」讲清楚。工程分工与任务状态仍以 [工作分解](routes/work-breakdown.md) 的 T 编号为准；[ROUTES.md](../ROUTES.md) 的「北冥风格路线 / 北冥原生路线」是创作组织方式，本页是**执行后端**的技术分档。两者不冲突：同一部作品先选创作路线，再选执行路线。

## A · 北冥风格路线 · WebGL 三渲二

| 项 | 内容 |
|---|---|
| 执行面 | 无头 Chrome + WebGL（ANGLE，可切 Vulkan）+ Canvas 2D；FFmpeg 编码 |
| 画面语言 | 三色分档卡通着色、屏幕空间 ID 墨线、Kuwahara 笔触、手绘底板视差、Canvas 2D 人物、显示层独立合成 |
| 代码入口 | `engine/`（九层）、`src/`（《北冥》样片）、`lab/`（模块自测） |
| 入口约定 | 页面暴露 `window.DUR / window.render(t) / window.READY`；确定性、无 `Date.now`、无无种子随机 |
| 已实现 | `npm run build` / `stills` / `video` / `video:4k`；1080p 与原生 4K 实测已记录 |
| 验收 | 帧数、尺寸、音轨、完整解码；视觉与动作人工验收；4K 成绩只属于 WebGL 路线 |
| 未完成 | FrameState 适配器、风格规范化版本、完整人物表演（T03–T08） |

选择这套路线时，画风由造型、着色与后期三处代码共同决定；换画风换的是参数与着色器，不是换素材。

## B · 北冥原生路线 · BNE（RTX 原生工具链）

| 项 | 内容 |
|---|---|
| 执行面 | 原生运行时；Rust + Bevy，原生 GPU；编码器按实际记录 |
| 资产桥 | 程序化鲲 → GLB（几何/顶点色/骨骼动画）→ 原生场景 |
| 代码入口 | `examples/raea/`（TSX 场景、资产桥、声音与运行包装）、`docs/raea/`（源码对照与集成） |
| 命令 | `npm run raea:prepare` / `raea:check` / `raea:render` |
| 已实现 | 独立 10 秒实验；资产转换与回读验证；运行时版本与源码快照记录 |
| 验收 | 实际设备、图形后端、编码路径分别记录；不能用 WebGL 的 Vulkan 记录代替原生 GPU 证据 |
| 未完成 | 通用双后端状态、原版墨线/Kuwahara 等价、人物表演（T08、T09–T13） |
| 许可 | 原生运行时不在本仓库分发，其技术底座、固定版本与许可义务见 [THIRD-PARTY](../THIRD-PARTY.md)；工程内目录与 npm 命令沿用历史代号 `raea`，便于追溯，不代表对外品牌名 |

## C · 北冥代码动画风格 · 86 式

| 项 | 内容 |
|---|---|
| 执行面 | Canvas 2D、SVG、DOM/CSS、WebGL 各自实现；不是统一着色器 |
| 代码入口 | `cases/vendor/` 风格库快照（86 式方法与示例）、`cases/source/`（66 部成片源码） |
| 方法库 | 笔触、材质、排版、信息图、剪辑节奏与声画编排的参考实现 |
| 状态 | 风格库为固定快照，逐文件 SHA256 校验；本机 66 部成片均有历史成片与可还原源码 |
| 验收 | 观看历史成片与还原后的源码；风格名与实现要对得上，不能只改标签 |
| 边界 | 风格库含第三方开源实现，保留原作者版权与许可；**不删除、不改写、不冒充原创**，明细见 [THIRD-PARTY](../THIRD-PARTY.md) |

C 不是第三套渲染后端。它是「已有 86 种代码画法」的资料层：新片可以从这里取构图、笔触与声音方法，落回 A 或 B 执行。

## 路线怎么选

| 需求 | 先走 | 原因 |
|---|---|---|
| 延续《北冥》画风、做品牌片/概念片 | A | 风格参数与样片基准都在 `src/`，可逐帧对照 |
| 明确要原生 GPU、要更高分辨率/更重的着色器 | B | 执行面不在浏览器，性能证据独立 |
| 想探索新画风、找成熟实现 | C 取方法 → A 落地 | 风格库给方法与参数，A 给确定性出片与统一验收 |
| 同一镜头要两个后端对比 | A + B | 先做 FrameState 最小适配，两侧分别验收 |

## 硬规矩

1. **证据分路线**：A 的 Vulkan/WebGL 数据、B 的原生设备与编码器、C 的历史成片，三者不互相引用为对方成绩。
2. **状态三分离**：已输出、技术检查通过、人工认可，是三件事；归档里的「历史成片」不等于全部被认可，未获认可的版本不进入作品站。
3. **许可不可移除**：风格库与 [cases/licenses](../cases/licenses) 的许可证、署名必须保留；原生运行时按其自身许可单独处理。详见 [THIRD-PARTY](../THIRD-PARTY.md)。
4. **新作品独立目录**：默认保留原版 `src/` 与基准帧；实验在 `lab/` 或新工程目录，不覆盖历史快照。
5. **整数帧驱动**：全局帧、镜头局部帧、动作相位分开；有状态模拟先验证顺序/跳帧，再谈并行。

## 2. 独立重渲第 177 帧

复核脚本：`d05-recheck.mjs`，放在 P08 的暂存目录，不入库。步骤：

1. 用金标准工具的页面导出（`tools/baseline/lib/git.mjs` 的 `exportPaths`）把 `ed11b83` 的页面导到临时目录；

4. 成片第 177 帧按 `yuvj420p / bt470bg / pc` 显式解码成 RGB；
5. 用 `tools/baseline/lib/metrics.mjs` 计算 PSNR 和 SSIM。

| 与成片第 177 帧比 | 整幅 PSNR / SSIM | 鲲背区域（右上 960×360）PSNR / SSIM |
|---|---|---|
| v1.0 + 噪声初稿 | **31.73 dB / 0.833** | **30.54 dB / 0.835** |

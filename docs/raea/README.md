# 北冥原生路线：运行时源码与集成

> 读者：想了解北冥原生路线现状的人｜状态：目录页｜依据：版本基线见下表

北冥保留已有的美术与制作体系，RAEA 作为可选的原生运行路径进行实验。本目录提供固定版本的源码证据、可运行示例和分阶段实施方案。

仓库对 agent 提供两条完整创作路线：[北冥风格路线与北冥原生路线](../../ROUTES.md)。前者吸收 RAEA 运行时的能力继续发展自身美术体系，后者直接使用 RAEA，不受北冥既有材质或后期模板约束。

**当前状态：源码研究和资产桥接示例已入库；通用双后端、角色表演系统、原版画风等价迁移仍是待实现项目。** 原有 `npm run build` 与 Three.js 主线不依赖 RAEA。

源码快照和发行包分别固定；本文不声称该 canary 二进制恰好由引用的 HEAD 构建。升级任一侧都需要重跑资产、颜色、动作与输出验证。

## 集成原则

1. **共享创作输入。** 镜头、动作、资产、色板与视觉要求逐步独立于执行后端。
2. **分别实现渲染。** Three 的 GLSL、RAEA 的 WESL、颜色管理和描边阶段分别校准；同名参数不直接等价。
3. **先证明一个事件。** 人物看到、反应、行动及环境反馈都要有真实画面，再扩大时长。
4. **保留原版作为基准。** 新后端的优势由同内容、同画幅、同画质要求的实测说明。

**一句话**：B 路线调用的原生运行时 RAEA 是第三方软件，许可是 FSL-1.1-ALv2（Functional Source License 1.1，到期转 Apache-2.0）。我们**只把它当内部制作工具**：用它做自己的影片、给客户交付成片；**不对外提供**基于它的产品、SDK 或渲染服务，不分发它，也不把它的源码搬进本仓库。

## 允许（我们正在做的）

- **内部制作**：在自己的机器与工作站上用 RAEA 渲染自己的影片、样片、测试与研究。
- **给客户做片、交付成片**：交付物是渲染出来的影片文件；运行时留在我们这边，不随交付物给出。
- **为本身持有 RAEA 许可的客户提供专业服务**（例如帮客户在他们自己的 RAEA 上搭工程）：FSL 明确允许这类服务。
- **写调用 RAEA 公开接口的自有代码**：`engine/native/`、`examples/raea/` 里的封装、桥接与例片都是我们写的，按本仓库 MIT 发布。代码公开不等于对外提供 SDK（见下文「对外怎么说」）。

## 不允许

- **把 BNE、`engine/native/` 或任何基于 RAEA 的东西做成对外的商业产品、SDK、托管渲染服务或 SaaS**，尤其是能替代 RAEA、或功能与 RAEA 实质相似的（这正是 FSL 的「竞争性使用」）。「通用原生渲染 / render anything」只描述 B 路线在**我们内部**能做什么，不是对外的产品承诺。
- **分发运行时**：不把 RAEA 的二进制、SDK 或模型放进本仓库、Release、作品站或交付物。
- **搬上游源码**：不复制或改写 RAEA 的源码（Rust、WESL 着色器、SDK 源文件）进本仓库。确有必要引用一小段时，那个文件必须单独标 `LicenseRef-FSL-1.1-ALv2` 并附 FSL 全文与上游版权行、登记进 THIRD-PARTY.md——先问用户再做。
- **用上游的名字当我们的产品名**：RAEA 只在技术说明、署名区块与许可说明里如实出现（D04）。
- **对外暗示是自研运行时**：不写「自研原生引擎」「BEIMING NATIVE ENGINE」一类说法。

## 拿不准时（先问用户，必要时请法务）

- 让外部客户自己登录、提交任务、在我们的机器上渲染（这就是渲染服务）；
- 把 B 路线打包给别的团队「装上就能用」；
- 向投资人或客户承诺 B 路线的商业化形态；
- 任何「要把 RAEA 一起给出去」的交付。

**商业化之前**：先取得上游的书面商业许可或法律意见，结论登记进 [register.json](register.json)（新开一类），再动手。

## 对外怎么说（D04）

- 路线名：**北冥原生 · BNE**。BNE 是「北冥原生」的英文缩写（Beiming Native Edition），不暗示自研运行时；产品名里不带 RTX。
- 署名区块的固定文字（作品站页脚、README 署名节、Release 说明末尾，位置固定）：

  > 北冥原生 · BNE 基于第三方原生运行时 RAEA（shinyobjectz/raea，FSL-1.1-ALv2，版权人 Shane Murphy）。运行时不随本仓库分发，需单独取得并遵守其许可。

- 技术文档里可以如实写上游名与目录（如 `examples/raea/`、`RAEA_BIN`），这是「上游项目名（内部目录沿用）」，不是我们的产品名。

## agent 规则（可直接抄进路线手册的「边界与常见坑」）

1. RAEA 是第三方 FSL 软件：只在本机或工作站上调用，不提交、不打包、不随成片给出。
2. `engine/native/` 只写调用 RAEA 公开接口的自有代码；不复制 SDK 或运行时源码，不加 Rust / WESL 文件。
3. 交付物只有影片；有人要「把渲染做成服务」「把 BNE 给别人用」，停下来问用户。
4. 对外只用「北冥原生 · BNE」，并带上面的署名句；不写「自研原生引擎」。
5. 升级运行时版本：同一提交里更新本页与 THIRD-PARTY.md 的版本、发布日和 Apache-2.0 转换日期。

## 机器检查

`node tools/compliance/scan.mjs --only fsl-boundary`（也是仓库规范检查的 `comp.fsl-boundary`）：

- MIT 目录的代码里出现 FSL 许可标题、FSL 许可标识、上游的版权行或「竞争性使用」条款原文 → 阻断；
- 仓库主体出现 Rust / WESL 源码或 Cargo 清单 → 阻断（本仓库自己不写这类代码，先确认来源）；
- 文档里逐字引用「竞争性使用」条款原文 → 提示（讨论许可可以，原文不要抄）；
- 已按派生代码单独标 `LicenseRef-FSL-1.1-ALv2` 的文件不报。

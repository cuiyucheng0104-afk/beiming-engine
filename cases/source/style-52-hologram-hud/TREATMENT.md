# 52 · 科幻全息界面《种子扫描》— 导演阐述

风格：hologram-hud（科幻全息界面）。1920×1080，24 fps（STYLE.md §5「Everything on ones at 24 fps」），时长 19.375 s。
无旁白、无字幕；画面内只有 HUD 自身的文字（中文为主，数字与微数据用 Rajdhani / Share Tech Mono）。

## 0. 三个候选结构与选择

| | 结构 | 开场 | 结尾 | 配乐形状 |
|---|---|---|---|---|
| A | **单程生长**：一颗种子 → 扫描长成全息树 → 锁定一圈年轮 → 局部爆炸、数字滚动 → 静默 → 树龄定格 | 黑场里一个热点亮起成种子（极特写） | 整树点亮为实体全息，「120 年」定格；树冠里一颗新橡子亮起，呼应开场 | 稀 → 密（八分 → 十六分加速）→ 半速减速 → 一拍真静默 → 大和弦打开 |
| B | **倒放擦除**：从成年大树开始，扫描平面自上而下擦除，年轮一圈圈退回，最后只剩种子 | 整树全景 | 一颗种子 | 密 → 稀，结尾单音 |
| C | **年轮外扩**：从一圈年轮的特写起，逐圈向外解算，拉远才知是一棵树，再找到它的种子 | 截面特写 | 拉远全景 | 一条持续上行的琶音 |

**选 A**：分镜条目给定的故事就是「从小到大」的单程，而 A 的最大资产是**从种子极特写到 18 m 大树全景的对数拉远**（同一镜头内尺度跨越 ~600 倍），这是全片的签名镜头；B 的情绪是消逝，与「120 年」的落定相反；C 把锁定放在开头，高潮会提前。A 的开头与结尾形成首尾呼应（一颗种子 → 树冠上另一颗种子）。

## 1. Logline 与弧线

**一颗种子被扫描成一棵 120 岁的橡树：系统锁定其中一圈年轮、把它拆开读数，屏息一拍之后，树龄定格。**

- 起：黑场里一颗悬浮的橡子被扫描线读出（「这是真实数据」）。
- 承：读完的种子线框缓动落到投影台中心（闷击），扫描平面从台面上行，把种子擦除并转成根与树干；根、干、枝、叶逐层生长，镜头对数拉远揭示尺度，侧栏数据片累积。
- 转：目标框甩镜追到胸高处的树干截面，锁定一圈年轮；局部爆炸——年轮沿树干轴向分层抬起（每层保持原半径、压成薄片，外层抬得少、内层抬得多，层间留缝；髓心留在原位发热），含水率滚动落定，树龄乱码滚动不停。
- 合：年轮合拢，一切停住（一拍真静默）；第一声是大和弦 + 808 下滑 + 锁定音，「120 年」以强调色定格，整棵树点亮为实体全息，光波爬上树冠，树冠里亮起一颗新的种子。

## 3. 视觉设计

- **主色**：冷薄荷青 `hsl(168, 85%, 62%)`（叶与光），**强调色**：琥珀 `#FFB347`（木心、树龄）——只用在「数值变为真」的那一帧及之后。
- **主体**：橡子（车削体：环线 + 经线 + 壳斗网格）→ 根系 / 树干（管：环 + 纵线）/ 分枝（递归管）/ 叶簇（小菱形单元）。所有部件物理相连：种子留在根颈处，作为根系的起点。
- **三层景深**：背景点阵（慢视差）、主体 + 投影台、前景 HUD（角括号、视差标尺、左上「种子扫描 // 样本 07」、右上状态行、底部遥测）。
- **原生招式**：扫描生长（开场 + 生长段）、目标锁定（甩镜）、局部爆炸（年轮沿轴分层）、滚动数字（含水率 → 树龄，高潮）、数据片累积（侧栏）、实体全息 + 光束（只一次，在高潮）。
- **高潮落在原生招式上**：滚动数字定格「120 年」+ 实体全息点亮，一次 3 帧故障（全片唯一一次）。

## 6. Cue map

- **速度 96 BPM**（分镜给 100，改为 96：一拍 = 0.625 s = 恰好 15 帧，一小节 = 2.5 s = 60 帧，所有拍点落在整帧上，量化偏差 0 ms）。4/4，全片 7 小节 + 3 拍 = 31 拍。
- 以 `B` 记全局拍号（B0 = 0 s，每拍 0.625 s）。

| 小节 | 时间 | 段落 | 配器 |
|---|---|---|---|
| 0 | 0–2.5 | INTRO | 投影仪嗡声、卡林巴（pluck.py）「叮」、四分音符低脉冲（正弦 + 2/3 次谐波）、扫频 |

## 10. 返修记录（审片后第一轮）

- **种子落台**：B4 读完后种子保持实心线框，两拍缓动（u²(2−u)，落地时仍有速度）落到投影台中心，B6 落地接闷击；扫描平面从台面上行，把种子自下而上擦除并转成根与树干。删掉了「退回点云、悬在半空」的那一步。生长与对数拉远从 B6 开始。
- **截面不再糊成白饼**：截面的 9 层同心壳实体面只给 15 %，光波经过时不再给截面加面亮度；光波热线只留最外一圈树皮（波前 0.2 m 内），年轮本身保持色相的 alpha 层级；高潮后截面亮度 0.25 s 内降到 62 %。
- **局部爆炸读成年轮片**：各层沿 +Y 等距（0.16 m）抬起、保持原半径，同时压成 0.08 m 的薄片，外层抬得少、内层抬得多，层间留缝；树皮作为底座外套留在原位，髓心原地发热。
- **音乐轻重**：B4 的下滑与闷击各压低 6 dB，闷击挪到 B6 落台；2.5–4.4 s 的 120 Hz–1 kHz 做 −3 dB 宽带衰减；15.0 s 的大和弦 +2.7 dB、大鼓 +3.5 dB、808 +2.4 dB。

## 11. 返修记录（第二轮）

- **高潮是全片最响的一下（实测）**：上一轮只调了推子，母带限幅器在 15.0 s 仍然压掉约 10 dB，静默后第一声被压扁。本轮从源头降低高潮的峰值因数：808 −4.8 dB、B24 底鼓 −4.4 dB、采样大鼓 −3.5 dB、落定闷击 −4.6 dB（这些都是低频尖峰，K 计权响度很小）；宽锯齿大和弦 +2.6 dB，滤波起点 500 → 800 Hz；高潮总线加一级 tanh 软饱和。开场与结尾的卡林巴「叮」各压低约 5–6 dB。母带前加 15.5 kHz 低通（合成踩镲的超高频毛刺在 AAC 编码后会让真峰值过冲 2 dB 以上），内部限幅上限 −2.0 dBTP。成片实测：整体 −14.1 LUFS、真峰值 −1.8 dBTP；400 ms 瞬时响度最大值在 15.15 s（−8.4 LUFS），比 15.0–17.0 s 高潮段以外的任何位置高 3.6 LU（B4 落地段约 −14.5 LUFS）。
- **爆炸读成「年轮片」**：目标年轮 R-087 在抬起到位后整圈热边，其余各层压到 70 %；髓心向上加一条 CAD 爆炸图式的虚线装配轴，每层一个刻度（目标层刻度加长、近白）。
- **截面高潮亮度**：高潮第一帧截面增益从 100 % 改为 72 %，0.25 s 内降到 62 %。

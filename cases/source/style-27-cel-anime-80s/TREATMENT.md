# 追电车的夏天 · TREATMENT

风格：80 年代赛璐璐动画（cel-anime-80s）· 1920×1080 · 24 fps · 19.5 s · 无旁白、无字幕 · 画面内文字只有电车行先牌与片尾标题。

## 0. 三个候选结构

1. **单程追逐（选用）**：海岸公路上少女与电车并跑 → 风吹走草帽 → 定格 → 接住 → 放走电车。一条直线的旅程，转折点在"选帽子还是赢电车"。最适合 15–20 s：一个主体、一个目标、一次转折。
2. **前后对照**：同一个海边电车站，开头少女错过电车（正午色指定），结尾她骑车赶上下一班（黄昏色指定）。依赖两次重复，20 s 里太挤。
3. **倒计时**：路口道口警铃倒数，少女要在栏杆落下前骑过去。张力强，但高潮会落在"冲过"而不是分镜指定的"接帽"，放弃。

选 1：故事和原生招式（大世界小主角 → 速度语法 → 静止即戏剧 → 逆光 → 光带扫过赛璐璐）按时间顺序一个接一个出现，各占一个段落，不打架。

## 1. Logline 与弧线

一个骑车追电车的夏日少女，在草帽被风吹走的一瞬间放弃了比赛——她接住了帽子，电车远去，她笑了。

- 建立：巨大的夏日海岸，小小的少女骑车。电车铃声从画外先到。
- 升级：电车追上来，她站起来猛蹬，速度线、近景、眼睛特写。
- 转折：风掀走草帽，帽子飞向太阳；音乐减速、全部停住——1 秒真静默的定格。
- 高潮：逆光里她伸手，"啪"一声接住帽子（全片最重要的声音），音乐升半音回到副歌，光带扫过定住的赛璐璐。
- 结尾：开场构图在夕阳色指定里重画一次，电车远去，标题闪亮。

## 2. 对标作品（只学语法）

- **80 年代 OVA / TV 动画的夏日片头**（总体，例如《橙路》一类 city pop 片头的剪辑方式）。学：剪辑卡小节、大背景平移 + 小赛璐璐、逆光剪影定格、白闪转场、片尾标题镀铬渐变 + 星芒。不学：任何角色设计、具体镜头、标志、片名字体。
- **山下达郎式 city pop 编曲的结构**（总体风格）。学：slap 贝斯 + DX 电钢 + 16 分吉他切音 + 门限混响军鼓的分层，前奏半速 → 主歌全速 → 刹车 → 副歌升半音。不学：任何旋律、和弦进行以外的具体动机、音色采样。

## 5. Cue map

段落动态：前奏 S1 整体 −4.5 dB、主歌 S2–S5 −1 dB、副歌 S7 原样（台阶放在 b8 与接帽 C 上），mix 阶段做 4 倍过采样真峰值驯服，让 mux 走 loudnorm linear 模式，不把动态压平（目标 LRA ≥ 5 LU、真峰值 ≤ −1.2 dBTP）。

声音调色板来源：STYLE.md §7 —— slap 贝斯（numpy 合成 + 电贝斯采样叠底）、FM 电钢带钟音瞬态（numpy FM）、16 分吉他切音（electric_guitar 采样）、门限混响军鼓与大通鼓（drum_kit 采样 + 门限混响）、鼓机（合成底鼓 + 拍手）、萨克斯主奏（alto_sax 采样）、合成铜管（numpy 锯齿 + 滤波包络）、弦乐垫（violins 采样）、竖琴刮奏（pluck.py harp）、FM 钟音闪亮。混音：-14 LUFS 由 mux.sh 两遍 loudnorm。

- 不做字幕、不做旁白。

# 北冥九景：画风与几何说明

## 三维部分

01书生、03舟人、04楼阁使用既有实体GLB，保留近百万面主体几何；01调整了过高的发髻轮廓。06/07以楼阁实体和程序化碑林、地面、山石组合。其余房屋、舟船、曲面瓦顶、树干、苔藓团、青铜器、剑、书卷、栏杆都是程序几何。

GLB原纹理仅作为固有色分类的输入，按衣/肤/发或瓦/木/墙重新映射色板，再接受真实法线与投影的卡通光照。分类可能误判，所以脸和衣服局部还有色块瑕疵。这不是自动得到干净PBR材质的流程。

树叶与苔藓用InstancedMesh；纸片有弯曲和法线；水面通过Reflector渲染场景反射，并以程序波纹扰动。灰模关闭卡通材质，改用中性标准材质；侧移图改变相机位置，显示真实遮挡。背景天空仍为绘制底板。

## 原片风格来源

直接复用北冥工程的 `src/toon.js`、`src/look.js` 和 `engine/shade`、`engine/look`。没有把JPEG的明暗简单取整作为三维着色。

基础计算为 `h = 0.5 * dot(N,L) + 0.5`，加真实阴影后进入三档；羽化与fwidth控制锯齿；边缘光取决于视线、法线和主光方向。蓝紫阴影、杏橙补光、绿色植被、深蓝墨线来自北冥配色关系，再按这九景的材质角色分配。

| 设置 | 原片默认 | 九景使用 |
|---|---:|---:|
| 主体明暗 | 三档 | 三档，普通材质阈值0.62 / 0.31 |
| 羽化 | 约0.02 / 0.03 | 0.02 / 0.025 |
| Kuwahara半径 | 5 | 1.2，远处1.4 |
| Kuwahara强度 | 1 | 0.14 |
| Bloom强度 | 0.55 | 0.18 |
| Bloom阈值 | 0.72 | 1.05 |
| 墨线宽度（1080） | 2.6 | 1.4 |
| 墨线扰动 | 1.2 | 0.3 |
| 纸纹强度 | 0.12 | 0.025 |
| 最终分辨率 | 样片1920×1040 | 3840×2160 |

“用北冥画风”在这里指复用原片的材质/线条/色彩语言；各场景的灯光、噪声尺度、阴影深度和后期强度作了适配，并非参数原封不动。

## 清晰度边界

最终PNG为5090原生4K输出，描边1.5倍采样、主场景MSAA4。纸纹与天空底板自身的水彩颗粒仍会显得柔。少量高频细节受4K贴图、GLB几何和语义重着色质量限制，提高输出分辨率不会修复模型的脸和手。

逐景日志记录GPU字符串、分辨率、三角面数、实例数、相机、后期和截图耗时。该耗时包含截图，不可当纯GPU渲染基准。

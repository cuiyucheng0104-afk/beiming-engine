# IN SIGHT 目之所及 · 故事介绍片方案

依据：`素材/IN_SIGHT_目之所及_完整故事提案.pptx`，共 16 页。每页是一张图，剧情写在备注里。
产出：约 3 分钟的故事介绍片。用 PPT 原图加代码动画，配 MiniMax 三语配音（中文旁白、英语对白、西语警卫）。

## 一句话

目之所及，眼镜帮他看清。目之所及之外，他只能选择相信。

片名本身就是主题。眼镜管的是**看得见的**部分：路、来电、照片、听不懂的话。故事的转折都发生在**看不见的**地方：Ryan 断了联络，Vex 不肯说出口的担心，结尾那个没有回答的问题。

## 两套视觉语言，绝不混用

| | 镜片层 | 故事层 |
|---|---|---|
| 颜色 | 镜片绿，单色 | 暖白底；人物色：Jack 橙、Ryan 蓝、Vex 红 |
| 用途 | 只表现眼镜真实能做的事：来电（手机协同）、导航提示、拍照、翻译 | 讲述者的地图、人物标签、联络线、抛物线、局面卡 |
| 出现方式 | 永远装在“镜框”里，左上角标“眼镜功能 · X” | 平铺在画面上，属于“讲故事的人” |

PPT 备注反复强调了功能边界：不预测落点、不读取基地系统、钥匙靠人传递、ABORTED 是设施屏幕。这套分法就是为它服务的。观众一眼能分清哪些是产品，哪些是叙事，汇报时也经得起追问。

## 三个贯穿全片的代码装置

1. **镜框**：开场从黑场张开，结尾收拢；镜框里的东西都是眼镜真能做的。追车那一镜特意让镜片**空着**，配一句“不预测落点，判断在人”。
2. **联络线**：Jack（橙）和 Ryan（蓝）之间有一条线，每过一个节点就亮一下“确认”。耳机损坏时线断开：Ryan 那边知道 4/4 人已撤出，Jack 那边只有“没有消息”。Ryan 用手机重新拨通时线接上，ABORTED 出现。
3. **抛物线**：开场 Jack 把饮料抛给 Ryan，代码记下这条弧。高潮 Jack 把钥匙抛给 Ryan，同一条弧再画一次：同一条抛物线，不同的重量。

避免“有声漫”的规则（沿用前两个项目的教训）：
- 原图不能只做推拉，每一镜都要被代码改变：定格、分屏、镜框压暗、连线穿过画面。
- 每个代码元素都要有叙事理由。
- 全片只有一张地图、一条线、一条弧。

成片阶段可以用 ROG 上的 Depth Anything 给原图做 2.5D 视差。

| Ryan | Arnold / Spanish_ReliableMan 说英语 |
| Vex | Spanish_PowerfulVeteran 说英语 / Trustworthy_Man 压低 |
| Ray | Spanish_Jovialman 说英语 / Spanish_HumorousElder 说英语（带口音的英语正合摊主） |
| 警卫（西语） | Spanish_PowerfulVeteran / Spanish_Deep-tonedMan |

MiniMax 国内站的英语系统音色只有约 7 个，所以 Ryan、Vex、Ray 用的是西语音色说英语（跨语种）。如果口音不对，可以换用声音克隆。

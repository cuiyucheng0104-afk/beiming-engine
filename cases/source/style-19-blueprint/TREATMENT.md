# 19 · 蓝图 / 工程制图 ——《擒纵机构》

无旁白、无字幕。画面内文字全部是图纸本身的字（标题、零件名、尺寸、图号、技术要求、标题栏），中文为主。1920×1080，24 fps（STYLE.md §5：相机与描线逐帧），总长 19.667 s（472 帧）。

## 1. 三个候选结构与选择

1. **线性制图（选用）**：空图纸 → 按制图顺序画出擒纵器 → 尺寸实时量出 → 图号翻面、正视图翻转成剖视图 → 停 → 运动符号变成真运动、机构活过来 → 拉远成整张图纸，签名盖章。分镜条目已给定故事与原生招式，这条最能卡拍：每层描线一拍，擒纵每一下一拍。
2. 倒拆：从一张画满的图纸开始，零件按拍逐个擦掉，只剩一根中心线，再在静默后一声滴答里重新长出来。好看但"符号变真"的高潮会被擦除抢戏。
3. 两张图纸一张桌：正视图与剖视图分别在左右两半同时画出，最后对齐投影线发现是同一台机器。信息量太大，20 秒读不完。

## 2. Logline 与弧线

一张空白蓝图纸上，一台钟表擒纵器被一笔一笔画出来、量出来、剖开来——然后在一秒静默之后，图上那个表示"摆动 ±6°"的箭头符号离开了纸面，把摆锤真的推了起来：滴答，机器活了。

- 建立：中心线划过空纸（0 s 就有动作）→ 轮廓 → 齿形 → 摆。
- 转折：图号"图 1"翻面成"图 2 · A–A 剖视"，整幅图像翻转 90° 沿投影线滑到右侧成剖视图；音乐写出的渐慢，掉进真静默。
- 结局：第一声擒纵"嗒"——全片最重要的声音；运动的零件获得体积、微光与投影，原位留下未曝光的淡印；拉远成整张图纸，标题栏手写签名，红色"核准"章落在终止式上（全片唯一的非蓝颜色，只用一次）。

## 3. 对标

- **19 世纪美国专利图（Fig. 1 / Fig. 2、零件气球、细线阴影）**——学：正视/侧视的投影对齐、图号作为章节；不学：任何真实专利的机器与签名。
- **《雨果》(2011) 里的自动机图纸** 与 **Iron Man (2008) 片尾的运动线稿**——学：线稿"活"起来时镜头放慢、推近，机构动作一拍一下；不学：任何角色、标志、具体镜头。
- 钟表制图惯例（锚式擒纵：叉轴距轮心 R√2，叉瓦跨 7½ 齿）——学：让零件真的能啮合。

## 6. Cue map

- **速度**：90 BPM（一拍 = 16 帧 = 0.6667 s；十六分 = 4 帧，八分 = 8 帧——所有细分都落在整帧上，偏差真为 0 ms）。拍号 2/4（嘀-嗒）。
- **为什么 90 而不是 100**：100 BPM 一拍 14.4 帧，落不到整帧；90 BPM 时摆的半周期 0.667 s，对应单摆长 L = g·T²/4π² = 9.807×1.3333²/39.478 = 0.442 m——图上标注的摆长 **442** 正是让音乐速度成立的那根摆。
- **网格（帧）**：b0–b12 每拍 16 帧（0, 16, …, 192）；**渐慢** b12=192 → b13=210（18 帧）→ b14=231（21 帧）；**延长/静默** 231→264；b15=264 起回到 16 帧一拍：264, 280, …, 392(b23), 408, 424, 440(b26), 456；片尾 472 帧 = 19.667 s。小数拍（如 b13.25）按所在拍的实际帧长等分后取整到帧，画面和声音用同一个函数。

## 9. 返修记录（审片意见 → 改法）

1. 高潮太小：b15 硬切直接进近景（zoom 2.30，摆锤 + 摆角弧约占画高 40%），b15–b16 缓推到 2.45，第一下"嗒"之后再沿摆杆上摇到擒纵叉；离纸的 ±6° 箭头加粗（线宽 6→8.5，箭头 30→40，辉光 16→22）。
2. 红章看不见：章放大 2.35 倍（全景直径约 150 px），移到标题栏左侧空白处，不压日期等任何字；落章从 1.18 倍压下，镜头一震加大。
3. 标注露出太短：标注整体前移半拍到一拍（跨角 b6.5、叉轴距 b7、摆长 b7.5、Ø84 b8.5、摆角弧 b9），气球压到四分之一拍网格 b9.5–b10.25，镜头 b9.5 拉回中景后停到 b12。

5. 翻面时像空白板：影图改用真实外轮廓（齿形、窗孔保留）做 cos 压扁，只在接近侧视时淡入外包轮廓；新图号落定 5 帧后影图和镜头才动。

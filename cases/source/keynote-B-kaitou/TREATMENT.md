# 方案 B《片库之夜》20 秒开头 · 导演阐述（TREATMENT）

> 规格：20.000 s，1920×1080，30 fps，**无旁白**。108 BPM，4/4，一拍 0.5556 s，一小节 2.2222 s，共 9 小节（36 拍）。
> 依据：`共用/方案B开头规范.md`（冲突时以它为准）＋ 设计原稿 `方案B_片库之夜.md` ＋ 风格 archive-lighttable（档案灯台）与 dataviz（数据叙事）。

## 0. 三个候选结构与选择

1. **一镜到底的"开灯—取证—归档"**：俯拍看片台，一切都在同一张台面上发生；镜头只在台面上滑行、推近、拉开，转场全部由台面上的物件（幻灯片、放大镜、图纸、底片套）完成。
2. **两场戏对切**：看片台（暗、冷）与数据纸（亮、暖）硬切交替，每小节一切。节奏强，但切碎了"同一张桌子"的空间感，也违背两种风格"不硬切"的语法。
3. **倒叙**：先给出 4 组轮廓的成品图，再倒回 477 个点逐个落下。信息清楚，但 20 秒里倒叙会把"看片台亮起"这个最强的开场钩子挤掉。

**选 1。** 理由：规范里四个段落本来就是"灯亮 → 放上一张 → 平移到图纸 → 移回台面"，这是一条连续的镜头路线；一镜到底让"资料从桌面上被找出来"这件事成立，也让与方案 A（手卷平移）、方案 C 的对比更纯粹——这一版的风格核心是**光从下方来的冷白台面 + 逐点落下的数据**。

## 1. 一句话与弧线

- **Logline**：深夜，片库的看片台一根根亮起，九色鹿在透光的幻灯片里醒来；铅笔在图纸上落下 477 个点，点被"拉"成 25 个分类、4 个组；镜头回到台面，三张角色海报滑上来——角色，是进入内容的入口。
- **弧线**：黑暗（无）→ 光（资源被照见）→ 数据（477 条记录 ≠ IP 数，收敛成 25 个分类）→ 角色（入口，未完待续）。
- **转折**：第 8 小节第一拍，点群在一声和弦上同时落进 25 簇，马林巴与钢琴两条错开的线在同一拍重新对齐——"从大量资料里找到对齐的那一刻"。
- **结尾回声**：开场是台面上一件件物件从黑暗里显影；结尾是三件新物件滑上已经亮着的台面，第三张还在滑——像片子刚开始。

## 2. 对标（只学语法）

- **对标一**：Steve Reich《Piano Phase》/《Music for 18 Musicians》的现场录像——学"两条相同的线以微小速差错开、再锁回网格"的过程感，以及打击乐器做旋律的音色；**不取**任何旋律与音型。
- **对标二**：档案纪录片里在看片台上推进照片的镜头（灯台下透光、放大镜落定、一屏一条读数）——学透光与"放大镜是镜头的门"；**不取**版式、字体与镜头。
- **对标三**：数据新闻里"一个点是一条记录"的单位图——学"标记逐个落下、标注钉在数据上"；**不取**图表样式。

## 3. 视觉系统（落地版）

| 项 | 做法 |
|---|---|
| 世界与镜头 | 一张世界坐标的看片台（x −1300…3700，y 0…1500），一台 2D 镜头 {中心 x, y, 缩放, 滚转}，台面、物件、批注、放大镜全走同一个 world→screen 函数 |
| 看片台 | 8 根横向灯管在乳白扩散板下，亮度场 = 各灯管高斯带之和（全亮时起伏 ±3%），冷白 ≈ #F3F6FA；扩散板的乳白斑驳取自材质「宣纸_逆光」（降到 4% 对比）；铝框；台外是压暗的木桌（材质「木桌」） |
| 启辉 | 每根灯管：拍前 0.13 s 两端灯丝微橙预热 → 拍上第一闪 → 4–6 帧明暗频闪 → 稳定 |
| 物件 | 不透明物（放大镜黑圈、铅笔、索引卡夹）比台面暗；纸（数据图纸、索引卡）透光发暖、边缘更亮；幻灯片框为不透明的灰白塑料框 |

| 放大镜 | 台式放大镜：黑色金属镜圈（左上一处斜向高光、右下弱反光）+ 半透明亚克力裙边（不透明度约 0.5，被台面从下方照亮，外沿一圈亮边）+ 偏右下的软接触阴影；镜内是同一世界以 **1.6×** 等比放大重绘，再加约 2% 的边缘桶形畸变（像素重映射，只作用于镜内的光学放大层；原图本身和镜外的幻灯片不受影响） |

| 红蓝铅笔 | 六棱笔杆，蓝半/红半，从右下入画；蓝芯点记录、写分类名与组名；红芯只写那句警示批注 |
| 底片套 | 透明聚酯套，上沿一条空白纸签；海报像素原样，套子只在图外加边缘高光。一叠空底片套放在放大镜停放处下方（世界 x≈2430），开场随灯光显影，结尾三张海报套从这一叠的方向抽出 |
| 强调色 | 朱红 #BE3A2E 只用于「477」落定后与「25」 |
| 字体 | 正文 Noto Sans SC（700/400）；数字 Inter 800；手写 Ma Shan Zheng（铅笔质感：石墨颗粒遮罩 + 逐字擦写）。均为 Google Fonts（OFL），`&text=` 子集化在 fonts/ |

**IP 图片规则自查项**：只用 drawImage 等比缩放 + 平移（幻灯片入场有 ≤8° 的整体刚体旋转，落定时归 0°）；不加滤镜、不改色、不抠图、不全屏（九色鹿约占画面宽 40%，海报每张约占画面高 55%）；放大镜内为同一像素的等比放大。

**音乐**：马林巴（VCSL）+ 钢琴（Salamander）相位错位，颤音琴（VCSL，软槌与弓奏）、低音提琴拨弦（VSCO 2 CE）点缀；**无弦乐铺底**。调性 G 大调，与电流嗡的 98 Hz 同为 G。和声：（嗡 G）→ Em → C → D → **G add9（和弦）** → C add9（开放结尾）。
**静默**：开场的黑（第一根灯管之前没有任何声音，第一声就是"咔"）；g27.5–g28 半拍静默（只剩极轻的高频群声尾音和压低的电流嗡），和弦是静默后的第一声。
**响度**：−14 LUFS（±1），真峰值 ≤ −1 dBTP（mux.sh 两遍 loudnorm）。

## 8. 关于"点"的诚实说明

PPT 只给了两个总数：25 个分类、477 条记录，**没有**每个分类各有多少条记录。所以 477 个点平均分到 25 簇（23 簇各 19 点、2 簇各 20 点，按就近分配决定哪两簇多一点），簇的大小**不表示**数量差异；4 组的大小则是真实的（各组分类数 6/6/8/5）。这一点写在这里，不在画面上额外加字。

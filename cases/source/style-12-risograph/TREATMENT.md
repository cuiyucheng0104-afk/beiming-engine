# 跳水 · Risograph 孔版印刷 风格样片 — TREATMENT

无旁白、无字幕。1920×1080，24 fps（STYLE.md 未规定帧率），DUR = 19.5 s。
画面内文字只有两处：开场套印标题「跳水」（双版错位的 double-hit），入水时水花里用缺墨抠出的纸白「扑通」。

## 0. 三个候选结构

1. **单程旅程（选定）**：从跳台到水面一条直线——站定、助跑、腾空、凝固、入水、涟漪。故事本身就是一个"下落"的抛物线，节奏天然从快到慢再到爆发，最适合把"套准=节奏"做成主线。
2. **两版对话**：粉版只画跳水者、青版只画泳池，两者交替各占镜头，直到入水那一刻才第一次叠印出第三色。概念漂亮但前 12 秒画面会显得半空，样片要的是满表现力，放弃。
3. **倒放减法**：从水花的满套印开始，每一镜少一版，倒退回跳台上只剩粉版的人。结尾太冷，入水不能做全片最重一拍，放弃。

选 1，并把结构 2 的核心吸收进去：**青版（水、太阳盘）在第 0.6 秒才由墨辊扫上来**，前 0.6 秒是"只有粉版的世界"；结尾青版再被墨辊揭走，只剩粉色涟漪——首尾呼应。

## 1. Logline 与弧线

**一个粉色的人从十米台跳进青色的水：两版油墨一路对不准，直到入水那一拍才咔嚓对齐，炸出第三种颜色。**

- 建立：只有粉版的跳台 → 青版墨辊扫入，泳池和太阳"被印出来"。
- 转折：助跑时每一步都把两版踢歪；腾空翻转放慢，粉色身体划过青色太阳，第一次叠出紫。
- 悬停：离水一掌高，时间停住，两版越漂越远（全片唯一的静）。
- 结局：入水那一拍两版瞬间对齐，水花满版紫色，缺墨抠出纸白「扑通」；涟漪套印收尾，青版被揭走，只剩粉色的人浮出水面。

## 3. 版与色

- **两版**：R = 荧光粉 `#FF48B0`（第一版，带剪影），G = 青（浅湖蓝）`#4CC0E8`。纸 `#F4EEE2`。
- 第三色 = 两版实地叠印 ≈ 紫 `#4C36A0`（只在"腾空划过太阳"和"入水水花"出现）。
- 配方（粉, 青）：天空纸白 (0,0)；远天 20%/40% 青阶梯网点；太阳盘 (0,1)；水 (0.25,1)；跳台混凝土 (0.4,0)；跳台阴影面 (0.4,1)→不用，改 (0.6,0)；跳水者 (1,0) 实地剪影 + 纸白泳帽；人物纸白抠空光晕 5 px（翻转镜头去掉光晕，让粉直接叠在青上出紫）。
- 一版测试：只有粉版时跳台、人物、水面浅粉网点全都可读；太阳盘是"刻意例外"——青版到来前是纸白空洞（knockout 开场）。

## 6. Cue map

- **BPM 90**（分镜写 92；改 90 后 1 拍 = 16 帧、八分 = 8 帧、十六分 = 4 帧，所有拍点、步伐、水滴都落在整帧上，视觉与音乐偏差可做到 0 ms）。4/4，拍号从 0 起算，`t = beat × 2/3`。唯一时间源 `timeline.js`。
- 小节：1=0.000 / 2=2.667 / 3=5.333 / 4=8.000 / 5=10.667 / 6=13.333 / 7=16.000 / 8=18.667。

|---|---|---|---|
| 印刷开场 | 1 | 送纸噪声、马达嗡、低通鼓机（kick b1/b3 + 响棒 b2）、Dm9 电钢琴 | 青版落定 b1；标题 b2 |

低频：主总线在原有 140 Hz 搁架之外再加一档 100 Hz 以下 −2 dB 的搁架，只有入水后约 1.2 s 不加（保住全片最重的次低频）；慢动作段（b12–18）贝斯被这一段的底鼓再侧链压深一次（击打瞬间约 −14 dB）。

动态弧线：开场 −5 dB → 助跑逐步推满 → 慢动作 −2 dB → 静默 −54 dBFS → 入水 +1.2 dB 峰值 → 收尾回落。

## 8. 文字设计

- 「跳水」：Noto Sans SC 900，230 px，只印在粉版上，b2 落定时伴一次套准踢，切镜即消失（印刷品不淡出）。（原计划双版 double-hit，会提前露出紫色，改为单版，把第三色留到 b15。）
- 「扑通」：水花满版紫中**缺墨**抠出的纸白字（两版都为 0），随两版对齐在 b20 落定，随水花长大到 245 px；字边接住错版色边。
- 跳水者的纸白泳帽在叠印模式（翻转出紫、凝固）下也对两版同时挖空，头部在任何底色上都是实心纸白加粉边。
- 墨辊（开场上青版、结尾揭青版）是硬边：1 px 抗锯齿、边缘几像素的毛刺，紧贴边缘一条约 10 px 的二次上墨带，绝不是羽化渐变。
- 字体用 Google Fonts `&text=` 子集化（7 个字），放 `fonts/`。

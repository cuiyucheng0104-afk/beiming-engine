# 悬索桥为何不倒 · TREATMENT

风格：工程简报板（briefing-board）｜1920×1080｜24 fps｜19.875 s（477 帧）｜无旁白、无字幕｜96 BPM

## 0. 三个候选结构与选择

1. **一条尺寸线一直长**：从桥塔出发，跨度尺寸线一路骑到对岸，长到"装不下"再回答为什么不倒。——只有测量，没有"力"的转折。
2. **清单逐项盖章**：塔、缆、吊索、锚碇四张卡片依次盖"承力"章。——像 PPT，镜头走成翻页，违背"一面墙"。
3. **（选定）摆证据 → 量跨度 → 挂荷载 → 擦掉只留结论**：墙上落下真实照片（证据）；骑尺寸线读出 1280 米（问题有多大）；一块块磁贴荷载挂上主缆、红箭头顺缆流向塔顶再压入塔身（力的路径）；静默一拍，两枚红磁贴砸上两座塔顶（裁决）；其余全部擦成残影，只剩一句"重量全部流进两座塔"，镜头拉到整面墙。
   选它的理由：一个主体（桥的重量）、一个目标（找到它去了哪里）、一个转折（擦掉一切，只剩去向）。结尾的整墙拉远同时就是答案的海报。

**与分镜条目的协调**：条目要求 0–4 s"整面墙揭开"。STYLE.md 不变量规定"整面墙只在最后拉远时出现一次"。处理：0–4 s 做"墙被揭开"——照片、磁贴、标题依节拍逐件落墙，镜头以裁切取景横移揭示（不超过墙宽 60%）；真正的整墙全景留给 17–19.75 s 的结尾拉远。四个原生招式全部保留：whole-wall reveal（结尾）、ride the dimension line、magnets as countable things、erase to a ghost。

## 1. Logline 与弧线

一座 1280 米的悬索桥，桥面的重量去了哪里？——磁贴一块块挂上主缆，力顺着缆流进两座塔；擦掉一切，只剩这句话。
- Setup（0–4 s）：证据落墙，问题写上墙：悬索桥为何不倒？
- 发展（4–9 s）：骑尺寸线，1280 米。
- Turn（9–13.4 s）：荷载磁贴逐块挂缆、节奏加速；红箭头沿缆流向塔顶、压进塔身。静默。
- Ending（14.6–19.875 s）：红磁贴砸上两塔顶；擦成残影；结论落墙；整墙拉远。

## 2. 对标

- **对标 A：在地图墙前拍的解释性纪录片（贴图钉、红线串证据的调查墙）**。学：镜头沿线索从一件证据滑到下一件，取景永远是墙的一个局部；照片带物理阴影与重量。不学：红线乱麻、侦探式人物、具体镜头与字体。
- **对标 B：土木教科书里的力流图（load path diagram）与工程立面图制图规范**。学：立面在下、尺寸线带箭头与界线、荷载箭头的读法、比例一致。不学：教科书排版、页眉、PPT 式居中条目。

## 5. Cue map

- 96 BPM，4/4，1 拍 = 0.625 s = 15 帧；网格偏移 0.25 s（第 6 帧）。全片 30 拍 ≈ 7.5 小节 + 尾。
- 调性：A 小调（Am | F | 走步 | A 踏板 | Dm–E–A）→ 静默 → A 大调。
- 小节 1–1.5（b0–b5）**A 墙**：合成低音（钢琴感，带 2/3 次谐波，叠 jazz_bass 采样）+ 大鼓/军鼓 taps/踩镲 + 木块；落墙全部在拍上。
- 小节 2–3（b6–b13）**B 尺寸**：低音走步上行（每拍一音 A→B→C→D→E→F→G→G#），踩镲 8 分，马林巴 8 分琶音随尺寸线上行；b12 箭头落定 = 低音到 A2 + 钢击 + 马林巴和弦。
- 小节 4–5.25（b14–b21）**C 荷载**：磁贴 clack 成为节奏主体，由 4 分→8 分→16 分加速，每块磁贴配一个木琴音、沿音阶 A4→C6 上行；低音 A 踏板 8 分；b18 军鼓 16 分渐强；b19 低铜管 Dm stab，b20 E 大三 stab + 钢击，b21 全奏短击后掐断。
- b21–b23 **D 静默**（1.25 s），只留空调底噪。
- b23 **E 裁决**：长号+大号+圆号齐奏 A 大三和弦（全片由 A 小调转 A 大调）、定音鼓、大鼓、两声钢击；之后半速，只在 b25（F）、b27（D）、b28.5（A）有和声落点 = 明显减速，尾声 A 大三和弦落定。
- 返修后：标题起笔提前到 b1.5（为了阅读时长与下摇不冲突）；骑线段新增 b8–b11 四个刻度 tick 拍点。
- 拍点核对脚本 `tools/cuecheck.mjs`：读取 timeline.js 中每个视觉事件（落墙、磁贴、箭头、裁决、擦除、拉远落定）与对应拍点，输出偏差（目标 0 ms）。

## 6. 声音设计表

| 段 | 底噪 | 拟音 | 音乐 |
|---|---|---|---|
| A 墙 | 空调低噪 + 窗外车流 | 照片拍墙 thump、纸拍、磁贴 clack（逐个音高）、笔吱 | 合成低音 + 轻鼓 + 木块 |
| B 尺寸 | 同上 | 长笔吱（按线长）、笔尖 tap、钢尺回响 | 低音走步上行、踩镲、马林巴 |
| C 荷载 | 同上 | 磁贴 clack 递升、吊索线笔吱、箭头 whoosh | 踏板低音、加速、低铜管 stab |
| D 静默 | 只剩底噪 | 无 | 无 |
| E 裁决/擦除/拉远 | 底噪 | 红磁贴重 clack、板擦毛毡、笔吱 | 铜管齐奏 + 大鼓 + 金属击；减速尾声 |

乐器全部来自 STYLE.md 声音调色板：低音（numpy 合成钢琴感低音 + jazz_bass 采样叠层）、轻鼓组（snare2 / hihat，CC0）、木质打击（woodblock / log_drum / claves）、马林巴（mallets）、低铜管（trombone_stac / tuba_stac / horn）、金属敲击（numpy 模态合成 + sus_cymbal bell）。不用钢琴+弦乐铺底。

## 7. 画面内文字设计

- 无旁白、无字幕。
- 马克笔字（LXGW Marker Gothic，Google Fonts &text= 子集化，放 fonts/；逐字揭示、种子抖动）：标题"为何不倒？"（石墨，140 px；照片已说明是悬索桥，缩短以满足阅读时长）；"1280 米"（蓝，140 px）；结论"重量全部流进两座塔"（石墨 + "两座塔"红，270 px）。
- 印刷标签：磁贴上无字；次要层便签"主跨 1280 米""塔高 227 米"与来源卡"HAER CA-31 / PUBLIC DOMAIN"（等宽体），只在结尾整墙出现。
- 阅读时长：标题 ≥3.1 s、"1280 米" ≥2.0 s、结论 ≥3.5 s 全程在画内（readcheck 校验）。

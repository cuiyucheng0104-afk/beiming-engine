# 《北冥》九分钟 · 画风锁定

制作依据：原版十秒《北冥》样片。用户明确要求完全沿用，不采用之后试验的 E 组配色。

原件保留：`toon.js`、`look.js`、`kun.js`、`girl.js`、`shotA.js`、`shotB.js`、`shotC.js`；逐文件 SHA-256 见 `style-lock.json`。

后期逐镜复用三组原始设置：远景 A、人物 B、鲲特写 C。新文件 `locked-look.js` 对这些设置做函数封装，未另设色板。

世界仍由原片手绘天空、云、上海天际线、江面、纸纹组成。鲲使用原版程序化几何与装饰；人物沿用原片贝塞尔侧脸，在同一色板内增加表演。鹏作为剧情要求的新角色，使用原 `toon.js` 材质与共享光照。关灯、日出是剧情光源变化，不能变成另一个画风。

时间仍按 24 帧逐帧导出。人物、墨线一拍二，城市中的鲲一拍三，入海一拍二，鹏一拍一。最终原生 4K 在 5090 的 Vulkan 后端渲染。

原剧本的语音回信保留为概念剧情；具体产品功能需品牌确认。影片不宣称获得品牌方审定。

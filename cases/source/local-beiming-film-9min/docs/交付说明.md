# 《北冥》九分钟完整动画

影片总长 09:00，15 场、84 个镜头，24 帧/秒。沿用原版十秒样片的色板、材质与后期，在 RTX5090 的 Vulkan 后端逐帧渲染。

## 文件

- `delivery/beiming_9min_4k.mp4`：3840×2080 原生4K，完整声音。
- `delivery/beiming_9min_1080.mp4`：1920×1040 观看版，完整声音。
- `delivery/index.html`：本地播放器，支持按十五场跳转。
- `delivery/北冥_对白.srt`：35句对白的字幕文件；视频已内嵌可见字幕。
- `delivery/qa/report.json`：从实际视频读取的验收数据与文件哈希。

## 保留的剧情

林潮在末班渡轮上看见追逐城市灯海的鲲；带它出江失败，得到老周默许；摘戴眼镜的同构图揭示“灯不是海”。她关掉工作灯，保留航行灯；鲲入海化鹏。最后仍停在江口，回复远洋聘书“我接受”，甲板上的真贝壳收束故事。

## 制作边界

人物由原片二维画法延展，鲲与鹏为三维形体，环境以原手绘分层底板为主。动作采用原片的一拍二/一拍三规则，摄影机与水面保持连续。声音使用通用合成对白、代码声效和自编配乐。486–488秒的定格与静音为有意设计。

原画风源文件的哈希锁定见 `style-lock.json`，同机与跨机器工程校验见 `project-manifest.json`。本片没有替换原十秒工程，也没有发布到公开GitHub。品牌功能按原剧本作为概念情节保留。

技术检测、场次联系图和实际编码后关键帧用于此次验收；品牌审定与真人配音导演工作不在这些自动检测的覆盖范围内。

## 编码后画面复核

从实际交付视频抽取全部84镜头的关键帧。复核曾发现第14场在520秒切镜后残留邮件卡片，已为截图流程增加Canvas读回与合成帧同步，并重渲该场。自动解码、黑帧与响度检测不能代替这项画面检查。

低运动的平涂镜头会触发低分辨率freeze检测；报告保留原始日志，不将其一概称为坏帧。GPU回读在个别复测中出现28/1996800像素、最大5/255的细边差异，未宣称跨跳帧逐像素完全一致。

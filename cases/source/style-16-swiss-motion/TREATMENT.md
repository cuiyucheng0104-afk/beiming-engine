# TEMPO · 节拍 —— 瑞士动态排版风格样片（19.75 秒）

> 无旁白、无字幕。画面内文字以中文为主（Archivo + Noto Sans SC 子集）。1920×1080，24 fps，120 BPM。

## 0. 三个候选结构与选择

1. **倒计时**：4-3-2-1 巨大数字倒数，最后例外的红点打断倒数，停在海报上。——结构清楚，但"倒计时+瑞士风"是最常见的套路，红点无处"破格"。
2. **一张成品海报被拆回规则**：开场是成品海报，逐层拆成网格、字号、色彩规则，结尾再装回去。——智力上漂亮，但前 3 秒没有节拍钩子，节奏感弱。
3. **数拍 → 加速 → 全停 → 例外 → 锁版（选定）**：数字 1-2-3-4 踩拍，TEMPO 按网格模块一拍一 snap，拍子越来越密直到一个下拍"全停"；一小节静默后，唯一的红色圆点无视网格地滚过所有元素，最后一切重排锁成一组音乐节海报。
   - 选它的理由：故事本身就是"节拍"——系统建立（数拍）、系统加速到极限（加速）、系统停摆（静默）、例外出现（红点）、例外被吸纳成作品的核心（海报）。一主体（节拍系统）、一目标（成为一张海报）、一转折（例外）。
   - 开场不用"空网格生长"的套路，用 STYLE §11 的"巨大数字充满画面，原来只是小版面里的一个细节"：第 0 帧就是一个充满画面的 **1**，镜头一拍一级地拉出。
   - 结尾呼应开场：拉出成**四张海报 1·2·3·4**（同一套程序生成的系列），开场数的 1-2-3-4 变成了四个舞台；只有第 4 张带红点。

## 1. Logline 与弧线

**一套严丝合缝的节拍网格被自己越推越快、直到停摆；一个不守规矩的红点滚过一切，反而成了这张音乐节海报的主角。**

- 建立（0–9 s）：数拍、拼字，一切落在拍上。
- 推进（9–12 s）：四分 → 八分 → 十六分，巨大 4 与 19 px 小注释极端对比，镜头两次推进。
- 转折（12–14 s）：下拍全停，一小节真正的静默。
- 例外（14–17 s）：红点线性、不吸附、半路停顿，滚过 4、注释、TEMPO 条，盖印式叠印。
- 结局（17–19.75 s）：红点落在 TEMPO 的 O 上，全部元素按距离由近及远重排成海报，镜头拉出成四联海报墙。

## 3. 设计系统

- 色：页面 `#EAE9E5`，纸 `#FFFFFF`，墨 `#111111`，灰线 `#D3D2CD / #C4C3BE / #E1E0DB`，信号红 `#E30613`（只给红点一个人用）。
- 网格：12 栏，边距 96，栏距 24，基线 24；纵向 6 行模块（边距 84，行高 132）。栏宽 122。
- 字：Archivo（500/700/800）+ Noto Sans SC（500/700）子集，同一字族栈；≥90 px 字距 −2%；大数字做光学左齐（减去字形左侧空白）。
- 曲线：只用 `cubic-bezier(.7,0,.2,1)`（吸附）和线性（画线、红点）。无回弹、无渐隐、无阴影、无颗粒（mux grain 0）。
- 入场：裁切上升 / 擦除；删除：knife cut（细线划过 → 收缩成中线）。
- 红点：线性、不吸附、可半路停顿；旁边坐标读数从"在网格"变成"离网格"；与黑字叠印（multiply：黑字压在红上）。

## 8. 画面文字设计

- 不是字幕：所有文字都是版面的一部分。左上标题行、右上小节计数、左下拍点方块、右下技术注释，都在栏线上，19 px 中等字重，上方 1 px 细线。
- 加速段注释（四分音符 0.500 秒 / 八分音符 0.250 秒 / 十六分音符 0.125 秒 / 每小节 4 拍）逐行裁切上升，和巨大 4 形成 50 倍字号差。
- 海报：竖排 TEMPO 书脊、巨大舞台号、"节拍音乐节"、日期 11.08—11.10、虚构地点"旧纺织厂 4 号车间"。不出现任何真实机构名。

- `tools/cuecheck.py`：89 个吸附事件全部在整帧与十六分网格上；69 个关键事件与音乐起音偏差 0.000 ms；9 个红点接触事件按"例外"故意离拍；第 7 小节无任何起音，静默后第一声在 14.000 s。

- ffprobe 19.75 s / 474 帧 / 24 fps；ebur128 −13.9 LUFS，真峰值 −2.6 dB；blackdetect 0 段。freezedetect 的三段静止：12–14 s 全停、15–15.5 s 红点停顿、18 s 起定版，都是设计。

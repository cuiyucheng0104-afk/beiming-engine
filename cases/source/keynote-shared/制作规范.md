# 方案 A《展卷》制作规范（三个样片段共用）

设计原稿：`~/Desktop/上影ppt/02-设计方案/方案A_展卷.md`。本规范是落地版，冲突时以本规范为准。
用户的决定：**无旁白**。音效设计必须**卡点、贴合主题**。全片约 3 分钟，这次先做三个片段看效果。

## 1. 三个样片段

| 片段 | 内容（对应原稿分镜） | 速度 | 时长（严格） | 在全片中的位置 |
|---|---|---|---|---|
| 片段一「开卷」 | A0 墨滴开场 + A1 三幅立轴 + A2 二十五方印谱 | A0 自由节拍；A1 起 72 BPM | 8 小节 + 序 = **33.333 s** | 0:00 起 |
| 片段二「材料变奏」 | A7 水墨留白 → A8 壁画 → A9 剪纸 → A10 偶 | 72 BPM | 48 拍 = **40.000 s** | 约 1:16 起 |
| 片段三「燃比娃与揭晓」 | A11 纸雕灯箱新作 → A12 静默后燃比娃迸发 → A13 镜头拉远，立体书三道门 | 96 BPM | 56 拍 = **35.000 s** | 约 1:56 起 |

片段之间以后要无缝接成一镜到底，所以：
- 每段**第一帧和最后一帧都必须是"可接"的状态**：镜头仍在向左平移、纸面连续，不要淡入淡出黑场。片段三的结尾除外。
- 片段一的开场例外，可以从黑场开始。

## 2. 视觉系统（硬性）

- **画幅**：1920 × 1080，**30 fps**（三段统一，便于以后拼接；风格里要求 12 fps 步进的东西，照风格做步进）。
- **镜头**：手卷从右往左看，镜头**持续向左平移**。速度随音乐呼吸：慢段约 120 px/s，快段约 260 px/s。只有片段三 A13 允许镜头拉远或转为透视。
- **纸**：暖白生宣，底色约 `#F2EBDD`，纤维可见。可用 `共用/材质/宣纸.png`、`宣纸_逆光.png` 作纹理，也可程序化生成，但三段看起来必须是同一张纸。
- **墨**：墨分五色，没骨，不勾外轮廓；晕染是真实扩散，不是透明度渐变。
- **唯一强调色**：朱红 `#BE3A2E`，只用于印章和关键数字（25、1960、9 等）。
- **IP 图片**（`共用/IP图_超分/`，已用 RTX 超分放大 2–4 倍）：
  - 只能装在装裱位里出现：立轴、扇面、册页、斗方、窗花框、幕布、灯箱窗口。
  - 占画面 35–55%，不全屏。
  - 用墨晕遮罩、剪开、透光等方式显影。
  - **原图像素不改**：不改色、不变形、不重画、不抠图，不让角色动。允许整体的光照明暗（如月光、灯光照在画上）和纸面纹理轻微叠加（≤15%）。
- **字体**（Google Fonts，OFL，按 TECHNIQUE.md §11 用 `&text=` 子集化放进工程 fonts/）：
  - 竖排题字：**Ma Shan Zheng**
  - 小字注释：**Noto Serif SC**（500 字重），灰墨色 `#5A534A`
  - 印章：朱红方印，印文用 Ma Shan Zheng 反白，边缘做成不规则的印泥残缺
- **文字只用下表里的内容**，不加 PPT 没有的事实：

## 3. 音乐与音效（重中之重）

### 3.1 调式与主题（三段共用，以后拼接时必须对得上）

- 调式：**D 宫五声**（D E F# A B），全片不转调。
- **主题动机**（古琴，`pluck.py` 的 guqin）：
  - 第 1 小节：D4（1 拍）E4（½）F#4（½）A4（2 拍，带吟揉）
  - 第 2 小节：B4（1）A4（½）F#4（½）E4（1）D4（1，泛音收）
- 每段都要**引用这个动机**：
  - 片段一：完整呈示
  - 片段二：笛（flute）在水墨段变奏，琵琶在壁画段变奏
  - 片段三：96 BPM 下古琴加弦乐温暖再现，落在主音 D

### 3.2 乐器（`core/audio/sampler.py` 采样 + `pluck.py` 拨弦 + numpy 合成）

- 古琴、琵琶、二胡、笛，配锣、定音鼓、管钟
- 京剧锣鼓的点子（单皮、铙钹、小锣）用 sfx 合成或采样拼
- 新作段加电子低频脉冲
- **不要泛泛的钢琴加弦乐**

### 3.3 音效必须"卡点 + 贴合主题"

每一个画面事件对应一个**有主题的声音**，并锁在拍上（目标偏差 0 ms，容差 ±1 帧）：

| 画面事件 | 声音 |
|---|---|
| 墨滴落纸 | 一声水滴，接古琴泛音 |
| 墨晕显影 | 毛笔擦纸的沙沙声，结束在拍上 |
| 立轴展开 | 卷轴纸张滑开的声音，止于第一拍，轴头落定一声木击 |
| 印章落纸 | 印泥压纸的闷响，加一声木鱼或板；印谱密集段用木鱼和梆子做成雨点般的节奏型，越来越密，最后一声收住 |
| 数字 477 点数 | 细笔点纸，配算盘珠的嗒嗒声 |
| 壁画纹样生长 | 矿物颜料研磨的细沙声，加琵琶轮指 |
| 剪纸 | 剪刀咔嚓，每一剪一个十六分音符；碎纸落下 |
| 油灯点亮 | 火柴划燃，配一声小锣 |
| 偶段 | 梆子打节奏 |
| 纸雕灯箱一层层亮起 | 每层一声管钟或编钟感的钟音（五声音阶内） |
| 燃比娃 | 先一拍**完全静默**（−60 dB 以下），然后大鼓、铙钹和火焰呼啸同时爆发，这是全片最强的一下 |
| 镜头拉远揭晓 | 环境声从"画里"切到"房间里"：台灯嗡鸣、远处的室内底噪 |
| 立体书翻页、纸门立起 | 纸页翻动的风声，每道门立起一声纸的"啵" |

刻意的静默：片段一开场前 2 秒；片段二水墨段约 3 秒留白（只有一声笛和水声）；片段三燃比娃前一拍。

### 3.4 混音

- 成片响度 −14 LUFS（±1），真峰值 ≤ −1 dBTP
- 静默后的第一下要比周围最响的段落高 3 dB 以上

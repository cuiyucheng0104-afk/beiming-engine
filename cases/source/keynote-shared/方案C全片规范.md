# 方案 C《打开》全片（3 分钟）制作规范

用户决定：做方案 C 全片，约 3 分钟；**无旁白**；音效必须卡点、贴合主题；可以用 5090 生成素材。
基础：20 秒开头已经做好，审片 8.1 分，工程在 `03-制作/C-kaitou/`。全片在它的 three.js 世界上扩展，开头 0–20 s 原样保留。
设计原稿：`02-设计方案/方案C_打开.md`。IP 规则、25 个分类名见 `共用/制作规范.md` §2；开头的视觉、音乐规范见 `共用/方案C开头规范.md`。三份冲突时以本规范为准。

## 1. 硬规格

- **时长 180.000 s**，1920 × 1080，30 fps
- **120 BPM**，4/4，一拍 0.5 s，一小节 2 s，共 **90 小节**
- **全片一个 three.js 世界**：同一张木桌、同一盏台灯、同一本书。书页翻动、拉片、折页、弹起是全片唯一的动作母题
- 章节之间**不硬切**，用翻页、拉片、镜头运动衔接
- 书的结构沿用开头：封面立起做背板，书页做地面；每章翻一页，换一个跨页舞台

## 3. 视觉

- 沿用开头的全部做法，见 `C-kaitou/TREATMENT.md` §0：
  - 台灯模型、HDRI、胡桃木 PBR
  - 群青布面书
  - Noto Sans SC Bold 加 Inter
  - 朱红 `#BE3A2E` 是唯一信号色
  - 纸条标签的样式
  - 卡片带白边，受真实光照
- **IP 图规则**：
  - 整张印成带白边的卡片
  - 卡片可以移动、翻转、受光，图本身不改色、不变形、不抠图、不重画
  - 卡片在画面中不全屏
- **第三章四种材质**要做出真实差别：
  - 宣纸纤维和墨晕
  - 壁画土墙颗粒和矿物色
  - 剪纸刀口和透光
  - 毛毡绒面和追光
  - 可用 `共用/材质/` 里的宣纸、红纸、壁画土墙、棉布幕
- **第五章合作城**（孟菲斯风格）：
  - 暖白纸底、平涂饱和色、深靛描边、紫色硬阴影、小图案
  - 城是从书页里"长"出来的纸模型
- **第六章等距**（等距绘本风格）：
  - 正交相机
  - 地面上的字一个字一拍"印"上去
  - 小人无脸、背影，只在该走的时候走
- **镜头**：每章至少三种运镜；关键时刻主体占画面高 1/3 以上

## 4. 音乐与音效

### 4.1 配乐结构

国风电子放克，**E 羽五声**，与开头一致，主题沿用开头的唢呐感动机。

| 章 | 小节 | 结构 | 写法 |
|---|---|---|---|
| 一 | 1–10 | 开场 | 已有 |
| 二 | 11–30 | 主歌 | 放克鼓组、贝斯、琵琶反拍；每次翻页前一拍鼓组加花 |
| 三 | 31–48 | 间奏 | 每换一档材质，主奏乐器换一件：水墨用 flute 和 guqin，壁画用 pipa 轮指，剪纸用剪刀声做成十六分音符节奏型，木偶用 woodblock 和 erhu；鼓组降到半编制 |
| 四 | 49–61 | 副歌 | 最满；第 58 小节第 4 拍全静；第 59 小节第 1 拍是全片最强的一下 |
| 五 | 62–73 | 桥段 | 最明亮，加 glockenspiel、marimba |
| 六 | 74–84 | 尾奏前段 | 鼓组减到只剩拍手和贝斯，每一步一个和弦 |
| 七 | 85–90 | 结尾 | 主题完整再现一次，第 89 小节第 1 拍合书"啪"，主音收住，余音约 2 秒到片尾 |

### 4.2 动作音效

每个"打开"动作都有专属声音，锁在拍上（±1 帧）：

| 动作 | 声音 |
|---|---|
| 翻页 | 纸的"唰" |
| 折页、卡片立起 | 纸板的"啵" |
| 拉片 | 木头摩擦 |
| 打字 | 短"嗒" |
| 灯光变化 | 开关"咔"加电流变化 |
| 城市生长 | 纸板层层弹开的连击 |
| 门打开 | 门轴纸响 |
| 等距地面印字 | 橡皮章"嘭" |
| 合书 | "啪" |

### 4.3 混音

- 所有动作音效通过侧链压住音乐，保证听得见
- 成片 −14 LUFS（±1），真峰值 ≤ −1 dBTP

## 5. 工程与分工

- **全片工程**：`03-制作/C-quanpian/`
  - 从 `C-kaitou` 复制而来，开头代码保留
  - 交付文件为 `C-quanpian.mp4`
- **模块化**：每章一个画面模块文件和一个音效清单文件，只改自己的文件；共用的书、台灯、相机、翻页由架构负责
- **分段渲染**：`?seg=<章名>` 只渲染这一章的时间范围，供分章自检；整片由合成负责渲染
- **配乐**：一份 `music.py` 按本表写全片配乐（音乐层）。各章的音效清单由合成阶段统一混进去
- **渲染约束**：
  - `node core/render/*` 在 LIB=`@@LEMO_ROOT@@` 下执行
  - 整片渲染前 `export RENDER_SLOTS=4`
  - 分章渲染用 `--workers 2`
- **不得出现** LemoLab、Opus 字样

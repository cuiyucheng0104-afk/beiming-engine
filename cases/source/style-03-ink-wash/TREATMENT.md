# 鹤出留白 · 中国水墨风格样片（19.0 s）

无旁白、无字幕。画面内文字只有题款「鹤出留白」（竖排墨书）与白文朱印「墨戏」。1920×1080，24 fps（STYLE.md 未另定帧率；人物/鹤按 12 fps 一拍二，相机、晕染、水纹走 24 fps）。

## 0. 三个候选结构与选择

1. **一笔到底的手卷**：整片是一幅右向左展开的长卷，山 → 留白 → 鹤 → 月夜松枝，一镜到底。优点：连贯；缺点：缺少"断裂"，静默无处落脚。
2. **一个字的笔画拆成场景**：「鹤」字每一笔开出一个小场景。缺点：变成书法片头，违背"不是 calligraphy title sequence"。
3. **昼 → 静 → 夜 的三段呼吸（选用）**：昼山一笔成形（快、重）→ 留白生鹤（慢、轻）→ 一拍绝对静默 → 鹤唳破静、加速飞越 → 一滴墨晕开入夜（高潮）→ 减速落枝、钤印。理由：故事有明确的"转"（昼入夜），静默和加速/减速都有天然位置；结尾回到开场的山形构图（月下同一道山脊），形成呼应。

开场意象：不是空纸慢慢起，而是 0.6 s 后一笔浓墨"啪"地横扫全画幅成山（3 秒内的钩子）。结尾：钤印后整幅画拉远成全景，题款与印章、山、月、松、鹤合为一幅完整的画。

## 1. Logline 与弧线

一笔墨成了山，山脚的空白里"生"出一只鹤；它飞走、留下一页空纸的寂静，再一声长唳飞越群山，一滴墨把白昼晕成月夜，最后落在一笔写成的松枝上，画家钤印。

- 起：一笔成山、飞白成瀑（墨"有"）
- 承：留白处以淡墨烘出白鹤（"无"即是物）
- 转：静默 → 鹤唳 → 加速飞越 → 墨滴晕染入夜（高潮）
- 合：一笔松枝、落鹤、题款、钤印，拉远成全幅

## 2. 对标

- **上海美影《鹿铃》（1982）**：学——动物形体由淡墨团块 + 少数浓墨重笔构成，动作轻、停顿长，水墨晕染当转场。不学——鹿与少女的角色、任何构图与配乐。
- **八大山人 / 齐白石的花鸟立轴**：学——一只鸟立于一枝之上、四周大面积留白的构图比例，题款位置与印章作为构图的"秤砣"。不学——具体画作的造型与题字内容。
- **古琴曲的"散—按—泛"三音色结构**：学——散音（空弦）做"量"，按音滑音做"情"，泛音做"空"；不引用任何现成旋律。

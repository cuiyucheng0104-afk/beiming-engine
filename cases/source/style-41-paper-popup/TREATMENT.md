# 《纸龙》TREATMENT

风格：纸片立体书（paper-popup）· 1920×1080 · 60 fps（STYLE.md §5"60 fps 适合微距相机"，且 100 BPM 的一拍 = 0.6 s = 36 帧，十六分音符 = 9 帧，所有拍点都能落在整帧上，偏差可做到 0 ms）· 时长 19.8 s · 无旁白、无字幕。画面内文字只有书封与书脊上的烫金书名「纸龙」（Noto Serif SC 子集化，作为书名的烫金设计）和城门牌匾「龙城」、拉片上的「拉」（ZCOOL KuaiLe 圆润童趣字体子集化，按 STYLE.md §4）。

## 1. 三个候选结构

1. **一次翻开的旅程（选用）**：书合着 → 翻开弹出城堡 → 机关运转 → 纸龙出世盘旋 → 静止 → 纸龙自己叼起页角翻页进入夜晚 → 放烟花 → 书合上、书脊特写。首尾都是"合着的书"，书封与书脊两次出现书名，形成书挡式呼应。
2. **同一页反复拉动**：只用一页，每拉一次拉片，城堡多一层机关，最后一拉放出纸龙。结构工整但第三拉之后单调，且没有翻页这一原生招式的位置。
3. **从页缝里看出去**：全片以纸龙视角，镜头始终低在书沟里，最后反打到模糊的房间。很有新意，但城堡、士兵、吊桥这些分镜主体会一直被裁掉，失去"立体书机关"的看点。

选 1：它完整保留总导演的故事、主体与四个原生招式（书打开 / 拉片机关 / 纸作为角色 / 翻页即换场），并且给"静止 → 翻页"留了最干净的位置。

## 2. Logline 与弧线

一本合着的立体书在台灯下自己打开，纸城堡里藏着一条纸龙；龙钻出页缝、绕城一周，停下看了我们一眼，然后亲口叼起页角把白天翻成黑夜，用纸烟花把夜空点亮——书合上，只剩书脊上的名字。

- 起：书翻开、城堡由后往前弹起、拉片放下吊桥、士兵摆动（机械、规整的世界）。
- 转：页缝里钻出纸龙——"机关"变成了"角色"；它盘旋、停下、和镜头对视（静默）。
- 合：龙翻页（纸作为角色 + 翻页即换场），夜空纸烟花高潮；书合上，书脊特写收尾。

## 3. 对标

- **Robert Sabuda《Encyclopedia Mythologica: Dragons & Monsters》式的大型立体书**：学层层 V 形折由后往前升起、一个跨页一种主色、龙身由多张硬卡铰接而成；不学任何具体纸艺设计、构图。
- **微距"桌上小世界"摄影 / 定格片《Kubo》中折纸活过来的段落**：学浅景深、暖色实用光、纸的僵硬折动与"折痕驱动的表演"；不学角色、配乐、镜头。
- 不学：任何书名、角色、旋律、字体设计。

## 8. 画面内文字

无字幕。书封烫金「纸龙」（宋体衬线、金箔质感，随灯光高光）与书脊烫金「纸龙」：Noto Serif SC 900，作为书名烫金的设计选择；城门小匾「龙城」与拉片「拉」：ZCOOL KuaiLe（STYLE.md §4 的圆润童趣中文字体）。两款字体都用 Google Fonts `&text=` 子集化到工程 fonts/。

## 9. 配色

- 现实：胡桃木桌面、暖色台灯、HDRI 室内。书：墨绿布面 + 金箔。
- 白天跨页：天蓝背景板 + 草绿山丘 + 米黄城堡 + 朱红旗/屋顶。
- 夜晚跨页：靛蓝背景板 + 深紫山丘 + 金色月亮，城堡改为灰蓝夜版画稿，窗户亮黄。
- 贯穿全书的强调色：朱红（纸龙身体）+ 金（龙鳞、烫金、烟花）。

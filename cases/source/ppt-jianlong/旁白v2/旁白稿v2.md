# 《见龙》旁白稿 v2

画面和段落时间不动；语速从 0.85 提到约 1.1，空出来的时间补了讲清故事的内容。「旧」是第一版，「新」是改后。

字数：旧 512 字 → 新 597 字

**S01 开场**
- 不变：一座村庄，一副眼镜，一段历史。

**S02 入村**
- 旧：暴雨初歇，调查队连夜抵达一座空村。全村漆黑，只剩一扇窗，还亮着。
- 新：暴雨初歇，调查员阿山随队连夜抵达一座空村。全村漆黑，只剩一扇窗还亮着。

**S03 守村人**
- 不变：窗里坐着守村的老人。车灯扫过窗纸，他头也不抬，只低声哼着一支老调。

**S04 嘱托**
- 不变：老人忽然抓住阿山的胳膊，异常激动，只说了一句：要记住。

**S05 浮现**
- 旧：雨夜檐下，阿山的眼镜回放着老人的歌声。镜片里，浮现出一头青色的鹿影。
- 新：雨夜檐下，眼镜回放老人的歌声，把歌词和山形一一比对，浮现出一头青色的鹿影。

**S06 应验**
- 旧：鹿角奇石，三块虎掌印石。口诀一句一句应验，传说一件一件落了地。
- 新：第二天，鹿角奇石、三块虎掌印石，都在山里找到了。口诀一句句应验，传说一件件落了地。

**S07 绝境**
- 旧：暴雨连夜撤离，泥石流截断了归路。进退之间，只剩上山一条路。
- 新：暴雨再起，队伍连夜撤离，泥石流截断了归路。进退之间，只剩上山一条路。

**S08 蛇颈兔眼**
- 旧：项横生，眼朝东。
- 新：老人的歌成了地图：项横生，眼朝东。

**S09 山形**
- 旧：走到一大块白石前，老人醒了。他像凭着肌肉记忆，指着白石低声吟唱。
- 新：走到一大块白石前，一路昏沉的老人醒了。他凭着肌肉记忆，指着白石低声吟唱。

**S11 归位**
- 旧：六百年的旧物凌空归位，口诀一字一字亮起。这些部件，拼成的是一段一段往事。
- 新：心跳，来自白石。六百年的旧物凌空归位，口诀一字字亮起。每一个部件，都是村里的一段往事。

**S12 闪回·角**
- 旧：角，救命田。荒年里，村长分粮，鹿角岩俯身守着那块田，全村靠它活了下来。
- 新：角，救命田。那年大荒，村长开仓分粮。鹿角岩俯身守着最后一块田，全村靠它活了下来。

**S13 闪回·爪**
- 旧：爪，退豪绅。三块巨石，刻下掌印，不战而退，豪绅再没敢来。
- 新：爪，退豪绅。豪绅带人进山抢地，却见三块巨石刻着掌印，不战而退，再没敢来。

**S14 闪回·眼**
- 旧：眼，守望灯台。崖顶圆潭如龙眼，守夜人挂灯，四百年接力，不曾断过。山洪没淹死过人。
- 新：眼，守望灯台。崖顶圆潭如龙眼，守夜人挂灯望山，四百年接力，不曾断过。山洪来了，总有人先看见，没淹死过一个人。

**S15 闪回·脊**
- 旧：脊，接力山路。梯田，之字石，凿了四百年，一代接一代，铺成龙脊。
- 新：脊，接力山路。梯田和之字石路，祖孙几代一锤一锤，凿了四百年，铺成了龙脊。

**S16 闪回·鳞**
- 旧：鳞，褪鳞成薪。龙褪下的鳞是满山落叶，码成柴垛，成了全村过冬的体温。
- 新：鳞，褪鳞成薪。龙褪下的鳞，是满山落叶。码成柴垛，就成了全村过冬的体温。

**S17 闪回·心**
- 旧：心，白石立约。白石上一纸村规，约立起的那一刻，龙，就有了心。
- 新：心，白石立约。村民在白石上立下一纸村规。约立起的那一刻，龙，就有了心。

**S18 见龙**
- 旧：山脊即龙背，梯田即鳞甲。世事变迁，我一直走在它的身上。
- 新：原来，山脊就是龙背，梯田就是鳞甲。世事变迁，我一直走在它的身上。

**S19 片尾**
- 不变：一部眼镜，看透六百年。

补的内容想讲清楚的几件事：
- 阿山是谁（调查员）；眼镜做了什么（录下歌、拿歌词比对山形）。
- 老人的歌就是地图（S08）。
- S10 的心跳从哪来（S11 开头点明「来自白石」）。
- 闪回各补一点因果：豪绅为什么退、灯台为什么救命、龙脊是怎么凿出来的。
- 结尾加「原来」，把六个闪回收回到「山就是龙」。

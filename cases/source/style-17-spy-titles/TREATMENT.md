# 零点密码 · 60s 间谍片头风格样片（TREATMENT）

无旁白、无字幕。画面内文字只有演职员字卡（虚构职务）和片名。1920×1080，24 fps，≈19.9 s。

## 0. 三个候选结构与选择

1. **线性追逐**：一条街一行字卡，特工从左跑到右，最后撞进片名。——简单，但只有横移一种节奏，没有转折。
2. **倒计时**：十张字卡，每张一个数字，倒数到 0 出片名。——卡拍好，但没有人物、没有笑点。
3. **潜入—追逐—定格—开锁（选定）**：特工翻滚着从一行字卡上坠入情报局 → 透过一个圆（窥镜）被发现，圆匹配剪成「〇」 → 被对手在斜格里追 → 半空定格眨眼（笑点）→ 落在保险箱转盘上开锁 → 最后一格打开，片名「零点密码」拼成。
   理由：它保留了分镜表的故事、主体、转折和四个原生招式（字即布景、字卡即节奏、图形匹配剪、定格笑点），而且整片是「圆」的韵脚：窥镜圆 → 〇 → 转盘圆，三次圆心半径完全一致，片名里的「零」正是这个圆。

开场、结尾、配乐形状的来源都是题目：「零点」= 〇 = 圆，「密码」= 转盘咔哒。

**对分镜表的调整**：分镜写的是「枪管圆形」，STYLE.md 明确「不是枪管开场」，所以改成**窥镜/放大镜的圆**——同样的圆形匹配剪，不碰禁区；BPM 由 132 微调为 **130.9（每拍正好 11 帧）**，让每一个视觉事件都落在整帧上，拍点偏差可以真正做到 0 ms；片名落在铜管长音上照旧。

## 1. Logline 与弧线

一个戴软呢帽、系红领带的特工潜入一张「片头字卡」组成的情报局，被对手追着跑过一行行演职员表，在半空停住眨了一下眼，最后拧开保险箱，拿到的东西就是这部片的名字。

- 起：坠入（字卡是楼梯）。
- 承：被发现（圆 → 〇）。
- 转：追逐加速 → 定格（世界静音，只有他眨眼）。
- 合：开锁 → 静默 → 铜管长音 → 片名。结尾对手才赶到，最后一记短音把他也定住（定格回扣中段的笑点）。

## 2. 对标

- **Saul Bass《桃色血案》（Anatomy of a Murder, 1959）片头**：学平涂不透明墨、剪纸边、爵士大乐队一个重音一刀的剪辑法、大面积单色底。不学它的肢解人形、字形、具体镜头。
- **Kuntzel + Deygas《猫鼠游戏》（2002）片头**：学剪影追逐、横移跟拍、字卡就是布景、底色随地点切换。不学它的角色造型、旋律、标题字。
- 两者都只学语法；旋律、人物、字形全部原创，尤其不碰最著名间谍主题的半音爬行和小大九和弦。

## 5. Cue map

- **速度**：130.909 BPM（每拍 11 帧，0.458 333 s）；4/4；D 小调（D 多利亚色彩，降 B 与还原 B 交替），附点节奏。
- **小节网格**（拍号从 0 起）：

| 段 | 拍 | 小节 | 配器 | 事件（拍） |
|---|---|---|---|---|
| A 坠入 | 0–7 | 1–2 | 铜管 tutti、冲浪吉他、邦戈、走步贝斯、拍刷 | 0 开场重音；2、4、6 着地；7 硬切 |
| B 窥镜 / 〇 | 7–16 | 2–4 | 铜管重音后让位：颤音琴动机、沙锤、贝斯；长笛；弱音小号 | 7 圆；9 匹配剪+字卡；10 角色字；12 探头；13 对手；15 推进开始；16 冲入 |
| C 追逐 | 16–24 | 5–6 | 全乐队，邦戈 16 分，铜管重音在切换点 | 16 / 20 / 22 / 23 底色切换；每拍一步 |
| 定格 | 24–26 | 7 | 第 24 拍最强 tutti 后真静音 | 24 定格；25 眨眼（磁带咔） |
| D 转盘 | 26–33 | 7–9 | 贝斯 + 低长号持续音 + 颤音琴跟随咔哒；31 后近静默 | 26 落地；27、28、29、31 咔哒；31–33 近静默 |

## 7. 字卡与片名设计

- 字卡（虚构职务，不出现真人名）：「零点情报局」「出品」/「原著」「第〇号档案」/「编剧」「破译组」。思源黑体式的粗壮 CJK 显示字（站酷庆科黄油体，OFL，`&text=` 子集），字形轮廓取出后**逐字重剪**：边缘噪声、±0.8° 旋转、±1.5 px 基线抖动，剪缝 + 纸影。
- 片名「零点密码」：**自制几何剪纸字**——由直切条和圆弧拼成，笔画粗细不匀、基线错落，不用任何现成字体。芥黄色片名衬黑色墨线底，是画面里最亮的东西（追逐对象）。
- 无字幕条。每行字卡都有一段完整可读的时刻，并满足 readcheck 的阅读时长。

## 8. 配色

黑 `#1b1714` / 奶油 `#efe4c9` / 红 `#d23a22` / 芥黄 `#e2a52a`，外加它们的暗色「阴影纸」。每场一个主底色：A 奶油、B 黑、C 奶油→芥黄→红→奶油、定格红、D 芥黄、E 黑。红只给特工领带和「危险」（追逐最急的一拍和定格）。

## 9. 制作后记（实现与自检时的调整）

- 片名揭示改为**保险箱门绕左铰链转开**（不用分镜原写的切条滑开），碎片沿 30° 斜线从画外飞入，第 34 拍落定。
- 定格那一拍改成**硬切进大特写**，眨眼在缩略图尺寸也看得清。
- 每个乐音都按「包络半高点」对齐到拍上（mix.py 的 HG / half_rise），不再手调 8 ms 提前量；tools/cuecheck.py 实测核对。
- 与 demo 对比（DIRECTOR §11）：结构（坠入—窥镜—追—定格—开锁 vs. 偷钥匙多地点追逐）、开场（字阶翻滚 vs. 锁孔冷开场）、招牌镜头（窥镜→〇→转盘→「点」的圆四次韵脚 vs. 斜格碎片拼片名）、运镜路线、配乐形状（无旁白、片名前近静默、片尾木鱼定格 vs. 旁白 + 片名后静默 + 邦戈）、结尾（帽子扣上片名定格 vs. 推进锁孔）——六项全部不同。

## 10. 返修记录（审片意见逐条）

- **推进〇的落点跳变（7.29→7.33 s）**：推进的放大率和横移都改为缓入缓出（eio），最后几帧连续收敛；第 175 帧〇内圈已大于画面对角线的一半，内圈里的追逐场缩放 ≈0.99，第 176 帧硬切到 1:1 时没有尺寸跳变。
- **红底追逐剪影压字**：追逐段两个人物的剪影外缘剪缝由 2.4 px 加宽到 4.5 px（底色剪缝），黑剪影叠在黑字柱上也能分开。
- **片名前近静默不够静**：第 31 拍最后一咔后，颤音琴与低音提琴拨弦改为短音（release ≤ 0.15 s），长号持续音提前收；第 31 拍 + 0.2 s 起全部乐器与拟音 20 ms 淡出，只留压低的磁带底噪（实测见交付报告），在第 33 拍长音组的第一个采样前 3 ms 重新打开。
- **片尾对手挡住「点」的四点**：急停点左移到「零」与「点」之间的下方（x = 640），他抬头看帽子，不压字。
- **第 12 拍探头太小**：特工从「号」顶上冒出半个上身（帽、脸、红领带、扒字的手），腿藏在字后；同拍镜头轻推 1.1 倍并上移（再推就会把左侧「第」或右侧「号档案」裁出画，读字时长自检不过），第 13 拍拉回，对手在拉出时从画左走进来（拉出揭示）。「原著」字卡移到「档案」上方，不再与特工重叠。运镜种类增加「轻推 / 拉出揭示」。
- **「零」字形像「雩」**：字体的「令」部被画成平顶 + 回钩；glyph.js 里把这三块轮廓换成手剪的「人」字顶 + 点 + 横撇 + 竖点（字体单位手工几何，再统一剪边）。
- **体积**：mux 之后只重压视频（crf 23），音轨原样拷贝。

# 64 · 1920s 新闻影片 ·《空中竞速》TREATMENT

风格：lemo-opuscar `newsreel`（1920s 有声新闻片）。1920×1080，24 fps，19.75 s。

事实（FACTS.md）：1929 年全国飞行巡回赛 10 月 5 日从迪尔伯恩出发、绕经加拿大和美国东部南部中西部回到迪尔伯恩，全程 5107 英里（1929-10-05 美联社电稿原文 "the 5,107 mile tour"；维基百科另有 5,017 的写法，采用一手报纸）。

## 1. 三个候选结构

1. **一次出发到归来（单程旅行）**：片头 → 号外 → 航线地图绕一圈 → 一架架放飞 → 停 → 归来落地被圈出。按分镜原样，线性、有起承转合。
2. **倒计时**：从 "29 架起飞" 数到 "1 架归来"，每一拍少一架。数字太多，无旁白时观众要读字，15–20 秒读不过来。
3. **双屏对决**：两架飞机分屏竞速，推挤出画。好看但素材里找不到同一场的两机对拍镜头，且偏离分镜的原生招式。

**选 1**。理由：分镜的四个原生招式（片头仪式、旋转报纸、地图展开、网格发牌→翻页）天然是一条线；结尾的 "落地 + 油性笔圈出" 与开头的 "地球 + 探照灯" 首尾呼应（从世界到一个点）。

## 2. Logline 与弧线

一纸号外宣布空中竞速，航线在地图上绕北美东部一整圈（5107 英里），飞机一架架被旗手放飞——乐队戛然而止——全场的第一声巨响里，赛机一架接一架滑回来，最后一架停到镜头前，驾驶舱里的飞行员被油性笔圈住："终点！"

- 设定：片头仪式 + 号外（世界在看）。
- 发展：地图航线 5017 英里，网格发牌，越发越快，翻页成动画。
- 转折：乐队急停，只剩放映机声（近静默 1 秒）。
- 结尾：静默后的全奏 + 降落 + 定格圈出，"da–DA!" 收。

## 3. 对标作品（只学语法）

- **Fox Movietone / Universal Newspaper Newsreel（1927–1930）**：学片头仪式的节奏（探照灯→地球→厂牌落定），学 "一地一事一素材"，学乐队急停给包袱。不学：厂牌名、地球造型、字体、号角旋律。
- **好莱坞旋转报纸蒙太奇（1930s）**：学旋转衰减→砸停→推近的三段式。不学：任何具体报头。
- **约翰·菲利普·苏萨式美国军乐进行曲**：学 oom-pah 低音、小军鼓、短号旋律 + 单簧管对位、"stinger" 收尾。不学：任何具体旋律。

## 6. Cue map

- **BPM 120，4/4，小节 = 2.0 s**，降 B 大调（军乐标准调）。全片 9.875 小节 = 19.75 s。所有视觉事件落在 8 分音符网格（0.25 s = 6 帧）上，翻页落在 16 分音符（0.125 s = 3 帧）。
- 编配（STYLE.md §7 的声音调色板，改成军乐编制）：小号（开放/弱音）、长号断奏、大号断奏（1、3 拍）、圆号、单簧管断奏（三度/六度和声）、短笛（结尾）、小军鼓、低音大鼓、镲、定音鼓、钟琴、木鱼（pickup）、班卓（pluck.py，地图段四拍扫弦）。**不用钢琴、不用弦乐。**
- 段落：
  - A 片头 fanfare（m1–m1.5）：定音鼓 + 小号/长号号角。
  - B 进行曲主题（m2–m3，b7–b12）：全奏 oom-pah + 小号旋律。
  - C 地图（m4–m5.5，b12–b22）：弱奏，弱音小号 + 单簧管 + 班卓 + 电报嘀嗒，渐强到 b20 和弦。
  - D 发牌加速（b22–b28）：节奏从 4 分 → 8 分 → 16 分，小号半音上行，加速。
  - E 急停（b28–b30）：一记刺 + 静默。
  - F 归来（b30–b39.5）：全奏大和弦，半拍感的宽阔旋律（减速），17.00 定格时只剩长音，"da–DA!" 收。
- 节拍核对：`tools/cuecheck.py` 读 timeline.json 的视觉事件和 score 的音乐事件，逐一比较（目标 0 ms）。

## 10. 制作后记（与演示片对照、实测）

- 与本风格演示片对照（结构/开场/招牌镜头/运镜路径/配乐形状/结尾 六项）：结构（单程出发→归来 vs 两方辩论+裁决）、招牌镜头（油性笔圈出降落的飞机 vs 唱片接管）、运镜路径、配乐（120 BPM 军乐进行曲 vs 200 BPM 查尔斯顿乐队+78 转唱片）、结尾（定格 da–DA! vs 片头重演+片尾卡）五项不同；开场同为片头仪式（分镜指定的原生招式）。
- 画面层级：真实档案（1927/1929 福特巡回赛影片、1929-10-05 报纸）+ 代码绘制的包装（厂牌、报纸道具排版、地图、网格板、油性笔）。
- 拍点：所有视觉事件写在 timeline.js 的拍子上（8 分音符网格，翻页 16 分音符），`tools/cuecheck.py` 三重核对：乐谱 0 ms、视频硬切/翻页帧 0 帧偏差、混音实测起音 −25…+27 ms（铜管采样自身的起音坡度，≤ 1 帧）。
- 实测：时长 19.75 s，−14.0 LUFS，真峰值 −1.1 dBTP，blackdetect 无黑帧，readcheck 全部通过。

## 11. 返修记录（审片意见逐条）

- 15.00 全片最重要的一声：远空小飞机（占画面高 5%）换成 200-FC-1224 源 269.40 s 起的 6 号赛机滑入镜头，机身占画面高约 40%，白机身 + 尾翼号码在银灰调里最醒目。
- 3.00 报纸起转：起始尺寸从门高的 14% 提到 34%，3.00 那一帧就能认出是报纸，不再是空灰底。
- 5.00 punch-in、13.00 俯冲进格：拍点那一帧直接到 62% / 85% 进度；17.00 定格：震动改为余弦起振（拍点帧就满幅位移）+ 闪白 0.6。`tools/cuecheck.py` 的画面核对新增这三处（paper_punch / dive / freeze），要求最大变化正好落在拍点帧。
- 地图城市标签：Noto Sans SC 600 30 px（STYLE §4 上限），取消淡入，到拍点那一帧就完全不透明。
- 定格：定格帧单独走一遍更强的降噪 + unsharp=5:5:0.8，推镜 6% → 3%，圈从一大片机身收小到驾驶舱飞行员；"终点！"字距收紧（LongCang 字面小、默认字距显得松散，letterSpacing −34 px）。
- 体积：mux.sh 只负责 −14 LUFS 音频（grain 0），最后一步单独加 grain 7 并用 -crf 18 -maxrate 18M -bufsize 36M 编码（成片约 45 MB），不加 -shortest 以免 AAC 尾帧短 10 ms 把画面截掉 3 帧。

# 四连关 · TREATMENT

风格：微游戏快闪（microgame）｜1920×1080，24 fps（STYLE.md 未规定帧率）｜时长 19.0 s｜无旁白、无字幕，画面内文字只有指令词与 UI。

## 0. 三个候选结构

| | 结构 | 评价 |
|---|---|---|
| A | **接力**：每关结果是下一关的道具（接住的苹果→被雨淋→……） | 因果链好看，但四个任务之间没有天然的物件传递，硬接显得做作 |
| B | **一天，一关一个时段**：早上接苹果（早饭）→ 出门躲雨云 → 晚上刷牙 → 睡前关灯；BOSS 是"边吃苹果边关灯"的手忙脚乱；主持人是一只**闹钟** | 四个任务本来就是一天的作息，节拍加速＝一天越过越快；结尾自然是"天黑、闹钟睡着" |
| C | **倒带开场**：先看 GAME OVER 画面再倒回去 | 15–20 s 太短，倒带要占 2 s 解释成本 |

**选 B。** 开场画面＝清晨蜡笔太阳（直接在游戏里，指令已在砸下），结尾＝整个舞台被最后一下关灯泡进夜色，闹钟主持睡着——首尾一昼一夜呼应。乐曲形状随之定为"越走越快 → 断电式静默 → BOSS 全开 → 摇篮曲式收尾"。

## 1. Logline 与弧线

**一个戴红帽的小豆子用 19 秒过完一天：接苹果、躲雨云、刷牙、关灯——每关换一种画材、越来越快，最后一关要一边接苹果一边关灯。**

- 建立（0–4.6 s）：闹钟响铃、舞台亮灯，推入电视；蜡笔关接住！成功，缩回电视盖 ✓，三颗心。
- 转折（4.6–7.8 s）：像素关躲开！失败——雨云追着淋了一头，✗，玻璃碎，心 3→2。
- 加速（7.8–12.4 s）：网印关刷牙！成功 → SPEED UP!（131→144 BPM，关卡变短、角色帧率 8→12 fps）。
- 高潮（12.4–18.0 s）：水墨关关灯！墨色一拍淹没纸面 → 舞台跟着断电成一束顶光、闹钟停摆、1.25 s 静默 → **BOSS!**（160 BPM）：蜡笔半屏与水墨半屏从两侧撞合，网印剪贴小豆子一手接苹果一手拍开关。
- 结局（18.0–19.5 s）：一拍拉回，墨色从电视漫上舞台，"通关！"盖章，闹钟响一下后睡着。

## 2. 对标

| 对标 | 学什么 | 不学什么 |
|---|---|---|
| 《节奏天国》系列 | 动作＝拍点；失败也必须卡拍且靠声音就能听懂；每关一个小乐器音色 | 角色、关卡、旋律、UI |
| Michel Gondry《Star Guitar》MV | 画面事件逐个锁在乐器音上，观众"看见"节奏 | 火车车窗母题、镜头 |
| 类型语法参照：STYLE.md 指明的派对小游戏系列 | 指令词→一个动作→结果；关间回主舞台；越来越快 | 名字、角色、界面、关卡、音乐一概不用 |

## 3. 主角、主持与固定舞台

- **主角小豆子**：圆脑袋、**红色毛线帽＋绒球**、两颗点眼。四种画材里都保留"圆头＋红帽＋点眼"，红色是跨画材的追踪色（蜡笔红 / 像素红 / 网印荧光粉版 / 水墨朱砂点）。
- **主持人：双铃闹钟**，有脸有腿，每拍"嘀嗒"一跳、指针跳一格；静默时停摆（最强情绪工具）；结尾响铃后睡着。
- **主舞台**：紫 `#2a0f5c` 地＋旋转放射光，品红 `#ff2e88`、金 `#ffc928`、青 `#1fd1d1`；成功色 `#3fe08a`（✓）、失败色 `#ff4a1c`（✗）只用于印章与生命板。7 px 近黑描边＋一道硬边阴影。画中画＝舞台中央一台 16:9 圆角电视（宽 40 %），左上生命板（三颗心），右上关卡牌，闹钟站在电视右侧。

## 9. 文字设计

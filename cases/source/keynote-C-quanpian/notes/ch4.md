## 0. 自行做出的决定（无人可问，记录在此）

1. **跨页色族 = "奇谭夜"**：背板是深靛青夜空（金线星宿 + 浅青祥云纸条 + 远山剪影），地面是淡青瓷色纸（金色同心水纹 + 书页一贯的朱红双细框）。上一跨页是第三章的材质墙，下一跨页是孟菲斯小城（暖白），夜色让本章自成一个颜色单元，也让"窗亮起""灯打亮"真的有意义。
2. **纸塔不是向前扣倒再立起，而是从书缝里"弹"出来**：塔高 0.25 m，比书页深度（0.274 m）还长，扣倒放不下（向前扣会伸出书外、向后扣会穿过背板）。所以四层塔身各自藏在书页下面，在拍上从切缝里向上弹出（`back()` 回弹，第一次到位 = 拍点），同时 V 形折页从 0 打开到 0.2 弧度。立体书里的"伸缩塔"机关。
3. **塔从前往后长（低层先出）**：开头的折页是从后往前立，但"塔弹起"要读成"长高"，低层先出、最高层最后出，第 50 小节第 1 拍塔顶落定。这是有意的例外。
4. **塔身用白墙、朱红立柱、深靛瓦檐、金色窗框**：深色夜空背板上白塔最显眼；朱红只用在立柱和塔刹宝珠上，仍是唯一信号色。
5. **纸轨是开头那根赭色带齿纸轨的弧形版本**（呼应开头剧照卡沿纸轨上升），从塔后的切缝里升起，越过塔顶。鲸鱼卡片骑在轨上滑行，卡片随轨道切线倾斜（最多 22°），图本身不动。开头是"每个八分一齿"的爬升，这里改成**连续滑行、到塔顶减速悬停**，避免重复。
6. **标题牌**：本章不用开头的打字纸条，改成一块米白纸板标题牌（墨框 + 朱红小方块 + 大字标题 + 小字），整块在拍上立起。左前方一块牌子先后承载「中国奇谭」→「中国奇谭 2」→「燃比娃」三段（森林段扣倒，燃比娃时带着新内容重新立起 = "翻到下一面"）；森林里另立一块「浪浪山小妖怪」。
7. **「中国奇谭 2」= 在原标题后面盖一枚朱红「2」的章**：第 53 小节第 1 拍"嘭"一下，同时小字从左到右刷成「9 部独立短片｜12 位导演｜2026.1.1」。续集 = 原牌子加盖一枚章。
8. **四扇窗 = 四对朱红窗棂小门**：塔身二、三层各两扇；第 53 小节第 2、3、4 拍和第 54 小节第 1 拍依次打开（左下 → 右下 → 左上 → 右上），窗里是《中国奇谭 2》四部的卡片，窗内一盏小暖灯随之亮起（真实点光源，照亮卡片，卡片不改色），窗下的片名小纸签同时向下翻出。
9. **全静一拍 = 全黑一拍**（设计原稿 C7"燃比娃前一拍全黑"）：115.467 起台灯 0.1 s 熄到 3%、环境光压到 5%，静音（`sound:false`，不响开关）。黑暗里前景森林、浪浪山卡片和牌子悄悄收回（只剩远山林带与塔的剪影）。
10. **最强一下**：115.967 起台灯 0.12 s 内转向 16°、对准燃比娃卡片、亮度冲到 1.5 倍（共用层自动配开关"咔"+电流 + 关节摩擦）；116.000 燃比娃卡片立起落定，卡片后面一把朱红/金色宣纸折扇"唰"地打开成一圈光芒（"打开"母题的最后一次放大）；同一帧泛光冲到 0.6 后 1.2 s 回落，镜头快推。0.6 s 后台灯回到 1.0（无声）。
11. **燃比娃的扇骨用宣纸材质**（`共用/材质/宣纸.png` 的纤维叠在扇面颜色上）——对应"宣纸手绘"。
12. 鲸鱼卡片停到轨道右端后一直停在那里（森林段在林梢上方露出来），不另做退场；燃比娃之后塔与鲸鱼都留在暗处做剪影，第 61 小节随书页摊平一起被压平。
13. IP 图：本章 7 张图复制到 `material/ch4/`（与 `共用/IP图_超分/` 逐字节相同），全部用 `kit.card` 整张印成白边卡片。

## 4. 声音设计（本章 `sfx/ch4.json`）

- 床：配乐副歌最满（作曲）+ 房间底噪 + 随台灯亮度的灯管嗡声（共用）。115.5–116.0 全静（作曲与本章都不放声；台灯熄灭不响开关）。
- 纸塔：一层一声"啵"，音高逐级升；塔顶一声钟琴 A5。
- 纸轨：纸片滑出"嘘"止于到位 + 纸边"嗒"。
- 鲸鱼：起步一口空气"呼"（1.4 s），到塔顶一声钟琴 D6（全章最高的音，像鲸歌），落定纸边"嗒"。
- 盖章：橡皮章"嘭"。
- 四窗：窗门"扑" + 钟琴 E5 → G5 → A5 → B5（E 羽五声上行）。
- 森林：纸板连击 + "嘘"（林带），"啵"（卡片、牌子），纸面平推"沙"（草丛）。
- 最强一下：共用层的开关"咔" + 电流 + 关节摩擦（115.967）→ 116.000 暖光"轰"（`burst`）+ 折扇"唰"（`flap` 大）+ 卡片"啵"。

## 5. 实测与返修记录（2026-11-02）

- 分段渲染 `sh tools/seg.sh ch4`：780 帧 / 26 s，约 1 分钟；联系表 `out/seg/ch4_sheet.jpg`。
- 音效：本章 29 条，`out/seg/ch4_mix_cues.json` 里实测落点与计划全部 0.00 ms；全静拍 115.55–115.95 s 混音 −37 dBFS RMS（只剩房间底噪），116.0–116.6 s −10.3 dBFS（本章最响）。
- 文字：`window.TEXTS` 抽样（101 / 106.5 / 112 / 117 s）全部是 `TEXT.ch4` 原串；只上报画面内看得见的框，下层两扇窗的片名在林带升起后不再上报。
- 返修一轮：① 窗门做成两张背靠背的纸（背面朱红内板），开门角从 112° 收到 93°；② 标题牌与燃比娃卡片错开（燃比娃右移到 x = .068，标题牌加宽到 .19 m、小字 7.9 mm），燃比娃小字不再被卡片压住；③ 森林段、鲸鱼段、四窗段的镜头左移，让左/右标题牌整块入画；④ 全黑一拍：共用层的 dim 不管轮廓光，本章在窗口内把 rim 一起压到 40%，窗灯留 55% 当"黑暗里的小灯笼"，画面均值约 8/255（不是纯黑帧）；⑤ 折扇改成从两侧水平位置向上展开，116.000 那一帧已经展开约一半；⑥ 燃比娃段光圈收到 40%，标题牌小字清楚；⑦ 地面切缝减淡。
- 已知：塔左侧的空白纸条标签、圆月、整块米白/藏青背板是第二、三章挂在背板（`spread(n).back`）上的件，在后面的跨页里穿过本章背板露出来（共用层没有按跨页窗口隐藏背板挂件），见返回的 requests。

一个 three.js 世界贯穿全片：同一张胡桃木桌、同一盏台灯、同一本群青布面立体书。章节之间不硬切，全部用翻页、拉片、镜头运动衔接。

## 0. 合成阶段的决定（没有人可问，自行决定，记录在此）

1. **背板挂件按跨页显隐（共用层 world.js）**：第 n 页的背面是跨页 n+1 的背板，上面的挂件（第二章的日芒、月亮、2d 标签，第三章的翻板面板，第五章远半页的城，第七章远半页的「谈」色带）现在只在跨页 n+1 的可见窗口里显示。修之前，第三章的藏青面板加「木偶」字会穿过第四章的夜空背板（106.5 s、118.5 s），摊平后还会盖住第五章远半页的城。第五章原来的兜底代码不删，和新规则叠加也没有副作用。
2. **台灯熄灭时轮廓光跟着暗（共用层）**：dim ≥ 0.25 时轮廓光不变（2c 月夜 0.25、木偶追光 0.28 都保持各章审过的样子），低于 0.25 时按 dim/0.25 等比压暗。115.5 s 全黑那一拍纸件边缘不再发亮。第四章自己压的 40% 叠在上面，结果更黑。
3. **开头标签的文字上报截止到 20.86 s**：第二章在 20.5 s 用 0.36 s 把「角色，是进入内容的入口」扣倒，之后画面上看不到这句，所以 readcheck 的文字框也到 20.86 s 为止。
4. **限幅天花板从 −2.2 改为 −3.0 dBTP（mix.py）**：低清预演实测，−2.2 时 AAC 解码后在 120.5 s、132.0 s 冲到 −0.9 dBTP，超过规范的 −1。改成 −3.0 后成片真峰值 −1.2 dBTP，这个值由开头的原母带决定，尾段更低。全片响度仍是 −14.1 LUFS。
5. **全静拍更静（mix.py）**：115.5–116.0 s 环境层只留 35% 的房间底噪，这一拍不走钟表。混音实测这一拍峰值 −36 dBFS、RMS −46 dBFS，之后 116.0 s 是全片最响的 400 ms（−11.4 LUFS 的第四章里最强）。
6. **海报改为结尾封面（179.5 s）**：封面上是片名「上美影 IP 全景」、「选定方向 · 开始洽谈」和开头那条数字条，一张图就能代表全片的"打开"和"洽谈"两头。116.5 s 燃比娃那一帧只代表一部作品，所以没有选。
7. **第三章的音效导出脚本收进工程**：原来在会话临时目录里，现在是 `tools/gen_sfx_ch3.mjs`，导出结果与现有 `sfx/ch3.json` 逐字节相同。
8. **cuecheck 的帧数解析修正**：原来 ffprobe 返回 `5400,` 时脚本会报错。
9. **各章只要不影响成片，我都没有改**：五个章节模块、五份音效清单和配乐都按交付原样使用。各章 issues 里写明的取舍（卡片立起前背面朝上、转盘侧面的灰条、木偶标题在推近时被切）都看过，保留。

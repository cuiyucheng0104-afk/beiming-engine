# 鲤鱼跃龙门 · 红色窗花剪纸风格样片（19.5 s）

## 0. 简报
- 风格：红色窗花剪纸（papercut-red），1920×1080，24 fps（STYLE.md 未规定帧率，取默认）。
- 无旁白、无字幕。画面内文字只有门楼匾额「龙门」和结尾斗方「福」，都是剪出来的字（阳刻/阴刻，笔画是真孔）。字体：Noto Serif SC 900（OFL），Google Fonts `&text=` 子集化到 `fonts/`。
- 配乐全部代码原创；乐器只取 STYLE.md 声音调色板。分镜原写「唢呐 + 锣鼓 + 梆子」：唢呐和戏曲锣鼓经不在调色板里（STYLE.md 明确说不要皮影那种戏曲打击乐），所以改成**梆子 → woodblock**，**锣鼓 → 小锣 + 一记大锣 + 框鼓**，**龙门一跃的唢呐长音 → 笙（numpy 簧片合成）+ 笛（flute 采样代笛）+ 二胡同度长音**。这样保住「一跃时一声长音冲出来」的意图，音色仍是明亮的民族室内乐。

## 1. 三个候选结构
1. **单程旅程（选用）**：一张纸 → 剪 → 展开成鲤鱼 → 鲤鱼复制成梯 → 跃门 → 变龙 → 福字落定。分镜原意，原生招式按顺序层层加码，高潮正好落在「展开」这个剪纸最本色的动作上。
2. **前后对照**：开场就是成品龙形团花，一片掉下来变回鲤鱼，倒叙回到红纸。好看但 20 秒里倒叙会吃掉「剪」的过程，砍掉。
3. **倒数式**：门楼上 8 盏灯，每跳一条鲤鱼灭一盏/亮一盏，到 0 时跃门。节奏清楚，但会把高潮变成计数器，弱化「折-剪-展」，砍掉。

选 1 的理由：故事本身就是「一次折、一次剪、一次展」被放大两次（鲤鱼一次，龙一次，福一次），三次展开形成同一种语法的回声：开头一张纸对折，结尾一张小方纸对折，首尾呼应。

## 2. Logline 与弧线
一张红纸被对折、剪开、展开成一对鲤鱼；鲤鱼一节节对称复制成梯，最后一条在全片唯一的静默里悬停于龙门前——一跃而过，展开成龙形团花，一张对折的小方纸剪出「福」，落定中央。
- 起：白天桌面，一张红纸（手作）。
- 转：纸面揭走，夜色与龙门出现，鲤鱼复制攀升，静默悬停。
- 合：跃门展开成龙，福字落定（再一次折-剪-展，回到手作）。

## 3. 对标
- **McLaren《Synchromy》《Begone Dull Care》**：学「每个可见事件就是一个声音」，画面锁死在节拍上；不学它的抽象图形和配乐。
- **上海美影 1960 年代剪纸片的水波与层叠（如《金色的海螺》）**：学纸层视差、水波由月牙/锯齿刻出、金色只留给一处；不学任何角色、造型、镜头。
- 不拿 demo 的故事、镜头、时间线（demo 只在本文件写完后用来学 paper/fold/light 技法）。

## 9. 制作后补记（与 demo 对照 + 实现时的调整）
- **与 demo 对照（6 项中 5 项不同）**：结构（单程旅程 vs 村庄驱年兽）不同；开场（俯拍落纸 vs 剪刀尖冷开场）不同；招牌镜头（鲤鱼梯 + 静默悬停后展开成龙 vs 窗上背光团花投影年兽）不同；运镜路线（一镜到底：推→跟剪→拉→揭纸→升→缓推→急拉旋转 vs 多场景切换）不同；结尾（福字落定锁定 vs 拉出到真实窗户）不同。配乐形状（静默后大锣）相近——这是分镜指定的高潮设计，保留。
- 主鲤起跳改为从窗花的「珠」上方弧线跃出（避免红鱼叠在红窗花上看不清，也让它不挡住「龙门」匾额），最高点抬到门楼屋脊之上。
- 「福」的金箔在小方纸落下时一起落下（垫在下面），避免红纸叠在红色圆心上分不清；展开时金色从字孔透出。
- 唢呐 → 笙（numpy 簧片加法合成）+ 笛（flute 采样叠膜噪）+ 二胡同度长音，见第 0 节。
- 所有子拍事件（八分/十六分剪、复制）取整到最近帧，画面、拟音、配乐里与之对应的音符用同一个取整时间（与理想网格最多差 20.8 ms，拍点上的事件本来就在整帧上，偏差 0）。

## 10. 返修记录（审片意见逐条处理）
1. **剪刀未到先有镂空（1.6–2.2 s）**：b3 折痕帧改为完整未剪的红纸。剪痕遮罩在第一剪（b5）之前长度为 0，剪口只沿剪刀轨迹生长，刀尖附近的遮罩圆半径收窄（刀尖处约 12%，向后约 70 单位内长到全宽）。「福」的小剪段用同样的写法。
2. **静默段主鲤挡住「龙门」（13.5–15.2 s）**：主鲤悬停点从 y −1400 抬到 −1720（门楼屋脊上方），团花中心 ROSC 跟着上移，静默推镜的终点改为 z 1.25，对准鱼身下沿。整个静默段里匾额都完整露在鱼尾下方。静默时匾额的灯只降到 0.75，窗棂和窗户照旧收暗。读字检查覆盖到 b28。
3. **鲤鱼梯红叠红（10.5–13.5 s）**：同一列中相邻的鱼交替用亮一档的纸（#e4503a）和深一档的纸（#a3121a），每条鱼另刻一道内轮廓阴线。每条鱼外面有一圈约 18 单位的深靛「底纸缝」，在画面上是 6–8 px。背光层单独合成：近处鱼的缝会擦掉后面那条鱼的发光，团花出现后又把梯子的发光盖住，bloom 不会把缝糊上。
4. **门楼像高脚（8.7–10.5 s）**：升镜提前。b17 揭纸收尾，b17→b18 急升加拉远，b18 门楼落地那一刻屋顶已经在画内，整座门楼从地面翻起，可以完整看到；翻起过程中门板压暗（背面）。
5. **b28 团花像斜向划像**：b28 起远景层（门楼、山）盖一层先深后浅的暗幕，门楼同时后退缩小 10%。折叠包下面露出 6 层错位纸厚，沿两条折边画折痕；b28.5 半展开、b29 全展开时纸厚逐层减少。
6. **双龙龙头块状**：重画龙头。楔形头骨加卷起的鼻球，张嘴并刻出上下牙，有火焰眉、月牙眼（上下眼睑加瞳孔）、鼻孔卷纹、腮部卷纹，两支鹿角形角的末端是卷云，下颌挂锯齿须，脑后是锯齿鬃，颈部补实，不再有方形空洞。龙头锚点略向内收，并上仰 0.2 rad 对着宝珠。片尾彩屑从 34 片加到 120 片，连续落向团花并向中心收拢；福字落定后背光有轻微呼吸，锁定段不再像冻结。

所有拍点（timeline.js）、事件表、配乐与拟音时间都没有改动，时长仍是 19.5 s。

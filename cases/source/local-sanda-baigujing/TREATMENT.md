# 三打白骨精 · 皮影戏 — Treatment

## 1. Logline 与弧线
**一句话**：白骨精三次化作凡人骗唐僧，悟空三次识破、三次挥棒；唐僧肉眼只见"打死了人"，把悟空逐出师门——只有转到幕后，才看得见台前那三个"人"原是同一副骨头。

- **起**：一盏灯点亮幕布，白虎岭上师徒饥饿，悟空驾云化斋。
- **承**：白骨精三变（村姑 / 老妇 / 老翁），悟空三打；唐僧一斥、二念紧箍咒。
- **转**：第三打前的静场——悟空回头看师父，明知要受罚，仍然举棒；老翁在铆钉处散架，现出一堆白骨。
- **合**：唐僧写贬书，悟空三拜辞师驾云而去（离布、虚化、融进灯里）。镜头绕到幕后：三个化身和白骨挂在同一根竹竿上。"台前看是人，幕后原是骨。"

## 2. 标杆（学什么 / 不拿什么）
- Lotte Reiniger《阿基米德王子历险记》(1926)：学侧身表演、剪影叙事、镂空布景；不拿任何角色造型与镜头。
- 陕西 / 华县皮影：学刻工密度、染色、锣鼓经的节奏语法；不复刻任何具体历史皮影头茬、曲牌或录音。
- 绍剧 / 1960 年代戏曲片《孙悟空三打白骨精》：只作为"三次递进 + 唐僧三种反应"的戏剧结构参照；造型、唱腔、镜头一概不借用。

## 3. 皮影的原生手段（用了哪几个、放在哪里）
| 原生能力 | 用法 |
|---|---|
| 灯就是世界 | 妖气来时灯色转冷、抖动；火眼金睛 = 一盏热点灯亮在悟空头后，脸部镂空处金光透出；紧箍咒 = 灯按木鱼节奏脉动 |
| 离布 = 变大变虚 | 悟空驾云离布 / 落云压布；白骨精每次"压上布"化身；前两次被打，白骨真身离布逃走（解尸法），假尸首留在布上 |
| 镂空透光 | **火眼金睛的 X 光**：灯越亮，化身的染色越褪，体内那副刻好的白骨（墨线）从虚到实压上布——情感高点之一 |
| 手持而非动画 | 全程手颤、杆影；第三棒时老翁的皮影**在铆钉处散架**，各片飞落，只剩白骨——本片的"只有皮影能做"的一刻 |
| 绕到幕后 | 结尾回声：从幕后看，三个化身与白骨挂在同一根杆上 |

## 5. 声音设计（仅音效：无配音、无旋律配乐；锣鼓只作舞台击节音效）
| 段落 | 环境底 | 拟音 | 击节（锣鼓） |
|---|---|---|---|
| 开场 | 小剧场底噪、灯芯噼啪 | 醒木、火柴、灯"噗"亮、竹杆碰布 | 片名落定一记大锣 |
| 白虎岭 | 山风（低呜） | 皮靴碎步、跃起皮片翻动、筋斗云呼啸 | 起跳一记小锣"台" |
| 妖气 | 山风转冷、低频嗡鸣、灯焰乱抖 | 巨影压布的反向吸气声、皮片拍布、碎步 | — |
| 火眼金睛 | — | 金属"铮"声 + 上扫的亮音；白骨浮现 = 木质骨响 | 板鼓一串 |
| 每一打 | — | 棒风、皮革重击、尸身落地、真身离布的空洞呼气 | 大锣 + 镲（第三打最大，加堂鼓） |
| 念咒 | — | 悟空打滚的撞地、金箍的高频紧绷声 | 木鱼由慢到快（僧人念经的乐器）+ 小锣脉动 |

| 散架 | — | 铆钉崩开的细碎"哒哒"、皮片翻飞、骨头落地的木质碰撞 | 最大一锣 + 碎镲 |

至少两处静场：11（54–58 s，硬切）与 15 末（悟空离去后）。声音转场：山风跨切进入妖气段（J-cut）；最后一锣余韵跨过幕后转场（L-cut）。

## 6. 字幕与片名
- 字幕 = 说书人题板：黑漆窄木牌、细金线、左侧朱红"说"字印，正文用马善政楷书（OFL），米白 `#f3e2bf`，距底 58 px。每条出现时上滑 18 px。
- 时长：≥ 字数 ÷ 4.5 + 1.5 s，下一条前 0.3 s 收。
- 片名 / 片尾牌也是皮影：深色皮牌上镂空刻字，灯光透字发亮；两根杆托上来，离布退场。片尾无任何署名水印。

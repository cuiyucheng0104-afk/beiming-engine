# 《落成之夜》TREATMENT · 装饰艺术（Art Deco）风格样片

1920×1080 · 24 fps（STYLE.md 未另定帧率）· 时长 19.17 s（= 46 拍 @144 BPM）· 无旁白、无字幕，只有画面内文字（中文为主）。

## 0. 三个候选结构与选择

1. **一次攀升（选定）**：金线从地基刻出一座塔 → 电梯楼层指针一格格爬升（越爬越快）→ 顶层双门对开 → 一小节屏息 → 楼顶机械万花筒烟花锁成纪年徽章「1929」。单一主体（一束珊瑚色的光＝电梯/“落成”的那一刻）、单一目标（到达楼顶）、单一转折（门开 → 静默 → 绽放）。
2. **倒计时**：钟面从 10 数到 0，每数一下点亮一个字母，零点烟花。太像发布会套路，且与“落成”（空间上的抵达）无关，放弃。
3. **前后对照**：同一个机位，脚手架之夜 → 落成之夜，帘幕/双门合上又打开。故事更“静”，但 15–20 秒里撑不起“表盘带剧情”与加速，放弃。

选 1 的理由：分镜指定的四个原生招式（表盘带剧情 / 门槛双门 / 机械万花筒 / 光泽扫过）在“攀升”里天然是一条因果链：表盘把“上楼”变成可数的节拍，门把“到达”变成一次中轴分裂，静默把“期待”压成一小节，万花筒把“庆祝”锁成一枚徽章。

## 1. Logline 与弧线

**Logline**：落成之夜，一束珊瑚色的光从地基沿金线爬上新塔，一格一格敲着拍子到达顶层，双门对开，全城屏息一小节——然后整片夜空被锁成一枚写着「1929」的金色徽章。

- 起：金线刻出塔身（慢、连绵，像一口长气）。
- 承：电梯指针一格格上升，越来越快（二分 → 四分 → 八分，分拍加速）。
- 转：叮！顶层双门两次闩响后对开，乐队全奏；随即一刀切断，屋顶只剩风声与一支升空的火箭哨音。
- 合：第一朵烟花炸开（全片最重要的一声），三朵递进后在中轴上旋转、镜像、咬合成日芒徽章，「1929」落定，光泽扫过，最后一记全体灯泡亮起收尾。
- 呼应：开场是一个金点在地基上点燃，结尾是同一中轴上的徽章——从一点到满天。

## 3. 色彩与字体

- 地：暖漆黑 `#120d0a`（夜空上半与立面全部是暖漆黑，只在地平线附近留一条深宝蓝 `#112039`；塔身、旧楼、城市剪影、天台地砖都是暖黑喷绘体积 + 金边）；金：带状金属渐变（暗-亮-热-亮-暗），`sheen` 可动；象牙 `#efe4c8` 用于灯光与字。

## 6. Cue map

- **BPM 144，4/4**，1 拍 = 0.41667 s = **整 10 帧**（24 fps），八分 = 5 帧，所以所有画面事件都放在拍或八分上，帧对齐 → 目标 0 ms 偏差。
- 摇摆：只有踩镲 ride/班卓切音的“后半拍”用 2:1 摇摆（音乐里），画面事件一律落在正拍/直八分上。
- 调：E♭ 大调。总长 46 拍 = 11.5 小节。

## 9. 制作落地与自检记录

- 时间源：timeline.js（→ timeline.json）；画面事件 window.EV（events.json，49 个）与配乐落点（music/score.json，40 个）由 tools/cuecheck.py 逐一核对：最大偏差 0.00 ms，全部落在整帧上（1 拍 = 10 帧）。采样的起音延迟按每个音的包络 10% 点自动前移补偿；单簧管滑音的音高曲线与金线绘制进度用同一函数（实测 b4 落在 B♭5）。
- tools/motioncheck.py：成片帧差在 34/37 个事件帧出现变化峰（其余 3 个处在快速升降/棘轮转动中，运动本身就是落点）。“叮”的顿推与全灯闪光的帧差峰值在第 200 帧（=b20，49.1，前一帧 2.7）；第一朵烟花的夜空一闪在第 320 帧（=b32，42.4，前一帧 3.1）。
- readcheck：表盘数字 4.20 s、“天台”2.48 s（降+拉提前到 b20 起步、推轨穿门推迟到 b25.5）、“1929”2.49 s、“落成之夜”2.49 s，全部达标。
- 成片 19.17 s，1920×1080，24 fps；响度 −14.4 LUFS（mix.py 末端加了 4 倍过采样真峰限幅，给 AAC 过冲留余量），真峰 −2.2 dBFS；blackdetect、freezedetect 均 0 处。分段 RMS：镜1 −17.4 / 镜2 −17.5 / 镜3 −15.9 / 镜4 −27.7 / 镜5 −12.5 dBFS，烟花段比开门段大约 3.4 dB。
- 静默：b27.5–b32（约 1.9 s）音乐为零，只剩风、引信与哨音（−35 dB 左右）；之后第一朵烟花是全片最响的一拍。
- 与示范片对照（结构/开场/签名镜头/镜头路径/配乐形状/结尾）：六项中五项不同；共同点只是分镜指定的“楼层指示器”与“烟花”。配色（珊瑚/宝蓝）也与示范（酒红/祖母绿）不同。

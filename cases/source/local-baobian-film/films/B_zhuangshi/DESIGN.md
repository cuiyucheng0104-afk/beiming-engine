## 〇、核心主张

**一句话**：角色是赛璐珞、背景是画出来的；全片只有一个形状——「文斑」（四瓣月牙围成的环，九色鹿的月牙斑 × 豹的梅花斑），它在**同一个屏幕点 A = (1188, 592)**、以同一个旋转角出现三次：指尖墨渍 → 豹身环斑 → 衬衫光斑；每一次转场都穿过一个圆（日轮、眼孔、豹眼/镜片），每一件大事都落在配乐「屏息之后的那一拍」上。

三条执行原则：

1. **画风分工（还原稿的核心判断，已对照参考核实）**：角色（豹、陆蔚、鹿、手）一律是 2D 赛璐珞精灵——无影平涂、细色线、规整彩斑（九色鹿）；背景是画出来的——有晕染、有层纹、有苔点，远处的山、云、日、雾不勾墨线（天书奇谭、九色鹿）；"满"和"吵"靠重复的形与朱砂金（大闹天宫）。3D 只做背景件和道具（书桌器物、卦爻光轮、崖石、松、山顶石、面具），用"叠晕"（一层套一层、层内外亮内暗、层间硬边）代替 3D 光影，避免塑料感。
2. **同位母题（电影稿的点 A + 还原稿的文斑形状）**：S1 食指尖墨渍在 A；S4 墨滴在 A 落上豹背、第一枚环斑在 A 收紧点亮；S6 第一枚光斑豹纹在 A（他的右肩）。三处用同一个形状函数、同一个旋转角 −18°。第二遍看的人会发现：A 点永远不动，世界围着它换。
3. **屏息—重拍（两稿共同发现，已复测）**：配乐里有五处近乎静音的屏息，每一处之后都是一记强起音。全片五件大事钉在这五记重拍上：入书（f141）、墨落豹背（f374）、起跳（f520）、破云（f543）、光斑成豹纹（f670）；外加全片最强起音 f658 = 豹眼→镜片。

**剪辑节奏**：长（0–10.8 s 一镜：修复桌 → 光轮 → 雾崖）→ 碎（集市 4 刀，刀刀踩鼓）→ 慢（眼孔 → 墨滴 → 环斑 一镜 5.5 s）→ 静（雾散，回到 S2 同一构图）→ 流（坐定 → 起跳 → 穿云 → 长卷 一镜 5.3 s）→ 点（三刀推近到豹眼）→ 静（回现实一镜 2.6 s）。全片 11 个镜头、10 刀，第一刀在 10.833 s。

**色彩脚本**：暖土（S1）→ 金 + 胭脂（T1）→ 冷青灰，七日一日比一日淡（S2）→ 热朱砂金（S3），随他走远被雾吸干 → 冷 → 暖（S4：灰豹变奶金、环斑一枚枚点成矿物色）→ 晴空金日（S4d/S5a）→ 群青夜空金月（S5b）→ 暖绢长卷、青绿叠晕山（S5c）→ 暖土（S6）。**冷的世界随"文"长出而变暖。**

**对 STYLE.md 两处的裁决**（还原稿提出，定稿裁决）：
- 「所有形体有流畅的勾线」：角色、道具、近景崖石与松干勾线；远山、云、日、光轮、雾不勾墨线，靠叠晕色阶边界成形；岩石只给"同色深一档、断续"的层缘线（ref_10 实测如此）。理由：参考原片里远景与云确实无墨线（ref_00、ref_03、ref_08），给它们勾线就是"国潮矢量"。
- 「壁画颗粒与轻微剥落肌理」：颗粒与水粉斑驳全片都做；剥落按 STYLE 保留但限定为"轻微"——只在大块静止的底色面上（S2/S4d 天幕、S5c 绢天、S6 墙），物体空间，覆盖约 2%，提亮 25% 向 #E8DDC6，不上角色、光轮、环斑、字幕。理由：参考里看不到剥落（它们是动画赛璐珞），但 STYLE 是本版画风的权威；限定范围后不破坏"截一帧放进参考板"的标尺。

### 0.3 全文约定

- **像素**：本文所有屏幕坐标与像素尺寸都是 1920×1040 设计像素，原点左上，x 向右、y 向下；代码里一律 ×K，`K = innerHeight / 1040`（4K 时 K = 2）。
- **look.js 参数**：look.js 内部已按 H/1080 缩放，本文 look.js 表里的数值是**直接传入值**，不再乘 K（与设计像素差 3.8%，可忽略，4K 一致性不受影响）。唯一例外：外部纸纹按图片像素平铺、不随分辨率缩放，所以 `paper.scale` 必须传 `K`（否则 G5 会差）。
- **自写着色器**：屏幕空间噪声一律用 `gl_FragCoord.xy / K` 取坐标；Canvas 2D 的线宽、字号、粒径都乘 K；画布贴图按 K 定尺寸。
- **世界单位 = 米**。焦段按 36 mm × 19.5 mm 画幅换算 three 的竖直 fov，`f_px = 520 / tan(fov/2)`：

| 等效焦段 | 28 | 32 | 35 | 40 | 50 | 85 |
|---|---|---|---|---|---|---|
| 竖直 fov（°） | 38.40 | 33.86 | 31.13 | 27.40 | 22.07 | 13.09 |
| f_px（@1040） | 1493 | 1707 | 1867 | 2133 | 2666 | 4533 |

  视差：相机横移 Δx 米，深度 D 处的层屏幕位移 `Δx · f_px / D` 像素。
- **相机**：`scene.js` 的 `aimCamera(cam, pos, yaw, pitch)`（YXZ，yaw 左正、pitch 上正，**全片不滚转**，地平线永远水平）。俯角 90° 时 `aimCamera(cam, pos, 0, −90°)`，画面上方 = −z，不退化。
- **一拍二**：`f = Math.round(t*24)`，`f2 = f − (f & 1)`，`tc = f2/24`。角色姿态与网格形变、角色手里的道具（镊子被捏着时、眼镜被拿着时、面具被举着时）、火舌长短跳动、S3 描线沸腾、环斑点亮事件，全部按 `tc`；镜头、雾、雨、水、云、日、光斑漂移、门户、道具自由下落，按连续 `t`（24 fps 平滑）。
- **确定性**：随机只用 `scene.js` 的 `hashi(n)` 或 `engine/core/math.js` 的 `mulberry(seed)`；一切运动由 t 直接算出，不跨帧累积。**`engine/core/noise.js` 的 `createNoise2D(random = Math.random)` 默认参数里有 `Math.random` 字样**：只能用绝对路径 `import … from '/engine/core/noise.js'` 并总是传 `mulberry(种子)`；绝不能把它拷进 `films/B_zhuangshi/`（G0 只扫本版目录，拷进来就判红）。
- **曲线**：写 `keys [[帧, 值], …]` 的喂 `engine/core/math.js` 的 `monotone()`（不过冲）；写 `ss5 / ss / eo / eio / seg` 的用 `scene.js` 同名函数；写"对数线性"的对 ln(值) 做分段线性插值。
- **场景划分**（搭建骨架）：场景 R（修复室：S1、T1、S6）、场景 Y（雾崖：S2、S4a–d，也作 T1 门户内容）、场景 M（集市：S3a–c）、场景 K（面具大特写：S3d，门户内容 = 场景 Y 的 S4a 机位）、场景 S（天空：S5a–S5d①）、场景 H（豹头像：S5d②、T2）、叠加层 O（正交相机，在 `look.render` 之后 `renderer.autoClear = false` 再画：雨、闪光、金环、浮尘）、DOM 2D 画布（叠在 WebGL 画布之上：字幕、片尾纸白；`page.screenshot` 会一并截到，门禁自测片同法）。`render(t)` 按 `f` 所在区间选场景与参数。

### 3.2 2D 角色精灵的统一做法

- 面片：`PlaneGeometry(1, 1, 48, 24)`，用 `scene.js` 的 `cutoutPlane` 思路（彩色层 + 只写深度的遮罩层，`cut = 0.5`），让 Kuwahara 按深度给角色小笔触、底板大笔触；`userData.outline = false`（**线画在精灵里，不走 look.js 描线**）。
- 顶点形变（呼吸、尾、头、压扁拉长、脊柱起伏）用 uv 区域遮罩（manifest 里每张图一份：枢轴、区域矩形、羽化），按 `tc` 一拍二。
- **豹的身色与斑由代码给**（因此 A00–A05 都是白身、无斑）：`lum = dot(rgb, (.2126,.7152,.0722))`，`sat = max − min`；`body = smoothstep(0.72, 0.86, lum) · (1 − smoothstep(0.08, 0.18, sat))`；`col = mix(rgb, 身色 · (lum/0.96), body)`——画师留下的微弱明暗按乘法保留；斑只画在 `body` 里，不会盖到线、眼、耳。身色 = mix(#A9ADAD, #EEDFB0, 擦除遮罩)。
- 剪影锐化：alpha 双线性放大后用 `smoothstep(0.5 − w, 0.5 + w, a)`、`w = fwidth(a)` 重新截边，放大到 2.2× 时剪影边仍是干净的（画在图里的线会略软，由构图与 Kuwahara 兜住，见 S4b）。
- 斑位布局（每个姿态一套，Asset 标进 manifest）：沿脊线 5 控制点样条 C(s) 排两行——上行偏离脊线 0.28 体厚、7 枚；下行 0.55 体厚、与上行错开半格、6 枚；后腿根 2 枚；尾 3 枚（0.6R → 0.4R）。共 18 枚，环半径 R = 0.045 m（体长 1.1 m 的 4%）；**环 0 = 上行第 3 枚（背中段），R0 = 0.052 m**。点亮顺序：由环 0 沿身体向两侧扩散，尾最后；颜色按 2.5 七色循环（环 0 = 石青）。

### 3.3 着色器配方（直接可抄的 GLSL 片段）

① **天书奇谭岩石层纹 + 苔点**（toon 的 `fragmentAlbedo` 钩子，可用 `vToonObj`、`toonNoise`、`toonFbm`）：
```glsl
vec3 P = vToonObj;
float s = P.y * 5.5 + 0.55 * toonFbm(P * vec3(0.9, 1.6, 0.9)) + 0.25 * toonNoise(P * 3.1);
float band = fract(s), aa = max(fwidth(s), 1e-4);
diffuseColor.rgb *= mix(1.07, 0.86, band);                                  // 每层上亮下暗
toonInk = max(toonInk, (1.0 - smoothstep(0.0, 0.07 + aa, band)) * 0.55);     // 层缘一道深线（inkColor #1E3444）
float moss = smoothstep(0.62, 0.66, toonNoise(P * 28.0)) * smoothstep(uTopY - 0.12, uTopY, P.y);
diffuseColor.rgb = mix(diffuseColor.rgb, vec3(0.014, 0.100, 0.246), moss);  // 苔点 #1F5988（线性值）
```
`uTopY` = 该石块物体空间顶部高度：`fragmentPars` 里写 `uniform float uTopY;`，经 `makeToonMaterial({ uniforms: { uTopY: { value: … } } })` 每块传一个值。

② **九色鹿叠晕**（`fragmentNormal` 钩子——此处已有视空间 `normal`，`diffuseColor` 之后才被光照读取）：
```glsl
float fr = clamp(dot(normal, normalize(vViewPosition)), 0.0, 1.0);   // 1 = 正对相机
float x = (1.0 - fr) * 4.0 + 0.35 * toonFbm(vToonObj * 0.9);         // 0 在中心，4 在轮廓
float k = floor(x), tt = fract(x);
diffuseColor.rgb *= mix(0.80, 1.12, tt) * mix(0.72, 1.00, clamp(k / 3.0, 0.0, 1.0));
```

③ **松针辐条盘**（朝相机面片，uv ∈ [−1,1]，seed/rot 每盘一个）：
```glsl
float r = length(uv), a = atan(uv.y, uv.x) + rot, n = 24.0;
float w = abs(fract(a / 6.2832 * n) - 0.5) * 2.0;
float len = 0.82 + 0.14 * h11(floor(a / 6.2832 * n) + seed);
float spoke = (1.0 - smoothstep(0.35, 0.55, w)) * (1.0 - smoothstep(len - 0.05, len, r)) * smoothstep(0.18, 0.30, r);
vec3 c = mix(C_HEART /*#113037*/, C_MID /*#39556C*/, smoothstep(0.2, 0.7, r));
c = mix(c, C_TIP /*#99CAB9*/, spoke * smoothstep(0.45, 0.85, r));
c = mix(c, C_DOT /*#A6CFC0*/, 1.0 - smoothstep(0.05, 0.08, r));
float alpha = (1.0 - smoothstep(0.92, 1.0, r)) * mix(1.0, spoke, smoothstep(0.70, 0.95, r));
```
每盘明度 ±6% 哈希。

④ **文斑**（母题，全片共用一个函数 `wenban(p, R, rot, idx, state)`）。局部坐标 p 以 R 归一：

⑩ **叠晕山（2D SDF 卡片）**（S2 六道远脊、S5c 三排长卷山）：一排山 = 高度剖面 `h(x) = max_k H_k·(1−|x−x_k|/w_k)^p_k`（3–7 个峰，峰位/宽/高由哈希；馒头峰 p 1.5–2.2，笋峰 p 1.2 且窄）+ 小噪声 0.02H；山内 `q = (h(x) − y)/bw`（bw = 0.06H）分带：`k = floor(q)`、`tt = fract(q)`，色 = mix(带亮边色, 带色_k, smoothstep(0, 1, tt))，k ≥ 4 用核色；带边缘 `q += 0.012·fbm(uv·6 + seed)` 出干笔起伏；外轮廓羽化 1.5·K px；**不勾线**；山脚压一条⑨雾带（S5c 用云堤）。

⑪ **卷云（2D SDF 卡片，ref_03）**：一朵云 = 5–9 个云头圆（中间大、两头小、上排高）`d = smin(|p−c_i|−r_i, k=0.08r̄)`，底边用一条平切 smin 压平；每个云头内按 `v = (p.y−c_i.y)/r_i` 三阶叠晕：v < −0.45 云暗 #213E77、−0.45…0.35 云中 #1A52A0、> 0.35 云亮 #0B68C4，阶间羽化 0.06r_i；云头按 y 由低到高依次叠画，每个云头下沿留 0.12r_i 暗带；最大的 1–2 个云头里画阿基米德旋涡（**深色缝** #213E77，线宽 0.035r_i，1.75 圈）；外轮廓羽化 1.5·K px；**不描白边、不勾黑线、没有白色卷线**。"化开"：`α *= 1 − smoothstep(th − 0.1, th, fbm(uv·3))`，阈值 th 随时间由 1.2 降到 −0.2。

⑫ **日 / 光轮 / 头光**（着色器卡片）：日面平涂、外环一道 0.03R 的深一档带、边缘 1% 剪纸起伏（七日）或硬圆（金日）；头光三环：半径 1.05R–1.35R（S5a）或 1.05R–1.6R（S4d），三色等宽、环间柔边 0.04R、整体 α0.85；**真日不加火舌**（与 S3 假光轮区分）。

⑬ **火舌环**（T1 上六、S3 假光轮）：环形面片（内径 r0、外径 r1），第 k 舌（k = 0..N−1）在极角 `a_k = k·2π/N + ω·t`；舌形 = 带 S 弯的水滴：半宽 `w(ρ) = 0.12·(1 − ρ)^0.7`（ρ 为沿舌长 0..1），中线偏移 `0.3·sin(πρ)·w0·(k 奇 ? 1 : −1)`；舌长交替 1.0 / 0.7，× `(1 ± j·hash(f2, k))`（一拍二跳动）；生长 `len(t)`；配色 ρ < 0.3 根、0.3–0.8 身、> 0.8 尖（2.2 / 2.4 色）；不描线。T1：N = 28，ω = 0.07 rad/s，j = 0.06；S3 假光轮：N = 36，ω = 0.25，j = 0.12（更躁）。俯冲时沿半径拉长 ×(1 + 2·v)，v 为归一化俯冲速度。

⑭ **壁画剥落**（物体空间，只用于〇节限定的四处底色面）：`m = smoothstep(0.72, 0.74, fbm(uv·f_flake))`，f_flake 按该面在本镜头的典型屏幕尺寸换算，使块大小 20–60·K px、覆盖约 2%；块内颜色 `mix(c, #E8DDC6, 0.25)`，块边 1·K px 暗一档。斑驳：fbm 周期约 220·K px，亮度 ±3.5%。

## 五、转场机关

### 5.1 T1：卦爻 → 光轮 + 地平线 → 门户

1. **金条弯曲器**（顶点着色器）：每段金条有中点 M、切向 T、指向环心的法向 N（都在 H1 平面内），弯曲量 m ∈ [0,1]，目标半径 R，曲率 `κ = m/R`，目标弧长 `L(m) = mix(L0, L_arc, m)`（阳环 `L_arc = 2πR`；阴环每段 `L_arc = πR·(1 − 0.14)`，两段之间各留 7% 周长缺口）。沿长度 s ∈ [−L/2, L/2] 的中心线：`p(s) = M + T·sin(κs)/κ + N·(1 − cos(κs))/κ`（κ → 0 退化成直线），截面沿 N 展开（宽 0.009 → 0.006 m）。m = 1 时弯曲中心 `M + N/κ` 落在 H1：中点按 `M(m) = mix(M_页上, H1 − N·R, ss(m))` 移动——九三在环心下方（N = −z，中点去 6 点钟），九四、九五在上方（N = +z，中点去 12 点钟）；阴爻两段先在平面内各转 90°（左段到 9 点侧、右段到 3 点侧），再弯成左右两个半环（缺口此时在 12/6 点），f98–f106 再整体转 90° 让缺口到 3/9 点。初九不弯：中点移到 H1 下 0.001 m，只沿 x 拉长 `L(m) = mix(0.090, 2.0, m)`、宽收到 0.0008 m。离纸时每段绕长轴转 180°（6 帧），材质双面：底面墨、顶面金。
2. **锁轮与扫光**：f106 缩放 1.04 → 1.00（4 帧）；金箔扫光：金材质里 `|atan2(p) − θs(t)| < 8°` 处进金箔高光 #F6DE8E，θs 在 f106–f116 转 360°。
3. **火舌环**：3.3⑬，N = 28，生长 `len = eo((f − 106)/6)`。
4. **门户**：
   - f116–f139 每帧先用 look.js 把场景 Y（S2 相机）渲到 `rtPortal`（W×H，UnsignedByte）：`look.render(sceneY, camY, { t, …S2 的 outline/kuwahara/bloom/grade…, paper: false, vignette: 0, grain: 0, target: rtPortal })`，**接着把雨叠加层也画进 `rtPortal`**（`autoClear = false`），这样雨只在门里、不落在书页上；再渲场景 R 到屏幕。
   - 日盘片元在 `r < 虹膜半径` 处输出 `texture2D(tPortal, gl_FragCoord.xy / uRes)`——**采到的是 sRGB 值，要先转回线性再输出**（`toneMapped: false`；否则外层 OutputPass 再编码一次会发白）；孔缘 3·K px 金线；`userData.outline = false`、`outlineOccluder: false`。
   - 外层调色 f116–f139 由 S1 参数线性过渡到中性（warmth 0、saturation 1、lift 0、shoulder 1），保证 f139 门户盖满时画面与 S2 第一帧一致，切过去不跳色；外层的 paper / vignette 与 S2 同值，内层关掉，避免叠两遍。
   - S2 相机在 f116–f163 一直前推（见 S2 运动表），门里的画面在动，与俯冲同向。只有这 23 帧渲两遍场景，G4 无压力。
5. **金线 → 地平线**：f106 起屏幕金线（y = 520、宽 5·K px）接替 3D 初九线；场景 Y 的相机俯仰 0°、地平线恰在 y = 520，最远一道远脊的脊线压在 y 505–525；f139–f150 金线淡去，同时该远脊脊线亮边由金褪回雾色（f139–f170）。
6. **闪**：f139–f145 叠加层白金闪 #FFF4D6（加色，峰值 f141 = 0.85），bloom 同步 1.10。
7. **降级**：门户对不齐时，取消虹膜开孔，f139 直接切在白金闪里（闪峰挪到 f139–f141，音乐重拍掩护）；离纸、成轮、锁轮、俯冲、金线照做。

### 5.2 S3d → S4a：面具眼孔 → 光轮缩回 → 墨渍

1. **面具**：`PlaneGeometry(0.30, 0.24, 48, 40)` 弯到椭球面 `z = −0.06·(x/0.15)² − 0.04·(y/0.12)²`；贴图 A15（眼孔与外轮廓透明），`mat.alphaTest = 0.5` 镂空——look.js 的 ID 图识别镂空，眼孔一圈自动出墨线，放大到满屏线宽也不变。背面叠一层 `BackSide` 暗朱砂 #7A2A1E 内衬，偏 −0.002 m。**若 A15 出图眼孔不透明**：加载时对 alpha 做一次从图边开始的泛洪填充得到"外部透明区"，再用 manifest 里两眼孔的中心与尺寸画两个椭圆当眼孔遮罩（确定性），不重出图。

# B · 装饰（九色鹿 / 天书奇谭 / 大闹天宫）
参考：refs/B_zhuangshi/（先看 refs/B_zhuangshi_board.jpg）
- 画风：敦煌壁画式装饰动画。平涂为主，1–2 阶硬边卡通着色，所有形体有流畅的勾线（赭红或墨色，粗细有变化，像铁线描）；矿物色板：石青、石绿、朱砂、土黄、蛤白、少量金；背景是装饰化的山石（层叠的平面块、程式化的山峦、卷云纹、火焰光轮）；画面有壁画颗粒与轻微剥落肌理。
- 豹参考九色鹿的造型方式：修长、优雅、轮廓简洁，斑纹是规整的装饰纹样；豹变后斑纹像壁画图案一样一枚枚"点亮"。
- 现实段（S1、S6）用同一套平涂勾线，暖土色调，像一幅当代壁画。
- 镜头：舞台式平面透视，层与层像布景片前后错开滑动；S5 用卷云纹层层推进。
- 转场：T1 用「圆形光轮」：卦爻变成一圈光轮（九色鹿式的日轮），镜头穿过光轮进入壁画世界；S3 面具集市用浓重的朱砂和金，眼孔推进后光轮缩回。

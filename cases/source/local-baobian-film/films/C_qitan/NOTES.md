## 四、转场

- **T1 卦门（框中框 + 俯冲）**：两场景 + 渲染目标。f86–f104 每帧先用世界相机 W(f) 把雾崖渲进 `rtWorld`（不加颗粒暗角），再渲房间；页面、书块、书桌在门洞遮罩处 discard，衬板（深度测试、最后画）只填门洞里没有几何的地方。门洞遮罩是页面 UV 上的 fbm 墨边，边缘一圈像纸被水浸湿。f104 只渲世界，两边像素一致（f103 → f104 平均差 8.9，主要是世界相机在快速俯冲；色调差 < 3.5/255）。
- **S3d → S4a（面具眼孔 + 雾对雾硬切）**：眼孔是几何洞（屏幕层内壁）；f342 起内壁二次 ease-in 放大并把左孔移到画面中心，f346–f355 全屏雾墙淡入；S4a 的雾用同一个函数、同一组参数从中心散开。实测 f354 / f355 / f356 平均亮度 205.5 / 207.6 / 207.4（`_work/stills/cut34b/`），切点两边差 0.2/255。
- **S4b → S4c**：f438 拍点硬切，级联从这一帧开始，第一枚斑在中景里也在 (s, v) = (.45, .35)。
- **S5a → S5b（化开）**：见上；一只豹连续不断，墨点在 3D 世界里退去、在长卷上重新吐。
- **T2 豹眼 → 镜片（匹配剪辑）**：形、光、运动、色四重匹配。f641（豹眼星芒峰值）和 f642（镜片星芒峰值）叠在一起看是同一个椭圆、同一个星芒中心（`_work/stills/t2b/`），只在 f642 直切，不叠化。
- **墨渍 → 豹斑 → 光斑**：同一个 `motif` 函数、同一个种子 7：S1a 食指上的墨环、S3c 指肚上的墨环、S4a 被雨冲淡的墨环、S4b 收紧成的第一枚斑（屏幕点 (1180, 600)）、S6 落在他手上的光斑（终态在 (1180, 600)）。

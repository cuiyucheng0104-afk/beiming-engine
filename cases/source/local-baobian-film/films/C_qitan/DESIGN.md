## 〇、核心主张与总表

### 0.1 一句话主张

**同一枚环，穿过三道框，换三种画法。**

"墨渍→豹斑→光斑"用同一个函数 `MOTIF`、同一个种子 7，三次落在屏幕同一点 **(1180, 600)**：
- S1a：他指尖的墨环；
- S4b：墨滴在豹背上收紧成的第一枚斑；
- S6：窗外树叶筛下来、正落在他指尖上的光斑。

画面按剧情在中国奇谭的三种画法之间接力：
- 修复室：《三条龙》式的暗褐暖光，像一个微缩模型。
- 书中雾雨七天：《鹅鹅鹅》式的银灰喷绘，整段只有七个一个比一个淡的朱红剪纸日。
- 集市：夜青底上只有琥珀金一种亮色，满街是一模一样的金豹面具（小人革面：假斑每一枚都一样）。
- 第七天：真豹斑一枚枚弹出来（每一枚都不一样），金色从每一枚斑心向外漫开；雾散以后，世界翻成青绿加金。

人物和豹是 2D 喷枪软体积精灵，因为参考里的角色就是这种画法。崖、洞、松、书桌、书、卦爻、面具、灯笼做成 3D 卡通体。三个转场都是穿过一道框：卦门、面具眼孔、豹眼→镜片。

三根支柱：
1. **母题可追踪。** 第一遍看懂"墨变成了斑"；第二遍会发现那是同一个形状、同一个位置。还会发现集市面具上的金斑全是同一枚对称梅花印，而真豹斑每一枚都不一样。
2. **画法就是叙事。** 灰的世界里只有朱红的日子在走。颜色不是从天上来的，是从豹斑里长出来的，再由雾散把整个世界翻过来。
3. **配乐结构就是故事结构**（配乐从 12.42 秒截）。0–12 秒几乎无声，是等待；12 秒一声炸开，是诱惑；16.0 秒一记低音，是墨滴落背；18.1–19.4 秒最大涌起，是豹斑级联；20.6 秒起跳；26.8 秒最响的和弦，是光落到人身上；之后是尾音和字幕。

### 0.4 情绪曲线与剪辑密度

暖而静（0–2.5）→ 惊奇，第一个"哇"（2.5–4.8）→ 等待：灰、慢、几乎无声的七天（4.8–12）→ 诱惑：满、吵，唯一的夜色段（12–14.8）→ 屏息再绽放，最慢最美（14.8–20.1）→ 释放，最开阔（20.1–26.75）→ 回家，最温暖（26.75–30）。

剪辑密度和情绪对应：前 12 秒 5 个镜头；12–14.8 秒 4 个镜头；之后回到长镜头，S5a 一镜 3.5 秒。

## 三、着色与后期参数表

### 3.1 统一约定

- **复制再改：** 把 `toon.js`、`look.js`、`scene.js` 拷到 `films/C_qitan/` 再改，不动 `_lib`。
  - `look.js` 要改三处：颗粒按 1.6K 一格（3.5）；新增景深通道（3.6）；新增屏幕层钩子（雨、闪光、字幕前的合成，3.9）。
  - 噪声用 `engine/core/noise.js` 的 `createNoise3D(mulberry(7))`，**必须传种子随机源**（它默认用 `Math.random`）。
- **`look.js` 调用约定：**
  - `createLook(renderer, W, H, { ss: 2, paperUrl: null })`：用程序化纸纹，它内部按 uK = H/1080 缩放，4K 不变样。
  - 每帧都写 `kuwahara: false`，因为默认参数是开着的。
  - 屏幕雾 `fog: false`：雾在场景里做。
  - `renderer.toneMapping = THREE.NoToneMapping`，保住色板。
- **确定性：** 一切随机都用种子哈希（`scene.js` 的 `hashi`、`look.js` 的 `pcgh`、GLSL 哈希），不准用 `Math.random`、`Date`、`performance.now`。雨、雾、尘、光斑、墨点、斑点出生全部由 t 或 tc 直接算，不跨帧累积状态。
- **一拍二：** 豹、陆蔚、手、鹿、卦爻浮起、斑点和墨点的"弹"、人群、摊主都按 tc 取姿态。镜头、雾、雨、光、墨的晕开、门扇转动按 t 连续。若剪辑点落在奇数帧（f27、f115、f211、f287、f315、f567），这个镜头首帧的 tc 会早于镜头起点，姿态函数要夹到本镜头的起始姿态。
- **K 缩放：** 线宽、颗粒格、景深半径、雨丝长宽、尘埃、闪光、边缘光、字号、精灵屏幕摆位、Canvas 绘制全部乘 K。相机 FOV 和世界尺寸与分辨率无关。

### 3.7 母题函数 `MOTIF`（墨渍、豹斑、墨点、光斑共用一个；GLSL 和 JS 各写一份，公式逐字相同）

```glsl
// q：以斑心为原点、按斑半径归一的坐标；ph：4 个相位，JS 端用 hashi(seed*4+i)*6.2832 算好传入；
// k：断口数 = 3 + seed%3（种子 7 → 4）；soft：边缘软度；gapK：断口强度 0..1
vec2 motif(vec2 q, vec4 ph, float k, float soft, float gapK){
  float r = length(q), a = atan(q.y, q.x);
  float rho = 1.0 + 0.16*(0.55*sin(2.0*a+ph.x) + 0.30*sin(3.0*a+ph.y) + 0.15*sin(5.0*a+ph.z)); // 不正的圆
  float w   = 0.30*(1.0 + 0.35*sin(3.0*a+ph.w));                                              // 粗细起伏
  float gap = mix(1.0, smoothstep(-0.80, -0.45, sin(k*a + ph.x*1.3)), gapK);                   // k 个断口，每个约占本段 20–35%
  float ring = (1.0 - smoothstep(0.5*w - soft, 0.5*w + soft, abs(r - rho))) * gap;
  float core = 1.0 - smoothstep(0.0, 0.78*rho, r);
  return vec2(ring, core);   // x = 环，y = 斑心
}
```

## 五、转场机关

### 5.1 T1 卦门（框中框加俯冲；门内世界用渲染目标）

1. **两个场景：**
   - 房间 `roomScene`；
   - 雾崖世界 `worldScene`，S2、S4c、S5a 也用它。
   - f86–f104 每帧先用世界相机 W(f) 把世界渲进 `rtWorld`（HalfFloat，W×H；按 S2 的调色，不加颗粒和暗角），再渲房间。
2. **爻条：** 12 段 `RoundedBoxGeometry`（three 自带的 addons）。
   - 阳爻每半段长 0.0285 m；阴爻每半段长 0.025 m，中间空 0.010 m。条宽 0.0055 m（沿页面纵向），厚 0.0025 m，圆角 0.0008 m。
   - 每段的旋转支点在外端。
   - 浮起、变色、开门的公式见第四节 T1 的动画表；开门绕页面的"上"方向转，内端往页内走。
3. **门洞遮罩 M（页面 UV 空间）：** M = smoothstep(−e, e, w(f) − |u − u_seam|·k + 0.04·fbm(18u, 18v))，e = 0.015。
   - w(f) 在 f86–f98 用 `eio` 从 0 长到 0.62。竖向范围先限在卦的高度，f96 起扩到整页。
   - 噪声固定在 UV 上，不随时间变，所以墨边稳定。边缘 0.02 宽的带子混入 40% 的 `#5A462F`，像纸被水浸湿的边。
   - 页面着色器在 M > .5 处 `discard`。页面下 2 mm 放一块"门洞衬板"，在屏幕空间采样 `rtWorld`。门扇在衬板前面，深度关系自然成立。
4. **世界相机 W(f)：** f86–f115 位置 = C0 + Δ·(1 − ss5((f − 86)/29))，Δ 在 C0 的相机坐标系里是"上 180 m、后 520 m"。俯角从 −14° 变到 C0 的 +1°（`ss5`）。这是一次俯冲再拉平：在高处往下看时，脊线在画面上铺得很开，能对上六条爻；拉平以后，它们挤到地平线下的 y 540–760，成为 S2a 的远景层。
5. **"横画变成远山的地平线"的对位：**
   - 初始化时，先用房间相机在 f92 的位姿算出六条爻的屏幕 y。
   - 然后在 W(92) 下用 `placeOnScreen(ridge_k, W, Wpx, Hpx, 960K, y_k, 4200K, D_k)` 摆第 k 道脊线，D_k = [520, 700, 950, 1300, 1900, 2900] m（自下而上）。
   - 门扇转开时，脊线正好出现在原来爻条的位置上。
   - f115 时脊线必须落在 y 540–760；不满足就把 W(86) 的俯角在 −12° 到 −16° 之间调。
   - 第一道（520 m）在俯冲中从相机旁掠过：离相机 < 30 m 的雾和脊线一律淡掉。其余五道到 C0 时深度约 180 / 430 / 780 / 1380 / 2380 m。
6. **调色衔接：** f96–f104 房间那一遍的调色线性回到恒等（warmth 0、saturation 1、lift 0、bloom 0），颗粒和暗角改用 S2 的值。f104 时门洞已铺满画面，从这一帧起只渲世界，两边像素一致，没有跳变。
7. **光的戏：** f82 起，爻缝和中缝里透出门内的雾光；门前纸面有一池琥珀光；两层琥珀雾片从门口溢到纸上，f96–f104 线性退掉。

### 5.2 S3d → S4a 面具眼孔（框中框加雾对雾硬切）

1. 面具内壁是屏幕空间的代码层（第四节 S3d），眼孔是几何洞，一定透明，不依赖生图抠底。
2. 眼孔外的雾墙和 S4a 起首的雾用同一个函数、同一组参数：色 `#E9E2D8`、fbm 频率、漂移速度。
3. f342–f356 内壁层二次 ease-in 放大，集市相机前推，越推越快。f354–f355 画面只剩雾。f356 硬切到 S4a 的雾。S4a 的雾以 `eo` 从中心散开，读起来是一次连续的冲刺：冲进眼孔、冲出雾、落到手上。
4. **验收：** f354–f357 四帧的平均亮度差 < 3/255，雾纹尺度一致。
5. 不用第二个传送门渲染目标。这是电影稿的做法，比还原稿的 `rtWorld2` 省一张渲染目标。

### 5.3 T2 豹眼一闪 → 镜片一闪（匹配剪辑，最干净）

1. **形状匹配：** S5c 末尾豹眼的外圈描边，和 S6 首帧镜片的暗铜镜框，是同一个椭圆：同中心 E = (1010, 500)、同半轴 (236, 200)K、同倾角 −12°、同线宽 9K。两边都由代码画，共用一个常量，像素级对齐。
2. **光的匹配：** 同一颗四芒星（3.9），中心都在 H = (950, 455)。f641 是豹眼高光的峰值，f642 是镜片高光的峰值，切点藏在最亮的那一帧里；f642–f652 衰减。S1b 的镜片闪光也用这套参数、这个中心：首尾呼应。
3. **运动匹配：** S5c 最后 8 帧和 S6 前 4 帧，都以每帧 0.5% 的速度微推。
4. **色的匹配：** S5c 最后 8 帧的调色向 S6 靠（3.5），切点两边色温差很小。
5. **内容翻转是故意的：** 眼里是黑瞳，镜片里是亮的书页。闪光盖住的那几帧过去以后，观众才看清"他看见了什么"。
6. 只做一个直切，在 f642。不叠化，不闪白。

### C. 关键取舍与理由

1. **配乐起点 12.42（采纳电影稿）。** 四个规定对位点里，它在"进集市""片尾"上明显最好，"起跳"不输；还把全片最响的和弦给了"光落到人身上"，片尾自然落进尾音，不被 28.3 秒的淡出削掉。代价是 T1 穿书时音乐屏息，接受：门在拨弦上成形，屏息正好接 S2 的七秒静默。
2. **豹和人全部 2D（采纳还原稿）。** 参考里的角色是 2D 喷枪画法，2D 精灵最像原片；Magpie 能直接出奇谭味的造型；几小时内能做完。电影稿的程序化 3D 豹要做 14 个姿态、五官着色、毛毡材质，是全片最大的工期和"塑料感"风险。BRIEF 要求的"真的有 3D"由崖、洞、松、书桌、书、爻条、面具、灯笼、云海满足。
3. **母题：同函数、同种子 7、同一屏幕点 (1180, 600)（采纳电影稿）。** 这是三次出现"一定相同"最可验证的写法；还原稿的 `rosette()` 只保证同形，不保证同位。
4. **颜色从豹斑里长出来，世界再由雾散翻色（两稿合并）。** 电影稿的"斑心向外漫开"把颜色和母题绑在一起；还原稿的"右往左翻色前沿"把第七天的雾散做成整个世界的事件。两件事按先后发生：先是豹自己变，然后世界变。
5. **七日用朱红剪纸圆，排成一列、一个比一个淡（色取还原稿，排法取电影稿）。** 朱色是灰段唯一允许的亮色；同时有 3 个太阳排成一列，"依次、一个比一个淡"一眼就读得出来。
6. **不开 Kuwahara，纸纹只做 0.04–0.06（采纳还原稿）。** STYLE 明说"画面干净，像电影而不是插画"。3D 岩石的笔触感靠材质钩子来做；只有出现塑料感时，才对岩石的深度段局部开 Kuwahara（R7）。
7. **景深用一个按深度的通道（采纳电影稿），参数按目标效果重算。** 还原稿的逐层预模糊管不了跨深度的 3D 物体。电影稿的 cocScale 和它自己写的意图对不上，本定稿逐镜重算了 z_f、cocScale、cocMax，并在 3.6 里写出关键层的结果。
8. **S1：还原稿的微缩模型定场，加电影稿的过肩戴眼镜。** 定场满足 STYLE"修复室像一个精致的微缩模型"；过肩满足 BRIEF"拿起眼镜戴上（只见手、镜腿、镜片一闪）"和"眼镜不做产品特写"。镜片的反射光点把视线引到上六爻，接 T1 的主观镜头。

# C · 奇谭（中国奇谭第一、二季，当代上美影）
参考：refs/C_qitan/（先看 refs/C_qitan_board.jpg）
- 画风：当代上美影的作者短片气质。造型极简而有体积（像软陶 / 纸雕被柔光照着），三渲二用 2–3 阶并带柔和的环境遮蔽和电影化侧光、逆光、体积光（丁达尔光束）；背景是有笔触的写意山水，低饱和暖土色（赭、灰绿、米白），只有一两处高光色（琥珀、朱红）；画面干净，有轻微颗粒和镜头暗角，像电影而不是插画。
- 豹：圆润、可爱又有点古怪，大眼睛，造型像一件手工玩偶；豹斑一枚枚长出来时有轻微的"弹"。
- 现实段（S1、S6）：同一套柔光体积质感，修复室像一个精致的微缩模型。
- 镜头：电影感，浅景深、焦点转移、缓慢推轨；S5 用一个大的升降镜头。
- 转场：T1 用「门洞/框中框」：书页上的卦画变成一扇门（类似中国奇谭2的红门意象但不照搬），镜头穿门而入；S3 用面具眼孔做框中框；T2 匹配剪辑做得最干净。

## 三、每段怎么做的

**S1 修复室（#01，f0–f83）**：3D 书（封板、页堆、两页曲面，书沟下陷）铺在 A11 桌面上；左页是 R01 左页降饱和后重画的画布，卦画 ䷰ 在着色器里按页面米制坐标印（带印刷毛边、不匀），「革」和两小列字用马善政楷书；右页直接用 R01 木刻豹。手 A07 两姿态一拍二按 DESIGN 4.2 的帧表走，锚点（镊尖 / 食指尖 / 捏合点）都按清单关键点对齐；3D 镊子挂在捏合点，f34 起留在页边；3D 眼镜 f49 捏起、朝镜头升起、镜腿三档展开。近视虚焦 = 桌面和书页取 mip 偏移 + 卦画边缘软化，f58–f69 镜片圈扩张出画；f66 星芒 G 半尺寸在 P\*；f78–f84 金光沿六爻扫过。光束 4 条 + 浮尘 3 层在后期加。

**T1 俯冲穿云（#02，f84–f118）**：六爻 8 片浮条自下而上依次离纸（Li = eo((f − 84 − 1.3i)/8)），墨 → 金 → 云白，印刷边被噪声撕开成云边，HDR 2.2 起晕；纸上那一画同时淡到 15%。相机按 DESIGN 5.1 的关键帧对准上六断口直落（每个分量单调插值），上六两半像门一样从画面两边擦过；f99–f101 纤维闪换景（σ ≥ 10 的暖白纤维，不是纯白）。CLIFF 一侧：两张纸云层（顶面从纸色冷却到冷灰）、谷底俯看层（林地 / 草坡 / 雾斑块）、云海 f102–f106 散开；拉平时六二 / 九四两排云带从"平铺在谷里"转成"立起来的一条线"，草坡和小松从云下浮上来，f118 落到 #03 起始机位。

**S2a 卦象远景（#03，f119–f179）**：大远景长焦（vFOV 30 → 28.5°），前移 2.5 m、右移 0.6 m。远 → 近：天穹、A12 南山底板（2800 m，按色差抠天，九五即天际线）、九四云带、远中雾面、草坡（3D 缓丘）+ 5 只鹿（R02 拆开、二值剪影、腰线剪切走路一拍二）+ 坡上小松、六二云带（缺口 x 330–690）、近雾、崖面（3D 位移网格，竖皴点苔）、平台（3D 回转体、不规则外缘）、一人一豹（A05、A01 姿态 A，梯度映射灰豹 + 湿墨斑，接触阴影）、右侧暗崖与松（暗框）、前景暗岩（初九，9 m，前移时放大约 1.4 倍）、三层雨（读场景深度，人物前面不下雨）。

**S2b 洞内看出·七日（#04，f180–f253）**：洞内机位，极慢前推 0.25 m；洞口暗拱是围在相机前 1.45 m 的程序环（超椭圆开口 + 噪声），toon 着色后内缘吃一点边光。七个剪纸太阳走同一条弧，到顶帧 t_k = {184,191,200,215,222,231,237}，峰值 1.00 → 0.28，拉长 1.25 倍；日夜脉动驱动雾色、天色、调色和接触阴影；f245 耳抖、尾尖慢卷、呼吸一拍二；f230–f253 雨加密加斜，f248 起画右金色预兆、左上湿墨光。

**S3 面具集市（#05–#09，f254–f347）**：A13 底板（巷尾金雾对灭点）+ 80 枚挂面具（InstancedMesh、5 条悬链线、0.6 Hz 摆、金芒按两帧时隙哈希）+ 14 个人群剪影（3 层深度右 → 左）+ 40 片金箔 + 暗雾；#06 面具甩进来带冲过头（f270–f278 帧表）、拖影帧、斜高光扫和 8 个金芒；#07 A08 侧面手从左下伸来、停在面具前一指远（食指尖环斑墨渍 SEED_STAIN），f306 换蜷指；#08 甩镜 130°（方向模糊最大 140·K）后低头面对雾墙走，身后金光铺在湿石板上，切出一条拉长的影子伸进雾里，调色冷下来；#09 客观镜头冲进面具左眼孔（六次顿挫），眼孔里实时渲染雨中的灰豹。

**S4 豹变（#10–#12，f348–f493）**：#10 镜头接着穿眼孔的推力减速落到指尖侧面（单调插值），灰豹精灵越来越近、假景深糊开；A08 姿态 3 的手 f355–f364 从左上滑进来，食指尖挂在豹肩上方；指尖墨渍 f357–f378 被雨洗开，墨顺指肚流下，f370–f389 聚成墨滴，f390 断开（颈缩 + 卫星小滴），f390–f398 慢镜（雨钟 ×0.15、雨丝缩成珠）。#11 俯拍 3D 豹背曲面（毛向场、两级毛簇笔触只在暗档、雨珠），f401 落背冠状飞溅 + 涟漪，沿毛向树枝状晕开，f412–f420 咖啡环，f420–f424 收紧成第一枚环斑（rosette，SEED_STAIN = 7，就是指尖墨渍的形状），f422 点金；三滴次级墨滴；f420 起波前扫开，原来的湿墨斑逐个收紧成环（回弹到 1.1 倍）、环上金光晚 2 帧。#12 同 #04 机位家族：从豹背后后拉回到 #04 的框；雨停、四张雾片在太阳处撕开、第七日从缺口升起、上帝光；灰 → 金梯度映射 f440–f476 一拍二；f470–f487 形变夹住姿态 A → B 的换图，坐直抬头。

**S5 一跃·逍遥（#13–#16，f494–f651）**：#13 低机位仰拍（ref_03 的调度）：暗崖顶（崖沿对角线，崖顶全在影档）+ 崖沿金线、逆光金豹（backTint 压暗 + 金边）、半在画内的太阳、金雾、金色云海；尾巴一甩、耳竖、蓄力压缩。#14 侧下方跟拍，A02 姿态 1 → 2 → 3 一拍二，轨迹"几乎不下落"，三层云（白场 ≤ 70%）+ 速度云带，第三层顶面金色；尾迹从 f526 起落墨。#15 侧跟 45 m/s，前景 5 座、远景 5 座圆顶山峰（竖向折皱 + 竖皴点苔 + 金边）从云海里冒出、向右飞掠；f586–f603 滑动变焦（31 → 10°，后拉 9 → 28 m，豹的屏幕大小不变）；化开后切到长卷层（南山底板当画心，向右 140·K px/s；云带 230、近雾丝 420；7 只白鹤一拍二扇翅；豹缩小、正弦起伏）。#16 A03 水平翻转，角膜高光对 P\*，代码虹膜（琥珀纤维 + 角膜缘环）、瞳孔 1.0 → 0.82、f642/f644 眯眼两档、身后云带高速左 → 右。

**S6 回现实（#17，f652–f719）**：A06 过右肩伏案，右镜片外缘对 P\*；镜头从 0.99 m 拉到 1.40 m（ss5）、升 6 cm、yaw −3°、pitch −32° → −38°；书摆在左手下（右页木刻豹可见），椅背压住精灵下沿，墙上开亮窗（暖金过曝、窗棂、虚化叶团），光束 + 浮尘从窗那边斜下来。光斑（母题第三次）：精灵 uv 网格（单元与身高比和豹斑同口径），叶缝门控 + 30% 实心光点 + 反相环斑，光斑之外乘 0.84 叶影，在原色上暖色提亮；右手食指尖那一枚用 SEED_STAIN；桌面、书页上另有世界坐标的光斑。补书三笔一拍二（f660、f670、f681）。题字：志莽行书竖排，右列「君子豹变」x 1660、左列「其文蔚也」x 1560，首字顶 y 210，84·K，逐字洇出（f687 / f689 / f691 / f693、f697 / f699 / f701 / f703，8 帧显全，洇边从模糊收紧），字后垫柔光；f710–f719 淡到纸白（纸纹保持），题字晚 3 帧才淡出。

**本轮查到的三处根因（问题单里没有点名，但几条问题都出在这里）**
1. **GPU 上的浮点哈希成行跳变**：共用的 `hash12()`（浮点哈希）输入一大（种子偏移几百以上）就会在 5090 上按行出错——同一个格点在相邻两格里被算成不同的值，值噪声出现一行行横向错开的跳变。v1-02 说的"横向撕裂、错行的拉丝"、这一轮新云块一开始的横纹，都是它。逐层关掉 + 把扭曲场直接输出成条纹图确认（`_work/stills/fix3_dbg_v3/`：有横向断层；`fix3_dbg_v3b/`：换整数哈希后连续）。在 `lib/glsl.js` 加了整数哈希的 `vnoise2i` / `fbm2i`（格点坐标转 `ivec2`，用 PCG），新写的云块全用它；旧着色器不动（随机图样不变）。
2. **加色辉光的面片边**：`glow()` 的高斯在面片边（r = 1）上不是 0，叠在暗处就是一条竖直接缝（v2-03 天空 x≈1559 那条、#13 x≈970 那条）。改成高斯减去边上的值再归一，并在内切圆外收到 0；所有辉光都受益。

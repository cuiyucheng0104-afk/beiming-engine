## 〇、核心主张与参考集说明

### 0.1 核心主张

1. **一口气入书，三次爆发，一口气出卷。** 开头 #01→#02→#03 是一个连续的镜头运动（0–7.5 秒）：书桌主观视角 → 卦爻浮起 → 镜头钻进上六爻（"君子豹变"那一爻）的断口 → 穿过云层的同形缺口落到南山，另外五爻已经铺成了山谷里的五层横带（九五就是远山的地平线）。中段靠配乐里三个最硬的点爆发：10.58 秒墨甩入市、16.70 秒墨滴落上豹背、21.55 秒起跳。结尾前 #15 是一个 3.4 秒的长镜头：侧跟穿云 → 滑动变焦把纵深压平 → 山水用洇墨的方式"化开"成一幅带裱边的手卷。
2. **像不像，靠参考里最稳定的三件事。** 明暗：大块青黛暗部 + 一道 2–5 px 的硬金边；层次：雾吃山脚、一层比一层淡、云是细长的带；笔触：山体顺坡竖皴、脊上点苔，角色平涂一层影、深色墨线、线干净。所有"燃"的手段都从参考里借：卦爻 → ref_07 的云带，速度线 → 拉长的云带，墨甩 → ref_05 干笔皴的肌理，面具 → ref_02 的鎏金青铜。**参考里没有的一律不加**：不加红灯笼、不加紫色阴影、不加漫画速度线、不加胶片颗粒。
3. **母题是一个函数、一组种子。** 指尖墨渍、豹斑（从湿墨团到成环）、尾迹墨点、窗下光斑，全部由同一个 `rosette()` 画（3.3d）。陆蔚指尖那枚墨渍用种子 `SEED_STAIN = 7`；墨滴落到豹背上收紧成的第一枚环斑用同一个种子；片尾落在他右手食指尖上的那一枚光斑还是同一个种子。三次出现是数学上同一个形状。
4. **一个闪点。** `P* = (1236, 438)`（设计像素）。S1 眼镜戴上时镜框一闪（f66）、S5 末尾豹眼里亮起星芒、S6 镜片一闪，都在这一点。匹配剪辑的切点 f652（27.167 秒）正踩全曲最强的低频起音。
5. **一个框用两次。** #04（洞内看出：灰雾、雨、七个太阳一个比一个淡、豹低着头）和 #12 的收尾（同一个框：雾散、第七个太阳从远山缺口升起、金豹坐直抬头）。"豹变"用同一构图的前后对照讲出来。
6. **方向。** 豹变之前书中世界的运动都从左往右（鹿群、七日）；豹变之后豹朝左、向左飞，长卷按手卷的读法自右向左展开（底板向右走），和片尾竖排字从右往左读是同一个方向。

## 一、视觉语法（12 条，可直接执行）

数值都按 1040 高的设计画面给，实现时乘 `K = innerHeight / 1040`。

1. **暗部整块化，青黛不发紫。** 暗部压成大块、少细节的青黛或墨绿，不在暗部里画纹理；画面里最大的那块暗是构图的"地"。逆光镜头暗部占 25–50%。——ref_03（浓墨 29–34%）、ref_08（26–32%）、ref_06。
2. **逆光 + 一道硬金边；金只在光照到的地方。** 主光在被摄体后方或侧后方（与视线夹角 ≥ 110°），受光侧只给 2–5 px 硬亮边：晴天金 #E8C45C / #F3D27A，雾里淡青白 #AFC3B6，林间黄绿 #C8D27A。不用正面平光。——ref_03 人物与崖沿、ref_06 石顶、ref_08 梯田金边。
3. **雾吃山脚，层层退远。** 每座山、每块崖的下部 25–40% 化进象牙雾；相邻两层明度差 ≥ 12%，越远越亮、越青、越软，最远一层只比天暗 10–15%。——ref_04、ref_05、ref_07、ref_00。
4. **云是带，雾有撕边。** 云主要是细长横带（粗 3–10 px、长 150–700 px、两端收尖、40% 成对平行）和大片软纱，不画卡通棉花团；竖向雾片的上缘是横拉 4:1 的干笔撕边，下缘才柔化。——ref_07 云带、ref_05 软纱与雾瀑、ref_04。
5. **顺坡竖皴，脊上点苔。** 山体、崖面的纹理是顺坡向下的长干笔条（长宽比 ≥ 12:1，宽 4–9 px），脊线和崖顶点深墨苔点（3–8 px）；岩层台阶处才出硬折痕（斧劈感）。不用各向同性的细碎噪声当石纹。——ref_05、ref_07、ref_04、ref_08 岩块。
6. **色相纪律。** 书中世界彩色像素 75% 以上落在 150–200°；金只出现在光照到的地方；赭、锈红只做 ≤ 2% 的点缀。S2 全段几乎没有暖色；金色只出现在集市（假金）和豹变之后（真金）。ref_03 那种"金独大"只给 S5a 崖顶一个镜头。
7. **留白是象牙白，不是纯白。** 天和雾的亮部取 #E6EEE6 / #EEF3E8 一族；除星芒外最亮不超过 #F3F6EE；天空几乎平涂（亮度起伏 ≤ 8%）。——ref_05（留白 29%）、ref_04、ref_01 天空。
8. **角色线干净：平涂 + 一层影 + 墨线；飞白只给墨。** 每种材质只有亮、影两档；外轮廓 2.6–3.2 px，现实段线色 #2B2119，书中世界 #1E2422；皮毛、布料纹理只用暗档里几笔短排线。——ref_01、ref_03。
9. **人小天地大，背影看纵深。** 大远景里人物 ≤ 画高 10%，放在三分线上；只给背影或 3/4 背影，人物朝向与"人物→镜头"方向的夹角 ≥ 120°，保证不出脸；剪影的上沿压在亮雾或地平线上。——ref_00、ref_03、ref_08。
10. **前景暗框。** 书中世界每个镜头至少有一块暗色前景（岩、洞口、松枝、袖子）压住 1–2 条画边，占 8–20%，不受光。——ref_06、ref_08、ref_03、ref_01。
11. **光有体积，点有节律。** 每个镜头只有一个光向；光束是加色 +10–25% 的斜向软带，带里有 2–5 px 浮光点（40–120 粒），只在亮的体积里出现。重复的小形（七日、鹤群、尾迹墨点、光斑）沿一条弧线由大到小排开，弧线方向和运动方向一致。——ref_08 光束与浮光、ref_04 鹤群斜弧、ref_01 草地光斑。
12. **镜头语法。** 远景用长焦压缩出层层叠叠的画卷感，慢推或匀速横移；角色镜头低机位、略仰、多背影，基本不动或极慢推；只有转场和动作段用广角快动。地平线放下三分（仰看）或上三分（俯看群山）；主体沿对角线或 S 线排布（ref_03 崖沿对角、ref_00 河道 S 线、ref_08 梯田 S 线）。

## 三、着色与后期参数表

### 3.1 全局约定

- 设计画面 1920×1040，`K = innerHeight / 1040`。文中屏幕像素量写作"N·K"，代码里一律乘 K；设计坐标换算：`X = (x − 960)·K + W/2`，`Y = y·K`。构图锚点、"高 N px"同样是设计像素；标"精灵原图"的是贴图像素，不乘 K。屏幕空间哈希网格的格子也乘 K（雨、浮尘、金芒、光斑），屏幕噪声一律用 `gl_FragCoord.xy / K` 作坐标。
- `look.js` 内部按 H/1080 缩放：传给 look 的像素参数是 1080 标定值，**下表写的就是直接传给 look 的数**，不再另乘 K（设计像素 × 1.0385 = look 参数）。
- 帧：`f = Math.round(t * 24)`。镜头切换、姿态选择、事件按 f；镜头、雾、雨、水、墨、光按 t 连续算。区间写成 fA–fB，含首尾两帧，秒数写 A/24–(B+1)/24。
- 一拍二：角色姿态、精灵网格形变、手持物体、手绘特效（墨甩、溅墨、甩墨）用 `f2 = f − (f % 2)`、`t2 = f2/24`。**例外**：#14、#15 跟拍飞行的豹，根位移按 t 平滑，只有姿态换图和形变一拍二。
- 世界单位：米。书中世界相机 near ≥ 0.05、far 8000；现实段 near 0.01、far 20。
- 确定性：所有随机用种子哈希（`scene.js` 的 `hashi`、`engine/core/math.js` 的 `mulberry(seed)`）。**`engine/core/noise.js` 的 `createNoise2D/3D` 默认参数是 `Math.random`，必须显式传 `mulberry(seed)`**；几何位移在加载时用固定种子算好。
- 输出：`renderer.toneMapping = NoToneMapping`（toon.js 保色板的约定），sRGB 输出。颗粒：页面内 0、mux 0（参考是干净的数字绘画）。
- 纸纹：用 look.js 的程序化纸纹（已按 H 缩放）；`assets/plates/` 下**不放** paper.png。若评审要更强的纤维，再拷 `films/_lib/paper.png` 进来并把 `paper.scale` 设成 K。

### 3.3 D 版自加的着色钩子（写进自己拷贝的 toon 材质 `fragmentAlbedo`，或独立 ShaderMaterial）

**a. 竖向皴（规则 5，ref_05）**——物体空间、沿世界竖直方向拉长，只作用于陡面：

```glsl
vec3 Q = vToonObj;                                                   // 物体空间（米）
float steep = 1.0 - smoothstep(0.45, 0.65, abs(vNormalW.y));          // 需要加一个世界法线 varying
float s1 = toonNoise(vec3(Q.x * 9.0, Q.y * 0.55, Q.z * 9.0));         // 横 9/m、竖 0.55/m → 宽 5–10 cm、长约 1.8 m
float s2 = toonNoise(vec3(Q.x * 19.0 + 7.0, Q.y * 1.1, Q.z * 19.0));
float st = 0.65 * smoothstep(0.16, 0.24, s1) + 0.35 * smoothstep(0.30, 0.36, s2);
diffuseColor.rgb *= 1.0 - uStreakAmt * st * steep;                  // uStreakAmt：rock 0.14，rock_deep 0.08
```

20 m 机距、vFOV 30° 下条宽约 4–8 px、长约 150 px（物体空间纹理，随分辨率等比，不乘 K）。

**b. 点苔（规则 5）**——只在朝上的面和脊沿：`up = smoothstep(0.45, 0.70, vNormalW.y)`；`d = toonNoise(vToonObj * 7.5 + 31.0)`；`toonInk = max(toonInk, smoothstep(0.42, 0.47, d) * up * 0.85)`，墨点用 inkColor #1C2622，3–8 px。

**d. 母题环斑 `rosette()`——墨渍、湿墨斑、成斑、尾迹墨点、光斑共用同一个函数**

```glsl
// p：以斑心为原点、按半径 R 归一化的坐标；seed：每枚斑的种子；aa：抗锯齿宽（≈ fwidth）
// crisp：0 = 湿墨软边，1 = 干透硬边；ring：0 = 一整团，1 = 环；petals：缺口数 0 / 3 / 4 / 5；ringW：环宽；wob：轮廓起伏
// 角向噪声一律在单位圆 (cos a, sin a) 上取，保证 a = ±π 处没有接缝
vec2 rosette(vec2 p, float seed, float crisp, float ring, float petals, float ringW, float wob, float aa) {
  float r = length(p), a = atan(p.y, p.x);
  vec2 u = vec2(cos(a), sin(a));
  float rr = r * (1.0 + wob * (vnoise2(u * 1.3 + seed * 7.1) - 0.5) + 0.08 * (vnoise2(p * 3.0 + seed) - 0.5));
  float e = mix(0.30, 0.04, crisp) + aa;
  float rg = smoothstep(1.0 - ringW - e, 1.0 - ringW + e, rr) * (1.0 - smoothstep(1.0 - e, 1.0 + e, rr));
  if (petals > 0.5) {
    float g = 0.5 + 0.5 * cos(petals * a + seed * 6.2832 + 1.2 * (vnoise2(u + seed * 3.1) - 0.5));
    rg *= smoothstep(0.12, 0.26, g);                                   // 断成几瓣（豹斑的"梅花"）
  }
  float blob = 1.0 - smoothstep(0.70 - e, 1.0 + e, rr);                // 湿墨：一整团
  float tide = smoothstep(0.86, 0.90, rr) * (1.0 - smoothstep(0.92, 0.97, rr)) * ring;  // 潮线：墨干后外圈更深
  float ink = mix(blob * 0.55, rg, ring) * (1.0 + 0.35 * tide);
  float heart = 1.0 - smoothstep(0.44, 0.56, rr);                     // 环心区域
  return vec2(clamp(ink, 0.0, 1.0), heart);                           // ink 是墨量（光斑时当光量）
}
```

JS 端同名同参函数（Canvas 画指尖墨渍、墨甩溅点、尾迹时用）。

**豹斑在精灵上的分布**（还原稿离线模拟验证过）：精灵 uv 里按网格单元做抖动点，单元 = 精灵高 × 0.078，哈希抖动 ±0.45 单元；加载时把精灵 alpha 模糊（半径 = 精灵高 × 0.06）得到体内度 `I = clamp((blur − 0.45)/0.5)`，`R = 单元 × (0.27 + 0.18·I) × (0.8 + 0.4·hash)`；I < 0.35 的头、腿、尾改用实心小斑；斑心落在墨线档、腹档上的不放；眼、口鼻用 manifest 的椭圆排除。**湿墨斑和成斑是同一组格点**：豹变就是同一枚斑从湿到干、从团到环。光斑（#17）在陆蔚精灵上用同样的单元/身高比例，密度与豹身一致。

**e. 豹背毛面与墨晕（#10 背景、#11）**

- 毛向场 `T(p) = normalize(vec2(1, 0.35) + 0.4·curl(fbm(p·1.5)))`（从脊线往两肋、往后流）；毛笔触 = 沿 T 拉长的噪声（长 14–22·K、宽 1.5·K）量化成两阶（#8E9591 / #5D6663，笔触 #3E4646）；雨珠 3–6·K 亮点带暗沿；湿墨斑按 3.3d 的湿态画在同一组格点上（表面坐标，格距 4.5 cm）。
- 墨晕（u = f − 401，落点 c，Rmax = 120·K 按 f401 时的画面尺度）：

```glsl
vec2 d  = p - c;
vec2 da = vec2(dot(d, T) / 1.4, dot(d, vec2(-T.y, T.x)));            // 沿毛向快 1.4 倍
float R1 = Rmax * (1.0 - exp(-u / 4.0));                              // f401–f412 晕开（先快后慢）
float edge = 0.22 * fbm(p * 0.09 / K + seed) + 0.18 * fbmAlong(p, T);   // 树枝状边：沿毛丝渗（fbmAlong = 沿 T 拉长 3 倍取样）
float blot = 1.0 - smoothstep(R1*(1.0+edge) - 2.0*K, R1*(1.0+edge) + 2.0*K, length(da));
float kR = smoothstep(412.0, 420.0, f);                               // 环化：边浓心淡（咖啡环）
float ringish = mix(blot, blot * smoothstep(0.45, 0.85, length(da) / max(R1, 1.0)), kR);
float t2 = smoothstep(420.0, 424.0, f);                               // 收紧：半径 ×0.88，断成 4 瓣
vec2 ros = rosette(da / (R1 * mix(1.0, 0.88, t2)), SEED_STAIN, t2, 1.0, 4.0, 0.42, 0.25, aa);
float ink = mix(ringish, ros.x, t2);
vec3 inkCol = mix(vec3(0.231, 0.290, 0.322) /* #3B4A52 */, vec3(0.102, 0.129, 0.149) /* #1A2126 */, smoothstep(0.3, 0.9, ink));
```

**f. 书页（#01、#02、#17）**——左页：以 R01 左页为底（降饱和 ×0.65、往 #E3D5B8 拉），代码重画成 2048×2867 画布：卦画 ䷰ 印在纸上（与 3D 爻条完全重合；爻条浮起时纸上那一画淡到 15% 的墨影）；卦画上方「革」（马善政楷书，字高 0.022 m）；卦画下方两小列「君子豹变」「其文蔚也」（马善政楷书，字高 0.016 m，墨 #1E1A16，带轻微印刷不匀）。右页木刻豹直接用 R01 右页。**无限放大的纸**：当一个贴图像素在屏幕上大于 1 px（看 fwidth(uv)），淡入程序化纸纤维（三级各向异性噪声，0.4 mm、1.2 mm、4 mm）；#02 里纤维与云 fbm 同尺度交叉。受光两阶硬分（阈值 0.5）。

### 5.4 化开成长卷（#15，f586–f611）

- **先压平**：滑动变焦（vFOV 31° → 10°，后拉 9 → 28 m）把纵深压成层（f586–f603）。

  - `n = 0.65·fbm(p·0.0035) + 0.35·fbm(p·0.014)`（p 用设计像素，屏幕噪声按 K 缩放）
  - `τ(f) = −0.15 + 1.3·ss((f − 596)/15)`
  - n < τ 的地方显示长卷，否则显示三维画面。
  - 边带 |n − τ| < 0.04：用 #15181F 压暗 45%，并沿 ∇n 方向把三维画面推开 6·K，像湿墨在纸上洇开。

- 裱边 f600–f611 从上下滑入（ss），纸纹强度 0.09 → 0.14。

> **降级**：化开看着像廉价交叉淡化时，只做横移，让长卷代替远景层，雾片盖住过渡。

## 附录 A　关键取舍的理由

1. **画风以参考为准，不按 STYLE 字面。** 规范第四节的画风还原标尺是"截一帧放进参考板里，看不出是外人做的"。参考板的暗部色相实测是青黛，角色线干净，没有速度线，所以"青紫暗部""角色飞白""漫画速度线"都按参考改写，STYLE 里的意图（暗部偏冷、线有力度、有速度感）用参考里有的形来实现。
2. **T1 用电影稿的"钻进上六断口"，换景用纤维闪。** 上六爻辞就是"君子豹变"，钻进这一爻的断口，比"六爻化云从身边掠过"更有"穿过书页"的实感，也更有意义；纤维闪在 4.144 秒起音上一闪即过，不需要两个场景同时渲，比还原稿的 3 帧交叉淡化省事，也没有接缝风险。
3. **五爻落成山谷的五层横带，九五就是地平线。** 这直接兑现 BRIEF 的"横画变成远山的地平线"，又保住了电影稿"整座山谷排成一个卦"的想法；上六不进地景（我们是从它的缺口穿过来的），避免还原稿"上爻变形成天际线"那种难做的形变。
4. **S2 两个长镜头，不切三刀。** BRIEF 要 S2"静、长"。还原稿的侧向大远景 + 洞内看出比电影稿的三刀更静；洞内看出这个框还要在 #12 用第二次（灰雾等待 ↔ 金光完成），这是全片讲"豹变"最省力也最清楚的办法。代价是没有电影稿的雨中豹侧脸特写，豹的"毛色暗淡、斑点像没干的墨"只在 250 px 高的背影上看；#10、#11 的灰毛近景会补上这一层。
5. **七日踩七个起音。** 7.66 / 7.96 / 8.33 秒是全曲最强的一组宽频起音，后面四个一个比一个弱——"一个比一个淡"正好跟着配乐的强弱走。还原稿的第四日（f211）底下没有起音，改到 f215（8.978 秒低频）。七日走同一条弧，读成"一天一天重复"，而不是"一个太阳走了一天"。
6. **集市不用红灯笼。** 参考里没有；红灯笼夜市正是规范说的"通用国风插画"。集市的"满、吵"靠成百个挂着的鎏金面具、人群剪影、金芒和快切；"假"靠规整得像印上去的金钉（ref_02 的青铜浮雕）。
7. **S3 走主观视角。** 递面具、抬手、转身，全用陆蔚的眼睛看，最后切回客观镜头钻眼孔。这样手和面具同框最直接，不用画走路的背影；甩镜 + 被金光拉长的影子讲"转身走回雾里"，只花代码。
8. **豹毛灰 → 金，不做银豹。** 金与青绿是色板里最强的冷暖对比，S5 长卷里一只金豹在青绿山上最清楚；银豹在青灰雾和青绿长卷上对比太弱。STYLE 要的"斑纹带一点金光流动"保留为环上的金光流动，环心是写实的暗赭，不做发光的金心（避免首饰感）。

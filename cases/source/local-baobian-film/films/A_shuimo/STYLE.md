# A · 水墨（山水情 / 牧笛 / 鹿铃 / 鹬蚌相争）
参考：refs/A_shuimo/（先看 refs/A_shuimo_board.jpg）
- 画风：上美影四部水墨动画的语言。没骨，不勾线（最多在豹的眼、鼻、爪尖点几笔焦墨）；墨分五色（焦、浓、重、淡、清）= 3D 卡通着色用 4–5 阶，交界很软并有噪声扰动，像墨在宣纸上洇开；留白 ≥ 50%，雾就是空白的纸；淡彩只用赭石、花青、少许藤黄，浮在墨上、不碰边；全画面宣纸纤维纹 + 边缘洇墨（屏幕空间后期）。
- 现实段（S1、S6）也用水墨淡彩，偏暖赭石，和书中世界同一套笔墨，只是更暖更实。
- 角色：豹按齐白石式大写意动物画，几团笔块概括，眼睛琥珀色是全片唯一的亮色点。
- 镜头：横移、缓推为主，像展卷；S5 用长卷横移加上下层视差。
- 转场：T1 用「墨晕化开」：卦爻浮起后墨在纸上洇开，吞没画面，再从洇痕里显出远山；S3 面具集市可以是淡彩里唯一一抹朱砂和金，眼孔推进后用墨晕回到雾崖。

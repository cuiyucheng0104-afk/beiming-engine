## 〇、核心主张与总则

**核心主张：**画面只由宣纸、墨的五个浓度和一两处淡彩组成；三维只做两件事——给墨找形、给镜头找深度；每个像素最后都过"墨在纸上"这道物理（减色叠加、洇、水渍边、纸吃墨）。全片靠**三条形状链**一路传下去，每一环都用同一个形状接上：

1. **卦画链**：书页上的六爻 ䷰ 浮起 → 横画变成南山六重山的山脊。两道阴爻的缺口各有去处：六二的缺口是鹿群走过的山口，上六的缺口是"天门"，七日从这里升落，第七日雾散后的太阳也从这里出来。
2. **母型链**：指尖墨渍 → 豹背环斑 → 窗下光斑，是同一个程序函数 `rosette()`（3.6）。**种子 7** 出场三次：S1 食指指肚的墨渍、S4 第一滴墨收紧成的 0 号斑、S6 落在同一根食指尖上的那一圈光。
3. **光点链**：戴眼镜时镜片一闪（入书）→ 豹眼一闪 → 镜片一闪（出书）。

**节奏三颗钉子**（全部实测，见附录 A.2）：12.15 s 的低频重击递出金面具；17.11 s 全曲最强起音让第一枚环斑"啪"地定形；22.86 s 全曲低频能量最大的一击让小豹起跳。18.52 s 的最大涌起是雾散。

**看第二遍才会发现的东西**（取自电影稿）：① S1 书页木刻豹的腹胁被一块新补纸盖住，只补回两枚斑；S6 补齐了。② S4 结尾的全景机位与 S2 终帧一模一样，灰雨换成了晴日。③ S6 他食指上的墨渍没了，原处落着一圈光。④ 七个太阳、七枚尾迹墨点。

| 总则 | 规定 |
|---|---|
| 尺度 | 屏幕量一律 K px。着色器里屏幕空间噪声用 `q = gl_FragCoord.xy / K`。从 `look.js` 拷来的代码，把第 541 行 `H / 1080` 和第 664 行 `k = H / 1080` 都改成 `H / 1040`，全片一个口径。 |
| 帧与一拍二 | 角色类动作（豹、人、手、鹿腿、灯笼摆、面具递出、金箔闪、手指搓动）一律用 `t2 = Math.floor(f/2)*2/24`，即只在偶数帧换姿态或位置；镜头、雾、雨、水、云、日、光斑、墨晕、墨滴下落按 24 fps 平滑，直接用 t。姿态切换点一律落在偶数帧。 |

## 一、视觉语法（12 条；出处已逐条对照参考核实，见附录 A.1）

**R1 纸就是雾，留白过半。**
- 出处：近纸色占比实测 ref_00 81%、ref_02 69%、ref_06 77%（阈值见下）；ref_03 / ref_01 纸色加清墨合计约一半。
- 执行：雾等于不着墨，不是灰蒙版。雾和空气透视一律往当段纸色里混。物体化进雾里时，不透明度和墨浓同时下降。
- 留白定义：亮度 ≥ 纸 − 0.15 ×（纸 − 焦）的像素。每镜下限见第二节；S3a 和 T1 吞没帧是有意例外。

**R2 墨分五色；深墨要么成块，要么成点。**
- 出处：ref_01 五阶 #070A17 / #36404A / #68727C / #98A3AF / #B5C0CE；深墨成块的 ref_01 31%、ref_03 35%；只作点缀的 ref_02 5%、ref_13 4%。
- 执行：每个墨块只用相邻 2–3 阶。焦墨只点睛（眼、鼻、爪尖、洞底、脊线、卦爻），面积 ≤ 5%。深墨要么聚成一块压一角或一边（25–35%），要么 < 8% 只作点；不准满屏均匀中灰。最暗不低于"焦"，最亮不高于"纸"；镜光、留白闪光例外，面积 ≤ 0.3%。

**R3 动物和山石没骨，人物白描淡彩。**
- 出处：没骨 ref_00 青蛙（一团墨，四肢一笔，焦墨眼圈和爪）、ref_07 雾中牛群、ref_09 水牛；白描 ref_02、ref_06、ref_08、ref_12；ref_13 小鹿身体是赭墨洇块、腿是细线——鹿铃里动物的细腿也用线。
- 执行：小豹、鹿、崖、松、山不画轮廓线，形靠墨块边缘；人物线条见〇的线条政策。

**R4 边是洇出来的，不是模糊出来的。**
- 出处：ref_02、07、09、10、13 强边缘 10–90% 过渡宽度约 0.4–0.6% 画高，即 1040 高下 4–7 px；ref_04 柳枝墨团是花椰菜状洇边，宽 12–25 px。
- 执行：主体墨块边缘 5K；焦墨点 3K；淡墨远山 9K；雾边 30–60K；边缘带 ±3K 不规则噪声位移。禁止整幅高斯模糊，禁止矢量硬边。

**R5 水渍边：边上深，心里浅。**
- 出处：ref_00 左下芦叶（边深心浅最清楚）、ref_04 赭石带下沿和卵石的深边、ref_09 地面色块。
- 执行：后期"水渍边"只加深暗侧，不出亮晕（3.3 ⑤）；代码色块（日、斑心、光斑、补纸）自带 6–10% 深边。母型 R 的环斑就是这条物理：墨干时颜料往边上走。

**R6 淡彩少，浮在墨上，色不碍墨。**
- 出处：彩色像素（HSV 的 S×V > 0.18）实测 ref_01/02/03/06 为 0%，ref_05 1.8%，ref_11 2.0%，ref_12 1.5%（全画只有一条红裤），ref_13 2.5%，ref_04 13.7%（赭石地）。
- 执行：颜料只用赭石、花青、少许藤黄；S3 只在那一张金面具上用泥金和朱砂。色块比墨形内缩 8–15%、错开 2–4K、边比墨软（6K），不画到墨边上。每镜彩色像素上限见第二节。

**R7 一角压重墨，主体小，落在留白里，走对角线。**
- 出处：ref_03 下沿重墨山、船约 10% 画高；ref_01 左下重崖；ref_05 左侧崖；ref_00 蛙在右下、蝌蚪沿对角上行。
- 执行：远景主体 8–22% 画高，近景 40–70%；主体背后永远是亮处；重墨块压一角或一边并出画；对面留出 ≥ 35% 的连续空纸。

**R8 前景用枝或石作框，近、中、远三层分开。**
- 出处：ref_04 柳枝压顶、ref_07 树干占右、ref_08 枝干横穿、ref_09 两侧柳树夹景。
- 执行：每个外景镜头至少三层（近景重墨可虚、中景主体、远景淡墨山加雾），面片按深度摆，镜头一动就有真视差（上美影多层摄影台）。

**R9 山头实，山脚虚；远一层淡一层、偏青一层。**
- 出处：ref_03 右上浮山顶深底化进白雾；ref_13 远山顶深底淡；ref_11 远山偏紫青。
- 执行：山脊"顶线浓、往下褪"；高度雾把山脚化成纸；远层墨浓逐层递减，每远一层向花青偏 12%。

**R10 水、雨、风都用线。**
- 出处：ref_03、ref_06 水纹是成组的短细断线、越远越小；ref_04 的风雨是又长又淡的斜线。**两稿都写成"左上→右下、14–20°"，与参考不符**：ref_04 主区域的雨线和柳丝同向，从右上斜向左下，偏离竖直约 35–40°（那是一场大风）。
- 执行：本片雨丝方向取参考方向（从右上落向左下），角度取 18°（雾雨，比 ref_04 的大风缓）；长而细的淡墨斜线，不用粒子圆点。雨色向淡墨混合，压在纸上显深、压在崖上显浅。

**R11 动得少、动得慢；快动作用淡墨残影。**
- 出处：ref_06 共 22 帧，镜头不动、船基本不动，只有少年撑篙；GIF 每帧 110–140 ms 是转 GIF 时的抽帧间隔，**不能据此推画稿的拍数**（两稿各有一处据此下的结论，均不采用）。
- 执行：角色一拍二；大部分时间只有呼吸加一个小动作。S5 起跳用 3 层淡墨残影，不用运动模糊和速度线（残影是本片自定的手法；ref_13 小鹿后腿那两条更像左右两条腿，不作出处）。

**R12 镜头横移或缓推，转场用虚焦与墨晕化开。**
- 出处：ref_06 第 18–21 帧画面整体发软、化进纸里；山水情以长卷横移和缓推为主。
- 执行：T1、S3→S4、S5 穿云都用墨晕或虚焦化开；只有 S3 允许快切和手持（"变吵"是剧情要求）。

**不要学的地方：**ref_02、ref_06 深色物体外那圈等宽白晕（连撑篙竿都有）是视频锐化振铃，不是画风；ref_08 牧童的饱和橙肤是赛璐珞上色，不学色、只学线；ref_10/11 的石青、紫蓝超出 STYLE 允许的颜料。

## 三、着色与后期参数

### 3.1 3D 水墨材质 `films/A_shuimo/lib/inkwash.js`（新写 ShaderMaterial，结构参照 `_lib/toon.js`；`_lib` 不动）

片元里算墨浓 D（0 = 纸，1 = 焦）：

```
hl = 0.5·dot(N, L) + 0.5
D  = Dbase + 0.85·(1 − hl) + 0.35·cav + 0.22·cun + 0.25·rimTop + en
```

主光 L（世界空间、指向光源）：S2/S4 (−0.35, 0.85, 0.40)；S5 (0.30, 0.85, 0.42)；S1/S6 书页 (0.55, 0.80, 0.25)（窗在右上）。

| 项 | 做法 | 参数 |
|---|---|---|
| 分阶 | 5 阶加纸：纸｜清｜淡｜重｜浓｜焦 | 阈值 D = 0.18 / 0.36 / 0.54 / 0.72 / 0.88。只有光照项时焦墨到不了，必须靠凹度、皴、顶轮廓叠上去——"石分三面"：顶面留白，正面淡、重，侧面浓，缝里焦 |
| 交界软硬 | 每道阈值羽化 | 0.045 + 1.2·fwidth(D)；加上后期洇 3.5K，屏幕上合计 5–9K，与 R4 实测一致 |
| 交界扰动 en | 物体空间 fbm | 0.10·fbm(P·0.9/m) + 0.04·fbm(P·3.5/m) |
| 凹度 cav | 生成几何时预算到顶点属性 | (邻点平均位置 − P)·N × 3/m，夹 [0,1]，平滑 2 次 |
| 皴 cun | 各向异性 fbm(x·5, y·0.6, z·5)/m（竖向披麻皴） | smoothstep(0.12, 0.24, n)，只加在 \|N.y\| < 0.6 的竖面 |
| 顶轮廓积墨 rimTop | smoothstep(0.55, 0.90, 1−\|N·V\|)·smoothstep(−0.1, 0.4, N.y) | 乘 (0.7 + 0.3·fbm(P·2/m)) 断笔；用墨块边缘代替勾线（ref_01 崖顶） |

### 3.2 2D 资产着色与合成：精灵和底板统一墨色

1. **墨色归一**：manifest 里记录每张图的纸亮度 Lp（95 分位）和墨亮度 Li（1 分位）。着色器算 `D = clamp((Lp − L)/(Lp − Li), 0, 1)`，按当段六色重新上色；饱和度 > 0.15 的部分保留色相、明度按 D 映射。多次生成的图墨色一致，也和 3D 层同一套墨。
2. **两类合成**：
   - A 类（白底墨画，不遮挡后景）：`cub_head_cu`、`market_crowd`、`woodcut_leopard`、`scroll_mid`。正片叠底 `out = bg × src`，白即透明，不出毛边。底图白要拉到 ≥ 250，否则叠底出灰框。
   - B 类（要遮住后景）：小豹、陆蔚、手。alpha 作遮罩，遮罩内是归一后的颜色 C_remap（资产里纸的部分 = 当段纸色）：`out = mix(bg, C_remap, α)`。浅衬衫、浅豹腹能挡住深洞口，颜色不来自抠图边缘，所以不出彩边。
3. **边缘**：alpha 先腐蚀 1.5K 再羽化 2K。小豹另加毛边：alpha 阈值抖动 ±0.08、频率 1/(3K)，静态不随时间变。
4. **去边**（资产角色在 Mac 上用 Python 做）：alpha < 0.98 的像素，RGB 用 3 px 内完全不透明邻点的中位色替换，再去饱和 70%；在黑底、白底上各合成一次检查，不能有白边、彩边、棋盘格。
5. **网格形变**：角色面片切 24×24 网格，顶点着色器里用控制柄驱动（尾巴转角、头部俯仰与转动、胸腔呼吸缩放、手指弯曲、拇指搓动），权重按到柄根的距离衰减；柄的位置记在 manifest。

### 3.3 后期链 `films/A_shuimo/lib/inklook.js`（从 `_lib/look.js` 拷出来改）

**顺序**：主场景（HalfFloat 线性，MSAA 4×，带深度）→ ① 空气透视雾 → ② 虚焦（按层或全屏）→ ③ 柔焦 → ④ 洇 → ⑤ 水渍边 → ⑥ 调色 → ⑦ 墨粒 → ⑧ 宣纸纹 → ⑨ 纸边吃墨 → ⑩ 颗粒 → 屏幕。字幕画进纹理后在 ④ 之前合成，跟着吃洇（强度 ×0.25）、纸纹和颗粒。

**关闭**：Kuwahara（出平块硬边，像油画水粉）；墨线描边；bloom（只在镜光、豹眼、光斑处用代码画局部加色光点）；`look.js` 的 `paper.png`（`paperUrl: null`）。

**各步公式：**
- **① 雾**：`look.js` 的 FOG，颜色 = 当段纸色；清屏处（天）浓度 1。
- **② 虚焦**：可分离高斯，σ 以 K px 计。
- **③ 柔焦**：`c = mix(c, blur(c, σ=2.5K), s)`（隔玻璃拍多层画的软）。
- **④ 洇**：半径 R 的圆盘上取 12 点，每像素用一张静态噪声（频率 1/(18K)）转角度；`dmin = min_i( L(p+o_i) + 0.35·|o_i|/R )`；`c = mix(c, c·dmin/L, A·smoothstep(0.03, 0.25, L − dmin))`；再做 σ = 1.0K 小模糊。效果：暗处向亮处长出不规则毛边。
- **⑤ 水渍边**：`E = L − blur(L, σW)`；`c = c·(1 + S·min(E,0)/max(L, 0.05))`；只作用于 0.12 < D < 0.85。
- **⑥ 调色**：沿用 `look.js` 的 warmth；调饱和度；最暗钳到"焦"、最亮钳到"纸"（镜光、留白闪光除外）。
- **⑦ 墨粒**：`c *= 1 + G·4D(1−D)·(0.6·n1 + 0.4·n2)`，n1 频率 1/(1.4K)、n2 频率 1/(5K)，种子静态。
- **⑧ 宣纸纹**（程序生成，不用 `_lib/paper.png`：实测它是亮度标准差 28 的厚浮雕纤维纸，不像宣纸）：长纤维（长 90–240K、宽 0.8K、±3%）+ 斑驳（频率 1/(220K)、±4%）+ 细颗粒（±1.5%），强度见表。**纸纹 UV 跟着本镜指定的"纸锚层"走**：每帧把该层上一个世界点投到屏幕，`uv = (q − 锚点位移/K)/锚层缩放`，推拉时一起缩放，避免"纸钉在屏幕上、画在纸下滑"的玻璃感。纸锚层：S1/S6/T1 前半 = 书页；T1 后半/S2/S4 = 崖台层；S3a = 人群底板，S3b–S3d = 面具；S5 = 长卷底板；T2 = 豹头底板。
- **⑨ 纸边吃墨**：强度 V，半径 smoothstep(0.42, 1.12)，乘 (1 + 0.25·fbm(边缘角度))；像纸边吃墨，不是光学暗角。
- **⑩ 颗粒**：三角分布 ±a（单位：亮度 0–1），按 4L(1−L) 加权，格子按 q 取整，种子 = f。`mux.sh` 的 grain 为 0，颗粒只在页面里画一次。

### 3.6 母型 R：墨渍、豹斑、光斑是同一个函数

`rosette(p, R, seed, mode, prog)`：p 是以斑心为原点的坐标，R 是定形后的环外半径，prog 是生命期进度。Canvas 2D 与 GLSL 各实现一份，参数完全相同。

- **字形**：n = 4 + [h(s) < 0.6] + [h(s+1) < 0.3]（4–6 块）；θ_i = θ0 + 2π(i + 0.18(h_i − 0.5))/n，其中 1–2 个缺口放宽到 1.6 倍（C 形断环）；每块是沿切向拉长、略弯的椭圆，半轴 a = 0.42R(0.8+0.4h)、b = 0.20R(0.8+0.4h′)；块内墨浓 1.0，边缘在 0.35b 内软化并加 ±0.18b 边界噪声，外沿深 15%（水渍边）；中心半径 0.62R；θ0 = 2π·h(s+7)。
- **模式**：

| 模式 | 用在 | 样子与时序 |
|---|---|---|
| stain（墨渍） | S1、S3c、S4 指尖 | 字形压成 1.3:1 的椭圆（按下去的指纹墨环），淡心（20%），再拖一笔 0.8R 的抹痕；焦墨；食指指肚 R = 13K（种子 7），拇指 8K（种子 8） |
| wet（未干斑） | S2、S4 f411 前的豹身 | 不成环的软墨团：湿斑色 55%，边缘软化 0.6R，下方拖 1.5R 的雨淋痕（不透明度 0.5） |
| bloom→ring（豹斑） | S4、S5 墨点、S1/S6 补纸上的斑 | **落点**：溅出 6–9 个焦墨小点（3–7K，离心 1.1–1.8R，方向按种子），2 帧内定住。**晕开** prog 0→0.5：单个软圆，半径 1.40R·eo（过冲），墨浓 0.9→0.65，花椰菜边逐渐长出，prog≈0.35 时前沿变深。**收紧** prog 0.5→1（ss5）：外沿收到 1.0R，中心降到 0.25、环升到 1.0，缺口打开，边缘软化 0.35b→0.22b。prog ≥ 1 定形。斑心：S4 雾散后淡入斑心赭 35–45% |

### 5.1 T1 六爻化六重山（f82–f122）

1. **几何**：8 个爻条网格（4 道阳爻、2 道阴爻各两段，BoxGeometry）：阳 0.083×0.0012×0.0072 m；阴两段各 0.034、中缺 0.015。材质焦墨、不受光，顶面用木刻边缘噪声做 alpha；f92–f104 顶点着色器把长度 ×1 → ×2.3，延出部分 alpha 乘沿长度的 fbm 飞白。投影：同形贴片模糊 6–12K、正片叠底 0.3、按高度偏移。
2. **相机**：f60、f81、f94、f102 四个关键帧，`monotone` 插值（4.2）。f100–f104 被墨覆盖，轻微穿插看不见。
3. **墨晕着色器**（屏幕空间，t 的纯函数）：每帧 CPU 把 8 段爻条两端投到屏幕作 uniform，片元里算到 8 个胶囊的最小距离 d（K px）。
   - `B = smoothstep(−w, w, R(f) − d + n)`，w = 24K，`n = fbm(q/60)·120 + fbm(q/16)·30`，`R(f) = 1400K·((f−94)/10)^1.6`（f94–f104）。
   - 前沿 `rim = exp(−((R − d)/14)²)`，深一阶。
   - 纸路：`B *= 1 − 0.6·smoothstep(0.78, 0.86, fbm(q/9))`。
   - 颜色重墨、浓度上限 0.82、叠墨粒 0.1；六道焦墨 2D 线（`inkStroke`，30K 粗）画在墨上。
4. **换场**：f102–f106 在墨下把书页场景交叉溶解成 S2 场景（f102 覆盖率 ≥ 80%）；墨晕层前后连续，盖住接缝。
5. **六线变形**：2D 线 i 的屏幕 y 与长度，从"f100 时爻条投影"插值到 S2 山脊直线（f100–f110，ss）；山脊 amp 0 → 1（f106–f118）；2D 线 f108–f114 淡出。
6. **显山**：`Rv = smoothstep(−w, w, Q(f) − |y − 425|·(1 + 0.3·fbm(x/80)))`，Q 在 f107 为 0、f114 为 700K（eo）；`out = mix(S2, 墨晕色, B·(1 − Rv))`；左下崖区 `Rv_cliff = Rv·smoothstep(114, 122, f)`。
7. **潮线**：每帧把 6 重山的屏幕顶线折线投出来；当退墨边界扫过某条顶线时，在顶线下沿加一道宽 6K、+0.25 墨浓的深线，8 帧内衰减并交给该山自己的 rimTop。

### 5.3 T2 豹眼 → 镜片（f637–f652）

1. 两边的亮点中心都钉在 P = (650, 372)；光芯 40K、外晕 140K，峰值同为 0.85 / 0.35。
2. 两边的光带方向、速度一致（左上 → 右下、−35°、每帧 18K），从 f640 在眼里开始，到 f650 在镜片上结束，横跨切点——这就是"匹配"本身。

### 5.4 共用工具："浓先淡后"显影 `inkReveal(D, τ)`

`显影 = smoothstep(τ − 0.08, τ + 0.08, D + 0.06·fbm(q/20))`，τ 从 1 降到 0（ss）。先出焦、浓墨（轮廓、山头、斑），后出淡墨和淡彩——像墨从纸背渗出来。用在：S5b 长卷化开（f572–f588）；反向（τ 从 0 升到 1.05）用在 S6 收尾退墨（f710–f716）。

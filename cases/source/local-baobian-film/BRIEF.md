# 《豹变》30 秒三渲二样片 · 制作任务书（四版共用）

## 一、故事（只配乐，无对白，无旁白）

典故：《周易·革卦》上六「君子豹变，小人革面，征凶，居贞吉」，《象传》「君子豹变，其文蔚也」；《列女传》南山玄豹，雾雨七日不下山觅食，为的是让皮毛润泽、长出文采。

主角陆蔚：28 岁，古籍修复师，戴眼镜，指尖有墨渍。全片只拍他的手、背影和剪影，**不拍正脸**。眼镜不做产品特写，也不出任何品牌字样。

母题：**墨渍 → 豹斑 → 光斑**，同一个形状出现三次。

## 二、30 秒分镜（四版共用；转场手法各版自定，见各版 STYLE.md）

24 fps，DUR = 30，画面 1920×1040（设计尺寸；要按 H/1040 缩放，4K 也能渲）。

| 段 | 时间 | 画面 | 要点 |
|---|---|---|---|
| S1 修复室 | 0.0–4.0 | 午后暖光的修复桌。线装旧书摊开，页上有一幅木刻豹子插图和革卦卦画 ䷰（自下而上：阳 阴 阳 阳 阳 阴）。沾着墨的手放下镊子，拿起眼镜戴上（只见手、镜腿、镜片一闪）。 | 慢、静；墨渍要看得清 |
| T1 透视转场 | 3.4–4.8 | 书页上六道卦爻浮起；镜头俯冲穿过书页，横画变成远山的地平线，进入书中世界。 | 全片第一个"哇"点 |
| S2 南山雾崖 | 4.8–11.0 | 雾雨中的南山。崖洞口蹲着一只灰色的小豹，毛色暗淡，斑点像没干的墨。山下鹿群走过，它不动。陆蔚的背影坐在它旁边。七个太阳（剪纸圆或光斑）依次从雾里滑过，一个比一个淡：七天。 | 静、长；雾要分层有视差 |
| S3 面具集市 | 11.0–14.5 | 快切插入：一只手递来金光闪闪的豹纹面具；陆蔚的手抬起又放下；转身走回雾里。透视转场：镜头推进穿过面具的眼孔，回到雾崖。 | 节奏突然变快、变满、变吵 |
| S4 豹变 | 14.5–21.0 | 雨冲下陆蔚指尖的墨；墨滴落在豹背上，先晕开再收紧，成了一枚枚环斑（近景到特写）。第七天，雾散，豹身满是文采。 | 全片核心，最慢最美 |
| S5 一跃·逍遥 | 21.0–27.0 | 小豹在崖顶坐定，然后一跃而起，却没有落下：镜头随它穿云，山水化开横移成长卷；它身后留下一串豹斑墨点的弧线。 | 大透视、大景深、最开阔 |
| T2 匹配剪辑 | 26.6–27.2 | 豹眼一闪 → 镜片一闪。 | 一闪即过 |
| S6 回现实 | 27.0–30.0 | 修复室，窗外树叶把阳光筛成斑驳光点，正好落成陆蔚衬衫和手上的一身豹纹。他继续补书。字幕竖排书法「君子豹变 其文蔚也」淡入（29.0 起），最后 0.4 秒淡出到纸白或墨黑。 | 安静收尾 |

## 三、技术约束（北冥引擎）

- 影片目录：`films/<版本>/`，入口 `films/<版本>/index.html`。只用 three.js（`/node_modules/three/...`，importmap）、Canvas 2D、页面里的 JS。**不要引入任何其他库或外部网络资源**（渲染时无网）。
- 页面约定：`window.DUR = 30`；`window.render(t)` 必须是确定性的（同一 t 永远同一张图，任意帧单独可渲，不用 Math.random / Date / requestAnimationFrame 累积状态；随机用种子哈希）；资源全部加载好、着色器预热后 `window.READY = true`。
- 三渲二要真的有 3D：至少崖石/松树/豹或其中几样是 3D 几何体加卡通着色（色阶、软交界、描线或墨晕，按各版 STYLE），与 2D 手绘底板分层摆在 3D 空间里，镜头运动产生真实视差。角色可以是 2D 精灵/剪纸骨骼动画，也可以是简化 3D 体块，由你判断哪种在 30 秒内做得最漂亮。
- 动画节奏：角色一拍二（每 2 帧换一次姿态，用 `f = Math.round(t*24)` 量化），镜头、雾、水 24 fps 平滑。
- 可复用：`films/_lib/` 里有《北冥》的 toon.js（卡通材质）、look.js（后期：Kuwahara 笔触、墨线、纸纹、暗角、颗粒）、scene.js（工具函数与底板加载）、paper.png。可以拷到自己目录里改，**不要改 `_lib` 本身**，也不要碰其他版本的目录。
- **Magpie 出图尺寸上限约 160 万像素**：不管要多大，实际都会按比例缩到这个量级（2:1 → 1774×887，16:9 约 1672×941，3:2 约 1536×1024）。长卷可以用 `3:1`、`4:1` 这类比例。底板放到 1080 或 4K 一定会变软，细节要靠着色器在原生分辨率上生成：纸纹、洇墨、笔触噪声、描线、雨丝、光斑。不要指望底板放大以后还清楚。
- 角色动画可行做法：少量关键姿态图，加网格形变（尾巴、呼吸、头部微动、眨眼叠层），一拍二；跃起用 3–5 张原画，加墨影或速度线。手和背影可以用剪纸式分件动画（上美影剪纸片的传统）。
- 卦画 ䷰、书页文字、雨、雾、墨滴、光斑这些能用代码画的，一律用代码画，不靠生图。
- `films/_archive_sonnet/<版本>/assets/` 是上一轮（已作废）留下的资产图，可以拿来看、挑能用的复制过来，但质量标准按本轮规范，不合格就重出。
- `films/_gatetest/` 是门禁自测片（最小可运行示例：importmap、底板贴图、卡通体、FontFace、K 缩放、DUR/render/READY），可以照着它起步。
- 每个影片的 `index.html` 加 `<link rel="icon" href="data:,">`，免得浏览器去要 favicon。
- 字体：`fonts/MaShanZheng-baobian.woff2`（马善政楷书）、`fonts/ZhiMangXing-baobian.woff2`（志莽行书）、`fonts/LiuJianMaoCao-baobian.woff2`（流江毛草），只含「君子豹变其文蔚也革南山七日」这几个字；用 FontFace 加载，等 `document.fonts` 就绪再置 READY。
- 资产图：用 Magpie 图像工具（`mcp__magpie-image__generate_image`，先用 ToolSearch 加载 `select:mcp__magpie-image__generate_image,mcp__magpie-image__generation_result`）。把 `refs/<版本>/` 里的参考静帧作为 `reference_images`（每次 2–4 张最贴切的）传进去，让画风贴近原片。需要抠底的层用 `background: "transparent"`。资产存到 `films/<版本>/assets/`。参考图版权方已授权给本项目，可以直接作为参考图使用，但不要把参考图本身直接放进画面。
- **渲染与自检全部在 RTX 5090 上**（规范见 `SUBAGENT_STANDARD.md`）：
  - 静帧：`sh tools/rog_stills.sh films/<版本> --range 0:29.5:1.5 --tag 名字`（或直接列时刻），取回到 `films/<版本>/_work/stills/<名字>/`，带 `sheet.jpg` 与 `render.log`
  - 门禁：`sh tools/gate.sh films/<版本>` → `films/<版本>/_work/gate/GATE.md`
  - 整片：`sh tools/finish.sh <版本>`（只有渲染角色用）
  - Mac 上不跑 `still.mjs` / `video.mjs`
- Python 工具一律用工程环境 `.venv/bin/python`（有 numpy、Pillow、scipy）：`tools/sheet.py`、`tools/compare.py`、`tools/palette.py`、`tools/audio_report.py`
- 配乐：`audio/<版本>.wav` 已生成；分析报告与能量曲线见 `audio/<版本>_report.txt`、`audio/<版本>_curve.png`。分段时间可在 ±1.0 秒内调整以踩音乐（规范第五节）
- 防崩：所有图像提示词末尾加「normal body structure, natural proportions, stable clear face, no text, no watermark」。人物不拍正脸。

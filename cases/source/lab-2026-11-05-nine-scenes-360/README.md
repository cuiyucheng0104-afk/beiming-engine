# 北冥 · 九景画风实验

本轮目标是理解参考素材的色彩、明暗与空间层次，验证它们经过北冥引擎着色后的画面表现力。共9张参考，每张40个配方，输出360张2400像素宽PNG；沿用各原图宽高比。

## 怎样选

打开 `delivery/index.html`。先看原图与A5（六阶塑形），再比较A2（三阶硬切）与A3（三阶柔边）。选到喜欢的配方后切换“同配方看九景”：看人物肤色是否失真，室内是否压黑，远山层次是否还在。收藏可以导出包含全部参数的JSON。

40个组合是8组色彩方向 × 5套明暗分阶，不代表40套完全不同的建模或绘画算法。A最接近原素材冷绿暗部与暖光关系，B更浅，C偏赭石，D偏青绿，E压低饱和，F偏紫金，G接近淡墨，H向蓝夜色探索。原配方名沿用上一轮，实际观感以成图为准。

## 本轮素材的共同语言

- 青绿、蓝灰的暗部，与烛火、夕照、窗灯的暖金色形成冷暖对照。
- 衣物、木石和植被大体低饱和；暖色集中在叙事焦点。
- 烟雾、远山褪色和景深让背景后退；不能给前后景同样粗的硬描边。
- 人脸、手、文字与建筑结构是信息区；大面积气氛需要简化，而非全部抹平。

## 两种资产，分开记录

**360张主图：单视角场景几何。** MoGe-2在RTX5090上估计原图深度和法线，将每幅参考建立为带纹理的可见表面网格。保留源图构图与颜色，经Three.js的三角面渲染、北冥材质分阶和后期输出。它属于2.5D场景代理，背面和遮挡后方没有完整内容，不能任意绕拍。当前图只能证明单帧画风，未证明动画时序稳定。

**主体建模试验：TRELLIS.2。** 楼阁从上一轮约25万面提高至994,851面，重网格分辨率1024、平滑2次、表面回投0.75、4K纹理。人物、道具试验另存模型目录。整幅室内/森林图直接输入物体生成模型的r1试验失败，主体未正确生成；失败记录留作方法判断，不列为合格主图。

不能将前一段的360张主图称为“九套完整的TRELLIS场景”。单视角几何与完整资产的用途不同，后续选定画风后需在完整人物、建筑资产与运动镜头上再验证。

## 着色实施

主图文件：`lab/frame/viewer.js`。

1. 读取场景GLB和估计法线，恢复原始投影机位。通过按深度分布限定近远平面，减少远山深度精度噪点。
2. 在片元着色器里对颜色做小范围保边平滑；以每张参考97%亮度分位数设定白点。
3. 色阶输入混合源图明暗与估计法线的光照（法线贡献0.19），再用阈值、档位亮度和羽化宽度量化。源图光照已烘焙在纹理中；这个过程不是物理反照率恢复。
4. 保留部分源图材质明暗，暖色细节保留更多，以保护肤色、纸面和烛光。用配方控制暗部/高光色相与明度方向。
5. 北冥后期：深度描边、低强度Kuwahara、轻Bloom、色彩调整、纸纹、颗粒。限制远景线条，避免把烟雾描成线稿。

这套配方可迁移，但迁移至纯3D资产时，源图明暗项需换成材质固有色与实际光照，不能只改一个参数就声称等价。

| 配方列 | 档数 | 阈值 | 羽化 |
|---|---:|---|---:|
| 1 二阶硬切 | 2 | 0.54 | 0.012 |
| 2 三阶硬切 | 3 | 0.34 / 0.66 | 0.015 |
| 3 三阶柔边 | 3 | 0.34 / 0.66 | 0.11 |
| 4 四阶叠色 | 4 | 0.24 / 0.48 / 0.73 | 0.035 |
| 5 六阶塑形 | 6 | 0.16 / 0.31 / 0.47 / 0.64 / 0.81 | 0.065 |

## 复现与存放

Windows：`D:\北冥\experiments\nine-scenes-360`（`D:\beiming`为同一目录的英文联接）。

```powershell
$env:BEIMING_CHROME="C:\Program Files\Google\Chrome\Application\chrome.exe"
$env:BEIMING_ANGLE="vulkan"
node tools/render.mjs --frame --scenes "01,02,03,04,05,06,07,08,09"
D:\beiming\tools\venv\Scripts\python.exe tools/package.py
```

- `refs/`：9张原图和SHA256；不改原图。
- `models/NN/view/`：场景GLB、深度、法线、工作流与Comfy执行记录。
- `models/NN/r*/`：独立物体重建试验，须结合验收状态使用。
- `out/frame-renders/NN/`：本景40张主图和实际GPU日志。
- `out/frame-qa/NN/`：原纹理、去贴图、侧移与着色检查。
- `delivery/`：离线选片页、每景40版总览、九景总览、全部参数及核验记录。

所有主图在RTX5090的Vulkan后端渲染。CUDA用于模型推理；此实验没有使用RTX光线追踪或DLSS。上一轮目录与北冥引擎原仓库未覆盖。

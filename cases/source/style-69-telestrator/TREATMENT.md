## 0. 素材决定（剪辑与纪实类：先找素材）

在 Wikimedia Commons 用 API 检索 "football goal / soccer match / beach soccer goal"（filetype:video，逐条看许可字段）：
- CC0 的只有 2021 沙滩足球世界杯两段**看台手持拍的点球**（Noël Ott、Akaguma），没有传球、没有跑位、不是能看全局的转播机位；
- 公有领域的只有美国海军基地新闻（AFN Naples）、总统活动、1900 年代老片（640 px，无法追踪）；
- 其余全是 CC BY / CC BY-SA（本片规则只许 PD / CC0）。

结论：没有一段合规素材能承载“一次进攻 → 传球线路 → 跑位 → 射门”。按分镜条目的退路，**用代码渲染一段转播机位的比赛画面**（主机位高位侧拍 + 球门后高位反打两个机位，俯视角），所有画线都画在这段“转播画面”上、跟着它的透视走。交付说明里注明。material/ 留空，CREDITS 写明无第三方影像。

## 1. 三个候选结构

A. **按时间顺序层层剥**（选中）：直播 1× 看一遍进攻 → 倒带 → 定格画传球线和跑位 → 慢放 + 追踪圈 + 帧数秒表 → 射门帧定格、音乐停 → 双机位并排同步定格 → 静默中慢放球飞行 → 进球那一帧比分条翻转、全奏。
B. **进球帧开场再倒回**：第 1 秒就冻住进球帧，比分已翻，然后倒带拆解。钩子强，但高潮（比分翻转）被提前用掉。
C. **秒表开场**：秒表在直播画面上跑，观众不知道它在数什么，结尾才揭晓 0.68 秒。悬念好，但 18 秒里“数什么”解释成本太高。

选 A：分镜条目的骨架就是它；比分条翻转是“只有这种风格能做”的原生招式，必须留到最后一拍，且第一次看到球进门就是高潮——前面所有拆解都在“憋”这一脚。

## 2. Logline 与弧线

**补时第 89 分钟 1–1，一脚直塞撕开两名中卫之间的空当，9 号从接球到起脚只用了 0.68 秒——战术板把这 0.68 秒拆开给你看，再让球进门。**
- 起：直播，一次快速进攻，正要射门——被主持人倒带抓回来。
- 承：定格画出传球线和无人盯防的跑位；慢放里追踪圈锁住射手、秒表一帧一帧数。
- 转：射门帧冻住，音乐也冻住；双机位同时停在出脚瞬间——门将的视线被自己的中卫挡住。
- 合：静默里球慢慢飞向远角，越线那一帧比分条 1–1 翻成 1–2，全乐队砸下来；英雄慢镜收在“那一脚 0.68 秒”。

## 3. 对标（只学语法）

- **电视足球分析节目里的触屏战术板段落**：学“先看后拆”、一次定格只说一件事、圈画在脚下、线跟着转播透视、定格时音乐跟着停。
- **用真实比赛画面做解说的分析频道**：学帧数秒表、双机位并排同步、标签卡放在空草皮上。
- 不学：任何转播商/频道的台标、字体、配色、片头；不用任何真实球队、球员、联赛名（全部虚构：港湾 vs 城南、节目名“复盘”）。

## 7. 声音设计表

| 段落 | 环境底 | 拟音（全部由 window.EV 驱动） | 音乐状态 |
|---|---|---|---|
| 直播 | 观众全频底 + 偶发喊声 | 擦屏 whoosh、每次触球（低频闷响 + 2 ms 宽频皮面拍击，起音 < 1 ms）；第一脚横传配一记铜管 stab | 全律动 |
| 倒带 | 观众底反向 + 低通 | 磁带电机啸叫（下滑音）、跟踪条噪声 | 鼓停，反向镲 |
| 定格① | 低通观众底（循环） | 快门 + 闪白；每个圈 pop（正弦扫频 + click 前沿，起音 < 1 ms）；每条线马克笔吱声（2–5 kHz 带通噪声 + 颤动）；标签落定 tick | 只剩闭镲 + 低音 |
| 慢放 | 低通观众底 | 圈 pop、慢放触球（降调闷响）、秒表每八分一 tick | 半拍律动 |
| 射门定格 | 几乎无 | 出脚重击（降调）、快门、秒表停“叮” | 停 |
| 分屏 | 低通观众底 | 擦屏 whoosh、分屏落位 thump、触球、快门、圈 pop、吱声、tick | 重启 → 冻结 |
| 静默 | 无 | 极轻的心跳、低通出脚闷响、球飞风声（都压在 −24 dBFS 峰值以下） | 无 |
| 进球 | 观众爆发（宽频噪声涌起） | 球网刷声、比分条翻牌咔嗒 + whoosh、门将倒地闷响 | 全奏 |

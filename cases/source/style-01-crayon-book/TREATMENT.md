# 小纸船遇上大雨 · 处理方案（Treatment）

风格：蜡笔儿童绘本（crayon-book）。1920×1080，24 fps（STYLE.md 未规定帧率），时长 19.79 s。无旁白、无字幕；画面内文字只有结尾一个手写「完」。

## 1. 三个候选结构

1. **一页画完（单页旅程）**：整片在同一张大纸上，镜头在纸面上移动；船从无到有、遇雨、被太阳救起，最后翻页。连续感最强，翻页只用一次，留给结尾。
2. **前后对照（两页翻页）**：第一页是雨，翻页后第二页是晴；靠翻页完成转折。转折太"机械"，把"涂色就是动作"降级成了"换页"。
3. **涂色本（线稿先在）**：开场所有轮廓已在纸上，每段"上一种颜色"推进剧情。开头没有"活画"的钩子，和分镜要求的"蜡笔线活画出纸船"冲突。

**选 1**：分镜给的剧情就是一条连续的天气弧线，单页 + 一镜到底的纸面运镜最能让"涂太阳赶走雨"成为动作本身；翻页作为唯一的结构性转场，放在结尾当句号。

## 2. Logline 与弧线

一只刚被蜡笔画出来的小纸船遇上了大雨，快要沉了——一支黄色蜡笔闯进来，把太阳涂了出来，雨点被一颗颗涂成彩色，变成船头上的彩虹。

- 起：蜡笔尖在纸上活画出纸船，船睁开眼，漂在蓝色蜡笔水洼上（暖、三拍子、慢）。
- 转：乌云压下，灰蓝水彩一扫而过，**早就画在纸上的白蜡雨线**被显影（蜡阻），船摇晃、半沉（小调、提速）。→ 1 秒近乎静默。
- 合：黄蜡笔闯入，第一笔落下 = 全片第一声大三和弦；太阳被涂出、水彩褪去；雨点被逐颗涂成彩色，再化成彩虹一笔一笔涂成；船从彩虹下驶过；翻页，新的一页上黄蜡笔被放下，写下「完」。
- 回声：开场是蜡笔尖落下，结尾是同一支（黄色）蜡笔被放下——"画完了"。

## 8. 画面内文字

只有结尾新页上的一个「完」：字形取自站酷快乐体 ZCOOL KuaiLe（Google Fonts `&text=完` 子集化放 `fonts/`），但字体只当遮罩用——刚放下的黄蜡笔在字形里按行之字形涂色（A 通道=压力，蜡只沾纸纹凸起，略出边），18.667 拍点上再补一遍交叉涂色；靛蓝描边单独一层蜡压力（两遍略错位，像手描两圈），随涂色从上到下显出。字高约占画高 30%。

## 9. 蜡笔盒（11 支，不用黑色）

靛蓝（轮廓）、天蓝（水洼/雨线）、灰紫（云）、柠檬黄（太阳）、橙、珊瑚红、草绿、紫、粉（腮红）、沙色（船内）、白（蜡阻）。唯一水彩：灰蓝（佩恩灰偏蓝），只出现在暴雨天空与水面，从不覆盖角色。

## 11. 返修记录（审片后第一轮）

| 审片意见 | 改法 |
|---|---|
| 白蜡雨线开场就隐约可见 | 白蜡层按水彩密度做遮罩：没有水彩的地方白蜡层完全为空（与纸面零差异），水彩扫到哪里才在哪里显出（蜡阻） |
| 水彩褪干像数码光晕、底边漏白 | 去掉径向渐变；改为锚定在纸面上的"干燥时间场"（离太阳的距离 + 四个八度的值噪声），水彩一块一块干掉，干掉的边缘留一圈淡淡的干痕，GL 水彩通道在退缩边缘自动积色；最下面一条水彩带延伸到页面下方 190 世界单位 |
| 水彩横向长条纹像地平线 | 刷毛条纹改为短（140–440）、细（0.7–2 px）、α ≤ 0.07，带高频抖动和轻微斜度 |
| 「完」是平面矢量字、颜色与手中蜡笔不符 | 见 §8：黄蜡笔涂色 + 靛蓝描边，都走蜡附着管线；字放大到画高约 30% |
| 雨声床盖住雨滴乐音和沉船单簧管 | 雨声床单独成轨：7.5 s 后整体 −3 dB，每个雨滴卡点与 8.0 s 沉船前后 120 ms 再闪避 4.5 dB；雨滴木琴力度 .5→.62，单簧管升 G 增益 .9→1.15 |
| 17.25 s 帆发淡 | 帆的涂色压力 .95→1.2，加一遍交叉涂色（帆本来就在彩虹之后合成，问题出在压力偏低） |

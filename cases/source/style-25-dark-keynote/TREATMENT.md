# Lumen · 暗色科技发布 风格样片 —— 导演阐述

无旁白、无字幕。1920×1080 · 24 fps · 19.75 s · 90 BPM（1 拍 = 0.6667 s，1 小节 = 2.6667 s，4/4）。

## 0. 风格与分镜的对齐

分镜给的是"虚构产品 Lumen——一枚会呼吸的灯"。STYLE.md 规定本风格**没有实体产品、不做玻璃渲染，主角是界面**。
所以把 Lumen 定义成**一款软件里的灯**：屏幕上一枚由点阵像素组成的圆形光（"屏上之灯"，环境光/专注灯应用）。它是本片的"活体元素"（living element），也是品牌标记。

- "勾出物体边缘" → 一道光沿着这枚圆形 UI 元素的 1 px 边缘走一圈。
- "表面光点生成式累积" → 点阵按向日葵叶序（黄金角）规则逐个点亮，每个音符点亮一批，越来越快，最终约 700 点。
- "产品三视图" → 软件产品的三视图 = 同一盏灯在**桌面 / 手机 / 手表**三种窗口里，一拍之内吸附到 48 px 网格。
- "0.3 W" → 这盏屏上灯整屏运行时的功耗（虚构产品的虚构参数，不做事实陈述，不需要 FACTS.md）。
- 强调色只给一样东西：灯的光（signal orange `#FF7A1A`）；数字出现时灯已经坍缩进数字，所以数字接过强调色。没有"问题色"（本片没有问题，只有"从暗到亮"）。

## 1. 三个候选结构

1. **一条连续的光路（选用）**：黑场 → 第一帧亮起的光沿边缘画圈 → 光带扫亮 → 点阵累积加速 → 一拍吸附三视图 → 坍缩成一点 → 字形噪声 → 定格静默 → 数字落定（最重一拍）→ 收成名字。整片是一个世界、一台摄影机，所有转场都是 UI 展开/坍缩，没有硬切。
2. **数字倒叙**：开场就是巨大的 "0.3 W"，再倒推它是什么、从哪里来。钩子强，但把全片最重一拍提前用掉了，静默后无处可落。
3. **缩放阶梯**：一个像素 → 一个光点 → 一盏灯 → 三台设备 → 一面墙的设备。尺度感好，但 19 秒装不下五级，且和"三视图对齐"重复。

**选 1 的理由**：分镜的高潮是"定格静默 → 数字落定"，只有连续一镜才能让"定格"成为真正的时间停止（同一个世界突然冻结），也只有一路加速才能让静默最有分量。开场不是 logo，而是第一帧就亮起并开始走的光——钩子在第 0 秒。

## 2. Logline 与弧线

**Logline**：黑暗里一道光描出一枚圆，圆被点亮、开始呼吸，越亮越快，一拍之间分身到三块屏幕上；时间停住一秒半，然后告诉你它只要 0.3 瓦。

- 起：纯黑，光只描了一个边（"有个东西"）。
- 承：光带扫过，Lumen 亮起，点阵生成式累积——加速。
- 转：一拍吸附三视图 → 坍缩成一点 → 字形噪声 → **定格，数字归零**。
- 合：静默后的第一声 = 数字 "3" 落定，全片最重；随后减速，收成名字，光再沿边画一圈（和开场押韵）。

## 3. 对标

- **对标**：发布会式的黑场产品揭示（只用一道光把物体"画"出来、一屏一句、单独一屏的巨大数字）；软件发布片的网格吸附运动语法；Steve Reich 式过程音乐（加法过程、拍子细分加速）。
- **学**：光作为揭示工具（未被光扫过的像素不亮）；"一拍一个承诺"的吸附；数字独占一屏不加说明；静默前的加速与静默后的落点；声音和像素一样有秩序——产品的声音是同一调式的一家人。
- **不学**：任何真实公司的界面、字体设计、系统控件、旋律、logo、镜头；不出现任何品牌名。

## 6. Cue map

- **BPM 90，4/4**，网格起点 t=0。所有事件都写在 `timeline.js` 的拍号上，画面、配乐、拟音、核对脚本读同一张表。
- 段落：A 暗（b0–b8，2 小节）→ B 累积（b8–b15）→ C 吸附（b15–b18）→ D 噪声与定格（b18–b22）→ E 数字（b22–b25）→ F 名字（b25–b29.6）。
- 调式：D 利底亚（D E F# G# A B C#）——"产品的声音是一家人"，所有点亮音都在此调式内，汇成一个和弦的 shimmer。
- 配器（来自 STYLE.md 声音调色板）：合成 pad/drone（numpy）、低频正弦脉冲 + sub 冲击（numpy）、颤音琴软槌 / 弓奏（VCSL 采样）、马林巴（VCSL）、钟琴（VCSL，代钢片琴）、拨弦合成（pluck.py harp 模型）、沙锤（VCSL）、glitch 碎片（numpy）。不用钢琴、不用弦乐。
- 过程音乐：B 段是**拍子细分加速**（四分 → 八分 → 十六分 → 三十二分），同一 BPM 不变速；E 段**减速**（半拍速）。
- 静默：b20–b22（13.33–14.67 s）数字归零；静默后第一声 = b22 数字落定。

## 10. 返修记录（第 2 轮，按审片意见）

- **拍点帧取整**：拍点时间按 1e-6 s 取整，b22 / b14.5 / b4 / b25 / b19 等落在 x.666667 的拍点比 f/24 晚半微秒，导致画面晚 1 帧。`renderFilm` / `texts` 统一给 t 加 10 µs，拍点帧即事件帧。"3" 落定加白闪现在从第 352 帧开始（白闪 352–353 两帧），落定后的回弹拉出也从拍点帧开始走。
- **片尾错误帧**：第 415 帧铺满全屏的橙色圆盘，原因是小灯半径趋近 0 时 `drawLamp` 的最小点半径 0.9/px 里的 px 被乘了 R/R0，导致最小点半径发散。改为传真实的摄影机缩放；第 415 帧改为 "0" 收成的 CRT 最后一个点（约 10 px 橙点 + 辉光），第 416 帧（b26 拍点帧）按 back 缓动已展开约 80%；收起段的光晕保留到最后一点，避免出现近黑空帧（blackdetect 实测 0 处）。数字收起改为"提前一帧"：拍点帧已压扁约 80%。
- **一拍甩出**：b14.5 前一帧（第 231 帧）做反向预备（摄影机微推 + 分身反向 4%），拍点帧已走 8%，前三帧只走到 30%，之后加速并在落格前过冲 3.5%，b15 正好落定。三份分身错开 0 / 半帧 / 一帧出发，原灯在头三帧里淡出让位。
- **三视图可读性**：落格目标缩放 0.52→0.56，并在 b15–b17.5 缓推到 0.63（桌面窗约占画面高度 50%）；标签 64 号字（成片约 36–40 px），窗口标题 40 号字、标题栏加高到 76。
- **开场构图**：摄影机注视点外移，光头与被擦亮的月牙落到画面上 1/3 到中线之间；描边线宽 1.6→2.4 px，掠射冷光 11%→22%，光头辉光加大。

# 节奏猜动物 · TREATMENT（综艺节奏扁平 Game Show Flat）

19.75 秒 · 1920×1080 · 24 fps · 无旁白无字幕（画面内只有电视字幕条式的文字）· 原创代码配乐

## 0. 三个候选结构 → 选定

1. **一条直线的回合**：卡片 → 猫狗问答 → 越来越快 → 下一关 → 鸭嘴兽 → 成绩单。分镜原样，节奏最清楚。
2. **先给判词**：空舞台上先砸一个「完美！」，再倒回去看它是怎么挣来的。钩子强，可 20 秒里倒叙会把加速的线切碎。
3. **一个长回合不断加码**：同一个问答模式从四分音符一路加到十六分，最后鸭嘴兽打破模式。加速最纯，但没有「下一关」的盒子可开。

**选 1，把 3 的「加速才是剧情」揉进来**：猫/狗的问答在 3 个小节内从四分加到八分；「下一关」用十六分字母和军鼓滚奏把速度推到顶，然后**刹停**，整整 1 拍半的静默，静默后第一声是选手喊出「鸭嘴兽！」。猫和狗教会观众规则，鸭嘴兽打破规则，这就是转折。

## 1. Logline 与弧线

一个黄色小豆子选手在节奏猜动物里越答越快，最后一题跳出来一只谁也猜不到的鸭嘴兽，它在一片死寂里喊对了。
- 起：回合卡「第1回合 猜动物」，选手落地，拍手预备。
- 承：剪影在拍上跳出，选手在下一个拍点喊答案（猫！狗！），从四分加到八分，镜头慢推。
- 转：「NEXT LEVEL」礼盒在军鼓滚奏里抖三下，锁弹开，一个怪剪影升起，**音乐断掉**，镜头急推到选手冒汗的脸。
- 合：选手喊「鸭嘴兽！」，剪影上色，判词「完美！」砸在强拍上，全曲升调；成绩单逐行打钩，「3/3 满分」印章落在小节线上。

## 2. 对标

- **节奏动作派对游戏（Rhythm Heaven 一路）**：学「提示 → 应答」的拍型、回合卡、判词一眼读完、教会规则后再打破规则；不学它的角色、界面、关卡、音乐。
- **日本综艺字幕（テロップ）与布景**：学粗描边字、条纹/放射光布景、硬切 + 白闪；不学任何节目的标志与字体设计。
- **70 年代电子 funk 的铜管 stab 写法**：学反拍铜管、切分 slap 贝斯、拍手在 2/4；不学任何旋律。

## 3. 关键决定

- **速度 120 BPM（分镜写 128）**：24 fps 下 128 BPM 的一拍是 11.25 帧，拍点会落在两帧之间；120 BPM 一拍正好 12 帧，八分 6 帧，十六分 3 帧，所有拍点都落在整帧上，画面和声音才能做到真正的 0 ms 偏差。funk 在 120 也很舒服。
- **人声不用 TTS**：选手和观众的喊声用共振峰合成的「玩具嗓」，按普通话声调画音高曲线（māo / gǒu / yā-zuǐ-shòu / wán-měi），辅音落在拍点前 25 ms，元音落在拍上。这是喊声，不是旁白。
- **调式**：F 大调，一小节一个和弦；「完美！」那一刻整体升到 G 大调（决赛升调）。

## 6. Cue map

- **速度** 120 BPM，4/4，1 小节 = 2.000 s = 48 帧；1 拍 = 12 帧；十六分 = 3 帧。所有事件都写成 (小节, 拍) 并由 `timeline.mjs` 换算。
- **小节网格与和弦**

| 小节 | 时间 | 段落 | 和弦 | 配器状态 |
|---|---|---|---|---|
| 0 | 0–2 | 回合卡号角 | F | 铜管号角、镲、马林巴点、军鼓滚奏 |
| 1 | 2–4 | groove 进 | B♭ | 底鼓、拍手、踩镲八分、slap 贝斯、吉他切音、三角波垫 |
| 2 | 4–6 | 问答·四分 | F | 全 groove + 提示/应答 |
| 3 | 6–8 | 问答·四分 | B♭ | 同上 |
| 4 | 8–10 | 问答·八分（加速） | Gm7 → C7（第 3 拍换） | 踩镲十六分、贝斯八分推进 |
| 5 | 10–12 | NEXT LEVEL | Dm → B♭ → C | 去掉贝斯，军鼓滚奏渐强，铜管半音上行 |
| 6 | 12–14 | 静默 → 喊 → 加花 | （停）| 12.0 一记 stab 后全停；13.0 人声；13.5 军鼓加花 |
| 7 | 14–16 | 完美！（升调） | G | 全 groove + 方波主旋律 + 观众喊 |
| 8 | 16–18 | 成绩单 | C | groove + 打字机 + 八音盒 |
| 9 | 18–19.75 | 满分 + 收尾 | G → G（button 在 19.0） | 镲、铜管终止 |

- **速度变化**：四分问答（4–8 s）→ 八分问答（8–10 s，加速）→ 十六分弹字 + 滚奏（10–12 s，顶点）→ 刹停静默（12.25–13 s，减速到零）→ 恢复常速。
- **拍点规则**：剪切全在小节线（4.0 / 10.0 / 16.0，另有 6.0 / 8.0 两次同布景跳切）；判词与印章落在强拍（14.0 / 18.0）；喊声的辅音提前 25–30 ms，元音落在拍上。
- **瞬态对齐**：mix.py 的 `put()` 默认把每个声音的主瞬态（2 ms 包络第一次到达峰值 −10 dB 处）对到事件时刻，而不是文件开头，采样贝斯、扫弦吉他、铜管断奏的起音延迟都被抵消；铺底、上冲、预卷的嗖声、人声辅音按设计不对齐。礼盒摇晃的七下咔哒收进前 60 ms 并逐下变轻。
- **低频**：总线在 120 Hz 以下做零相位低架（−6 dB），20–120 Hz 比 500–2k Hz 低约 2 dB，slap 贝斯在小音箱上不再发轰。

## 7. 声音设计表

| 段落 | 环境底 | 主要拟音 | 音乐状态 |
|---|---|---|---|
| 回合卡 0–4 | 演播室底噪（极轻粉噪）| 嗖、落地噗嘣、逐字弹点、盖章、拍手 | 号角 → groove |
| 问答 4–10 | 同上 + 轻微观众底 | 剪影弹出啵、应答叮、星星点亮的小音高点、白闪「咻」| 全 groove，提示/应答进拍 |
| 下一关 10–12 | 同上 | 字母弹点、礼盒摇晃三次、锁咔 | 滚奏渐强、铜管半音爬升 |
| 静默 12–13 | 只剩房间底噪 | 剪影升起的伺服声（很轻）、汗滴叮 | 无 |
| 完美 13–16 | 观众底升起 | 玩具嗓喊、判词砸、爆点、彩纸沙沙、跳拍落地 | 军鼓加花 → 升调全 groove |
| 成绩单 16–19.75 | 观众底 | 打字机、打钩盖章、八音盒、印章重击、定格白闪 | groove → button → 余音 |

转场声：4.0 与 16.0 的白闪带「咻」，16.0 前一拍提前进粉色段的打字机第一下（J-cut 的思路由十六分加花承担）；12.0 的锁响拖过静默的开头（L-cut）。

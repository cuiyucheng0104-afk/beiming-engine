# 高速公路倒放翻车 · 白模预演（v3.2：24fps 真实时间 + 物理约束 + 一键门禁）

参考：ref/reference.mp4（10 秒，4 个镜头，有效画面 784×448，左右有黑边）。它标的是 30fps，实际是 24fps 拉成的 30fps：
每 5 帧有 1 帧重复。`decimate.py` 去掉重复帧后得到 ref/reference24.mp4（241 帧），**预演按 24fps 做，下文帧号都是 24fps 帧号**。
目标：空间位置和车辆轨迹逐帧对上原片；人和车只做白模，可以替换。

## 一键重建

```bash
./run.sh            # 从源码重建 → 门禁验证 → 运动曲线（约 1 分钟），不达标就以非 0 退出
./run.sh render     # 再渲染 241 帧，出成片和左右对比视频
```

## v3.2 改了什么（2026-10-30）

1. **改成 24fps 真实时间**。原片 301 帧里有 60 帧是前一帧的重复（判据：与上一帧的差 ÷ 前后帧间差中位数，重复帧 ≤ 0.13，其余 ≥ 0.42，阈值 0.25）。去掉后剩 241 帧 = 24fps × 10.04 秒。
   - 读点、姿态关键帧、相机曲线都换算到 24fps 帧号。落在重复帧上的键，归到它复制的那一帧；两个键落到同一帧（原 30fps 的 131/136/141/144/159/164 与前一键）时取平均。
   - 平滑宽度按时间保持不变（帧数 × 0.8）。
   - 映射表在 `data/timebase_24.json`。
2. **参数只有一个来源**：`calib.py`（标定、场景尺寸、时间基准、相机曲线、像素→路面投影）。
   - 原来 `build.py` 和 `ground_track.py` 各写了一份常量，主点 480 被写死，`ground_track.py` 里还留着一份旧读点。
   - 读点只在 `flip_keys.py` 里维护；相机曲线合并成 `data/cam_track.csv` 一张表。
   - 路面投影改用和相机动画相同的线性插值（原来取最近的关键帧）。
3. **腾空段用重力抛物线**：
   - 车身最低点离地超过 6cm 的连续帧算腾空。重心高度换成 z = zp − g/2·(t − tp)²：g 固定，顶点对匹配出来的高度做最小二乘，起跳、落地点是抛物线和地面的交点。
   - 共 3 段腾空：100–110、114–125、133–141 帧，各约 0.4–0.54 秒。顶点处车身最低点离地 0.12 / 0.40 / 0.34m，和原来目测的高度最多差 0.17m。
   - 贴地翻滚时，重心严格跟着"车身最低点贴地"的高度走。
4. **物理检查加了一条硬约束：z″ ≥ −g**。地面只能往上推，所以重心往下掉不可能比自由落体还快。
   - 起跳、落地帧算着地冲击，加速度阈值放宽到 20g；其余帧仍是 8g、14 rad/s。
   - 结果写到 `out/physics.json`。
5. **一键流水线 + 门禁**：
   - `run.sh` 每次从源码重建。之前的 `out/previs.blend` 是旧文件，验出来 18.3px，从源码重建才是 5.0px。
   - `verify.py` 的阈值在 `data/gate.json`：中位 ≤ 6px、最大 ≤ 30px，物理超限帧只能是已登记的那几帧。出现新的超限帧就判失败。已做反向测试：收紧门槛后流水线会报红。
6. v1、v2 的旧脚本移到 `legacy/`。项目改用本地 git 管理（`out/`、`ref/` 不入库）。

## v3 改了什么

1. **翻滚车改为逐帧姿态匹配**。原片里的车边翻边原地打转，是三维翻滚，物理参数搜索不可能逐帧对上。现在的做法是：
   - 关键帧写在 `flip_keys.py`：位置用原片读点，朝向用 h/r/p 三个角度。
   - 用原片叠加对比，一轮一轮校正。104–127 帧是逐帧校的。
   - 离地高度自动按"车身最低点贴地"计算，只在腾空时额外加高度，所以车身不会穿进地面。
   - 重心轨迹做了高斯平滑。
   - `build.py` 里的 `physics_check` 会检查加速度和角速度，作为物理合理性的兜底。
2. **车模能分前后**（`car_model.py`）：Saab 9-5 比例，下车身和车舱各做一个凸包；有白大灯、黑格栅、红尾灯、白车牌、深色车窗和深色底盘。
3. **远处距离改用车身尺寸反算**。50 米外的地面读点差 1~2 像素，距离就差十几米。按车高反算，43 到 100 帧之间车基本停在 Y≈83 米处。
4. **机位**：相机在前排两座中间、眼线后 0.3 米。这是按原片 A 柱位置反推的；同时把 A 柱改成真车比例、加粗，方向盘压低。

倒放结构保持不变：成片时间的位姿反过来写成正向动作 `FlipCar_ForwardCrash`，放进 NLA 片段并打开 Reversed。

## v3.1 改了什么（128–182 逐帧 + 流畅度）

- **128–182 帧逐帧校正**：改用"渲染边缘红线叠原片"来检查（`overlay.sh`），比左右并排对比更准。
- **流畅度**：
  - 车身姿态（四元数）做 1.8 帧的高斯平滑。
  - 离地高度平滑后，再保证车身不穿地。
  - 打开运动模糊（快门 0.5），原片本身有很重的运动模糊。
- **174–186 帧距离**：近似侧面视角下的地面读点不可靠，改用车身轮廓叠加来校准，车离镜头约 12~14.5m。184 帧原来的读点是错的，已删掉。
- **本车整车点头**：后段相机"往下看"，其实是本车刹车点头。车内模型跟着一起转，所以仪表台和 A 柱在画面里不会乱跑。
- **镜头 4 重新标定**：用"墙脚在 X=10.4、翻滚车在 X=2.7"两个约束反解相机，结果是镜头在往右摇（22.8° → 31.8°）。翻滚车摆正后比本车每秒慢约 0.9m，领先距离从约 11m 降到 9m。

## 验证

- **投影误差**：`verify.py` 把模型车身中心下方的点投影回相机，和 19 个原片读点比较。v3.2 **中位误差 5.3 像素，最大 29.0 像素**（画面宽 784）；v3.1 是 5.0 / 28.1。变化来自落在重复帧上的两个读点（原 116、136）换成了真实时刻。
- **物理检查**（`out/physics.json`、`out/motion_curve.png`）：
  - 最大角速度 8.6 rad/s（111 帧）。最大加速度 80.8 m/s²（145 帧）。
  - **已知问题：144–146 帧重心下落比自由落体还快**（z″ 为 −59 / −80 / −39 m/s²）。这里原片是车头朝下砸地、再落回四轮，按读出的姿态，重心 3 帧（0.125 秒）掉了约 0.4m。叠图确认姿态和原片一致，所以要么原片这段做过变速，要么姿态读数里俯仰偏大。试过强制满足 z″ ≥ −g，结果车在空中多飘了 15 帧、离地 1m，明显更糟，已撤回。这段留给后续的自动姿态优化（P2）。
  - 98、105 帧有轻微的同类问题（−13 / −23 m/s²），原因是凸包贴地高度的折点。
  - 以上 5 帧都登记在 `data/gate.json` 里。

## 换模型

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b out/previs.blend --python-exit-code 1 -P swap_model.py -- --slot SLOT_FlipCar --glb ~/models/car.glb --rot 90 --save out/previs_car.blend
```

- 插槽：`SLOT_FlipCar`（按中心对齐）、`SLOT_HeroCar`、`SLOT_Driver`、`SLOT_Passenger`（按底面对齐）、`SLOT_Env`。
- `--rot`：把车头转到 +Y。
- 默认缩放到和原白模一样长。原白模只隐藏不删除。
- 动画都在插槽上，换模型不影响运镜和轨迹。

## 改姿态 / 重建

1. 改 `flip_keys.py` 里的 `POSE`（h、r、p、离地高度）或 `PICKS`（24fps 帧号，对照 `ref/frames24/`）；测量值改 `calib.py`。
2. 重建并验证：`./run.sh`
3. 出逐帧对比图（参数依次是起始帧、结束帧、步长、输出图）：
   ```bash
   ./compare_frames.sh 104 127 1 out/cmp_104_127.png
   ```
   或者出叠加检查图（渲染边缘红线叠在原片上）：
   ```bash
   ./overlay.sh 128 182 1 out/ov_128_182.jpg 5
   ```
4. 渲染成片和对比视频：`./run.sh render`

v1、v2 的旧脚本在 `legacy/`，只留作参考。`track_far.py` 是 30fps 时代的远景跟踪工具，它的结果已经并入 `data/cam_track.csv`。

## 已知局限

- 纵深比例依赖虚线周期 12m 这个假设。
- 前方路面的上坡没有建模。
- 149 帧以后车身相对路面斜约 6°，是按原片外观对出来的。
- 144–146 帧的重心下落比自由落体快（见「验证」），姿态和原片时间在物理上没法同时满足。
- 镜头 1、3（驾驶员近景）没有可测量的参照，是按构图摆的。
- 原片是电影《信条》片段，只用作运镜和空间研究。

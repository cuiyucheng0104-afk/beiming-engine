# 片段一「开卷」TREATMENT

《上美影 IP 全景》升级版（方案 A《展卷》）样片段一，对应原稿 A0–A2。
33.333 s｜1920×1080｜30 fps｜无旁白、无字幕条｜风格：中国水墨（ink-wash）的语法，统一在一张暖白生宣的手卷上。

> 结构、拍数和转折由总导演定稿（A0 序 6.667 s + A1 四小节 + A2 四小节），本文件只在这个框架里做细节决定。没有人可问，下面所有取舍都是我自己定的，并写明理由。

## 1. 三个候选结构与选择

结构骨架是定稿，候选只在"这 33 秒怎么讲清'角色是入口，25 不是 IP 数'"上做选择：

1. **一滴墨展卷（选用）**：黑里一滴墨落纸 → 墨晕撑出团扇、显出九色鹿 → 题字、盖印、开卷 → 三幅立轴按小节落下 → 一甩笔，墨点在前方纸上等着，镜头走到哪里，墨点就在拍上变成朱印 → 25 方印落满，页边 477 个细墨点同时数完。好处：一滴墨 → 三幅画 → 25 方印 → 477 个点，**"量"一路放大**，最后用"25 方大印 vs 477 粒小点"让观众一眼看懂"分类 ≠ 记录 ≠ IP 数"。
2. **印先行**：先盖「内容资源概念发布」大印，再从印里晕出扇面。放弃：开场钩子不如"静默后一滴墨"，而且印章的力量要留给第 1 小节第一拍。
3. **挂轴纵移**：A1 改成镜头竖向下摇三幅立轴。放弃：三段以后要接成一镜到底，必须全程向左平移；竖摇会在拼接处留下断点。

## 2. Logline 与弧线

一滴墨落在空纸上，晕开成一把团扇；手卷展开，三个熟悉的角色在拍上落下；墨点化作 25 方朱印，页边 477 个细点同时数完——熟悉的角色只是入口，后面是一整卷内容。

- 起：黑、静、一滴墨（单点）。
- 承：开卷，三幅立轴（三个面）。
- 转：一甩笔，墨点变成印雨（二十五个点 → 越落越密）。
- 合：锣一声收住，朱红「25」与「477」并置，镜头仍在左移，前面是空白纸面，等下一段。

## 6. Cue map

- 速度 72 BPM，4/4，一拍 0.8333 s，一小节 3.3333 s。序（0–6.667）为自由节拍，但事件仍落在隐藏拍格上（2.5、3.333、4.167、5.0、5.833），这样第 1 小节第一拍的朱印"来得必然"。
- 小节网格：第 1 小节 6.667｜2: 10.000｜3: 13.333｜4: 16.667｜5: 20.000｜6: 23.333｜7: 26.667｜8: 30.000｜终 33.333。
- 调式：D 宫五声（D E F# A B），不转调。
- 主题动机（古琴，完整呈示）：
  - 第 1 小节（按音）：D4(1) E4(½) F#4(½) A4(2，吟揉)
  - 第 2 小节（按音）：B4(1) A4(½) F#4(½) E4(1) D4(1，泛音收)
  - 第 3–4 小节：同一动机高八度用**泛音**再奏一遍（散—按—泛，古琴的三种音色各占一段），下面低音 D2/A2 散音托底。
- 印雨（第 5–8 小节）：25 方印的木鱼音高按动机走：第 1–9 方 = D E F# A B A F# E D，第 10–18 方 = 同一句高一个八度，第 19–24 方 = D E F# A B D 上行，第 25 方 = 锣 + 低音 D。印雨本身就是主题的加速再现。
- 板眼：第 5、6、7 小节第一拍各一声"板"（板），印落在"眼"上；第 7 小节起梆子补反拍。
- 第 7 小节第 3–4 拍大鼓滚奏渐强，29.792 一刀切断（空一个十六分），30.000 锣。

三层：环境（极低的纸房间底噪，2.5 s 后才出现）／拟音（全部按 EV 事件时刻放置）／音乐（古琴 + 低鼓 + 木鱼梆子板 + 锣）。

混音目标：−14 LUFS（±1），真峰值 ≤ −1 dBTP；2.5 s 那一声水滴后、朱印那一拍、30.0 的锣是三个最响的点。

母带（第二轮重做）：原来只有一个快释放（60 ms）的总限幅，锣尾被压了约 9 dB 且增益随波形起伏，有把锣"调制"出金属失真的风险。现在拟音总线（印泥、水滴、墨点这些尖瞬态）先单独用快释放限幅，打击乐总线用 300 ms 慢释放轻压，总限幅释放 250 ms、天花板 −2 dBTP；锣、30.0 的定音鼓和大鼓、朱印与印声都降了 2–4 dB。实测锣尾（31–33.3 s）总限幅最大只压 2.8 dB，增益最快变化 1.5 dB/10 ms，无削波样本（mix.py 每次运行都打印这些诊断）。

## 10. 与相邻片段的衔接

- **首帧**：全黑（规范允许片段一从黑场开始）。
- **尾帧**：镜头仍以 122 px/s 向左平移（规范的慢段约 120 px/s），缩放 1×，纸是同一张（`共用/材质/宣纸.png` 镜像平铺、锚定在世界坐标上），画面左侧约 900 px 是空白宣纸，右侧是「25」与印谱。没有淡出、没有黑场。
- 声音尾：锣尾与古琴泛音自然衰减但片尾仍有声；底噪持续到最后一帧，下一段可以直接接上。
- 拼接时，下一段第一帧只要以同样速度、同一纸纹相位继续向左即可：本段结尾镜头左缘世界坐标 `camL(33.333) ≈ −4164 px`，速度 122 px/s；纸纹坐标 `uv = 世界坐标 / (3328, 1856) + (0.5, 0.21)`（宣纸.png 横向平铺，两份错开半周期交叉混合消接缝），都在 timeline.js / comp.js 里。

## 11. 技术路线

- `timeline.js` 唯一时间源 → `index.html` 的 `render(t)`（Canvas 2D 世界层 + WebGL2 合成：宣纸、墨的渗化与积墨）→ `window.EV` → `events.json` → `mix.py`（`pluck.py` 古琴、`sampler.py` 锣/定音鼓/大鼓/木鱼、numpy 合成纸声/水滴/算盘）→ `mux.sh`。
- 所有随机量都用固定种子，任意帧可单独渲染。
- 母带：mix.py 拟音/打击乐分总线限幅后把响度推到 −14 LUFS，总线再用 4 倍过采样前视限幅（释放 250 ms）把真峰值压在 −2 dBTP，mux.sh 两遍 loudnorm 收尾（实测数字见第 12 节）。

## 12. 自检结果（第二轮修改后，成片实测）

- 时长 33.333 s，1000 帧 @30 fps，1920×1080；AAC 48 kHz 立体声，音轨 33.333 s。
- 响度 −14.1 LUFS，真峰值 −1.5 dBTP，LRA 5.4 LU，无削波样本。母带诊断：锣尾（31–33.3 s）总限幅最大压 2.8 dB、增益最快变化 1.5 dB/10 ms（第一轮约 9 dB、60 ms 快释放）。
- blackdetect：只有 0–0.5 s 设计内黑场；freezedetect（1 s）无冻结；scdet 阈值 8 无硬切。0–2.0 s 数字静默，2.25–2.49 s 峰值 −∞ dB。
- 对拍（tools/cuecheck.py）：34 个画面事件全部在 ±33 ms 内，平均 6.6 ms，最大 17.3 ms（八分、三连、十六分落在两帧之间，画面取最近一帧；音频起音都在事件时刻 ±1 ms）。
- IP 占比（逐帧实测 2.4–5.4 s）：微距阶段（2.5–3.9 s）画面里九色鹿彩色像素为 0（≤0.03% 是纸面背光杂点）；画芯从 4.0 s 才露出，此时缩放 1.004×，扇面直径 ≈ 526 px（画面高 49%），九色鹿外接框最大 469×504 px（画面高 47%）。
- 显影收束：扇面内与终帧的差异在 4.90 s 降到 0.03%（未洗净像素），4.933 s 起为 0，5.000 s 平均差 0.07（只剩潮线淡出），与沙沙声止于 5.000 一致。
- 「宝莲灯」印放大检查：简体「莲」（艹 + 车 + 辶），与其余 24 方印同一字体风格。
- 第二轮改动（审片不通过后）：①微距里九色鹿铺满全屏（IP 规则违规）→ 微距只有墨与空绢，拉远提前到 2.85–4.1 s，显影改到 3.9–5.0 s；②显影开口是锐利的正圆 → 显影前缘与墨晕共用角向噪声 + 纤维拖拽 + 毛边，从偏心的不规则水口开始；③「宝莲灯」印的「莲」是繁体写法 → 用同一字体拼出简体；④ 25 颗墨点在空中排成点阵、最长等 9 s → 每颗墨点在自己的印之前一个八分到一拍才斜落溅开，画面里同时只有两三颗；⑤甩笔是一条实心浓墨压在第一组上 → 干笔飞白、淡到重墨与淡墨之间，起笔移到印组外侧右上方；⑥木鱼、梆子、板换成真实采样，母带改为分总线限幅、慢释放，锣尾不再被重压。
- 第一轮改动：纸纹镜像平铺有接缝 → 交叉混合平铺；背光纸纹在微距下出现镜像 → 换采样区；墨晕边缘太硬、像烧焦 → 水晕/墨心两道前缘 + 纤维拖拽 + 颗粒；扇面圆窗切到鹿脸 → 换圆心；甩笔压在第三幅立轴上 → 移到主题句左侧；朱印读字时长不够 → 印移到小字下方、平移晚起步半拍；印雨段比 A1 响 10 dB → 降低印声与滚奏。

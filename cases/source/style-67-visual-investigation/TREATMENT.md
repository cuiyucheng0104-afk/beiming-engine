# 大桥的五十九分钟 · TREATMENT

风格：视觉调查（visual-investigation）。1920×1080，**30 fps**（STYLE.md §5），时长 **19.333 s**（90 BPM × 29 拍）。无旁白、无字幕；画面内文字以中文为主。

> 片名说明：分镜原题「四十二分钟」。核对 WSDOT 时间线（FACTS.md）后，"42" 是风速（42 英里/时），不是分钟数；从 10:03 开始扭转到 11:02 第一段桥面断落是 **59 分钟**。片名改为「五十九分钟」，42 留给风速读数。

## 1. 三种结构候选

1. **严格时钟**：07:30 → 11:10 一路走表，事件在发生时落下。稳，但开头 3 秒没有钩子。
2. **一个问题**："风有多大？"逐个来源回答。偏说理，高潮不够硬。
3. **冷开场倒带 + 重建（选定）**：开在决定性的冻结帧（桥面撕裂），三个来源砸进网格，红色同步线扫过，然后整片倒带回 07:30，再按时钟重建，在 11:02 硬同步、静默一拍、断裂。结尾回到开场那一帧，这次完全标注。理由：钩子在第 0 帧；倒带本身就是本风格的原生招式；结尾与开场呼应。

## 2. Logline 与弧线

**一段 42 英里/时的风，让桥面扭了 59 分钟，然后撕裂。**
设定（倒带回 07:30）→ 转折（10:03 开始扭转，冻结、圈出、放大：倾角达 45°，每 5 秒一次）→ 结局（11:02 硬同步，静默一拍，断裂；回到开场帧，证据全部指向同一时刻）。

## 3. 对标

- **对标**：报纸视觉调查栏目的视频重建、法证建筑类重建片的"多源同钟"版式。
  - **学**：多来源在同一秒对齐的版式逻辑；冻结→圈→放大的节奏；时钟读数随段落换形态；克制的灾难表现（不慢放）。
  - **不学**：任何机构的品牌、字体、片头、具体镜头与配乐；不引用它们的名字。

## 6. Cue map

- **速度**：90 BPM，4/4，拍 = 0.6667 s = 20 帧（30 fps），所有事件落在 1/4 拍（5 帧）网格上，偏差目标 0 ms。
- **小节网格**：第 1 小节 b0–4，第 2 小节 b4–8 …… 第 8 小节 b28–29（末尾单拍余响）。
- **段落与配器**：

| 段 | 拍 | 配器 | 状态 |
|---|---|---|---|
| S1 冷开场 | b0–5 | 低音提琴 D1 + 定音鼓 D2 重击；高音颤弓小二度簇（D5/E♭5）极轻；tick；倒带 = 反向镲 + 下滑合成音 | 悬置 |
| S2 网格 | b5–12 | 合成低频脉冲（每拍，带 2/3 次谐波）；低音提琴 + 大提琴 D 持续；大提琴/中提琴拨奏八分 ostinato（Dm–B♭–Gm–A）；木鱼 tick 每拍；b7.5 起颤弓簇 | 推进 |
| S3 冻结放大 | b12–18 | b12–15 脉冲每两拍（减速、呼吸）；弓擦颤音琴金属应力；b15 起 tick 八分、b17 十六分；大提琴跳弓；颤弓簇渐强 | **加速** |
| S4 硬同步 | b18–20 | b18 一击后全部切断；b19–20 近静默 | **静默** |

电平层级（返修）：b19 之前的音乐与拟音整体低 2.9 dB，S2/S3 低频脉冲再低 3.3 dB；b20 断裂总线 +4.6 dB 并做 tanh 饱和（峰值不变、密度上升），保证 b20 是全片短时 RMS 与 150 Hz 以下能量的最高点。
| S5 断裂与结论 | b20–29 | b20 深沉重击 + 金属撕裂；低音弦长音 Dm → B♭；b26 D 小调加九（颤音琴 + 中提琴/大提琴）；b28 小槌 ✓ | 落定 |

## 7. 声音设计表

| 段 | 环境底 | 主要拟音 | 音乐状态 |
|---|---|---|---|
| S1 | 过滤房间底噪 | 快门（冻结、卡片）、摩尔斯、按键、同步线 whoosh、倒带 | 重击后悬置，倒带下滑 |
| S2 | 房间底噪 + 低风噪 | 栏亮快门、摩尔斯打字、读数跳动小槌、每拍钟摆 tick | 脉冲 + 拨奏 |
| S3 | 房间底噪 | 快门、铅笔画圈、标签按键、放大镜金属应力、tick 加速 | 脉冲减半 → 加速 |
| S4 | 几乎无 | 一声硬 tick，然后静默一拍 | 静默 |
| S5 | 房间底噪回来 | 深沉重击（唯一的一次）、金属撕裂、摩尔斯、纸、圈、✓ 小槌 | 长音 → 加九和弦 |

克制：不慢放坠落，不加水花或人声效果，重击只有一次。

## 8. 画面文字设计

- 中文：Noto Sans SC 700；时码与标签：IBM Plex Mono 400/600；均为 OFL，按字子集化放 `fonts/`。
- 来源标签：6×12 红色块 + `类型 · 来源`（影片 · Elliott / 天气图 · NOAA / 转录 · WSDOT）。
- 电报卡：纸色 `#E4E0D4`，墨 `#1D1D1B`，等宽时间戳 + 中文一句，打字机出现。
- 时钟读数随段落换形：HH:MM（S1–S2，小时→分钟）→ HH:MM:SS + T+（S4，秒）→ 图表播放头 + T+（S5）。首次读数注明 `1940-11-07 PST`。
- 推断标记：影片时刻 "≈"（影片与时钟的对齐是推断，见 FACTS.md）。

## 9. 自检结果（成片，返修后）

- 时长 19.333 s（580 帧 @30 fps）；响度 −14.0 LUFS（mux 后加一步线性增益校准，本次增益 0.00 dB），LRA 8.3 LU，真峰值 −1.1 dBFS；blackdetect 0 处；freezedetect 只有 12.10–13.33 s 的硬同步定格。
- scdet 8 个硬切：0.667 / 3.333 / 5.000 / 8.000 / 9.000 / 12.000 / 13.333 / 17.333 s，全部 0 ms 落在半拍网格上（放大镜改为整块切入后，b13.5 不再偏一帧）。
- `tools/cuecheck.py`：38 个事件全部落在 1/4 拍网格与整帧上（0.000 ms）；6 个关键声音起音偏差 0 至 −2.5 ms；6 个硬切（含 b13.5）最大帧差都在预期帧；b19–b20 静默 −60.5 dBFS。
- 各拍 100 ms 峰值 RMS：b20 −7.4 dB 为全片最高（次高 b17 −9.4、b5 −11.1）；150 Hz 以下能量 b20 −8.9 dB 同样最高（次高 −11.4）。
- `readcheck.mjs`：24 段关键文字全部达到阅读时长（含新增「跳过 8 分钟」）。
- 与演示片对照：结构（倒带回 07:30 后按钟重建 vs. 多段尺度）、招牌镜头（冻结放大 45° + 断裂实时）、运镜路径、结尾（回到开场帧标注 vs. 证据地图 + 片尾卡）四项不同；开场（冻结帧 + 倒带）与配乐调色板为本风格规定，相同。

# 《交接录像》TREATMENT（后室 / 新怪谈 · 风格样片 36）

- 规格：1920×1080（画内 4:3 柱状框），24 fps，23 拍 = **19.167 s**（460 帧）。
- 无旁白、无字幕；画内文字只有：OSD（REC / 时间码 / 日期 / 电量，自制点阵字体）、墙上的告示、尽头门牌。
- 分镜条目片名是「第 0 层」，但 STYLE.md 明令不得在片中出现后室社区的 "Level" 编号，所以这个名字**只作档案名，不上画面**；片内标题改为原创的《交接录像》（也不上画面，只在文件里）。

## 1. 三个候选结构与选择

1. **一条直走 + 规则递进**（分镜原案）：开机 → 走 → 读规则 → 违反规则（数门）→ 磁带断 → 尽头门牌写着「你」→ 时间码归零。一个主体（持机人）、一个目标（往前走）、一个转折（数了门）。
2. **同一路线两盘带**：第一盘走到门口被打断，第二盘同一机位只有 OSD 变了。信息量大，18 秒装不下。
3. **点名清单**：告示列出 1–5 条，镜头逐条对照，第 6 条不在单子上。偏文字，画面招式少。

**选 1**：分镜指定的四个原生招式（自动对焦搜寻 / 磁带跟踪损坏 / OSD 即剧情 / 画内规则文字）在一条直线里可以一个接一个递进，而且 18 秒只容得下一个转折。我在原案上做的调整：
- 「数门」由**观众自己完成**：镜头扫过门的节奏从八分音符加速到十六分音符，观众会不自觉地数——数到第 4 扇，磁带断了。第 5 扇永远不出现。
- 静默之后的第一声 = 全片最重要的声音 = **低频冲击 + 全部灯管同时重新打火**（STYLE §7 的 "soft scare"），同一帧画面恢复，尽头门牌「你」出现。
- 结尾的「时间码跳回 00:00:00」配第二个、更轻的低频闷击，然后开场那段吸顶喇叭提示音**走调地再响一次**（磁带变速），暗示录像从头开始——这一盘带是「你」的。

## 2. Logline 与结构

一个新来的夜班员工打开摄像机，沿着无尽的黄色办公区往前走；墙上写着「不要数门」，他（和观众）还是数了，磁带断开，再亮起时，尽头的门牌上写着「你」，时间码归零。

- 起（0–4.2 s）：开机，静止持机，慢摇揭示空间无限。
- 承（4.2–8.3 s）：手持前行，对焦来回搜寻（看不清远处）。
- 转（8.3–12.1 s）：转身读告示（屏息，一切静止）→ 甩镜扫过一排门，越扫越快。
- 断（12.1–13.3 s）：磁带跟踪撕裂，数字零静默。
- 合（13.3–18.3 s）：冲击，灯全亮，门牌「你」；慢推；时间码归零；提示音走调重来。

## 3. 对标

- **Kris Straub《Local 58》**（模拟电视恐怖）——学：规则/公告式文本的平静口吻、介质本身失灵带来的寒意、几乎不用"怪物"；不学：电视台包装、任何角色和台标。
- **1990 年代家用 Hi8 / VHS-C 摄像机原片**（家庭录像、房产看房带）——学：OSD 版式、对焦电机的犹豫、AGC 噪点、开机滚屏、手持的步态与呼吸；不学：任何真实品牌的 OSD 字形与标志。
- **《女巫布莱尔》**——学：只靠持机人的呼吸和脚步建立恐惧曲线、"看不清"比"看见"更可怕；不学：任何镜头、人物、情节。

## 6. Cue map（配乐 = 带子录到的声音本身）

- 速度 72 BPM，4/4，5.75 小节：bar1 b0–3｜bar2 b4–7｜bar3 b8–11｜bar4 b12–15｜bar5 b16–19｜bar6 b20–22（3/4 小节）。
- 所有事件坐在 1/16 网格上（1/16 = 0.2083 s = 5 帧，网格与 24 fps 帧边界完全对齐，目标偏差 0 ms）。
- STYLE §7：**没有配乐**。所以"音乐"由片中世界里的声音按节拍组织：

## 8. 画内文字设计

- **OSD**：自制 5×7 点阵字体，黑描边，不受桶形畸变影响：左上 `● REC`，右上电量格，左下日期 `OCT.31.1996`，右下时间码 `00:00:00`（HH:MM:SS，按带内时间走，b16 跳到 03:47:15，b20 跳回 00:00:00）。时间码是计数器，不列入 readcheck 的 TEXTS（只列 REC 与日期）。
- **告示**：发黄的激光打印纸，胶带贴墙；页眉「注意」+ 表单号 `表 B-117 第3版`；正文大字「不要数门」（Noto Sans SC Black）；落款「——管理处」。镜头与纸面平行，避免假斜体。
- **门牌**：办公室亚克力门牌，灰底黑字「你」（Noto Sans SC Bold），门上方一盏红色占用灯——**全片唯一的饱和色**，自发光推到 20（远过泛光阈值），再加一层贴墙的加色红晕，红光还会染到门框和墙面；它在冲击后最后一个稳定（b16.5、b16.75 两次断火，b17 稳住）。门牌边长 0.38 m（门宽的 42%）。
- 字体：Noto Sans SC（OFL），Google Fonts `&text=` 子集化到本片用到的字，放 `fonts/`。

## 11. 返修记录（审片后第一轮）

- **高潮门牌太小** → 门牌由 0.26 m 放大到 0.38 m（门宽 42%）；变焦终点由 26° 推到 16.5°（约 1.5 倍），且在 b18 对焦锁定前已推到 22°。实测门牌 b18 时约占画高 17%，b20 以后约 23%。
- **红灯泛光弱** → 自发光 9 → 20，灯箱和透镜放大，新增贴墙加色红晕，墙面/门框受红光 0.55 → 1.05；冲击后红灯最后稳定（b16.5、b16.75 断火，b17 稳住），三个事件都有拟音并进了拍点核对。
- **第二条走廊单调** → 两侧墙各开一个错开的缺口，缺口外的灯是死的，纵深退进暗雾；中段一盏灯只打着三成、偏绿，形成「亮 → 暗 → 门口亮」的纵深分区；墙脚一圈很淡的水渍线，尽头墙门右侧一道从吊顶渗下的水痕，残灯旁一块发黄带水圈的吊顶板。老化保持克制。

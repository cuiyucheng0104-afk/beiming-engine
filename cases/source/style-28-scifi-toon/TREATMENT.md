# 《冷冻柜》 TREATMENT

风格：科幻情景喜剧卡通（scifi-toon）· 1920×1080 · 24 fps · 19.5 s · 无旁白、无字幕 · 画面内文字仅「冷冻食品」吊牌与收银机「合计 ¥5.00」。

## 0. 三个候选结构

1. **三开门 → 冻成冰棍 → 扫码**（分镜原案，线性升级）：两个外星人在超市冷冻柜前拉门三次，第三次是冰冻的宇宙，被吸进去冻成冰棍，被收银员面无表情地扫码。优点：rule of three 天然卡拍，结尾的「哔」把宇宙级事件降格为一件商品。
2. **倒叙：从收银台开始**：先看到收银员扫两根奇怪的冰棍，再闪回冷冻柜。缺点：结尾失去「哔」的反转，笑点前置，15–20 s 里倒叙解释成本太高。
3. **同一机位的三次开门蒙太奇**（只用柜内机位，观众始终看不到柜里是什么，只看两张脸被不同颜色的光照亮）：很冷，但看不到「冰冻的宇宙」这个原生画面，浪费了这种风格的发光装置。

**选 1**，但做两处加强：(a) 第三次开门前插一次「犹豫」（加长的预备动作），把三次开门做成「4 拍 → 2 拍 → 犹豫 2 拍 + 揭晓」的先加速后急刹；(b) 两段静默：第一段是开门后的尴尬死寂（死寂后第一声是冷冻柜「吸气」），第二段在冰棍落到传送带之后（死寂后第一声是全片最重要的「哔」）。高潮 = Dead-air reversal + The suspiciously normal world：宇宙级灾难被扫码、计价、结账。

## 1. Logline 与弧线

两个来超市买冰淇淋的外星人第三次拉开冷冻柜，里面是一整个冰冻的宇宙——他们被吸进去冻成了冰棍，而收银员只是「哔」了一声。

- 建立：米色超市（可疑地正常的世界），高瘦（无聊、半闭眼、长围巾）与矮胖（紧张兴奋、鱼缸头盔），对冰淇淋的反应完全不同。
- 转折：第三次开门，柜里是紫黑色的冰冻星系，唯一发光的东西。死寂。
- 结局：被吸入、冻成两根冰棍、滚上收银传送带；收银员面无表情扫码「哔、哔」，合计 ¥5.00，罐头笑声。

## 3. 角色与世界

- **高瘦**（冷面）：雾紫色皮肤，细长脖子，一根带圆球的天线，眼皮总是半垂；荒诞服装＝一条拖到地上的芥末黄长围巾。动作慢、少。
- **矮胖**（慌张）：番茄珊瑚色皮肤，球形身体，大眼小瞳孔、眼袋；荒诞服装＝一个太空鱼缸头盔（透明圆罩，套着头，罩外有扣环）。动作快、抖。
- **收银员**：米色皮肤、灰绿制服、厚眼皮、嚼口香糖，表情从头到尾不变（可疑地正常）。
- **世界 A 超市**：米色/浅棕/灰绿/奶油（刻意平庸）＋冷冻柜白边、结霜玻璃门（看不到里面）。
- **世界 B 冰冻宇宙**：深紫黑底、冰蓝结晶、金色星点；**冰青色发光只属于这个柜门里的宇宙**，其它地方都不准用。
- 冰淇淋：粉色和棕色的圆桶，桶盖上画冰淇淋甜筒图标（无文字），有霜点和冷气，避免读成别的东西。

## 6. Cue map

- **速度**：每拍 13 帧 = 0.541667 s（≈110.8 BPM；分镜原定 112 BPM，取最近的整帧速度，让每个拍点都落在帧上，理论偏差 0 ms）。4/4，一小节 2.1667 s。拍号 b → t = b × 13/24。
- **段落**

|---|---|---|---|---|

## 7. 声音设计

| 段 | 环境底 | 主要拟音 | 音乐状态 |
|---|---|---|---|
| A 超市 | 日光灯 120 Hz 嗡 + 冰柜压缩机低嗡 + 远处购物车 | 吊牌晃「吱」、哈欠、玻璃「咚」（脸贴玻璃）、指 | 电梯波萨（采样+拨弦），特雷门琴进 |
| B 三开门 | 同上 | 把手「咔」、门开「嘶—（冷气）」+ 门封胶条「啵」、关门「噗」（fwump）、甩镜「嗖」、反应眨眼「blip」 | 鼓机 + slap bass + stinger，逐次变短 |
| 开门 #3 | 冷气变成冰晶「叮铃」高频 | 门开 + 宇宙「嗡」低频 + 震 | 特雷门琴大滑音 → 硬切 |
| C 死寂 | **只有**压缩机嗡、日光灯 | 咽口水「咕」 | 0 |
| D 吸入 | 风暴噪声 | 吸气 boom、拉伸「吱呀」、旋涡「呼」、冻结「咔嚓」（冰裂）、冰棍弹出「啵嘤」（boing）| 全开 |
| E 收银台 | 日光灯、远处极小商场音乐 | 冰棍落地「哐、哐」、传送带电机、拿起冰棍「沙」 | 0 |
| F 结账 | 同 E | **哔**、哔、收银机打印「嘀嘀嘀」、泡泡糖「啪」、眨眼「blip」 | slap bass 过门 + 罐头笑声 + 收尾 |

响度 −14 LUFS（mux.sh）。低频：groove 总线（slap bass＋鼓机）与 b21 吸气 sub boom 各加一个 95 Hz、Q 0.9、+3 dB 的峰值 EQ（覆盖 80–110 Hz，40 Hz 以下基本不动），总线低频压制从 35% 放松到 18%。

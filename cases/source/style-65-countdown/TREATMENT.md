# T−15 · 实时倒计时分屏 — 导演阐述

## 0. 硬约束
- 1920×1080，**30 fps**（STYLE.md §5），时长 19.8 s。
- 无旁白、无字幕（用户决定）。现场广播解说（NASA 解说员的 "seven, six…"）属于人声解说，按用户决定**不进混音**，只用来做对时参考；"拼到点上"的工作改由时钟的每一秒、每一次格子开启与配乐承担。这是对 STYLE §7 第 1 层"现场声"和 §4 直播转写框的有意偏离。
  - 返修时重新核对过：从 iso 原片取出同步广播声，用 Whisper 逐词定时（FACTS.md）。解说没有 "ten…eight"，从 "seven" 开始数（T−6.9），而且比真实时钟晚约 0.5 s："one" 落在 T−0.43…−0.11，"boosters ignition" 在 T+0.4…+1.2，"liftoff" 在 T+2.3。如果把这条现场声放进来，"one" 正好落进零点前的静默拍，要么破坏用户定下的"静默后第一声最重要"，要么得把真实口令剪掉一个字（等于篡改现场声）。转写框按 STYLE 就是字幕，用户已经否掉。所以维持不用现场声的决定。
- 画面内文字只有风格本身需要的：时钟、控制条、机位牌、同步徽章、事件旗。中文为主，英文小字。

## 1. 三个候选结构
1. **格子从 1 开到 9，零点合一**（风格原型）：时钟独占黑场 → 一格 → 3×3 待命网格逐秒填满 → 零点合一。最清楚，但"合一"只是 0.42 s 的一下。
2. **两条倒计时并排**：发射台 vs 控制室两列各自倒数，零点相遇。15 秒里两条线都撑不起来，素材也只有一个控制室机位且不同步。
3. **填满 → 拼图 → 合一**（选用）：结构 1 的前半，但 T−3 到 T−1 不是"减格子"，而是八个格子按加速的节拍**一格一格换成同一个主机位的对应局部**——全画面像拼图一样在网格里拼出来，格线还在；静默的一拍后，零点格线消失、闪白、时钟翻转。合一被拉长成 3 秒的过程，高潮落在零点。

选 3 的理由：把分镜要求的"分屏一格格合并"与 STYLE 的"Many into one"做成一个连续动作；拼图的加速（八分→十六分→三十二分）天然就是全片的加速段；静默一拍后格线消失，是全片唯一的"一个画面"。

## 2. Logline 与弧线
**阿尔忒弥斯 I 号发射前最后 15 秒，一秒不剪：九个机位随倒数逐格亮起，在零点拼成同一团火。**
- 起：黑场里只有时钟 T−15，休斯敦控制室先亮（老实标注"未逐帧同步"）。
- 承：3×3 待命网格，每一声秒响开一个机位；T−6.36 四台 RS-25 点火，发动机机位亮起。
- 转：T−3 起格子按加速节拍换成同一机位的局部，拼出完整画面；T−1 之后全静一拍。
- 合：T−0 助推器点火，格线消失，一个画面，时钟翻成橙底 T+，一刀切到远景，火箭离开发射台。

## 3. 对标
- **对标 A：纪录片《Apollo 11》（2019）的多画面档案面板与任务时间码。** 学：同一秒多个机位并置、每格都老实标机位、时间码当主角。不学：它的字体、配色、版式、音乐、任何画面。
- **对标 B：电视剧《24》的实时时钟与分屏。** 学：分屏数量就是紧张度、时钟每秒必响。不学：它的音效、时钟设计、黄色数字。
- 片中不出现以上作品名称。

## 4. 素材（公有领域，全部来自 NASA images.nasa.gov）
- 主素材：`Artemis I Isolated Launch Views`（KSC-20221116-MH-AJN01-0001，4K 60 fps）。每段机位都带同一条广播声；我用**声音互相关**把各段对到同一条时间轴（相关系数 0.90–0.99），再用**画面事件**定零点：近景机位 913 的助推器点火羽流出现在参考时刻 21.70 s；观众机位画面里的倒计时牌在参考 9.3→9.7 s 之间由 −13 翻到 −12，两者一致（详见 FACTS.md）。
- 控制室：`Mission Control Houston During Artemis I Launch`（jsc2022m000284，4K）。没有时钟可对，**标"同一时段 · 未逐帧同步"**。
- 映射：片长时间 f，倒计时 T = f − 15，参考时刻 ref = f + 6.70，第 k 段源时刻 s = ref + shift_k（shift 表见 material/sync.json）。

## 7. Cue map
- **BPM 60**，一拍 = 一秒 = 一声秒响；4/4，5 小节：①f0–4 ②f4–8 ③f8–12 ④f12–16 ⑤f16–19.8。拍 k 在 f = k。
- 调性：零点前是 C–G 空五度长音（没有三音，不定悲喜），零点落 **A♭ 大三和弦**（♭VI，"抬升"），T+2 硬切时解决到 **C 大调**（到达）。
- 乐器：采样定音鼓、大鼓、通鼓、小鼓、镲、管钟、钟琴、长号、大号、圆号、低音提琴拨奏 + numpy 合成低音长音（低通随时间打开）、合成秒响与火箭轰鸣。不用钢琴、不用弦乐长音铺底。
- 事件与拍点（全部在网格上，脚本核对）：
  - 秒响：f0…f14 每拍，f16…f19 每拍（零点由大和弦取代）。
  - 开格：f1, f3, f4, f5, f6, f7, f8, f9（整拍，配通鼓）；重排 f2（整拍）。
  - 旗落定：f3, f9, f16（整拍）；推近 f10, f11（整拍）。
  - 擦换：f12, 12⅓, 12⅔（三连音）, 13, 13⅙, 13⅓, 13½, 13⅔（六连音）——加速段。30 fps 下三连音 = 10 帧、六连音 = 5 帧，每次擦换都落在整帧上（十六分音符 7.5 帧做不到 0 ms，所以不用）。
  - 静默：f14.0 秒响之后到 f15.0，音乐、拟音全断。
  - 零点：f15.0 合一、闪白、翻转、大和弦——静默后第一声。
  - 硬切：f17.0（整拍）。
  - 画面动作的起步：开格、重排、拼图擦换、事件旗都从拍点前一帧起算（那一帧位移仍为 0），并用 easeOut，所以**拍点那一帧就是第一帧可见的动作**，和咔嗒、通鼓同帧；T−0 闪白在零点帧已亮到一半，下一帧到峰值。
- 快慢：第 1–3 小节匀速逐秒，第 4 小节加速到六连音再急停，第 5 小节半速感（铜管长音 + 拨奏八分）。

| 段落 | 氛围床 | 主要拟音（来自 window.EV） | 音乐状态 |
|---|---|---|---|
| f0–2 开场 | 极低的电子嗡声（控制室空调感） | 秒响、开格咔嗒、重排呼声 + 金属合扣 | C–G 长音 + 每拍大鼓（心跳） |

| f14–15 静默 | 无 | 只有 f14 那一声秒响 | 全断 |
| f15–17 零点 | 火箭轰鸣（噼啪 + 次低频） | 点火重击、时钟翻转咔嗒 | A♭ 大三和弦（长号/大号/圆号）+ 大鼓 + 镲 + 管钟 + 定音鼓 |
| f17–19.8 升空 | 轰鸣持续、尾段渐收 | 硬切闷击、轻秒响 | C 大调和弦（大号/长号/圆号/小号）、拨奏低音八分、钟琴 C–E–G、管钟收尾 |

- 低频（TECHNIQUE §5，tools/bands.py 按每倍频程能量量）：轰鸣在 60 Hz 以下再加 −3 dB 低搁架；零点后大号、低音提琴拨奏和定音鼓在 80–150 Hz 由轰鸣包络驱动的动态 EQ 让出 2 dB；零点前长音的 C2/G2 减薄、改由 C3/G3 承担。零点后 20–120 Hz 比 120 Hz–7.7 kHz 平均倍频程低约 3 dB。

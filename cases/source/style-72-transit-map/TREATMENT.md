# 十年 · TEN YEARS — 地铁线路图风格样片 TREATMENT

> 风格：transit-map（STYLE.md 全部不变量照办）｜ 1920×1080 · 30 fps（STYLE §5）｜ 时长 19.733 s（= 37 拍 @112.5 BPM）｜ 无旁白、无字幕，只有印在图纸上的字和左上角计数器。

## 0. 题材定位

这不是某座真实城市的线网，而是**把一个人的十年画成一张线路图**（STYLE §11「A topic drawn as a network（a career）」）。线网是隐喻，图签上印明「虚构线网」，因此不需要真实线网的 FACTS；年份是故事自身的数值，计数器只落在这四个故事年份上：2016 / 2018 / 2021 / 2026。

线网规模按「topic drawn as a network」下限：4 条线（≥4）、21 个命名站（≥20）、6 座换乘站（≥4）、两块印刷区域 + 一条江（区域代表领域）、4 个年份状态（≥3）。

| 1 号线 | 红 #E3002B（故事强调色） | 自己 | 2016 | 毕业 Graduation · 出租屋 First Flat · 早班车 Early Bus · 第一份工 First Job · 加班 Late Nights · 相遇 Met You · 升职 Promotion · 江边 Riverside |

印刷区域：江西「那些年 THOSE YEARS」，江东「后来 LATER」；江名「那条江 THAT RIVER」。

## 1. 三个候选结构

1. **一条线从头画到终点**（单线逐站）：1 号线一路画到「今天」。干净，但只有一种动作，撑不起四个原生招式。
2. **两张网对照**（之前 / 之后两张线网并排，最后锁定画面判定）：信息量大，但「十年」是情感题，不是比较题，判定式结尾太冷。
3. **网一条条长出来，最后一圈把它们连起来**（选定）：红线 = 自己 → 蓝线 = 遇见你（换乘站落下）→ 绿线 = 过江去远方（江底隧道）→ 停一拍 → 环线两枚笔尖反向绕城、在新家会合闭环（最大的换乘站落下）→ 你在这里。
   理由：每一条线都是一个「人生章节」，每一座换乘站都是一个和弦，网越长音乐越厚；环线闭合天然就是「十年画成一个圈」，高潮落在原生招式「换乘站落下」上，结尾回到「你在这里」与整张网。

开场与结尾的选择：开场不用片头卡——第一帧就是图签「十年」旁的红色笔尖开始走（STYLE §11 列出的开场之一，但用在一个人的十年上）；结尾「你在这里」红点脉冲之后整网全景，图签在左下角回到画面。

## 2. Logline 与弧线

一支红笔从「毕业」出发，十年里遇见一个人、跨过一条江，最后两枚笔尖绕城一圈在「新家」会合——原来这些年画出来的，是一个家。

- Setup（0–5.9 s）：红线一个人往前画，站点一个个亮。
- Turn 1（5.9 s）：蓝线落到红线上——相遇站从天而降。
- Turn 2（8.0–11.7 s）：绿线钻进江底，镜头压低跟着它穿过去。
- 加速（11.7–15.5 s）：环线两枚笔尖反向狂奔，沿途换乘站一个接一个弹出，年份滚动。
- 静默（15.5–16.5 s）：音乐抽空，两枚笔尖从两侧慢慢靠近新家。
- 高潮（16.53 s）：闭环，新家换乘站从高处落下，四色冲击环，计数器落在 2026。
- 结尾（16.5–19.7 s）：拉升到整张网，「你在这里」红点脉冲，图签回到画面。

## 3. 对标作品

- **学**：长期运营的城市线网图海报的八方向几何与留白节奏；微距翻拍纸质地图的浅景深、斜光与纸纹（台面上的实物感）；城市宣传片里「线网生长」段落的生长-停顿-再生长节奏；地铁报站「叮咚」作为全片动机的做法。
- **不学**：任何真实线网的布局、线色组合、站名、字体与线路标志；不出现任何城市或运营方名字；不复刻任何宣传片镜头。

## 6. Cue map

- **速度**：112.5 BPM 全程不变（加速靠加声部与和弦节奏加密，STYLE §7）。选 112.5 而不是 116，因为 112.5 BPM @30 fps 时 1 拍 = 16 帧、8 分 = 8 帧、16 分 = 4 帧，所有拍点都落在整帧上，视觉事件与音乐拍点可做到 0 ms。
- **网格**：4/4，9.25 小节（37 拍）；B0 = 0.000 s；第 n 拍 = n × 0.53333 s。
- **调性**：F 大调；换乘站和弦序列：B♭△7（相遇）→ Gm9（婚礼）→ Csus4/C（过江）→ Am7（新家·呼吸）→ Dm（出租屋）→ B♭（雨天）→ C（南门）→ Am（老友）→ Dm–C（孩子）→ 静默 → **F（新家闭环）**。叮咚动机：振音琴 C6→F5（相隔半拍），钢片琴高八度叠在上面。
- **配器（每条线加一个声部）**：

| 段落 | 拍 | 声部 |
|---|---|---|
| A 红线 | B0–B6 | 钢片琴（glockenspiel）站点拨音 + 振音琴叮咚；B4 起合成底鼓/hat（numpy） |
| B 蓝线 | B6–B15 | + 马林巴 16 分固定音型；+ 合成贝斯（带 2、3 次谐波） |
| C 绿线·江底 | B15–B22 | + 小提琴拨奏；B17–B19 全混音低通 600 Hz + 水泡；B21 抽薄 |
| D 环线·加速 | B22–B29 | + 木琴、竖琴琶音、16 分 hat、拍手；和弦节奏加密 |
| E 静默 | B29–B31 | 只留拉弓颤音琴高音（−30 dB）+ 拟音 |
| F 闭环 | B31–B35 | 全体 + 定音鼓；每拍轻钟 |
| G 尾声 | B35–B37 | pad + 叮咚 |

- **卡拍核对**：timeline.js 是唯一时间源，导出 `CUES`（名称 → 拍号）；index.html 的视觉事件从同一张表取时间；`tools/cuecheck.py` 读 events.json（画面实际事件）与 score 事件表逐条比对，目标 0 ms。

## 8. 字与标题设计

- 字体：Inter（拉丁与数字）+ Noto Sans SC（中文，按用到的字用 Google Fonts `&text=` 子集化），均 OFL，放 `fonts/`。
- 所有站名双语：中文在上、英文在下，一行一种语言，纸色光晕。
- 图签（左下角，墨条 + 「十年 / TEN YEARS」+ 灰色小注「一个人的十年，画成一张线路图 · 虚构线网」）就是片名；开场 0–2.6 s 完整在画内（阅读时间 2.48 s）。
- 计数器：左上角深色珐琅铭牌，「年份 / YEAR」，滚轮只落在 2016 / 2018 / 2021 / 2026。
- 「你在这里 / YOU ARE HERE」：红点 r 0.17 G 白描边 + 脉冲环，印字在新家旁，16.53–19.73 s（3.2 s ≥ 阅读时间 3.06 s）。

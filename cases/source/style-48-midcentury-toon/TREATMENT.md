# 明日早晨 · TREATMENT

风格：50s 扁平卡通（midcentury-toon）。1920×1080，24 fps，19.875 s（477 帧）。无旁白、无字幕；画面内文字只有：三个标注标签（吐司 / 咖啡 / 报纸，报纸特写上印报头「晨报」）、编号奖章 1·2·3、结尾片名「明日早晨」。

## 1. 三种结构候选

1. **说明书一页（选这个）**：先把厨房"印"出来 → 机器按 1·2·3 依次工作，每台配圆形标注和编号奖章 → 全停一拍 → 三台机器一起动、越来越快 → 动作凝固成一枚对称的纺织图案。按分镜条目，是一张"使用说明"自己翻页变成了墙纸。
2. 前后对照：左半屏乱糟糟的手工早晨，右半屏全自动早晨，最后两半合成一个图案。分屏把高潮分散了，原生招式到最后才出现，放弃。
3. 倒计时：闹钟从 3 数到 0，每数一下一台机器动。数字会抢走奖章的戏，而且"倒数"不是这种说明书的语法，放弃。

选 1 的原因：它和分镜条目一致，"设置说明"的信息顺序（产品 → 编号步骤 → 细节落在动作拍上 → 结尾成果）正好是 STYLE §11 的语法；"功能变成装饰"的高潮能用本风格专属的"拉远 + 反向旋转，从细节到图案"来拍。

开场画面不用常见的"厨房淡入"，改用**套色一版一版盖印**：先是断续墨线，然后墙、地、台面、机器这几版颜色按拍子错位盖上（off-register 本身就是开场的钩子）。结尾不是 logo，而是这枚"早晨纹样"拉远后铺成整面墙纸。

## 2. Logline 与弧线

**一个 50 年代的全自动厨房按说明书走完早晨的三个步骤，然后越跑越快，最后凝固成一幅墙纸。**

- 开端：厨房被一版版印出来，时钟指着七点。
- 发展：吐司弹出（1）、咖啡倒满（2）、晨报递到（3），标注和奖章把每一步钉在拍子上。
- 转折：全停。三拍完全无声，咖啡滴悬在半空。
- 高潮："叮！"三台机器一起开动，节拍从 144 加速到 240 BPM，轨迹越积越多。
- 结局：定格。轨迹变成花瓣，六瓣镜像旋入，成为一枚对称纹样；拉远后纹样成为整面墙纸，正中盖上「明日早晨」。

## 6. Cue map（节拍网格）

- **速度（对分镜的改动）**：分镜总表写的是 132 BPM（每拍 10.91 帧，拍点会在帧间漂移，取整后最多差 ±21 ms）；为了让每一拍都落在整帧上（0 ms 偏差），本片改为 **144 BPM = 24 fps 下每拍正好 10 帧**，摇摆后半拍取 60 % = 第 6 帧（b22.6、b44.6、b49.6 都是整帧）。加速段每拍帧数依次为 10,10,9,9,8,8,8,7,7,7,6,6,6,6,6,6（144 → 160 → 180 → 206 → 240 BPM），全部是整帧。
- **调性**：A–C 段 B♭ 大调；定格后整体升一个全音到 C 大调（STYLE：结尾成果升一级）。
- **拍子**：4/4，摇摆八分（加速段后半自然拉直）。

## 8. 画面文字设计

- 标签：纸色圆角小卡 + 细墨边 + 星形项目符号，Noto Sans SC 700，44 px；卡片色版错位。
- 奖章数字：墨色圆盘 + 纸色数字（Alfa Slab One），外圈芥末色版错位；按 back 缓动弹入。
- 片名「明日早晨」：按 STYLE §4「标题用板衬线，墨字压错位色版」，中文取最接近板衬线的粗衬线 Noto Serif SC 900（字距 +6），墨字压在珊瑚色版上，色版向右下错位 3 px；放在纸色圆角牌里（墨边 + 内细线 + 错位色版），牌两端各一颗转动的小星（芥末色版错位于墨线），b50 起停转。报头「晨报」同字体同做法。
- 中文用 Google Fonts CSS API `&text=` 子集，存在 `fonts/`。
- 阅读时间：标签 2 字 ≥ 1.94 s，片名 4 字 ≥ 2.39 s，用 `readcheck.mjs` 核对。

## 9. 制作记录（实现后补记）

- **配器落地**：口哨旋律（numpy 合成：近正弦 + 音高周围的气声噪带 + 起音滑入 / 滑音 / 晚起颤音 / 加速段颤音）、摇摆木琴（VCSL）、颤音琴每步一个和弦（B♭6/9 → E♭maj9 → F13，硬槌 + 马达颤音）、低音提琴拨弦行走（Karoryfer）、刷子扫与点（合成）→ 加速段后半换 ride（MuldjordKit）、响指（合成）、最后四拍邦戈鼓、定格加定音鼓 + 镲。没有钢琴、没有弦乐。
- **加速段**：每两拍一个和弦（B♭6/9 · G7♭9 · Cm9 · F13 · B♭7 · E♭7 · Dm7 · G7alt），G7alt 解决到 E 段的 C6/9，正好"升一个全音"。木琴八分音的摇摆比例随拍长从 60% 收到 50%（拍子越快越直）。口哨每两拍一个长音，带颤音往上爬（D6 → B6），定格时跳到 C7。
- **静默**：b24 齐奏收住后 0.07 s 内淡到 0，b25–b27（10.42–11.67 s）**连房间底噪一起切成数字静音**（实测 −240 dBFS）；b28 第一声是吐司机的铃（钟形分音 + 陶瓷敲击），同帧全队重新进入。
- **拍点核对**：`tools/cuecheck.py` 逐个比对 30 个视觉命中 + 16 个加速循环 + 摇摆后半拍 hop2，画面帧时间与配乐写入的音符起点偏差全部 0.000 ms；events.json 80 个事件全部落在整帧上。
- **与演示片对照（DIRECTOR §11，六项中五项不同）**：结构（无主持人的机器连动 + 停 + 加速 vs 带主持人的产品设置指南）、开场（套色一版版盖印 vs 盒子揭开）、运镜路线（横移 + 爬行推进 + 阶梯拉远 vs 每步穿奖章的圆形转场）、配乐形状（停—静默—逐拍加速—升调 vs 倍速/半速切换）、结尾（纹样铺成墙纸 vs 圆形收光片尾卡）不同；高潮招式同为本风格原生的"拉远 + 反向旋转成图案"，但对象（三台机器的飞行轨迹镜像成六瓣玫瑰窗）和后续（铺成墙纸）不同。

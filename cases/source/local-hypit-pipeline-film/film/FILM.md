# 每一关都有证据：导演方案

**一句话。** 一座蓝调时刻的石膏建筑模型就是整条 Hypit 复刻管线：石膏是由代码保证的结构，光是 AI 生成的素材；镜头沿一条路穿过 11 道关卡，每道关卡要等它的"证据块"嵌进去才亮起金灯，最后抵达一条由 13 格画面组成、亮着的胶片。

**核心画面（缩略图）。** 一条石膏小路上立着 11 座拱门，灯一座接一座亮成金色；路的尽头悬着一条 13 格的发光胶片，每格里是你的复刻画面。

**画风。** 三维石膏模型，用 three.js 做真三维。建筑师的比例模型，蓝调时刻：
- 材质是没上釉的石膏，缝隙里有环境光遮蔽；
- 远处有薄雾，**镜头始终待在模型内部**，不拍模型边缘；
- 零件用"分解图"逻辑：按层抬起、沿法线推出，在镜头到达前一刻就位锁定，锁定时灯闪一下。

配色：

| 用途 | 颜色 |
| --- | --- |
| 石膏 | `#E9E4DA` |
| 暗部（深靛，不用纯黑） | `#1C2436` |
| 天空 | `#2B3A55` 渐变到 `#0F1626` |
| 金色泛光和"已放行" | `#F2B45A` |
| 窗光 | `#FFCF7A` |
| 数据线和证据（取自原片的青蓝） | `#3FB7B0` |
| "未放行" | 冷灰，不打光 |

**声音。** 用代码合成，120 BPM（每拍 0.5 秒，每小节 2 秒）：
- 底鼓打在每小节的第一拍，低音持续推进，拨弦琶音；章节转折前有上升音；
- 零件锁定时一声陶瓷轻碰，关卡放行时一声钟音，数字跳动时有细小的滴答，镜头大幅移动时一声呼啸；
- 开场带一点雨声，呼应原片；
- **所有画面变化都落在拍点上**，关卡放行落在小节的第一拍。

**真实画面。** 只用你的复刻片截帧（13 格），作为发光面板嵌在模型里。原片镜头用石膏浮雕加线稿示意重绘，**不出现原剧画面**。

**画面文字。** 只用中文，思源黑体（Noto Sans SC）。标题 68 px，正文 42 px，位置固定在画面下方三分之一，全片不跳动。数字用等宽排版。

**开场。** 第 0 帧就有运动：金光、飞散的零件、13 块亮着的面板。0.5 秒时第一拍落下，零件锁定。不从黑场淡入。

**结尾。** 落在核心画面上：11 盏金灯加那条胶片，然后渐隐到黑。

**画幅。** 16:9，1920×1080，30 fps。文字块固定在画面下方三分之一，左右各留 120 px。

## 风险和检查办法

- **3 分钟里每 2 秒一次卡点，可能太密。** 每一拍只放一个意思，文字每 4 小节才换一次。先做开场加第 1 关，按成片标准做完、出 MP4，给你看节奏后再铺开。
- **石膏世界里的图表读不清。** 图表的柱子是三维石膏加金色顶面，数字标签用二维文字叠在最上层，保证清晰。每张图表都出一张 1:1 全尺寸截图核对数值。
- **中文字体没加载好就开始截帧。** 确认字体加载完成后才截帧，并逐帧检查文字没有和移动的物体相撞。
- **渲染耗时。** 共 5400 帧，用多个无界面 Chrome 并行渲染，最终按每像素 2×2 采样再缩小输出。
- **声音。** 我听不到声音，只能用响度表检查（峰值低于 1.0，各段响度约 −17 dBFS），混音好不好听需要你来判断。

## 制作方式

1. 先写制作圣经：世界规则、配色、模块接口。
2. 并行做几套可复用部件：石膏世界（路、拱门、分解与锁定）、胶片和面板、图表、文字、配乐。
3. 按成片标准做完开场，出 MP4 给你看。
4. 你认可后，各场景并行制作。
5. 合成，逐帧复审，渲染出片。

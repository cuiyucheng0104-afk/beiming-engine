# 制作圣经：《每一关都有证据》（Hypit 复刻管线讲解片）

导演方案见 `../film/FILM.md`（已由用户批准）。本文件是每个制作 agent 的契约，必须遵守。

## 1. 全片
- 1920×1080，30 fps，180 s；120 BPM：每拍 0.5 s，每小节 2 s。**所有画面变化落在拍点上**，段落重拍落在小节第一拍。
- 画风：**三维石膏建筑模型，蓝调时刻**（three.js 0.186.1，已打包为 `film/vendor/three-0.186.1.iife.js`，全局 `THREE`，含 EffectComposer、RoundedBoxGeometry 等）。
  - 没上釉的哑光石膏（`F.mat.plaster` 等），远景有雾，**镜头永远待在模型里面，不拍到模型边缘**。
  - 零件按"建筑分解图"逻辑运动：按层抬起、沿法线推出、轻微翻转（±0.35 rad），在镜头看到前一刻锁定就位，锁定时闪一下光。**不要随机乱飞的碎石效果。**
  - 克制：每帧元素少，留白也是设计；动作是结果，不是装饰。
- 配色（`F.C`）：石膏 `#E9E4DA`、石膏阴影 `#C9C2B6`、暗部深靛 `#1C2436`（不用纯黑）、天空 `#0F1626 → #2B3A55`、**金 `#F2B45A` = 已放行 / 确定 / 结构**、窗光 `#FFCF7A`、**青蓝 `#3FB7B0` = 证据、数据、实测**、冷灰 `#8C96A6` = 未放行、红 `#D9695F` 只用于"错位/不对"的标记（少用）。
- 真实画面：**只用用户的复刻片截帧**（`F.images[0..12]`：13 个镜头各一帧，640×320；`F.seqImages`：8.3 s 复刻片 15 fps 共 125 帧，`F.seqTexture(u)` 给出 u 秒处的 CanvasTexture）。原片镜头只能用石膏浮雕 / 线稿示意，**绝不出现原剧画面**。
- 文字：只用中文（`PingFang SC`），通过 `F.bake/F.label/F.drawText` 画在 2D 叠层上；数字可用 `mono:true`。字幕块由核心统一画在下三分之一（y≈870–970），**场景自己的 2D 标签不要进入 y>800 的区域**，也不要压住字幕块。标签字号：主数字 44–72 px，说明 24–30 px。

## 2. 技术契约（违反即返工）
- 页面从 `file://` 打开，所以只用经典脚本（不要 ES module / import）。所有代码挂在全局 `F`（见 `film/core.js`、`film/kit-road.js`）。
- 每个场景文件是一个 IIFE，调用 `F.addScene({ id, t0, t1, captions, build(), seek(tl, t), overlay?(g, tl, t), bloom?(tl,t), exposure?(tl,t) })`：
  - `build()` 只调用一次：`const scene = new THREE.Scene(); F.makeEnv(scene, {...}); ... return { scene, camera }`。在这里用 `F.ev(绝对时间, 类型, 参数)` 登记声音事件。
  - `seek(tl, t)`：tl = t − t0。**每一帧的全部状态只由 t 决定**：不要 `Math.random()`（用 `F.rng(seed)` 在 build 里预生成）、不要帧计数器、不要 `performance.now()`、不要在 seek 里累加状态。
  - `overlay(g, tl, t)`：2D 叠层（g 已按胶片像素坐标，1920×1080）。用 `F.project(camera, [x,y,z])` 把 3D 点投到屏幕。
  - `captions` 用下面第 4 节给的原文，一字不改。
- 工具：`F.block(w,h,d,mat,r)` 圆角石膏块；`F.piece(obj,{d,axis,ang,t0,t1,mode})` + `F.poseAll(list, t)` 分解组装；`F.engrave(text,{w,h,size})` 石膏刻字贴图；`F.glow(hex, intensity)` 发光材质；`F.goldMat()`；`F.keyed / F.mspline / F.easeOut / F.easeIO / F.easeBack / F.smooth / F.env / F.win / F.lerp`；`F.aimCam(cam, pos, look, fov)`；`F.buildStrip()`、`F.buildGate(i)`、`F.buildRoad()`、`F.buildTown()`、`F.frameTexture(i)`。读 `core.js` 和 `kit-road.js` 了解细节。
- 发光：金、青蓝、窗光用 emissive，泛光（bloom 阈值 1.05）会让它们出光晕。别让大面积发光把画面洗白。
- 性能：`seek` 里不要新建几何体和材质（在 build 里建好，seek 只改 transform / uniform / emissiveIntensity / visible）。单帧渲染在 ss=1 下应 < 200 ms。
- 声音事件类型（配乐按这些出声）：`hit` 段落重拍、`lock` 零件锁定（陶瓷轻碰）、`gate` 关卡放行钟音、`tick` 数字跳动、`whoosh` 镜头大动（`{dur}`）、`riser` 转折前上升音（`{dur}`）、`thud` 石膏块落地、`pin` 金属钉、`paper` 纸张展开、`gear` 齿轮咔哒、`crack` 石膏裂、`rain` 雨声（`{dur}`）、`stamp` 盖章。事件时间要落在拍点或画面动作的准确时刻。
- 不要改别人的文件：`core.js`、`kit-road.js`、`index.html`、`scenes/s0-hook.js`、`scenes/s4-gates.js` 归总导演。需要新的共享工具，就写在自己的文件里（以自己的前缀命名，挂在 `F.<前缀>` 下），并在报告里说明。
- **自测不要用 `index.html`**（别人文件写到一半可能报错）：复制一份 `film/test-<你的id>.html`，只加载 vendor、frames.js、data.js、core.js、kit-road.js、（证据模块还要 s4-gates.js）和你自己的文件，最后加 `<script>F.boot()</script>`。然后：
  ```bash
  S=~/.claude/skills/opus-js-animations/scripts
  node $S/stills.mjs film/test-<id>.html --every 1 --sheet --cell 480 --cols 4       # 注意：只看你的时间段，其余时间是别的场景或空
  node $S/stills.mjs film/test-<id>.html --range a:b:0.0333 --sheet                  # 关键时刻逐帧
  node $S/stills.mjs film/test-<id>.html --times 12.3 --crop 200,100,800,500 --sheet # 1:1 细节（数字是否清楚）
  node $S/verify.mjs film/test-<id>.html --times <你时间段里的几个时刻>               # seek 纯函数检查
  ```
  用 `--times` 指定你时间段内的时刻（sheet 的 `--every` 从 0 开始，你的场景之外会显示别的内容）。**每张图都要读**，检查：文字不和运动物体相撞、没有闪白/闪黑帧、数字清楚准确、画面不拥挤、每个节拍落在该落的时间。
- 数据：`window.FILM_DATA`（= `assets/film_data.json`）与 `window.FILM_META`（失误分类统计）。**图表数值必须与数据完全一致，不许为好看改数。**

## 5. 各段画面（导演意图；细节由你设计，但必须表达这个意思）
- **问题 8–24**：一条石膏"时间轨"上，13 块石膏浮雕镜头块（宽度按原片镜头帧数：切点帧 0,27,42,66,88,104,114,128,135,147,161,171,191,249）是原片的结构，块面上只有线稿示意。旁边送进一条长长的发光"生成片"，它身上有它自己的切痕（红色细线），和 13 刀对不上（错位要一眼可见）。第二句字幕时，13 把金色"刀"在原片切点处落下，把生成片确定地切开、各段落进对应的镜头块——结构由代码决定。
- **原理 24–64（每条 8 s = 4 小节）**：
  1. 石膏骨架先搭好（13 个空框按原帧排在时间轨上 + 下方字幕条 + 一条原声波形石膏条），然后光（用户复刻截帧）灌进空框。
  2. 统一时钟：三条不同刻度的石膏尺（24 / 25 / 60 fps 标记）经过一组石膏齿轮，出来都是 30 fps 刻度；13 块依次落在第 0、27、42、66、88、104、114、128、135、147、161、171、191 帧的位置（刻度数字清楚可读），尾端 249。
  3. 金色图钉把一格满意的画面钉住；一道"重建"扫描光扫过整条胶片，其他格闪动重排，被钉住的格纹丝不动；角落计数"付费生成 0 次"。
  4. 一张石膏账单展开：4 行请求（r1 5 秒、r2 4 秒、r3 5 秒、r4 6 秒），单价 ¥0.05/秒（闲时），合计 20 秒 ¥1.00；最后一枚金印盖上（`stamp`）。数值取自 FILM_DATA.ledger 与 market.price。
  5. 一座四层石膏塔：方案（TREATMENT）/ 源码（SVML）/ 配方（Recipe）/ Run。某一层出现裂缝（`crack`），只有这一层滑出、换上新的一层，其他层不动。
- **为什么要关卡 64–72**：69 块石膏碎片落下，按失误类别堆成 9 堆，堆高就是条数（FILM_META.categories：说过头 15、绕开方法 10、先做后问 10、沟通与记录 8、只看像不像 7、副作用没核实 6、凭据与合规 6、等待与上下文 5、范围漂移 2），最高一堆标"说过头 15"。最后一拍，碎片被扫成一块整齐的拱门地基（为下一段关卡道路做过渡）。
- **证据板（第 0–10 关）**：每关的证据画在该关的证据板上及其前方（`F.boardAnchor(i)` 的局部坐标），数据见导演方案第 11 道关卡表和第 6 节。证据板在本地时间 u∈[1, 6.5] 是主角；u=4.0 时青蓝证据块从板上 `emitLocal` 起飞，4.5 锁进拱门。证据画面在 u≈3.5 前要完整出现，读得清。
- **收束 160–176**：从道路上方升起并后拉：11 盏金灯沿路连成一线（复用 `F.buildGate`、`F.buildRoad`、`F.gatePos`，全部已放行），路的尽头竖着那条 13 格胶片（`F.buildStrip`），中央放一块大屏播放复刻片（`F.seqTexture(u)`，从 0 放到 8.3 s）；灯按节拍依次闪一遍。176–179.6 由核心统一渐隐到黑，你的画面在这段保持缓慢运动即可。

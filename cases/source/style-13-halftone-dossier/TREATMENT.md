# 消失的第十三页 · TREATMENT

风格：复古半调案卷（halftone-dossier）。1920×1080，**30 fps**（STYLE.md §5 规定 30 fps 变换、10 fps 线条抖动）。时长 **19.6 s**。无旁白、无字幕，画面文字只用案卷本身的标题、证物签、说明条和印章。

## 1. 三个候选结构

| | 结构 | 好处 | 问题 |
|---|---|---|---|
| A | **按证物编号依次展开**：封面 → 证物 1/2/3 → 证物板连线 → 停顿 → 嫌犯照 → 盖章 | 最贴合分镜给的剧情；"编号证物"是这个媒介的原生招式；节奏可以按"一小节一件证物"锁拍 | 容易变成一张张轮播的 PPT，需要用运镜把证物串成同一块板 |
| B | **倒着查**：先给喜鹊嫌犯照，再回放证物证明它 | 开场钩子强 | 把高潮（嫌犯揭晓）提前用掉了；盖章没有悬念 |
| C | **涂黑报告**：一页被涂黑的报告，黑条一条条揭开 | 很有案卷味 | 偏离总导演给的"证物+证物板+嫌犯照+印章"四个原生招式 |

**选 A**，但做两处改造让它不像轮播：①三件证物钉在**同一块证物板**上，镜头横移经过，前一件证物留在画左，最后一镜猛拉远才看见整块板（证物板是一个连续的世界，而不是三张卡片）；②嫌犯照用"**先大特写网点，再猛拉远**"揭晓：闪光后先看到巨大网点里的"13"和一截黑喙，下一拍才拉出整只喜鹊，再加一个笑点：证物板上的嫌犯剪影是个**戴礼帽的人形**，真凶却是只鸟。

## 2. Logline 与弧线

一本案卷少了第 13 页；三件证物被红线连到同一个嫌犯身上；闪光灯一亮，嫌犯是一只叼着那页纸的喜鹊，"结案"印章砸下，它吓得松了嘴，第 13 页飘落归档。

- 铺垫：封面打字机敲出"第13页失踪案"（页数 12/13 的缺口）。
- 推进：书签（带一个 V 形咬痕）→ 墨水指纹 → 窗台上的黑白羽毛（带一抹喜鹊的蓝绿光泽），逐一钉上。
- 转折：证物板上三根红线拉向"嫌犯？"剪影，网点从画边越挤越密，直到把整个画面吞成深墨色 → 一秒停顿。
- 高潮：闪光 → 嫌犯照 → 音乐抽空 → **"结案"印章**（全片最重一拍）。
- 收尾（呼应开场）：喜鹊"喳"一声松嘴，第 13 页落下，正面朝上露出"13"。

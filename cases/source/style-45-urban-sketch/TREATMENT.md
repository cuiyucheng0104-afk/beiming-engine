# 早餐铺开门 · 钢笔淡彩风格样片 TREATMENT

无旁白、无字幕。1920×1080，24 fps，时长 19.5 s。画面内文字只有：左上角手写日期地点、招牌"早点"、结尾页边手写片名。

## 0. 三个候选结构

1. **一个早晨的顺序（选用）**：笔先画出空街 → 行人和自行车让街"动"起来 → 淡彩一块一块到达 → 停一拍 → 早餐铺成为全片唯一的饱和色。故事、主体、转折都和分镜一致，"线先于色 → 色是事件 → 唯一的有色物"三步刚好是这种风格的完整语法。
2. **倒计时到六点**：页边画一只手写钟，每走一格多画一笔，六点整灯笼亮。节拍清楚，但钟会抢掉主体，画面变成解说图。
3. **同一街角两遍**：先画成纯线稿，翻页后同一个构图上色。翻页好看，但 19 秒放不下两遍，而且"色"的到达会变成一次性切换，不是事件。

选 1：主体（早餐铺）从开场就在画面里，只是一直不给颜色；转折（停顿后的蒸汽和灯笼）就是高潮的原生招式。

## 1. Logline 与弧线

**老街还没睡醒，钢笔把它一笔一笔画出来，颜色只敢淡淡地来；直到早餐铺掀开蒸笼，整张纸上才有了第一块真正的红。**

- 起：空白纸页 + 手写日期，笔把屋檐、电线、晾衣竿画出来（只有线）。
- 承：胡萝卜人踩着拍子走过，一辆自行车叮铃铃穿过画面；天空淡蓝、墙面赭石依次"抵达"，唯独早餐铺依旧只有墨线。
- 转：全片静止 1 秒（连环境声一起抽空）。
- 合：蒸笼盖掀开，白汽升起，两盏灯笼由中心晕开饱和的红；镜头推到招牌"早点"，再滑进页边留白，手写片名，收。

## 8. 实现备注（制作后补）

- 时间源：`timeline.js`（`tools/dump.mjs` 导出 `out/timeline.json`），画面 `film.js`、静态纸页 `world.js`、配乐 `music/score.py`、拟音与混音 `mix.py` 全部读同一组拍点；`tools/cuecheck.mjs` 核对 23 个命名拍点 + 21 个脚步：画面事件、帧网格、配乐起音、笔画起笔，最大偏差 0.0 ms。
- 颜色到达场按区域分别计时（天空/墙/地面/屋顶/铺子），源时间比拍点晚 0.22 s，抵消着色器湿边的时间抖动，保证颜色不会抢在拍子前出现。
- 车铃：没有现成的自行车铃录音，用 D7 调的穹顶铃合成（三连击）叠一层 VCSL 钟琴真实采样。
- 与风格库演示片对照：结构（线→人→淡彩→静默→唯一饱和色）、开场（空页写日期）、招牌镜头（蒸笼盖冲击推）、运镜路线、结尾（近景滑入页边而非整页拉远）五项不同；配乐同属爵士华尔兹家族、同有一小节真静音（用户硬性要求）。

## 9. 返修记录（第二轮）

- 湿边：着色器里的前沿积色加上限（最多 1.15 倍），深色本地色只给一半；前沿宽度收到约 0.12 s；去掉细碎的斑点抖动，避免半显色的深色门窗像泥渍。
- 高潮：铺子木色推迟到 B1.2（13.833 s）之后，速度加倍，前沿抖动收为 0.35 倍，13.0–13.83 s 只有左灯笼的红。
- 车铃：三道同心墨线弧，屏幕上 60–90 px，0.15 s 内画出、0.4 s 内从尾端擦掉，弧后垫一圈纸色留白光晕。
- 8.0–9.3 s：弹簧跟拍的目标加软上限，不再拍到页边外的空白；升镜从 A5.1（8.000 s）开始，自行车从画面下缘离开。
- 开场：初始缩放加大约 15%，日期落在左上 1/3；日期提前两帧起笔，第 0 帧就有"十"字。
- 15.5 s：下拍那一帧招牌红边积色"啪"地出现（随后 3 帧铺满），同帧一次 1.4% 的轻推镜重音（呼应 13.0 的冲击推），蒸笼第二口气同拍，配轻蒸汽声和湿笔声。

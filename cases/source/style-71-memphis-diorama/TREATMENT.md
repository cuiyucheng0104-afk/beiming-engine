# 冰淇淋车 · TREATMENT

风格：孟菲斯微缩景观（memphis-diorama）。1920×1080，**60 fps**（STYLE.md §5 规定），时长 19.25 s（38.5 拍，BPM 120）。
无旁白、无字幕。画面内文字只有：画框下三行字（标题 / 一句话 / 小数据）与 callout 气泡。

## 0. 三个候选结构

1. **一镜流水线**：一个长镜头从广场一路推进车里，跟着一支甜筒走完流程，最后拉出。——优点是 STYLE 偏爱长镜；缺点是"广场一起跳"的群体动作没有位置，高潮不够炸。
2. **前后对比**：同一锁定三分之四机位，车来前的安静广场 / 车来后满场狂欢，中间用波浪换态。——对比清楚，但剖面看不到，也没有"巨大冰淇淋"的尺度跳变。
3. **因果链（选定）**：车一停（蹲-弹）→ 波浪带动整个广场跟着节拍蹲-弹 → 剖开车厢看清做法 → **整首曲子停下，车慢慢蹲紧** → 巨型冰淇淋从车顶弹出 → 标注"今日限定"，画框收回。
   选它的理由：三个原生招式（Squash and spring → Wave → Cutaway → Callout）串成一条"这导致那"的链，静默放在剖面与弹出之间，静默后第一声＝巨型冰淇淋弹出的那一声；节奏有两次明确变速（静默减速、弹出后加倍密度加速）。

## 1. Logline 与弧线

一辆冰淇淋车开进孟菲斯小广场，车一停，整座广场就跟着它的音乐跳起来；剖开车厢看完奶油、甜筒、撒糖三步，全场屏住呼吸——一支巨大的冰淇淋从车顶弹了出来。

- 起：安静的广场，画框长开，车哼着八音盒小调开进来。
- 承：车停，蹲一下弹起，乐队进来，波浪从车下扩散，树、长椅、路灯逐个在拍点上蹲-弹。
- 转：侧板抬起滑开，剖面里一条小流水线；做完，侧板合上——音乐戛然而止。
- 合：车身慢慢蹲紧（蓄力），砰！巨型冰淇淋弹出、晃三下，"今日限定"气泡弹出，画框收成一个圆窗。

## 4. Cue map

- **BPM = 120**（分镜给 116；取 120 是为了 60 fps 下一拍正好 30 帧、八分音符 15 帧，拍点与帧零误差）；4/4，一小节 2 s。
- 乐队第 1 小节下拍 = b6（3.0 s）。小节线 b6、b10、b14、b18、b22、b26、b30、b34。
- 调性：E Dorian funk vamp（Em9 ↔ A13），B 段末转 Cmaj9 → B7sus4 → B7（不解决，悬在静默里）→ b30 回到 Em9 炸开 → 收尾 Cmaj9 → D6/9 → **E6/9**（♭VI–♭VII–I，最后一下转大调变亮）。
- 主题动机：车上八音盒的原创叫卖小调（E5 · G5 B5 A5 · F#5 · | G5 F#5 E5 D5 E5）。它的最后一个 E5 正好落在 b6 乐队进来的下拍；A 段由马林巴接过；C 段用 16 分音符**加倍速度**重奏（加速）；结尾八音盒用 E 大调变体再奏一次（首尾呼应）。

| 段落 | 拍 | 时间 | 乐器 | 事件（全部落在拍上） |
|---|---|---|---|---|
| Intro | b0–b6 | 0–3.0 | 车顶小喇叭里的八音盒（pluck.py 物理建模，带通"喇叭"音色，声像跟车）+ 环境 | b0 画框长开；b4 刹车；b5–b6 手拍 16 分过门 + bass 从 E1 滑上 E2；**b6 刹停点头＝全乐队进** |
| A 波浪律动 | b6–b14 | 3.0–7.0 | 合成 slap bass、Rhodes（FM）、合成铜管 stab、手拍（采样）、踩镲、沙锤、软底鼓、马林巴主题、钢片琴 | b6 第一圈波浪；道具每个 8 分音符一圈地蹲-弹（调音琶音往上走）；b10 车喇叭 + 第二圈波浪 |
| B 剖面流水线 | b14–b26 | 7.0–13.0 | 减薄：bass + Rhodes + 沙锤 8 分 + 马林巴 16 分琶音（像传送带） | b14 侧板外移；b15 升起；b16/b18/b20/b22 每道工序一个钢片琴和弦音；b24–b26 铜管渐强 + 军鼓滚奏渐强；**b26 一下短促的 B7 + 侧板"咔"＝全曲停** |
| 静默 | b26–b30 | 13.0–15.0 | 只有房间底噪、5 声越来越轻的车身吱呀（b27–b29，8 分音符上）、弹簧收紧的细响 | 喷泉与鸟声也压到零；b29.5–b30 只剩底噪（实测 −57 dBFS） |
| C 弹出（加速） | b30–b34 | 15.0–17.0 | **b30 全片最重要的一声**：低频 thump + 大 boing + pop + 竖琴上行刮奏 + 铜管全奏 + 群手拍 + 镲；之后 16 分踩镲/沙锤、bass 八度跑动、主题加倍速度 | b30 弹出 + 第三圈波浪；b31、b32 回弹；**b32 "今日限定"弹出**（钢片琴 B6 + E7） |
| D 收尾 | b34–b38.5 | 17.0–19.25 | 铜管、Rhodes、竖琴 E 大调上行、八音盒尾句 | b34 Cmaj9；b35 D6/9；**b36 E6/9 收束 + 画框收回**；b38.5 结束 |

拍点核对：`tools/cuecheck.py` 读 events.json（画面）、out/music_onsets.json（配乐音符）和 out/mix.wav（成品音轨），123 个关键画面事件全部落在整数帧与 16 分网格上，16 组"画面—音乐"配对偏差 0.000 ms，静默后第一声在音轨上实测起音偏差 +0.02 ms。

## 5. 逐秒节拍

| 秒 | 画面 | 声音 |
|---|---|---|
| 0–1 | 画框从中心长开，广场露出，喷泉、行人 | 底噪、鸟鸣、喷泉水声；八音盒小调从左边远处进来 |
| 1–2 | 车从左路口开进来，镜头跟着平移 | 发动机突突（声像跟车）、八音盒越来越近 |
| 2–3 | 车减速、蹲、刹停点头 | 刹车吱；手拍过门 + bass 滑音 |
| 3.0 | 车整体蹲-弹，第一圈波浪 | **乐队进**，叫卖小调的 E5 落在下拍 |
| 3–6.25 | 镜头环绕；地面波浪起伏、换成粉黄格；道具逐圈蹲-弹；5.0 第二圈换成蓝绿 | 每圈道具一个调音 boing + 竖琴音，音高随圈数沿和弦往上走；5.0 喇叭"嘟嘟" |
| 6.25–7.75 | 推近车侧，侧板外移、升起 | 门闩 click、气压嘶 |
| 7.75–13 | 横移看流水线：搅拌桶转 → 甜筒接奶油 → 撒糖 → 成品；三个气泡 | 马达嗡嗡、挤奶油"噗叽"、甜筒咔哒、糖针沙沙、callout pop；12–13 铜管与滚奏渐强 |
| 13.0 | 侧板落下 | "咔"＋一下 B7——音乐同时停 |
| 13–15 | 退半步看整辆车，再极慢推近，车身越蹲越低 | 只剩底噪与越来越轻的吱呀，最后 0.25 秒几乎无声 |
| 15.0 | 巨型冰淇淋弹出 | **全片最重要的一声** |
| 15–16.25 | 急拉远升起，冰淇淋回弹两次，糖针雨，第三圈波浪 | 加倍密度的律动，主题加速 |
| 16–19.25 | "今日限定"弹出；18.0 收束和弦，画框收成圆窗 | 叮；Cmaj9 → D6/9 → E6/9；八音盒尾句；纸面轻嘶 |

## 9. 返修记录（审片后第一轮）

- 弹出后 15.03–15.13 s 球顶被画框上沿裁掉 → setCam 在弹出窗口里加"放得下"约束（先升降、不够再拉远），升高量与距离随时间连续变化。
- 母带真峰值 −1.0 dBTP 没有余量 → 弹出那一下的 POP_brass / POP_kick / 低频 thump 各降约 2.4 dB；总线限幅改为 4 倍过采样真峰值限幅，天花板 −1.9 dBTP，mux 的 loudnorm 走线性增益。
- 第 0 帧几乎全是纸色 → 画框长开的半径从 20% 起步。
- b6 车身只占画面高约 1/10 → 跟车段末尾向车靠近，b6 时约 1/5，环绕段前半再退回全景。
- 成片与源码不同源的疑问 → 用 build.sh 从头完整重渲。

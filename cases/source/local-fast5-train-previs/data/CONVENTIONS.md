## 世界坐标（米，右手系，Z 向上）
- X：沿轨道，火车行驶方向为 +X。Y：+Y 是行驶方向左侧。轨道中心线 Y=0，轨面 Z=0。
- 桥：穿式桁架桥（through truss），桥头近端（入口门架/端柱）在 X=0，桥身向 +X 延伸过峡谷。桥是 CG 做的。
- 卡车贴在火车行驶方向**右侧**（−Y），科尔维特在卡车再往右（更负的 Y）的地面上跑。
- 峡谷在轨道右侧（−Y）前方，崖边斜着向桥头收拢；桥旁（X>0、−Y 侧）还有一段地面，科尔维特最后沿桥旁地面往前开。
- 阳光大致从 +Y 侧来，火车影子落在 −Y 侧地面上（S15 可见）。

## 物体尺寸（先验，可被测量推翻）
- 科尔维特（1963 C2 Grand Sport 敞篷）：车长 4.45，车宽 1.77，轴距 2.49，车高约 1.2（含防滚架约 1.3）。
- 客车车厢：银色带蓝条，长约 26（待测），宽约 3.2，车顶高约 4.0（距轨面）。
- 卡车：改装重型卡车，尺寸待测。

## 读点命名（像素点 [u, v]）
- `cv_fw` / `cv_rw`：科尔维特近侧前轮 / 后轮**着地点**；`cv_nose` / `cv_tail`：车头 / 车尾最外点（离地高度约 0.5）；`cv_c`：车身中心（看不到轮子时用）；`cv_w`：科尔维特在画面中的像素宽度（标量，放在 u，v 填 0）。
- `tr_fw` / `tr_rw`：卡车近侧前轮 / 后轮着地点；`tr_c`：卡车车身中心。
- `tj1`, `tj2`, …：火车车厢连接处（车厢间缝）**底部**，按从车头（靠桥一端）到车尾编号，只标画面里能看到的，注明是第几节缝（若不确定就从画面里最靠前的那条记 tj1，并在 notes 写清）。
- `roof_a` / `roof_b`：同一节车厢车顶近侧边缘上相距尽量远的两点；`rail_a` / `rail_b`：近侧钢轨上的两点。
- `portal_base` / `portal_top`：桥头近侧（−Y 侧）端柱的底部 / 顶部。
- `hz_a` / `hz_b`：地平线（远山脚或地平线）上相距尽量远的两点。
- `brian` / `dom`：人物骨盆（坐姿取胯部）。

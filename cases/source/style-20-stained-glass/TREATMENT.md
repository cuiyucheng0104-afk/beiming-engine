# 浴火 · 彩色玻璃窗风格样片 TREATMENT

无旁白、无字幕。1920×1080，24 fps（STYLE.md 未规定帧率），成片 19.17 s（23 拍）。

## 0. 三个候选结构与选择

1. **玫瑰窗当表盘**：一天的阳光绕玫瑰窗走一圈，花瓣按小时逐个亮起，中心圆窗是凤凰；高潮是中心碎裂再被铅条补好。优点：完全贴合"光即时间"，玫瑰窗本身就是钟。
2. **一扇高窄尖窗自下而上**：镜头沿尖窗竖向上摇，凤凰从蛋到火到新生分格排列。优点：成长线清楚；缺点：凤凰在窄格里只能占画面小块，破碎与修补的大动作施展不开。
3. **地面先行**：开场只有石地上的一块彩色光斑，镜头沿光柱上摇找到光源，再在窗上发生浴火与修补，最后回到地面看新的光斑。优点：首尾押韵；缺点：开场 3 秒内没有"光亮起"这个钩子，容易慢。

**选 1，并借 3 的结尾**：开场是黑暗中的玫瑰窗被第一缕光一格格点亮（3 秒内的钩子），高潮在中心圆窗的凤凰上"裂→静→铅补"，结尾回到开场的仰角广角，但窗已燃亮、地面铺满新凤凰的投影。

## 1. Logline 与弧线

- **Logline**：晨光一格格点亮石厅里的玫瑰窗，窗中凤凰在正午前浴火碎裂，铅条沿裂纹生长，把碎片焊成新的羽毛，整扇窗在正午燃亮。
- **起**：黑暗、冷、静，光是唯一会动的东西（光即时间）。
- **承**：凤凰在中心圆窗被照醒，彩色投影落到石地上随太阳移动（玻璃投到石上）。
- **转**：凤凰起火，玻璃开始出现裂纹，越裂越快，一声碎响后彻底无声（玻璃裂开）。
- **合**：静默里第一声钟响，铅条沿裂纹生长、焊点火花一拍一个，碎片滑回成新的羽翼；正午白光，整窗燃亮（铅修补），回到开场机位押韵。

## 5. Cue map

- **速度**：72 BPM 恒定（原分镜 70 BPM，改为 72：1 拍恰好 20 帧，半拍 10 帧、¼ 拍 5 帧，全部视觉事件落在整帧，可做到 0 ms 偏差）。4/4，共 23 拍（5 小节 + 3 拍）。
- **调式**：D 多利亚（暗、古）→ 修补段转 D 大调（利底亚式上行 E–F#–G–A–B–C#–D），终止于 D 大三和弦。
- **段落与配器**
  - A 拍 0–5「晨光」：管风琴脚键 D2 持续；手铃每拍一音（光之音，花瓣亮起）；拍 3 起合唱 pad（numpy 共振峰合成 "oo"）；拍 4 竖琴琶音。
  - B 拍 5–11「凤凰」：管钟 D4 开段；柔音管风琴 D–A 开放五度+平行奥加农；竖琴八分音符；竖笛（recorder）圣咏式短句；拍 8–11 玻璃琴（glass）泛音点缀。
  - C 拍 11–15「浴火」：全奏管风琴 Dm–B♭–C–Dm；定音鼓滚奏渐强；节奏密度 四分→八分→十六分（加速）；每个裂纹点上一记定音鼓重音。
  - 静默 拍 15–17：音乐与混响硬切，只留碎裂本身的玻璃余振。
  - D 拍 17–21「铅补」：拍 17 低管钟 D3（全片最重要的声音）；之后每半拍上行一级（柔音管风琴 + 手铃双重），合唱 pad 随之升起。
  - E 拍 21–23「正午」：D 大三和弦全奏管风琴 + 合唱 + 管钟 D4/A4 + 定音鼓 D，延音到结尾。
- **视觉事件 → 拍点**：花瓣亮起 拍 1/2/3/4/4.5；凤凰显形 拍 5；扑翼 拍 6/7；下摇起 拍 8；光斑滑动 拍 10；上摇回窗/起火 拍 11；裂纹 拍 12/13/13.5/14/14.5/14.75；碎响 拍 15；首焊 拍 17；焊点 拍 17.5/18/18.5/19/19.5/20/20.5；石刻显字 拍 20；燃亮 拍 21。
- 核对：`tools/cuecheck.py` 读 timeline.json 与 events.json，逐一比较视觉事件帧时刻与乐谱音符起点。

## 8. 制作中的调整（相对初稿）

- **光的戏剧**：拂晓冷蓝（太阳 1.9）→ 早晨暖白（2.2）→ **起火时太阳压暗到 1.05、火光升到 4.0**，让"故事光"压过日光 → 碎裂后冷灰 0.3 → 修补中回升 → 拍 21 正午 3.2 并同时抬亮墙面与光柱。
- 预曙光：所有玻璃先以 17% 的冷天光幽暗可见（STYLE："未照亮的玻璃暗而乳白"），开场不是黑屏；blackdetect（pix_th 0.10）0 处。
- 72 BPM 代替 70 BPM：1 拍 = 20 帧，全部视觉 cue 落在整帧；人物 8 fps 步进以"每拍重新起算"的步进时钟实现，动作落点正好在拍上。

## 9. 自检结果

- 时长 19.167 s（460 帧，24 fps，1920×1080）；响度 −14.0 LUFS，真峰 −1.1 dBFS，LRA 5.1。
- 拍点：`tools/statecheck.mjs` 逐帧检查 28 个画面 cue 的"开关变量"，首个生效帧与拍点偏差全部 **0.0 ms**；`tools/cuecheck.py` 网格偏差 0、乐谱音符起点偏差 0；成片音轨谱通量起点 −14…+46 ms（含分析窗偏差与设计上的气流预卷）。
- 静默段（拍 15–17）音乐 −85 dB、整体约 −39 dB，只剩碎裂余振、两三粒碎屑和铁条嘀嗒；拍 17 低管钟+焊声是静默后第一声。
- 联系表（每秒一帧）与关键动作 0.2 s 帧条见 `stills/`。

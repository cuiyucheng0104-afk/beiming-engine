## 1. 三个候选结构

1. **一张底片三次潜入**：地点 → 人 → 时间。信息全，但 19 秒里三次下潜会变成流水账。
2. **前后对照**：先给电报（"四次飞行"），再回到底片找到"第一次"。转折在中段，可是开场没有钩子（电报一上来读不完）。
3. **一次量到底 + 一次对照 + 一次进入（选它）**：灯亮 → 放大镜下负片显影 → 在照片上量出 120 英尺 → 停 → 电报并排放上，只有底片题名里写着"12 秒" → 推进照片，定格。开场就是"黑暗里灯台闪亮"的动作钩子；静默放在对照之前，静默后的第一声就是"12 秒"被点亮；结尾进入照片，与开场的"冷灯台平面"形成平面→纵深的回声。

## 2. Logline 与弧线

电报只说了"四次飞行"；放大镜下，一张玻璃负片自己的题名记着第一次：120 英尺，12 秒。

- 起：冷灯台在暗里闪两下亮起，一块破角玻璃负片躺在上面。
- 承：放大镜落下，镜内负片转正，人类第一次动力飞行在显影前沿里出现；在照片地面上铺一把透视尺，读数冲到 120。
- 转：一切停住（近静默）。电报被并排放上，两张读数卡同时在场——电报只写"四次飞行"，底片题名写"12 seconds"；"12 秒"被点亮。
- 合：放大镜再次落在底片上，镜框长出画面，照片获得纵深，飞机向前漂，定格在"十二秒"。

## 3. 对标（只学语法）

- **对标 A：以静态照片推进为主的档案纪录片**（摇移 + 推进静照的纪录片传统）。学：镜头在静止物件上"呼吸"——慢推、慢摇、停顿给阅读；一张照片只讲一件事。不学：任何具体镜头、配乐、片头字体，不用做旧滤镜。
- **对标 B：视觉调查类影片（在真实影像上做标注）**。学：一屏一条线、一个读数、一个出处；标注从锚点经引线到文字；数字由计数器落定。不学：其版式、配色、字体与声音标识。
- **对标 C：产品微距片**。学：玻璃边缘的透射光、镜头落下的"咔"与金属环的高光。不学：其镜头与音乐。

## 6. Cue map

- **BPM 96**，4/4，一小节 2.5 s；全片 7.9 小节（31.6 拍）。所有时间在 `timeline.js` 中用拍号写，`mix.py` 与 `index.html` 读同一份 `timeline.json`。
- 段落与配器：
  - **A 灯亮（bar 1，b0–b4）**：嗡鸣 100 Hz + 谐波、启动器咔声；单音玻璃（hand chimes）。
  - **B 显影（bar 2–3 上半，b4–b11）**：弓奏颤音琴 Dm(add9) 淡入，玻璃竖琴随前沿上行；大提琴 D3 长音；毛毡钢琴（Salamander 低力度 + 低通）稀疏单音。
  - **C 测量（b11–b17）**：拨弦音阶 8 分 → 16 分 → 32 分，每个刻度一音：主线是 `core/audio/pluck.py` 的竖琴波导合成（越密衰减越短、越亮），采样拨弦压在下面给琴体；刻度"嘀"与之同起音；小提琴颤弓渐强；b16 落点。
  - **静默（b17.75–b20）**：只剩 −55 dBFS 室内底噪。
  - **D 对照（b20–b25）**：D 大调九和弦（玻璃 + 手钟 + 低音），随后电报音响器按莫尔斯"1""2"（·−−−− ··−−−，1 单位 = 16 分音符）敲出节奏，拨弦低音（`pluck.py` 立式贝斯波导，b21–b24 每拍一音，b22.5/b24.5 弱拍回应长划）跟随；毛毡钢琴动机 D–A–F#–E。
  - **E 进入（b25–b31.2）**：减速：长音弦乐 + 弓奏颤音琴 D 大调，风声；无打击。
- 视觉事件 → 拍点（核对脚本 `cuecheck.py` 输出偏差，目标 0 ms）：flicker b0/b0.5/b1；tag b3；loupe_land b4；develop_done b8；ruler b11；ticks b12–b16；bracket b13；count_land b16；loupe_lift b17；glide_end b18；light12 b20；cardB b20.5；underline b21.5；cardsOut b25；loupe_land2 b26；enter/title b28。

## 9. 返修记录（第 2 轮，按审片意见）

1. **升镜阶段标注越界**：镜内标注改走照片的前向映射——`int2s` 反解着色器的桶形畸变（q = dl/(1+k·ρ²)），刻度与"离地"卡尺在 b16.25 起镜圈回弯时仍贴在地面上；"飞行距离 120 英尺"读数卡改为挂在镜片上（随镜圈缩放、平移），并被镜圈圆形裁切，在 b16.25 起 0.3 s 内淡出。
2. **卡片擦出时与物件脱开**：两张读数卡、引线和锚点在 b25 之后跟着相机的世界→屏幕变换一起滑走（与底片、电报同一变换）；擦出缩短到 0.3 s（半拍内），引线随卡片收回锚点，橙色边条同步淡出。
3. **拨弦改用 pluck.py**：刻度加速段（b12–b16）的音阶以 `pluck.py` 竖琴波导为主、采样拨弦为底；对照段（b21–b24.5）的拨弦低音整段换成 `pluck.py` 立式贝斯。
4. **卡 B 裁切图看不清**：`tools/prep.py` 为电报那一行单独出 `tex/crop_tg.jpg`，做黑白场拉伸（灰度 131–180 → 全幅，正像轻度定标，不加滤镜感）；两张卡的引号原句放大到 30 px。
5. **结尾标题对比弱**："十二秒"与日期移到机翼上方的亮天空（左上），墨字压在浅灰空气上；字后加一层很淡的椭圆局部提亮，保证在风沙纹理上始终可读。

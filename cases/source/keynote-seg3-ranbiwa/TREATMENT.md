# 片段三「燃比娃与揭晓」TREATMENT

方案 A《展卷》样片段之三。对应原稿 A11–A13。**35.000 s，1920×1080，30 fps，96 BPM（拍长 0.625 s），56 拍 = 14 小节。无旁白、无字幕条。**
风格语法：纸雕灯影（paper-lantern）做 A11–A12 的灯箱，纸片立体书（paper-popup）做 A13 的真实桌面与纸门，中国水墨（ink-wash）的宣纸、留白、手卷平移作为贯穿三者的底子。三者统一在"一张宣纸手卷"里：灯箱是裱在手卷上的，手卷是印在立体书上的。

---

## 0. 结构的三个候选与选择

总导演已定稿结构（灯箱新作 → 静默后燃比娃 → 拉远揭晓），本段的候选是在这个结构里**揭晓怎么做**：

1. **正交平移 → 推拉变焦式拉远（选定）**：A11–A12 的镜头其实是一台极长焦（视场 2°）的透视相机，正对书页俯拍，等于正交；A13 时视场从 2° 平滑开到 30°、同时相机后退并抬起到 52° 俯角。画面里纸面先只是"缩小"，随后透视慢慢出现、书页边缘、书脊、桌面、台灯依次入画。整个过程是同一台相机的连续运动，没有任何切换。
2. 焦点转移揭晓：先对焦画面，再把焦点拉到前景台灯，画面糊开后露出桌面。好处是简单，缺点是"拉远"的尺度感弱，揭晓变成模糊转场，不够硬。
3. 俯拍升起：相机垂直升高（保持正交），书本在画面中央变小，最后才倾斜。尺度感强，但透视出现得太晚，结尾的三道门会很仓促。

选 1：它让"原来是一页书"和"从平面变成立体"在同一个动作里发生，是本段要给评委记住的技术镜头。

**无穿帮的做法**：A11–A12 渲染的就是书页本身的贴图（同一个 2D 绘制函数，同一张宣纸），相机在 A12 已经锁定在燃比娃灯箱上（不再有视差），所以 A13 第一帧和 A12 最后一帧逐像素一致；整卷手卷在世界里是一个连续坐标系，燃比娃灯箱就印在书的左页上，浪浪山森林灯箱和《中国奇谭2》四窗印在右页上，和前面镜头经过它们时的左右顺序完全一致。

## 1. Logline 与弧线

**一句话**：灯一层层亮起，新作一部部出现；一拍黑与静之后，燃比娃从宣纸后烧出来；台灯一开，原来这一切都印在桌上一本立体书里——翻过一页，三道纸门立起，等你走进来。

- 起：棉布幕的灯熄，黑里亮起纸雕灯箱（中国奇谭、四部短片、浪浪山）。
- 转：全黑全静一拍，燃比娃爆亮——全片最强的一下。
- 合：台灯"嗒"一声开了，声音从画里回到房间里，镜头拉远揭晓立体书，翻页，三道门依次立起，古琴主题落在主音 D。

## 2. 标杆（只学语法）

- **上美影《山水情》**：学留白、古琴的呼吸与"静后一声"。不学其画面、构图、旋律。
- **Lotte Reiniger 的剪影片 / 商业纸雕灯（shadow box）**：学多层卡纸的明度阶梯（后亮前暗）、背光与层间软影。不学任何具体灯的图案。
- **Robert Sabuda 的立体书**：学 V 形折页"从后到前"立起的机械节奏与纸张的硬挺。不学具体纸艺结构与图案。
- **《布达佩斯大饭店》的书本框架叙事**：学"故事原来在一个物件里"的尺度反转节奏。不学其色彩、字体、镜头。

## 3. 美术设定

- **纸**：手卷底纸用 `material/宣纸.png`（与片段一、二同一张纸，底色约 #F2EBDD），燃比娃那张被烧透的纸用 `宣纸_逆光.png`。暗场里纸只被灯箱的溢光照亮；A13 台灯亮起后整张纸回到 #F2EBDD。
- **灯箱**（paper-lantern 语法）：漆黑木框 + 多层切割卡纸，每层一个平色，后层浅而透、前层深而不透；每层上沿暖色亮边、下沿暗带、向后层投软影；背光为暖金色。**中国奇谭 / 中国奇谭2** 一只长灯箱，夜蓝阶梯（#0a1330 → #6a86c2 → #3f5a92 → #0e1532），远山、月、祥云、前景水浪；**浪浪山** 一只灯箱，林绿阶梯（远林青灰 → 中林墨绿 → 前景深草）；**燃比娃** 一只灯箱，红蓝双色背光（取自原图的红盘与蓝底），前景为火舌与云纹剪纸。
- **IP 图片**：全部装在灯箱窗口里（窗口即装裱位），不全屏：鲸鱼 700×394（36% 画宽）、四个短片各 210×210（一组约 47% 画宽）、浪浪山 720×379（37.5%）、燃比娃 760×428（40%）。**原图像素不改**：只做整体亮度（背光强弱）与窗框遮边；显影方式＝背光点亮（灯箱）、宣纸被光烧透（燃比娃）。纸纹叠加不超过 10%。
- **字**：标题＝灯箱前层卡纸上**镂空的字**，光从字里透出（Ma Shan Zheng，竖排）；小字＝前层上的**题签纸条**，背光透过纸条，墨字（Noto Serif SC 500，#5A534A）显为深色。朱红 #BE3A2E 只用在「9」这一个关键数字上（本段没有印章）。
- **A13 房间**（paper-popup 语法）：胡桃木桌面（Poly Haven CC0 木纹贴图，真实俯视纹理；`木桌.png` 是带透视和光斑的照片，做贴图会穿帮，故不用）、藏蓝布面精装书（`书封布面.png`）、书左前方一盏摇臂台灯（Poly Haven CC0 模型，灯泡处放真实聚光、软阴影）、右后方一只茶杯（虚焦），微距景深。三道 V 形折页纸门用同一张宣纸，门楣上墨字题名（Ma Shan Zheng）+ 灰墨小字问题（Noto Serif SC），门楣下是拱形门洞；三门从后到前、由高到低排成隧道，门楣层层露出，像 A11 灯箱的纸层在三维里再现一次。
- **翻页方向**：按中式右翻书的习惯，左页向右翻（与手卷从右往左读一致）。

## 9. 技术方案

- 一个页面，`timeline.js` 是唯一时间源（BPM、拍、每个事件），导出给混音与校验。
- `scroll2d.js`：手卷世界的 2D 绘制，每帧输出两张图：**反照率**（纸在白光下的样子）与**自发光**（背光透过纸的光）。A11–A12 屏幕颜色 = 反照率 × 室内光 + 自发光；A13 在 three.js 里同一公式：页面材质的 map = 反照率、emissiveMap = 自发光，台灯就是真实光源。所以"画里的光"和"房间里的光"是同一个模型里的两项，交接没有跳变。
- `stage3d.js`：three.js r170 + 库里的 `core/three/post.js`（景深、泛光、暗角）。书、页、翻页（多段条带、沿长度积分的弯曲）、三道门（alpha 纸片、切口形状的阴影）、台灯、木桌。
- 相机：始终是一台透视相机，A11–A12 视场 2°、距离约 4 m，正对页面（与正交相同），A13 视场与距离按对数插值。

## 10. 风险与取舍

- 木桌素材是带透视和台灯光斑的照片，贴到桌面上会穿帮：改用 CC0 胡桃木俯视贴图，光照完全交给三维台灯。
- 燃比娃原图分辨率最低（超分后 2200×1240），放在 760 px 宽窗口里，清晰度足够。
- 黑拍里镜头快速左移 1700 px（画面全黑看不见），让燃比娃灯箱能单独占一页；拉远后书页上的左右顺序与前面一致，不穿帮。

## 11. 实现中的决定（制作后补记）

- 题签（小字纸条）不预先摆着，而是从左端"写"出来，0.2 s 写满，写满的那一刻正好在拍上，同时纸条滑出声止于拍上。
- 每个卡点声音在混音时按它自己的起音（峰值 −30 dB 处）对准拍点，而不是按样本第 0 个点，所以起音偏差为 0 ms。
- 燃比娃那一下在母带前做了 1.6 s 的软饱和，让它在真峰值受限的情况下仍比其余最响处高 3 dB 以上。
- b24 的黑拍里镜头左移 1700 px 到燃比娃灯箱；那一拍整条总线是数字零。

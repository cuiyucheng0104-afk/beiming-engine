# 风车的一天 · TREATMENT（低多边形等距 lowpoly-island）

无旁白、无字幕；画面内文字只有片尾标题「风车的一天」（瓦片式从水线下逐字升起）。1920×1080 / 24 fps / 19.75 s / −14 LUFS。

## 0. 三个候选结构

1. **一镜到底的时钟**：一个固定机位，太阳横扫一圈，岛上一切按光变化，最后灯亮。优点是纯粹；缺点是只有一种运镜，15 秒里节奏单一，撑不起"表现力拉满"。
2. **拼装→点亮**：先一块块长出小岛（Townscaper 式），再入夜点灯。缺点：生长是这个风格的套路（也是演示片的主线），会和演示片撞车，而且冲淡了分镜指定的"光作时钟"。
3. **转台上的一天（选用）**：小岛一开始就完整存在，主角是风车；镜头像转台一样绕岛，太阳同时反向扫过——相机与光两种旋转叠加，阴影在画面里明显"走针"；转到黄昏骤停、风停、音乐归零；入夜后窗户的自发光方块一个接一个亮起（每扇窗一个音），屏息一拍，风车顶的灯亮起，风回来，叶片重新转动，镜头从灯拉开到满天星。
   选它的理由：完全保留分镜的故事与三个原生招式（Turntable / Light as clock / Emissive blocks in the dark），开场、高潮、结尾都由"风车"这个主体决定，与演示片（空海生岛）结构不同。

## 1. Logline 与弧线

**Logline**：一座小岛上的风车，从第一缕晨光转到黄昏停下；夜里，全岛的窗一扇扇亮起，最后风车自己点亮了顶上的灯，风又吹了起来。

- 开端：晨光打到叶片，风车开始转（钩子：第 0 秒第一个音 + 光 + 动作）。
- 转折：黄昏风停，一切静止 1.25 秒（全片唯一的数字静默）。
- 结局：窗灯接力 → 屏息 → 风车顶灯亮 = 全片最重要的一声；叶片复转，与开头的"开始转"呼应；镜头拉到星空，标题升起。

## 7. 标题设计

「风车的一天」Noto Sans SC Light（OFL，&text= 子集化），宽字距，暖白 + 深蓝柔影；位于星空上方三分之一；每字从一条细水线下升起（三次缓动 + 阻尼正弦过冲），破水时一圈小涟漪。旁边一枚小平面六角瓦片图标，顶色随时间变化（入夜为暖黄发光）。

## 9. 返修记录（审片后一轮）

- 入夜段（10.25–11.25 s）：11.0 s 关键帧加月光蓝半球补光（天色 #97a2e2、强度 .66→.98），地平线提亮，剪影在第一扇窗亮起前就可读。
- 夜色配色：所有平面着色材质随 night 向月光蓝紫混合（按亮度保持，亮/中性的沙、岩、白墙混 78%，饱和色混 45%，亮度 ×0.66），窗灯与顶灯成为夜里唯一的暖色亮点。
- 转台段：加一次不切镜的景别呼吸（正午推近到中全景），打破 7.5 s 同景别。
- 屏息段：推镜不再死停，留 0.6 s 减速余推；窗灯轻微烛火呼吸。静默与拍点不变。
- 结尾：视锥终点 20→16，构图上移靠近标题。
- 所有改动不触碰时间网格与事件，拍点核对仍为 0 ms。

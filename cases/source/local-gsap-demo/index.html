GSAP · Stagger 与 Ease 手感演示

点击每块的按钮即可回放。这些正是你笔记里的代码片段，跑起来看时序。

① 数字 stagger — 每个元素错开 0.1 秒

gsap.to(".item", { y: -20, stagger: 0.1 });

② 对象 stagger — from: "center"

amount 把总时长在所有元素间分摊 · 从中间向两侧扩散 
gsap.to(".item", { y: -20, stagger: { amount: 0.3, from: "center" } });

③ Ease 手感对比

同一段 1 秒平移，不同 ease 的加减速曲线。点击单块可单独回放。

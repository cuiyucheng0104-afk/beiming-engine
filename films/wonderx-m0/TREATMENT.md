# 《告别幻灯片 · 万物有戏》M0

A 路线复用 toon、墨线、纸纹和 WebGL2 后期。十二幕共 8640 帧，演示时间 6 分钟。M0 实现第八幕连续推拉、第九幕实例压力段和第十幕分屏操作，其余幕供演讲者切章和试提词。现有纸雕输入只用于技术测量，后续视觉参考由创作线确定。

## 本地构建

首次准备环境后，从仓库根目录执行以下命令。字体下载需要网络，构建后的 HTML 可以断网双击。

```sh
npm ci
npm run setup
npm run standalone:fonts
node tools/env/py.mjs films/wonderx-m0/plates/make_plates.py
npm run standalone:build -- films/wonderx-m0
```

产物为 `out/standalone/index.html`，资源内联开销列在 `out/standalone-size.json`。替换视觉时直接覆盖 `plates/clouds_far.webp`（16:9 远景）、`plates/proscenium.webp`（16:9 透明前景）或 `plates/paper.webp`（方形可平铺灰度纹理），只执行最后的构建命令。样例生成脚本会写出全部三张原型图，应在替换前运行。

## Cue map

| 触发点 | 声音动作 |
|---|---|
| 各章的 in 帧 | 导览启用时触发一次短钟声 |
| 手动播放至目标拍 | 停止画面和三轨循环 |
| 自动播放或从章节入口重启 | 三轨按同一声卡时刻与素材偏移起播 |

## 声音设计

M0 从同一 AudioContext 排程和声、脉冲和主奏三条循环。`S` 打开逐轨 Mute/Solo，`M` 总静音，`V` 独立控制默认关闭的导览轨。各章入口的钟声是导览 cue 的排程样例。正式中文配音、`composer.py` 与 `orchestra.py` 的配乐分轨、A05/B03 的场景拟音属于 Phase 2。三轨循环和 cue 的素材偏移随 seek 重算。

`O` 选幕，左右键走拍，Shift 加左右键切章，空格走到下一拍，`A` 切换自动播放，`F` 切换全屏，`N` 打开独立备注窗，`H` 显示完整键位。画面按绝对时间和输入重绘，录制时可通过 `window.render(t, {pointer, split, tier})` 设置同一帧。手动按 `T` 选档后会锁定画质。

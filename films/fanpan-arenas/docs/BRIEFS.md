## 制作《珊瑚龙宫》场景

你要给一个网页卡牌棋盘游戏《一步翻盘》做一个新的对战盘场景（自定义擂台），做到能在本地游戏里实际对局。只写 `<游戏仓库>/arenas/shan-gong/` 这一个文件夹（入口 `arena.js`，地址参数名是 `sea`）。

**先读**（必须，按顺序）：
1. `docs/CONTRACT.md` —— 接口、坐标、不能动的东西、质量底线、自检工具。里面每一条都要遵守。
2. `<游戏仓库>/arenas/b-shui/arena.js` 和 `arenas/c-zhai/arena.js` —— 两个已经做好的场景，学接口怎么用、合批怎么做、细节密度到什么程度。只学做法，**不 import、不照抄它们的贴图画法**；你要有自己的一套画法文件。
3. 用 Read 看两张参考截图 `<截图目录>/b/desktop-high.png`、`<截图目录>/c/desktop-high.png`：你的成品要达到同样的精细度，但主题、配色、组件完全不同。

### 你的场景：《珊瑚龙宫》（海底）

擂台沉在海底的一座珊瑚宫殿前庭。HD-2D 风格：像素贴图的 3D 微缩场景 + 移轴景深 + 强光影和泛光。

- **色调**：深青、群青做底（暗部往蓝紫偏），珊瑚粉 / 橙、珍珠白做亮色，青色和品红的生物荧光做点缀。饱和度要高。远处被海水的蓝青色雾吞掉。
- **光**：主光从正上方偏后的水面漏下来，冷的青白色；水面波纹在海床上投出晃动的光纹（焦散：可以用一张会流动的叠加贴图铺在盘外的海床上，盘面上要很淡，别干扰棋子）；几道从上往下的光柱。暖色来自珊瑚和珍珠灯的自发光，冷暖对比要明确。
- **盘面**：螺钿 / 贝母拼的方砖，深色（比棋子暗、素），缝是深蓝；本方出兵列偏青、对面出兵列偏红。盘四周一圈雕花石沿。
- **本方城堡（青）**：一只张开的巨型砗磲 / 鹦鹉螺壳做的门，里面托着一颗发青光的大珍珠，旁边是珍珠串和青色海葵。**对面城堡（红）**：红珊瑚长成的王座门，或一具巨大的鮟鱇鱼头骨、嘴里吊着一盏红色的诱灯。两座造型不同，不只是换色。
- **独有组件**（尽量多做，几十种小件）：枝状 / 脑状 / 扇形珊瑚丛、会开合的巨蚌、随水摆动的海葵和海带、成串往上冒的气泡、成群游过的小鱼、慢慢漂的发光水母、海星、海胆、贝壳、海螺、藤壶、沉没的断柱和石像、后景一艘沉船的剪影、藏宝箱和散落的金币、珍珠灯、远处缓缓游过的蝠鲼或海龟剪影、船锚和锁链、陶罐。
- **会动的东西**（至少 8 种）：光纹流动、光柱明灭、气泡上升、鱼群游动、水母漂浮并脉动、海带海葵摆动、巨蚌开合、珍珠灯明灭、浮游的发光微粒、远景的大鱼剪影游过。
- **三层景深**：贴镜头的前景是海带和珊瑚的暗色剪影（压在画面角上）；中间是棋盘和两座城堡；后景是宫殿残墙、沉船、珊瑚林，越远越蓝越淡。
- 不要做成和 `b-shui`（水上遗迹：莲叶、瀑布、灯笼、霜 / 焰祠）相似的东西：你这是水下，没有水面、没有莲叶、没有瀑布、没有火。

### 纪律

- 只写 `arenas/shan-gong/` 里的文件。不改 `board3d.js` 或任何别的文件，不 git 提交 / 推送，不起也不停 8770 端口的服务，不再派子代理。
- 代码注释用中文（和仓库一致），写清楚每块是干什么的。
- 用 `node films/fanpan-arenas/tools/shot.mjs sea …` 截图自检（见 CONTRACT），用 Read 看图，自己挑毛病反复改，至少看 6 轮。重点盯：有没有空的大色块、棋子是否最醒目、血量牌是否清楚、两座城堡是否一眼分得出敌我、手机横屏下是否正常。
- 交回内容按 CONTRACT 最后一节写：文件清单、五条自检命令的结果（stats 和报错）、你自己认为还不够好的地方（如实）。

### 你的场景：《云上浮岛》（高空，黄金时刻）

擂台在一座飘在云海之上的浮空岛顶上。这是五个新场景里唯一的白天、开阔的场景，要有通透的高空感。HD-2D 风格：像素贴图的 3D 微缩场景 + 移轴景深 + 强光影和泛光。

- **色调**：天蓝到桃金的天空渐变，雪白带金边的云，草绿，赤陶色的屋顶，白石和黄铜，浮石水晶的青色辉光。饱和度要高、明快。
- **光**：低角度的金色夕阳从左后方打来，长长的投影，所有东西朝阳的一面镶金边；天光补蓝色的暗部（暗部要明确偏蓝，不要发灰）。有云的影子在岛上缓缓移过（可以用一片只投影的、缓慢移动的镂空板）。注意：虽然是白天，**盘面本身仍然要比棋子暗、素**（用深石板蓝的石砖，或让盘面处在柔和的阴影里），棋子必须是最醒目的。

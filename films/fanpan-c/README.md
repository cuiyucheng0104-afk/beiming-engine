# 林间寨擂（C 版 · 北冥代码动画风格 · 86 式）

《一步翻盘》对战盘的风格样张：4 路 × 5 格的石板擂台摆在林间寨子里，两头是挂着图腾和晶石的寨门，像素棋子站在打了光的立体微缩景中。6 秒循环（144 帧，24 fps，1920×1080），没有声音。

[B 版](../fanpan-b/README.md)是另一个场面（沉水遗迹），两版**不共用任何代码和素材**：各自的像素画工具、贴图、小件、调度、棋子阵容都是分开写的。

这一版后来搬进了游戏的渲染器，成了游戏里可以对局的场景 `?arena=c`，源码和另外六套一起在 [fanpan-arenas](../fanpan-arenas/README.md)。

状态：只出了风格关键帧，look、animatic、final 三道闸都没有用户认可。

## 画法

画法参考 `cases/vendor/lemo-opuscar/styles/hd-2d/STYLE.md`（MIT，LemoLab），只取方法，代码自己写。用户给的四张样图是美术参考（不是游戏里的真实场景），从里面量出来的是景深和光影方案，不是内容：

- 角色和小物件是平的像素卡片，逐帧跳着动（每秒 10 帧）；镜头、灯火、飘浮物连续滑动
- 贴图全部用代码逐像素画，全场同一个像素密度（每米 40 像素，棋子的一个像素和石板的一个像素一样大），每种材料 6 级色阶，交界处用 4×4 抖动
- 光：暗而偏青的环境光，一束穿过树冠的金色斜阳（只在擂台上留一个完整的光池，四周是碎光斑），暖橙色的火和灯，两颗阵营色晶石
- 景深按样图量：画面高度 25%–58% 是清楚的一带（擂台和棋子全在里面），往上只略微发软，往下越来越虚
- 棋子的显眼度：贴身一圈深色描边再加一圈阵营色，脚下有阵营色的圈和战力牌，棋子自带一点自发光，背阴里也不会沉下去
- 后期顺序：2 倍超采样 → 景深 → 泛光 → 暗角与调色 → 胶片曲线

## 文件

| 文件 | 管什么 |
|---|---|
| `stage.js` | 场面调度：棋盘尺寸、谁站哪一格、镜头、光的方向。只有数字 |
| `pix.js` | 像素画工具：色阶表、画布、抖动、基本形、描边 |
| `tex.js` | 全部贴图与小物件的像素画（砌石、树皮、竹、木板、茅草、布、陶罐、蘑菇、蕨、灯笼、牌子……） |
| `scene.js` | 场景本体：擂台、两座寨门、竹栅、茅屋、树、灯和满地的小物件 |
| `film.js` | 这一版的渲染：光、棋子卡片、交手特效、光柱、飘浮物、后期。调画面改开头的 `LOOK` |
| `main.js`、`index.html` | 页面入口 |
| `units/` | 十条棋子待机序列帧（CC0，来自游戏仓库 `assets/units`，敌方已左右翻转） |
| `tools/` | 制作过程里用的脚本，不参与出图：`analyze.py`、`dof.py` 量样图（逐行清晰度、明暗、饱和度、色相、暗角，以及换算成等效模糊半径），`measure1.py` 用同一套量法量自己的出图，`prep.py` 从游戏仓库取棋子并翻转敌方，`unit-sheet.py` 拼候选棋子目录图，`baseline-shot.mjs` 截游戏现在的对战盘，`compare.py` 拼带说明的四格对比图。用法写在各文件开头；用户给的四张样图不在仓库里 |

## 出图

在仓库根目录：

```sh
node engine/render/still.mjs films/fanpan-c 0 3 5.96 --size 1920x1080 --out films/fanpan-c/out/stills
```

调试时在页面地址后加 `?dof=0`、`?bloom=0`、`?grade=0` 可以关掉某一步后期。

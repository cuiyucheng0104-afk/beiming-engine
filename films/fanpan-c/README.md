# 林间擂台（C 版 · 北冥代码动画风格 · 86 式）

《一步翻盘》对战盘的风格样张：4 路 × 5 格的石板擂台摆在林间空地里，像素棋子站在打了光的立体微缩景中。6 秒循环（144 帧，24 fps，1920×1080），没有声音。同一个场面的 B 版在 [../fanpan-b](../fanpan-b/README.md)。

状态：只出了风格关键帧，look、animatic、final 三道闸都没有用户认可。

## 画法

画法参考 `cases/vendor/lemo-opuscar/styles/hd-2d/STYLE.md`（MIT，LemoLab），只取方法，代码自己写：

- 角色是平的像素卡片，逐帧跳着动（每秒 10 帧）；镜头、灯火、浮尘连续滑动
- 场景贴图全部用代码逐像素画，全场同一个像素密度（每米 40 像素），每种材料 5–6 级色阶
- 光：暗而冷的环境光，从树冠缝里漏下来的暖色斜阳（有影子），13 盏暖色小灯
- 后期顺序：2 倍超采样 → 景深（移轴并进同一个弥散圆）→ 泛光 → 暗角与调色 → 胶片曲线

## 文件

| 文件 | 管什么 |
|---|---|
| `layout.js` | 场面调度：棋盘尺寸、谁站哪一格、灯的位置、太阳、镜头怎么走。只有数字 |
| `px.js` | 像素贴图：砌石、石板、地面、木板、茅草、树叶、旗、血量牌、战力牌、脚下的圈 |
| `diorama.js` | 立体场景：擂台、两座城门、茅屋、树、灌木、灯、杂物。`createDiorama({ part })` 的 `part` 只给 B 版用 |
| `film.js` | 这一版的渲染：光、棋子卡片、光柱、浮尘、后期。调画面改开头的 `LOOK` |
| `main.js`、`index.html` | 页面入口 |
| `units/` | 十条棋子待机序列帧（CC0，来自游戏仓库 `assets/units`，敌方已左右翻转） |

`layout.js`、`px.js`、`diorama.js` 是两版共用的：改了之后把这三份原样拷到 `../fanpan-b/`（那边不能 import 作品目录之外的文件）。

## 出图

在仓库根目录：

```sh
node engine/render/still.mjs films/fanpan-c 0 3 5.96 --size 1920x1080 --out films/fanpan-c/out/stills
```

调试时在页面地址后加 `?dof=0`、`?bloom=0`、`?grade=0` 可以关掉某一步后期。

并排对比图（现在的对战盘 / 风格样图 / C 版 / B 版）：

```sh
node tools/env/py.mjs films/fanpan-c/out/compare.py <B 版静帧 PNG> <样图目录>
```

# 墨烟成字

北冥 A 路线的三组技术对照。第一个镜头比较解析墨晕和上游流体染料对流，第二个比较解析烟团和带涡卷的流体烟尘，第三个比较 CPU 字形点插值和 GPU 点着色。左右使用同样的底图、事件输入和种子。

流体在 192×192 半浮点缓冲区以 24 fps 固定步长推进。同一镜头内连续出片复用状态，向前跳转补算，倒跳或跳到另一个流体镜头从明确初态重放。上游着色器来源和 MIT 许可见源码头和 USE-SHADER-FX-LICENSE.txt。

预览：仓库根目录运行 npm run serve，访问 /films/funtech-fx-ab/。也可用 engine/render/video.mjs 生成 9 秒无声工作预览。

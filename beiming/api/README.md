# 协议

定义对外协议的动词、请求与响应信封以及鉴权。

通过契约与作业组件交接请求及结果。跨组件通过契约交接，引用旧目录须命中白名单。

业务契约：[信封](../kernel/contracts/envelope/CONTRACT.md)（每个动词的返回包装）、[错误码表](../kernel/contracts/errors/CONTRACT.md)（错误码与退出码）、[补丁格式](../kernel/contracts/patch/CONTRACT.md)（对片子描述的修改请求）。

通用约定见[契约目录](../kernel/contracts/)、[契约写法约定](../kernel/contracts/CONVENTIONS.md)和[目录归属契约](../kernel/contracts/ownership/CONTRACT.md)。

# 收获

整理运行或验收中得到的可复用成果。

通过契约接收产物及验收记录，并交接整理后的成果。跨组件通过契约交接，引用旧目录须命中白名单。

业务契约：[卡文件格式](../kernel/contracts/card-file/CONTRACT.md)（成果整理成卡时的字段、来历与验证状态）、[题目文件格式](../kernel/contracts/question-file/CONTRACT.md)（成果沉淀为考题时的格式）。

通用约定见[契约目录](../kernel/contracts/)、[契约写法约定](../kernel/contracts/CONVENTIONS.md)和[目录归属契约](../kernel/contracts/ownership/CONTRACT.md)。

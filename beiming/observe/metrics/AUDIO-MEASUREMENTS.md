# O2 音频量测

从感知组件的 `index.mjs` 导入 `beatOnsetHit`、`pitchF0` 和 `avSameFrame`。三个指标读取已解码的单声道有符号 16 位 PCM，以 `Int16Array` 传入。调用方负责选取正确音轨和记录时间偏移。

## 起音命中

`beatOnsetHit(pcm, { eventFrames, fps, frames, toleranceFrames, jump, minGapMs, audioOffsetMs })` 读取 16 kHz PCM。帧从零起算。时间按成片首帧对齐，`audioOffsetMs` 是音频首样本相对成片首帧的整数毫秒差。局部选段的声音与事件须使用同一时间轴。

指标以事件为单位计算命中率。同帧多条事件分别计数。随机基线是从全片帧区间均匀抽取一帧时的命中概率。重叠的起音容差区只计一次，基线可以重复复算。结果还给出超出基线的幅度、实际命中的事件帧和检测到的起音毫秒数。

## 独唱音高粗估

`pitchF0(pcm, { sampleRate, startSec, endSec })` 要求明确标定独唱时间段。输出有声帧数、基频范围、最近音名计数、绝对音分偏差和偏差在 25 音分以内的比例。静音或置信度不足的帧不会进入音高统计。

量测采用 40 毫秒窗口、20 毫秒步长，按名义 150–450 Hz 的范围取整数滞后。窗口前端与后端按独唱选段限制，相关性所需的短滞后会读取后面的 PCM。为区分基频与倍周期，先在相关峰附近插值对齐 PCM，再比较局部峰的归一化相关度；近等强时取较短周期，频率仍从整数滞后换算。基频远弱于谐波时可能仍报高八度，直流偏置、伴奏和合唱也可能产生误读。音分偏差按最近半音计算，乐谱核对需要另外提供目标音符。

## 声画同帧

`avSameFrame(visualCounts, pcm, { samplesPerFrame, segments, visualFraction, audioDropDb })` 将每个视频帧的区域计数和对应 PCM 整窗同步。计数由调用方按区域及像素阈值取得。输入从视频第 0 帧对齐，`segments` 为半开帧区间。

每个区间用各自的中位数判断画面计数跌落和声音变弱。结果给出两类帧、交集、音量峰值帧和同帧命中率。命中率以视觉跌落帧为分母。没有视觉跌落时返回 `null`。

# 剧照对位

`metric:still.match` 从同尺寸的灰度帧中找最接近剧照的一帧，同时给出在指定帧距之外最接近的候选。

```js
const reading = stillMatch(queryGray, candidateFrames, { width: 48, height: 27 });
```

- `queryGray` 是行优先的 `Uint8Array` 或 `Buffer`，每像素一个灰度码值。`candidateFrames` 可以是同类帧的数组，也可以在一个紧密缓冲里按帧连续存放。每帧含 `width * height` 字节，缓冲不带行填充和帧头。接口接收已经按同一口径裁切、缩放并转灰度的帧。
- 逐帧取对应像素绝对差的平均值（MAE），差值相同取更早的帧。`value` 是从 0 开始的最佳帧号。`details.best` 与 `details.runnerUp` 均含 `frame` 和 `meanAbsError`。分离次优帧与最佳帧的帧距须严格大于 `exclusionRadius`，默认 `10`。没有合格候选时 `runnerUp` 为 `null`。
- `maxPan` 接受 `0` 到 `64` 的整数，用于核验附近的整像素平移。`motionZoomPan` 固定缩放为 `1`，在重叠区覆盖至少一半采样点的位移中选候选。采样步长为长边除以 `48` 后向上取整。核验要求重叠区覆盖至少一半帧像素、包含不同灰度值，并且每个重叠像素完全一致。若搜索范围内还有另一个满足半帧重叠、且在同样步长的采样网格上完全一致的位移，位移仍无法确认。
- 核验通过时 `details.offset` 为 `{ dx, dy, meanAbsError: 0 }`，方向从剧照到最佳候选帧，正 `dx` 向右、正 `dy` 向下。省略 `maxPan` 或位移无法确认时，`offset` 为 `null`。压缩、噪声、重复图案或重叠不足都可能使位移无法确认。全帧 MAE 仍用于排名。

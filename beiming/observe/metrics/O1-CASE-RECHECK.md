# O1 参考片实测复算

2026-11-27 在引擎 `121e605e` 上用 Node.js 25.6.0、FFmpeg / ffprobe 8.0.1 复算。样本 A–D 都是案例报告对应的本地原始媒体，逐一核对私有媒体清单的 SHA-256，四个样本均一致。下表的历史读数来自各样本的《量测结果.txt》。

五项指标均已实跑。交付规格、响度、YDIF 切点与选定案例的可比历史读数一致。场景切点未复现历史结果，黑帧／冻结／重复帧仍缺按统一口径记录的历史基准。O1 整体验收待完成。

| 指标与样本 | 历史读数 | 引擎复算 | 对照结果 |
| --- | --- | --- | --- |
| `deliver.spec` · A，第 1 节 | 1920×1080，24/1 fps，852 帧，matrix / transfer / primaries 均为 `bt709`，range 为 `tv` | 八个字段逐一相同，实解码 852 帧 | 精确一致 |
| `audio.loudness` · A、B、D | A −14.6 LUFS、−1.7 dBTP。B −16.2 LUFS、+5.5 dBTP。D −14.0 LUFS、−1.7 dBTP | 第一音轨按 EBU R128 `ebur128=peak=true` 复算，三个样本的两个数逐一相同 | 精确到历史报告的小数后一位 |
| `cut.ydif` · C，第 3 节 | 三个区域各 300 帧，`YDIF > 12` 均报第 105、195 帧 | 三个窗口均报 `[105, 195]`，对应 3.500、6.500 秒 | 帧号精确一致 |

C 的窗口宽 1080、高 608、横坐标 0。历史裁剪在源 `yuv420p` 上请求纵坐标 23、656、1290，首个坐标实际按色度采样对齐到 22。引擎先转 `yuv444p`，显式使用 22、656、1290。原裁剪滤镜重跑后，第 105、195 帧的 YDIF 分别是 22.0065 / 25.7561、37.9303 / 33.8483、46.8552 / 46.5808，四舍五入到一位小数与历史报告相同。D 的历史硬切还要求当前 YDIF 超过相邻帧最大值的三倍并设 0.5 下限。D 上半在引擎的单阈值下得到 64 个候选，历史规则只报 2 个硬切。

`frame.black-freeze-dup` 的引擎默认值是 `blackLevel=32`、`blackPercent=98`、`freezeDiff=0.15`、`freezeFrames=3`、`duplicateDiff=0`。引擎以帧计黑、以连续帧计冻结，并以 Y/U/V 三通道帧差的最大值判冻结与重复。验收仍需用这些定义独立建立参考读数，并覆盖有黑帧、冻结和重复帧的片段。

从 [指标入口](index.mjs) 调用 `deliverSpec(A)`、`audioLoudness(A/B/D)`、`cutYdif(C, 12, { x: 0, y, width: 1080, height: 608 })`、`cutScene(B, threshold)`、`blackFreezeDup(A/D)` 可重跑表中读数。括号中的样本代号对应本地参考媒体路径，阈值和裁剪坐标取上文。合成 MP4 回归可运行 `node --test beiming/observe/metrics/metrics.test.mjs`。

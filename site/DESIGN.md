# 北冥作品站 · 设计说明（DESIGN）

方向：**A「黄昏纸上」**（用户 2026-11-09 选定）。本文件是定稿，实现时按本文执行；要偏离必须在汇报里写明理由。

## 1. 概念：一页从黄昏走到入夜

滚动就是《北冥》里的一天在流逝。四个篇章，各自是一个视觉世界，用同一套字体和墨色连起来：

| 篇章 | 锚点 | 主题（`data-theme`） | 画面 |
|---|---|---|---|
| 黄昏 · 首屏 | `#hero` | `dusk` | 实时渲染的青绿仙山鲲在黄昏天空里游；毛笔“北冥”由引擎的笔顺代码当场写出 |
| 纸上 · 引擎 | `#engine` | `paper` → 进入“景”这一步后天空铺满 | 同一条鲲被拆回素模，随滚动一层层画回去：形 → 光 → 笔 → 景 → 时 |
| 入夜 · 作品 | `#works` | `night` | 79 部作品像一张夜里的接触印样，悬停即播，点开就在原地放映 |
| 星 · 方法 | `#method` + 页脚 | `night`（更深） | 一句制作原则，四条方法，三条路线，许可与链接 |

**场景句：**投资人在会议间隙用笔记本点开链接，室内光，有点累。打开后先看到一片暖色黄昏和一条正在游动的鲲，第一反应是“这是视频吗？”，下一行字告诉他不是。所以首屏用暖亮色，作品区才入夜，让成片在暗底上最亮。

## 2. 色彩（策略：Drenched 首屏 + Committed 墨紫）

全部令牌在 `site/css/tokens.css`，取自影片色板 `src/toon.js` 的 `PALETTE`。不准用 `#000` / `#fff`，所有中性色都带一点紫调。

- 首屏的表面本身就是天空：天顶 `--sky-zenith` → 薰衣草 `--sky-lavender` → 粉 `--sky-pink` → 地平线杏色 `--sky-apricot`。
- 纸面：`--paper` 暖奶油色（带纸纹），正文墨色 `--ink`（就是影片墨线的颜色 `#2A2D52`）。
- 夜：`--night` / `--night-2`，正文 `--mist`。
- 强调色只有一个：**窗灯金 `--lamp`**（影片里城市窗灯的颜色），用于可交互的高亮、当前步骤、播放态。面积不超过 10%。
- 实时数据的小读数用 `--hud`（影片显示层的青），只出现在“实时渲染中”那一行。
- 对比度：正文对底色至少 4.5:1，大字至少 3:1。`tokens.css` 里列了已核对的组合，不要自己调浅。

## 3. 字体：用影片自己的字

| 角色 | 字体 | 用在哪里 |
|---|---|---|
| 毛笔展示字 | **Ma Shan Zheng**（马善政毛笔，OFL） | 只用于 1–4 个字的大字：北冥、九层的单字（形光景笔人界时声片）、篇章名（作品、方法）。元素加 `class="f-brush"`，构建时按页面上实际出现的字子集化 |
| 中文正文 | 系统字体栈（苹方 / 冬青黑 / 微软雅黑 / 思源黑体） | 正文、标题、按钮。不下载中文正文字体 |
| 数字与西文 | **Barlow**（OFL，影片显示层用的就是它） | 数字、时长、编号、英文小标签（全大写仅限 ≤3 个词的标签，字距 0.12em） |

- 字号用 `clamp()` 流式，相邻层级比例 ≥ 1.25（令牌 `--step--1` … `--step-6`）。
- 正文行长 ≤ 36 个汉字（约 `36em` 以内，用 `max-width: 34em` 左右），行高 1.75；深色底上行高再加 0.05。
- 中文不用斜体；强调靠字重和颜色。
- 不用等宽字体装“技术感”。模块路径（如 `engine/form/loft.js`）用 Barlow 小字即可。

## 4. 版式

- 左对齐为主，不做居中堆叠。首屏文字压在左下，鲲占右上大半。
- 栅格：12 栏，外边距 `--gutter`（手机 16px，桌面 clamp 到 64px）。章节之间的留白要有节奏：篇章之间大，篇章内部紧。
- **不要卡片网格**。作品区是“接触印样”：海报 16:9 紧密拼接（间隙 2–4px），左上角 Barlow 编号 01–66，标题写在海报下方。故事片和发布会是横向胶片条。
- 不用侧边色条、渐变文字、玻璃拟态、大数字指标卡、模态框（详见 impeccable 的禁令）。
- 引擎篇章是一段固定（pin）的滚动叙事：左 5 栏是文字面板，右 7 栏是鲲；手机上鲲在上 55vh，文字在下。

## 5. 动效（GSAP 3.15 + ScrollTrigger，必要时 Flip）

总原则：动效只为讲清一件事。缓动用 `expo.out` / `power4.out`，**不用 bounce、elastic**；不动画布局属性（宽高、top/left），只动 transform、opacity、clip-path、CSS 变量和着色器 uniform。

**首屏开场（≤ 1.8 秒）：**

1. 0–0.4s：纸色底上，天空渐变从地平线往上晕开（clip-path 或遮罩）。
2. 0.3–1.5s：“北冥”两个字由 `engine/overlay/brush.js` 按笔顺逐笔写出，带飞白（墨色用 `--ink`，与首屏文字同色：近白字压在薰衣草色天空上只有约 2.7:1，墨色约 4.6:1，也更像题在画上的款）。
3. 1.0s 起：副标题、按钮依次上浮（y 16px → 0，stagger 0.08）。
4. 引擎就绪后：静态海报交叉淡出，实时画面淡入（0.9 秒）。海报就是实时画面 t = 0 的那一帧，构图逐像素一致，看不出跳变；淡完鲲“醒过来”：目光先被引向右上，再转回来看着访客，镜头跟着有一点真实的视差，这是海报做不到的。没就绪就一直显示海报，不出现空白。

**引擎拆层（scrub，pin 约 5 屏）：**

- 进入时先“拆开”：鲲从完整画面（第 4 层）快速退回素模（第 0 层），文字“拆开这条鲲”。
- 然后每一屏画回一层：形 → 光 → 笔 → 景 → 时。层与层之间在着色器里交叉过渡（`setLayer` 收小数），文字面板同步切换（opacity + y）。
- 左侧九字轨（形 光 景 笔 人 界 时 声 片，按引擎原序）随进度点亮；人、界、声、片四层在叙事末尾用一句话交代。
- “时”这一步配一条帧条：1 秒 = 24 格，每 3 格一个金格，是鲲换姿态的那一帧。实时画面在跑时，“当前这一拍”（金格下面一条墨线标出同一姿态的 3 帧）跟着舞台派发的 `stage:beat` 每拍前进 3 格，8 拍走完 24 格正好 1 秒，与画面同拍；静态版（无脚本、减少动态、无 WebGL、实时画面没接上）只画 24 格与金格。
- 背景：前三层是纸面（画布透明，透出纸色），到“景”时天空在画布里铺满。

**主题切换：**ScrollTrigger 在篇章交界处 scrub `--bg`、`--fg` 等 CSS 变量，导航文字颜色跟着变。

**作品区：**海报进入视口时 `ScrollTrigger.batch` 分批淡入（y 24px，stagger 0.04）；悬停或聚焦 180ms 后开始加载并静音循环播放，播的是构建时从海报那一帧剪好的 4 秒短循环（没有短循环时从海报那一帧起播整部预览），离开即停；点击在原地展开“放映台”（Flip：海报放大成视频，后面的格子与分组一起滑开），带声音、带控件，正在放映的那一格用窗灯金的油性笔圈出来。打开后焦点落在放映台的片名上（键盘打开时显示窗灯金 2px 描边），Tab 一次进入视频控件，Esc 收起、焦点回到原来那一格。

**减少动态（`prefers-reduced-motion: reduce`）：**不 pin、不 scrub、不自动播放；首屏只显示海报；拆层改为五张静帧依次排列；悬停不播放，点击才播放。

## 6. 图像

- 首屏海报 `site/assets/hero-poster.jpg`（竖屏用 `hero-poster-portrait.jpg`）：用引擎实际渲染（不是截图拼贴），与实时画面第一帧一致，这样交叉淡入时看不出跳变。
- 拆层五张静帧 `site/assets/stage-{form,shade,look,stage,time}.jpg`：减少动态和不支持 WebGL 时用。
- 作品海报用 `cases/previews/*.jpg`（个别作品在 `site/data/posters/` 里另取一帧覆盖，原因写在 `works-meta.json` 的说明里）；预览视频用 Release 里的 `*-preview.mp4`（构建时放进站内同源目录），悬停用构建时从海报那一帧剪的 4 秒短循环。
- 每张图都要有中文 alt，写画面内容，例如“青绿仙山鲲背负仙岛在黄昏云海上游动”。

## 7. 文案规则

- 全站简体中文；英文只做小标签。
- **不用破折号**（包括“——”和“--”），改用逗号、冒号、句号、括号。
- 对外名称只用：北冥风格路线 · WebGL 三渲二、北冥原生路线 · BNE、北冥代码动画风格 · 86 式。**不出现内部代号**：RAEA、raea、Lemo、opuscar、SY100 等（链接路径里的目录名除外，但尽量链接到不带代号的文档）。
- 作品标题只写片名，去掉 TREATMENT、导演阐述、处理方案、风格样片、编号、秒数等工程残留；画风名用中文（例如“蜡笔绘本”“中国水墨”）。
- 数字必须能在仓库里查到出处：79 部对外展示、96 条归档、86 式 = 66 部成片 + 20 种方法模板、RTX 5090 重着色器单帧 0.52 ms、原生 4K 整片 240 帧 31 秒、工作站与 Mac 的 4K 成片 SSIM 0.973。

### 定稿文案（各篇章主文案，实现时照用，可微调措辞但不改事实）

**首屏**
- 小标签：`BEIMING ENGINE` · 代码即影片
- 主句：一条鲲，由代码一帧一帧画出来。
- 副句：北冥引擎把造型、光影、墨线和纸纹都写成代码。同一份程序，渲出 1080p，也渲出原生 4K。
- 实时读数（小字）：你看到的不是视频 · 实时渲染中 · {fps} fps · {三角形数} 三角形
- 按钮：看《北冥》样片 · 10 秒　｜　79 部作品

**引擎**
- 标题：把画风写成代码
- 引言：画风不锁在素材里。拆开这条鲲，每一层都是一段可以单独替换、单独验收的程序。
- 形（`engine/form`）：先有形。轮廓表放样出鱼身，翼型撑起胸鳍，沿脊传播的波推着全身游动；背上的仙山与松树按种子确定性地散布。
- 光（`engine/shade`）：再给光。三色分档的卡通着色把阴影量化成色块，背光在轮廓上勾出一道暖边。
- 笔（`engine/look`）：然后落笔。墨线从深度、法线和物体编号里算出来，每两帧抖动一次，像手描的线。
- 景（`engine/stage`）：放进天空。手绘底板分层摆进三维空间，远处罩上一层空气透视的薄雾。
- 时（`engine/core/clock.js`）：最后定节奏。镜头每帧都在动，鲲一拍三：每三帧才换一次姿态，这是手绘动画的呼吸。
- 收尾：另外四层：人（Canvas 2D 逐笔画人物），界（显示层与片名），声（程序化音效与混音），片（无头浏览器逐帧出片）。
- 注脚：0.52 毫秒：RTX 5090 上一帧重着色器的耗时。31 秒：原生 4K 整片 240 帧。同一份代码在工作站与 Mac 上渲出的 4K 成片，SSIM 0.973。

**作品**
- 标题：作品
- 引言：79 部成片，每一部都由代码合成出片：镜头、版式、笔触与混音都写在程序里。
- 北冥代码动画风格 · 66 部：每部 18 到 20 秒。同一套代码骨架，换一组笔触与材质，就是另一种画风。
- PPT 故事介绍片 · 7 部：2 到 4 分钟的品牌故事片。原画来自提案，分层、时间线、镜头与混音由代码完成。
- 发布会动画 · 6 部：开场、段落与落版，20 秒到 3 分钟，同一套管线批量出片。
- 注：部分作品以提案原画、AI 生成的画面或公有领域影像为素材，来源写在每部的案例卡里。站内播放的是历史成片的 960 宽转码；原始画质与素材包在 GitHub Release。

**方法**
- 引语：代码不是素材的替代品，而是画风的来源。
- 确定性：没有墙钟时间，没有无种子随机。任何一帧都能单独重渲，第 137 帧永远和第 137 帧一样。
- 整数帧：全局帧、镜头局部帧与动作相位分开计算；预演与成片用同一条时间轴。
- 原生分辨率：镜头按设计尺寸摆位，4K 是算出来的，不是放大出来的。
- 可复刻：每一部旧片都能从归档源码还原重建；换一组参数，就是新的画风试验。
- 三条路线：A 北冥风格路线 · WebGL 三渲二（主线，可出 1080p 与原生 4K）；B 北冥原生路线 · BNE（10 秒实验已跑通）；C 北冥代码动画风格 · 86 式（66 部成片与 20 种方法模板）。

**页脚**：GitHub　案例库　成片与素材下载（Release）　｜　代码以 MIT 开放；影片、底板与展示图保留所有权利；字体遵循 SIL OFL 1.1。部分画风基于开源实现，来源与许可见 THIRD-PARTY.md。

## 8. 无障碍与性能

- `lang="zh-CN"`；地标 `header / main / section / footer`；标题层级不跳级；所有交互可键盘操作，焦点样式用 `--lamp` 2px 外描边。
- 画布加 `aria-hidden="true"`，旁边用文字说明画面内容；视频有 `title` 与可见标题。
- 首屏可交互时间：桌面 ≤ 2.5 秒（海报先到）；除视频外首次加载总量 ≤ 2.5 MB（three.js 最小化版约 0.7 MB，必须异步加载，不阻塞首屏文字与海报）。
- 实时画面：MacBook（M 系列）1440×900 下中位帧率 ≥ 50；桌面像素比上限 1.5（1 倍屏也往上超采样，补到画布实际像素约 2160×1350 为止，墨线才不成阶梯）；帧时间持续高于 22 ms 时自动降低像素比，稳定后再试着升回来；降到最低档仍连续约 3 秒低于 15 fps 就交回海报；离开视口或标签页隐藏时停止渲染。阶梯与阈值见 CONTRACT 第 2 节。
- 手机：390×844 无横向滚动；鲲用更低的细分（lod 0.3），像素比上限 1.5（不超过设备像素比）；实在跑不动就停在海报。

## 2. 统一标注

| 标注 | 含义 |
|---|---|
| 【仓库实证】 | 附 `文件:行号`，可复查 |
| 【仓库实证·复算】 | 用仓库里的真实参数、调用仓库原函数或照抄源码公式算出的数，不渲染 |
| 【仓库实证·渲染】 | 用仓库自带渲染器出静帧后人工查看 |
| 【仓库实证·实测】 | 在只读检出上实际跑过命令得到的输出（平台见各章） |
| 【仓库实证·文档】／【仓库实证·代码】 | 依据是仓库文档的记录／代码本身，没有另行实跑 |
| 【通用工艺】 | 行业通行做法，**不声称仓库已实现**；`·估算`、`·建议` 表示按通行做法估的数或给的写法 |
| 【推断】 | 由代码或算术推出，没有实测 |
| 【未实现】 | 仓库里没有这项能力；正文里不加括号的"未实现"同义 |

## 4. 术语表

**时间与节拍**

| 词 | 含义 |
|---|---|
| 全局帧 f | 影片时间的整数帧号；秒只在入口换算一次（`engine/core/clock.js:11`） |
| 镜头局部帧 | `f − inFrame`（`docs/routes/contracts.md:62`） |
| 动作相位 | 角色轨道从自己的起点帧算起的时间（`contracts.md:63-64`） |
| 一拍 n | 画面每 n 帧换一张；24 fps 下一拍一／二／三＝每秒 24／12／8 张 |
| 拍号 | `hold(f, n) = floor(f / n)`；同一拍号内姿态不变 |
| 轨道 | 按同一个 n 更新的一组对象或参数（人物、鲲、墨线、镜头……） |
| 节拍、拍点 b | 音乐的拍，记作 b（如 b12.5）；说音乐时只用这两个词，不和"一拍 n"混用 |
| 每拍帧数 | `fps × 60 / BPM`；整数时叫"整帧速度" |
| 结果帧 | 撞击、落定、字落稳的那一帧；拍点那一帧必须已经是结果 |
| 事件表／唯一时间源 | 画面、混音、字幕、核对共读的一份事件清单；同一事件不在两处各写一个数 |
| cue map（拍点表） | 速度段、每拍帧数、配器、每个剪切／动作／字幕落在哪一拍 |
| 静默／近静默／数字零 | 数字零＝总线归零连混响尾一起切；近静默＝只留底噪，写明电平 |
| 最重要的一声 | 静默后的第一声；A 类靠最响（给出实测 LU 差），B 类靠静默反衬（不必最响），阐述里要写明是哪一类 |

**空间与画面**

| 词 | 含义 |
|---|---|
| K | 输出高 ÷ 设计高；设计高 1040（`engine/stage/film.js:20-21`；`src/main.js:20`） |

| 底板 | 手绘或生成后整理的图片面片（`engine/stage/plates.js`） |
| 穹顶面片 | 以相机为球心的球面底板，摇镜仰拍不变形（`engine/stage/dome.js:1-3`） |
| 抠像面片 | 彩色层＋只写深度的遮罩层，让笔触按距离变粗细（`plates.js:77-86`） |
| D | 面片在起始机位下的视深；视差与 1/D 成正比，决定"压缩" |
| 出血 o | 底板需要画到画框外的量（two-five-d §2.1） |

| 淋浴门效应（shower-door effect） | 屏幕空间的纸纹固定在屏幕上、不随物体运动，相机快速运动时被看出来；修法关键词：纹理锚定在物体或世界空间、动态纸纹（dynamic canvas） |
| 明度键 | 一段或一镜的明暗基调（高调／中调／低调）与明暗面积比（VISUAL §2） |

| 背光侧／受光侧边缘光 | `rim*`／`rimLit*`（toon 判据 7） |

| 色彩脚本 | 全片按段的主色、主光与情绪（`docs/作品.md:55-65`） |
| 屏幕墨线／材质内画线 | 后期按 ID 与深度画的线／材质钩子里用 `toonInk` 画的线；只有前者叠在 Kuwahara 之后 |
| 沸腾 | 线条按拍换抖动种子，`boilFps 12` 即一拍二 |

**导演**

| 词 | 含义 |
|---|---|
| 原生招式 | 只有这种媒介能做的一下，放在情绪峰值 |

## 6. C 方法落到 A 路线的对照表

C 路线的风格（木刻、水彩、像素、皮影……）落到 A 路线执行时，A 的默认后期（Kuwahara、纸纹、颗粒、ID 墨线）本身就是北冥画风；不关掉它们，任何风格都会被染成北冥味。规则：非北冥风格的新片，style-lock 的 `derivedFrom` 填 null，`forbidden` 与 `newVersionWhen` 自己写；先出一张"全部后期关闭"的帧证明风格本体成立，再逐道加回后期（与 VISUAL-DESIGN §3 的六步一致）。每帧参数填 false 或 null 就关掉该道后期（`src/look.js:14`）。

| C 路线里常见的做法 | A 路线里对应的部件 | 注意 |
|---|---|---|
| Canvas 2D 画法（人物、道具、纸片） | 画布层 `canvasLayer`（`engine/stage/plates.js:48`）；要按深度取细笔触就用抠像面片 `cutoutPlane`（`plates.js:78`） | 画布按设计尺寸乘 K 建；Canvas 滤镜长度不随变换缩放，要手动乘倍率（`src/shotB.js:16-17,36,40`） |
| 二维笔刷、墨迹、水洗、发丝 | `engine/paint/` 下的 `ink.js`、`wash.js`、`path.js`、`strand.js`、`curve.js` | 人物配方见 animation §4.4（`src/girl.js`） |
| 二维光效：轮廓光、内渗光、光包裹、垫底辉光 | `engine/paint/light.js`（`rimPass`、`rimBleed`、`lightWrap`、`glowBehind`，`light.js:1-12`） | 只作用于 2D 画布层；三维物体与底板之间的光包裹【未实现】（two-five-d §4.1） |
| 纸纹、颗粒、暗角 | look 的 `paper`、`grain`、`vignette`（`src/look.js:45-47`） | 非北冥风格先关掉，再按本风格重定强度与尺度 |
| 颜料笔触 | Kuwahara（`src/look.js:41`） | 版画、像素、扁平矢量这类风格通常要关掉 |
| 轮廓线 | ID 墨线（屏幕后期）或 2D 自绘线 | ID 墨线的线色是整帧一个（toon 判据 8 的【未实现】项） |

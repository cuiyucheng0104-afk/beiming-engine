# 长镜头与媒介交接

用在同一主体要从一个叙事节拍带到下一个节拍的片子。先选观众要一直跟住的东西，例如一条轮廓、一枚缺口、移动方向、同一把工具或同一处声源。每个节拍结束时，这个线索应当已经准备好引出下一步。

需要判断为何失去主体时，按[技术考察](onetake-study.md#把相机动作和剪辑分开诊断)分测相机与动作。对可疑窗口同时留存追踪身份、事件帧和解码邻帧。只改身份可让 carry 由 1.00 降到 0.00，身份不变的跳位反而可得 1.00。快门采样也可能漏掉短于一帧的闪现。[《校准环》独立对照](../../../films/calibration-ring/ONETAKE-LAB.md)

## 接到作品流程

- **新片**从仓库根执行 `npm run new -- c <作品名> --title <片名>`。按《校准环》的[导演阐述](../../../films/calibration-ring/TREATMENT.md)填写本片的节拍和交接，再把帧号登记在 `film.json`。页面读 `pageTiming`，声效从同一事件定位。
- **既有片**在原工作目录加一处交接试验，先保留一份原版渲染。先修试验段的时间和构图，再改前后段；其他镜头沿用原路线和出片入口。v2 作品把运镜节点和动作结果写进现有事件表。在还用 v1 时间表的片子里，先沿用它的原时钟；需要将节拍交给 v2 管理时，按[作品描述包](../../../engine/production/README.md)升级。
- 一镜内的动作、空间或媒介变化登记为事件，保持一个覆盖全段的 `shots` 区间。确实分镜或交演员、光源、场景给下一独立镜头时，给每个镜头一个半开区间 `[in, out)`。改真实切点用 `node engine/production/film.js retime`，移动后复核事件与 QA 期望。

## 排节拍，再画镜头

| 阶段 | 先明确 | 回看片时问 |
|---|---|---|
| 建立 | 让主体先进入画面的明确位置，给出它要去的方向 | 缩到 240 px 还能一眼找到主体吗？ |
| 预备 | 下一步所需的轮廓、目标工位或可预期的障碍先露一个 | 下一步来自当前动作的结果吗？ |
| 交接 | 指定连续的主体 id、交接帧、同一处形状或遮挡边作为锚点 | 观众的视线在交接时去了哪里，运动继续向哪边？ |
| 揭示 | 松开速度或景别，给新的深度、关系、产品结果留出阅读时间 | 最有意义的动作有没有被快速运镜、字幕或音效盖住？ |

相机与主体各记一条轨迹。相机记录位置、目标、视场与朝向，主体记录位置、姿态、动作相位与可见轮廓。切点两边各取两个相邻帧，把锚点投影到同一尺寸的屏幕坐标。比较交接首尾的位置、轮廓大小、方向和每帧移动量。位置相同而速度或方向突然反转时，先检查缓动端点和相机轴线。真有意反转，就在预演里检查观众是否看懂原因。

构图先用主体与背景的明度或色差确立焦点，用留白给后续动作方向腾位置。快段只承担一件事，例如穿过框架或改变景别。低速段让动作结果读清楚，可以保留环境和相机的少量移动。声音在结果帧落位，交接只有方位变化时可让上一段声尾跨过交接。

## 平面图交给三维

1. 选可投影的锚点，至少找一个中心与一个方向标（缺口、把手、角点）。在两侧各记落点、宽高或面积、方向标角度、明暗与遮挡顺序。
2. 在三维入口把摄影视角对齐平面轮廓。用真实投影检查 3D 首帧，加前后各两帧看主体是否跳位、缩放是否反向。俯拍或正对平面时可以先匹配轮廓，再推俯仰和透视；有相同遮挡物时可在遮挡期间交接，复查遮挡前后的判断线索。
3. 保持照明和主色可辨，待锚点对稳再揭开厚度、阴影或层差。透视变形已经开始时，用对应的投影角点复查；面积一致仍可能有错轴。
4. 固定其他条件，逐项改变交接变量做对照。量持久物体的位置与速度，检查轮廓重合和全帧变化是否相对邻帧陡增。把疑似问题定位到帧，再看它是否由有意遮挡、闪光或快速摇镜引起。多个变量一起调整时记录组合效果。

## 用成片复核

先用 `npm run film -- stills` 检查焦点，用 `npm run film -- animatic` 检查节奏，再用 `npm run film -- build` 生成母版和机器 QA。用同一幅面、帧率、编码和取样规则对两版母版解码，记录帧号、主体锚点偏移、面积变化和邻帧差。若用颜色取轮廓，先确认当前镜头其他物体没有同色干扰，遮挡后样本不足时改用互相对应的特征点。采用多个 worker 出片前跑确定性检查，将交接帧与渲染分段边界一并取样。

技术门通过后，请指定审片人全速带声看完整片，再暂停比对交接两侧。请审片人先复述看到了哪一个主体、动作如何引出结果，再记录视线丢失、跳轴、停得过久或注意力被声音拉走的帧。按[审片标尺](../../../docs/quality/RUBRIC.md)记录版本、意见原话和评分。像素和投影指标只用于定位异常，叙事清楚、构图舒展和节奏合适须由观看判断。

## 判据（计划书 7.2）

- 拒绝使用 `-A`（`git add .`、`git add --all`、`git add :/` 同样算）。
- 只添加 `films/s3-demo/` 下的源码文件，不包括 `out/` 和媒体文件（mp4、wav 等）；或者先请用户确认。
